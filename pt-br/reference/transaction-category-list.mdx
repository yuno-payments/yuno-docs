---
title: "Categoria de transação"
description: "Lista as categorias de transação que a Yuno usa para agrupar meios de pagamento"
---

A Yuno organiza os meios de pagamento disponíveis em categorias de transação distintas. Nesta página, você encontra todas as categorias de transação usadas na API da Yuno e suas descrições. Observe que cada meio de pagamento está associado a uma dessas categorias de transação.

| Categoria de transação | Descrição                                        |
| -------------------- | -------------------------------------------------- |
| `BANK_TRANSFER`       | Transferência bancária.                                     |
| `CARD`                | Cartões.                                             |
| `BNPL`                | Buy Now Pay Later.                                 |
| `WALLET`              | Pagamentos com carteira digital.                                   |
| `TICKET`              | Pagamentos em dinheiro.                                     |
| `PAYMENT_LINK`        | Links de pagamento que aceitam vários meios de pagamento. |

Para acessar a lista de meios de pagamento disponíveis na API da Yuno, consulte a página [Tipo de pagamento](/pt-br/reference/payment-type-list).
