---
title: "Atualizar sessão de checkout"
openapi: "/openapi/pt-br/checkout-sessions/update-checkout-session.json PATCH /checkout/sessions/{checkout_session}"
description: "Atualiza campos de uma sessão de checkout existente, modificando apenas os valores que você envia"
---

Atualize uma sessão de checkout existente com este endpoint. Somente os campos que você enviar serão atualizados.

<Note>
  Atualizar uma sessão de checkout não estende o prazo de expiração dela. A sessão continua expirando 2.5 horas após a criação (3.5 horas no sandbox). Se a sessão já tiver expirado, este endpoint retorna `CHECKOUT_SESSION_EXPIRED_TIME`, e você precisa criar uma nova sessão de checkout.
</Note>
