---
title: "Criar sessão de checkout"
openapi: "/openapi/pt-br/checkout-sessions/create-checkout-session.json POST /checkout/sessions"
description: "Cria uma sessão de checkout vinculada a um cliente, usada para iniciar um pagamento pelo SDK"
---

Esta requisição cria uma sessão de checkout usando o identificador único gerado quando o recurso `customer` foi criado.

<Note>
  Se o seu fluxo exigir o envio do objeto `additional_data`, ele pode ser enviado como parte da sessão de checkout.
</Note>
