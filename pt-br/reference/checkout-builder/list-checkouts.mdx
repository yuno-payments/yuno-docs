---
title: "Listar checkouts"
openapi: "/openapi/pt-br/checkout-builder/list-checkouts.json GET /checkouts"
description: "Lista os checkouts personalizados da conta (somente resumos): ids, nomes, status e qual deles é o padrão"
---

<Note>Esta API está em **Beta**. Endpoints e schemas podem mudar sem aviso prévio.</Note>

Os resultados são ordenados com o padrão primeiro e depois pelos atualizados mais recentemente, e incluem checkouts `ARCHIVED`. O `id` de cada item é o `checkout_code` usado pelos endpoints [Fetch](/pt-br/reference/checkout-builder/fetch-checkout-configuration) e [Publish](/pt-br/reference/checkout-builder/publish-checkout-configuration).

A paginação é opcional: sem `page` ou `size`, a resposta é um array simples com todos os checkouts correspondentes; enviar qualquer um deles muda a resposta para um envelope paginado (`data` + `pagination`, em que `total` é a contagem filtrada completa).
