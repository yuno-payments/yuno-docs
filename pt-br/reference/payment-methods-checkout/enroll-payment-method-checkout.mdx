---
title: "Cadastrar meio de pagamento"
openapi: "/openapi/pt-br/payment-methods-checkout/enroll-payment-method-checkout.json POST /customers/sessions/{customer_session}/payment-methods"
description: "Cadastra o meio de pagamento selecionado pelo cliente para uso futuro durante o checkout"
---

Esta requisição cadastra um meio de pagamento para um cliente. Com as informações fornecidas pela Yuno depois que o cliente seleciona o meio de pagamento a cadastrar, você poderá salvá-lo para compras futuras no objeto de meio de pagamento criado.

Observe que esta requisição exige um `X-Idempotency-Key`. Consulte a [Autenticação](/pt-br/reference/getting-started/authentication#idempotency).

<Note>
**Webhooks**

Recomendamos escutar os [Webhooks](/pt-br/docs/webhooks/configure-webhooks) para se manter atualizado sobre o estado dos meios de pagamento cadastrados dos seus clientes.
</Note>

Caso um cliente cadastre o mesmo cartão duas vezes, mas com nova data de validade ou novas informações do titular do cartão, removeremos o cadastro do cartão cadastrado anteriormente e manteremos o novo.

## Meios de pagamento disponíveis para cadastro {#available-payment-methods-for-enrollment}

Os seguintes meios de pagamento podem ser cadastrados usando este endpoint:

| Meio de pagamento        | Tipo                   |
| ------------------------ | ---------------------- |
| **Cartões**              | `CARD`                 |
| **Nupay**                | `NU_PAY_ENROLLMENT`    |
| **PayPal**               | `PAYPAL_ENROLLMENT`    |
| **Daviplata**            | `DAVIPLATA_ENROLLMENT` |
| **MercadoPago Wallet**   | `WALLET_CONNECT`       |
| **dLocal Yape**          | `YAPE_ENROLLMENT`      |
| **dLocal Smart PIX**     | `SMART_PIX`            |
| **Astropay**             | `ASTROPAY_ENROLLABLE`  |
| **Adyen PIX Biométrico** | `PIX_BIOMETRICO`       |

<Note>
**Disponibilidade dos meios de pagamento**

Ao obter os meios de pagamento disponíveis para cadastro, só aparecerão aqueles que você conectou, para os quais criou uma rota e que adicionou ao seu checkout. Para mais informações sobre fluxos de cadastro, consulte o guia [Cadastrar meios de pagamento](/pt-br/docs/payment-features/enrollment/enroll-payment-methods).
</Note>
