---
title: "Criar sessão de cliente"
openapi: "/openapi/pt-br/customer-sessions-enrollment/create-customer-session.json POST /customers/sessions"
description: "Cria uma sessão de cliente para cadastrar e gerenciar meios de pagamento salvos para uso futuro"
---

Cria uma sessão de cliente para cadastrar e gerenciar meios de pagamento. Use para salvar cartões, carteiras digitais e outros meios de pagamento para uso futuro. Requer um `customer_id` obtido em [Criar cliente](/pt-br/reference/customers/create-customer).
