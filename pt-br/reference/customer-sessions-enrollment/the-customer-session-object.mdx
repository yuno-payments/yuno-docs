## Atributos {#attributes}

Este objeto representa uma sessão de cliente que pode ser criada para cadastrar os meios de pagamento de um cliente.

<ParamField body="customer_session" type="string">
  A sessão de cliente que foi criada para o cadastro (MAX 64; MIN 36).

  Exemplo: fe50d39a-5a1c-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="customer_id" type="string">
  O identificador único do cliente (MAX 64; MIN 36).

  Exemplo: 3956053c-5a1d-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="country" type="enum">
  O país do cliente (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Valores de enum possíveis: Consulte a <a href="/reference/country-reference">Referência de países</a>.
</ParamField>

<ParamField body="callback_url" type="string">
  A URL para redirecionar seu cliente depois que o cadastro é feito no ambiente do provedor (MAX 526; MIN 3).

  Exemplo: www.your-url.com
</ParamField>

<ParamField body="created_at" type="timestamp">
  Data e hora de criação da sessão de cliente (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Exemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="checkout_id" type="string">
  O identificador único do Custom Checkout usado para esta sessão de cadastro.

  Exemplo: 6822f80c-684e-41a3-8628-78963d3d60f7
</ParamField>
