---
title: "Criar campanha"
openapi: "/openapi/pt-br/communications-campaigns/create-campaign.json POST /campaigns"
description: "Cria uma nova campanha de comunicação para recuperação de pagamentos recusados, com status INACTIVE por padrão."
---

Cria uma nova campanha. Se nenhum `status` for informado, as campanhas usam `INACTIVE` por padrão.

Consulte a [referência do objeto de campanha](/pt-br/reference/communications-campaigns#campaign-object)  para mais informações.
