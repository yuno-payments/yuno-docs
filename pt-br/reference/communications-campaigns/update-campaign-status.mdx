Atualiza o status de uma campanha. Use para pausar, retomar, concluir ou cancelar uma campanha.

## Transições de status {#status-transitions}

* `ACTIVE` --> `PAUSED`, `COMPLETED`, `CANCELLED`
* `PAUSED` --> `ACTIVE`, `COMPLETED`, `CANCELLED`
* `COMPLETED` --> (final - sem outras transições)
* `CANCELLED` --> (final - sem outras transições)
