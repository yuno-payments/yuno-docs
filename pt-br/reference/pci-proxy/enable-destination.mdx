---
title: "Ativar destino"
description: "Reative um destino desativado na allowlist do seu PCI Proxy para que o forward proxy possa usá-lo novamente."
keywords: ["pci proxy", "allowlist", "destino", "segurança"]
openapi: "/openapi/pt-br/pci-proxy/manage-destinations.json POST /pci-proxy/destinations/{id}/enable"
---

Reativa um destino desativado para que o [forward proxy](/pt-br/reference/pci-proxy/invoke-forward-proxy) volte a usá-lo. Só destinos `ENABLED` podem ser acessados. Uma requisição para um host `DISABLED` é rejeitada com `403 DESTINATION_NOT_ALLOWED`. Consulte o [guia de Allowlist de destinos](/pt-br/docs/security-and-compliance/pci-proxy/allowlist).
