---
title: "Registrar destino"
description: "Adicione um host de terceiros à allowlist do seu PCI Proxy para que o forward proxy possa enviar dados de cartão para ele."
keywords: ["pci proxy", "allowlist", "destino", "segurança"]
openapi: "/openapi/pt-br/pci-proxy/manage-destinations.json POST /pci-proxy/destinations"
---

Adiciona um host à allowlist de destinos da sua conta. O [forward proxy](/pt-br/reference/pci-proxy/invoke-forward-proxy) só envia dados de cartão para hosts dessa lista; não existe um modo "qualquer host". Consulte o [guia de Allowlist de destinos](/pt-br/docs/security-and-compliance/pci-proxy/allowlist) para saber como a correspondência funciona.

<Note>
**Adicionar um destino é uma operação sensível**

Registrar um host amplia os lugares para onde os seus cartões armazenados podem ser enviados. Restrinja quem pode gerenciar a allowlist e revise qualquer adição inesperada.
</Note>
