---
title: "Invocar o Forward Proxy"
description: "Chame qualquer API HTTPS de terceiros com dados reais de cartão por meio do ambiente PCI DSS Nível 1 da Yuno, referenciando cartões armazenados pelo vaulted_token."
keywords: ["pci proxy", "forward proxy", "yuno-proxy-destination-url", "vaulted_token", "destokenização"]
openapi: "/openapi/pt-br/pci-proxy/invoke-forward-proxy.json POST /pci-proxy/forward"
---

Encaminha sua requisição ao destino informado no cabeçalho `yuno-proxy-destination-url`, substituindo as expressões `{{vaulted_token.<TOKEN>.<field>}}` dentro do ambiente seguro da Yuno pelos dados armazenados sob o vaulted token: o cartão (PAN, validade, nome do titular), seu network token (DPAN e sua validade) e seu ID de transação de rede (NTID). Para destinos que exigem requisições assinadas com HMAC, envie `yuno-proxy-auth` + `yuno-proxy-auth-secret-key` e o proxy assina o corpo resolvido para você. Consulte [Destinos assinados](/pt-br/docs/security-and-compliance/pci-proxy/forward-proxy#signed-destinations-hmac-request-signing) para mais detalhes. Consulte o [guia do Forward Proxy](/pt-br/docs/security-and-compliance/pci-proxy/forward-proxy) para uma integração passo a passo.

<Note>
**Beta**

O PCI Proxy está em beta e é habilitado por organização. Em produção, as requisições retornam `403 PRODUCT_NOT_ENABLED` até que sua organização seja ativada; entre em contato com seu Key Account Manager (KAM). O sandbox está aberto para testes.
</Note>

<Warning>
**Somente no lado do servidor**

As requisições ao proxy destokenizam os dados do cartão e devem ser feitas somente a partir do seu backend. Nunca exponha sua `private-secret-key` em código do lado do cliente.
</Warning>

Todos os métodos `GET`, `POST`, `PUT`, `PATCH` e `DELETE` são suportados: o destino recebe o mesmo método que você usou. Coloque a URL completa do destino, incluindo o caminho e qualquer query string, no cabeçalho `yuno-proxy-destination-url`; uma query string na própria requisição `/pci-proxy/forward` é rejeitada. O host de destino precisa estar na sua [allowlist de destinos](/pt-br/docs/security-and-compliance/pci-proxy/allowlist).

Se você é um lojista com certificação PCI e precisa dos próprios dados brutos do cartão em vez de uma chamada de repasse, use [Obter meio de pagamento cadastrado por ID com dados PCI](/pt-br/reference/payment-methods-direct-workflow/retrieve-enrolled-payment-method-by-id-pci-api).
