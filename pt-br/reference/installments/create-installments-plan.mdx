---
title: "Criar plano de parcelas"
openapi: "/openapi/pt-br/installments/create-installments-plan.json POST /installments-plans"
description: "Cria um plano de parcelas que define faixa de valor, BIN do cartão, moeda e regras de disponibilidade"
---

A Yuno permite que você crie planos de parcelas para oferecer aos seus clientes. Esses planos podem ser usados com base em fatores como o valor a pagar, a moeda e o cartão usado, conforme descrito abaixo:

* **Filtrado por faixa de valor (obrigatório):** O sistema verifica se o plano de parcelas é adequado para o valor específico da sua transação. Somente os planos que comportam esse valor são considerados.
* **BIN do cartão:** O sistema verifica se o BIN do seu cartão corresponde aos permitidos para determinados planos de parcelas. Se houver correspondência, esse plano é considerado.
* **Moeda específica:** Somente os planos que funcionam com a moeda que você está usando são considerados.
* **Disponibilidade do plano:** O sistema verifica se o plano de parcelas está ativo. Somente os planos que não expiraram e estão disponíveis são considerados.

<Note>
**Definindo o ID do plano**

O `plan_id` só é necessário ao aplicar um plano de parcelas fixo que não muda durante a compra. Se o `installment.plan_id` não for informado, o SDK buscará automaticamente entre todos os planos de parcelas disponíveis associados àquela conta e selecionará o que considerar mais adequado. Você deve incluir o `plan_id` para garantir que um plano específico seja aplicado.
</Note>

<Note>
**Parcelas do lojista**

Este endpoint só é necessário para a [integração de parcelas do lojista](/pt-br/docs/payment-features/installments). Para parcelas definidas pelo provedor, usamos o plano de parcelas definido pelo seu provedor de pagamento.
</Note>

Para parcelas criadas pelo lojista, você também tem a possibilidade de especificar o plano para cada sessão de checkout usando o `plan_id` ao [criar a sessão](/pt-br/reference/checkout-sessions/create-checkout-session). Se você não o enviar, usaremos o plano de parcelas que corresponde às condições definidas para a sessão de checkout.
