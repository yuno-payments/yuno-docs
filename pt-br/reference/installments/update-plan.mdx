---
title: "Atualizar plano"
openapi: "/openapi/pt-br/installments/update-plan.json PATCH /installments-plans/{installment_code}"
description: "Atualiza o status, os detalhes das parcelas ou o meio de pagamento de um plano de parcelas existente"
---

A API **Atualizar plano** permite modificar um plano existente, possibilitando atualizar atributos como o status do plano, os detalhes das parcelas e o meio de pagamento associado ao plano.

Use esta API para gerenciar e ajustar planos de parcelas após a criação.
