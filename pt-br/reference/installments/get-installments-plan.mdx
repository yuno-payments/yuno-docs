description: "Obtém os detalhes de configuração de um plano de parcelas específico pelo seu código"
---

A API **Obter plano de parcelas** permite obter informações detalhadas sobre um plano de parcelas existente. Isso inclui as opções de parcelas, a frequência de cobrança, os limites de valor e outros detalhes relevantes do plano.

Use este endpoint para buscar a configuração atual de um plano de parcelas específico.
