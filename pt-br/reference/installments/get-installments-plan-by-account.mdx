---
title: "Obter planos de parcelas"
openapi: "/openapi/pt-br/installments/get-installments-plan-by-account.json GET /installments-plans"
description: "Obtém a lista de planos de parcelas configurados para uma conta específica"
---

A API **Obter plano de parcelas** permite obter uma lista de planos de parcelas associados a uma conta específica. Este endpoint ajuda a visualizar todos os planos disponíveis vinculados a uma conta, incluindo as opções de parcelas, os limites e os períodos de disponibilidade.

Use esta API para buscar todos os planos de parcelas disponíveis em um determinado ID de conta.
