Esta página é a **Fonte Única da Verdade (SSOT)** de todos os enums e identificadores principais da plataforma da Yuno. Consolidar esses valores aqui garante consistência, agiliza o desenvolvimento com a API e oferece um local centralizado para os desenvolvedores consultarem os parâmetros válidos de todos os endpoints.

## Identificadores principais da API {#core-api-identifiers}

Estes são os identificadores padrão principais usados no roteamento de transações, no processamento de meios de pagamento e na escolha da estratégia de integração na Yuno.

<Note>
  Para um mapeamento completo, categoria por categoria, de quais **tipos de meio de pagamento** são suportados por quais **provedores**, consulte diretamente o [Catálogo de pagamentos](/pt-br/reference/payment-type-list). As tabelas abaixo servem como referências simples para consultar os valores individuais de cada parâmetro de enum.
</Note>

### Fluxo de cadastro (`type_of_enrollment_flow`) {#enrollment-flow-typeofenrollmentflow}

Define a estratégia de integração usada ao cadastrar novos meios de pagamento para os clientes.

<div className="code-nowrap-table dense-table">

| Valor | Descrição |
| :--- | :--- |
| `SDK_FULL` | Fluxo de cadastro completo gerenciado pelo Yuno SDK. |
| `SDK_LITE` | Fluxo de cadastro lite com controle parcial da interface. |
| `SDK_HEADLESS` | Fluxo de cadastro headless para personalização completa da interface. |
| `DIRECT_API` | Cadastro por chamadas diretas à API (servidor para servidor). |

</div>
