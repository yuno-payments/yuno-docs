Fique por dentro das mudanças e atualizações da API da Yuno.

Na Yuno, todas as atualizações feitas na API são compatíveis tanto com a versão atual quanto com as versões anteriores.

Quando uma modificação disruptiva é implementada na API da Yuno, uma nova versão é lançada. Para evitar problemas no seu código, a troca de versão não é obrigatória até que você esteja pronto para fazer a atualização.

### Mudanças compatíveis com versões anteriores {#backwards-compatible-changes}

Consideramos que as seguintes modificações mantêm a compatibilidade com versões anteriores:

* Adicionar novos recursos à API.
* Adicionar novos parâmetros opcionais de requisição aos métodos existentes da API.
* Adicionar novas propriedades às respostas existentes da API.
* Modificar a ordem das propriedades nas respostas existentes da API.
* Alterar o tamanho ou o formato de strings opacas, como identificadores de objetos, mensagens de erro e outras strings legíveis por humanos. Isso inclui adicionar ou remover prefixos.
* Introduzir novos tipos de eventos. Certifique-se de que o seu serviço de recebimento de webhook suporte tipos de eventos desconhecidos.
