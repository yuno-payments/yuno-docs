Esta página explica as URLs base da API e os dois ambientes que você pode usar ao chamar a API da Yuno: **Sandbox** e **Produção**.

Para saber como alternar entre Test Mode e Live Mode no Dashboard da Yuno, veja [Ambientes (Dashboard)](/pt-br/docs/using-yuno/environments).

## Visão geral: Sandbox vs. Produção {#overview-sandbox-vs-production}

| Ambiente              | Finalidade                                                   | URL base                                       |
| --------------------- | ------------------------------------------------------------ | ---------------------------------------------- |
| **Sandbox**           | Testes e desenvolvimento. Sem dados reais nem transações reais. | <CopyChip value="https://api-sandbox.y.uno" /> |
| **Produção (EUA)**    | Ambiente real com sede nos EUA. Transações e contabilidade reais. | <CopyChip value="https://api.y.uno" />         |

No Dashboard, o Sandbox é chamado de **Test Mode** e a Produção de **Live Mode**. Você usa a mesma conta para os dois; o seletor do Dashboard define qual ambiente você está usando.

## Credenciais {#credentials}

<Warning>
**Credenciais**

Sandbox e Produção usam **chaves de API diferentes**. As credenciais que você usa no Test Mode (Sandbox) não são as mesmas do Live Mode (Produção). No Dashboard, as chaves exibidas dependem do ambiente selecionado. Veja [Credenciais de desenvolvedor](/pt-br/docs/using-yuno/settings/developers-credentials) para saber onde encontrá-las.
</Warning>

## URLs base {#base-urls}

### Sandbox {#sandbox}

Use esta URL base em todas as requisições à API durante os testes. Os dados são simulados e não afetam a contabilidade nem as métricas reais.

```text
https://api-sandbox.y.uno
```

### Produção (EUA) {#production-us}

Use esta URL base quando a sua integração estiver em produção e sediada nos EUA, processando pagamentos reais.

```text
https://api.y.uno
```

## Tempo de processamento e timeout {#processing-time-and-timeout}

<Note>
**Tempo de processamento**

O tempo de processamento de cada requisição depende do processador ou adquirente. O tempo total é a soma do tempo de processamento da Yuno com o do processador.
</Note>

<Warning>
**Timeout**

A Yuno usa um **timeout de 60 segundos** para todos os endpoints. O ciclo completo de requisição e resposta deve terminar em até 60 segundos. Os tempos de resposta costumam ser bem menores; os 60 segundos cobrem respostas mais lentas dos processadores.
</Warning>
