Esta página oferece um catálogo fácil de consultar de todos os endpoints da API REST da Yuno. Use-a para descobrir quais operações estão disponíveis antes de ir para as páginas de referência individuais.

Para detalhes de implementação:
- [Autenticação](/pt-br/reference/getting-started/authentication): como autenticar requisições da API
- [Ambientes](/pt-br/reference/getting-started/api-environments): URLs base de sandbox e de produção
- [Especificação OpenAPI](/openapi.json): definição da API legível por máquina

<Note>
Esta visão geral é gerada a partir da especificação OpenAPI completa (172 operações). 
Um subconjunto de 39 operações foi testado em sandbox e está disponível em `openapi/yuno_sandbox_tested.json`.
</Note>
