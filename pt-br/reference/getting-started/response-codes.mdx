Esta seção descreve os códigos de erro comuns e as soluções que você pode encontrar ao usar a API da Yuno.

A Yuno usa códigos de resposta HTTP padrão para indicar o sucesso ou a falha das requisições à API.

Códigos na faixa 2xx geralmente indicam sucesso. Códigos na faixa 4xx indicam um erro ocorrido com base nas informações fornecidas (por exemplo, um parâmetro ausente). Códigos na faixa 5xx indicam um erro interno.

## Exemplo {#example}

```json
{
  "code": "INVALID_REQUEST",
  "messages": [
    "Invalid request."
  ]
}
```
