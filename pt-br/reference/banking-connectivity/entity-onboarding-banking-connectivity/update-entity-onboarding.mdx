---

Envie documentos adicionais para um onboarding existente. Normalmente usado quando o onboarding está com o status `PENDING_ADDITIONAL_DOCUMENTATION`. Só é possível atualizar onboardings que não chegaram a um status final; caso contrário, a API retorna 400 `INVALID_STATE_TRANSITION`.
