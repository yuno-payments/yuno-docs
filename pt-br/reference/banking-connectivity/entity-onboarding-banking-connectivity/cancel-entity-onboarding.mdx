<Warning>
  Este endpoint ainda não está disponível pela API pública. Requisições para este caminho retornam 404 `NOT_FOUND`. O restante desta página descreve um comportamento que não está implementado hoje.
</Warning>

Cancele um onboarding pendente. Só é possível cancelar onboardings que não chegaram a um status final. Consulte [Status de onboarding](/pt-br/reference/banking-connectivity#onboarding-statuses) para saber quais status são finais.
