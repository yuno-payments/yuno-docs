Faça o onboarding de uma [Entidade](/pt-br/reference/banking-connectivity/entities-banking-connectivity/create-entity) existente com um provedor de Banking Connectivity.

## Tipos de onboarding {#onboarding-types}

* **`ONE_STEP`**: Envie todas as informações, declarações de compliance, avaliação de risco e documentos de uma só vez. O provedor processa imediatamente.
* **`PREVIOUSLY_ONBOARDED`**: Gere um ID de onboarding interno da Yuno sem contatar o provedor. Use quando a entidade já tiver passado por onboarding externamente.

Para `ONE_STEP`, inclua `compliance_declaration`, `risk_assessment`, `source_of_funds` e `documentation`. Consulte [Tipos de documentação](/pt-br/reference/banking-connectivity#documentation-types) para ver a lista completa de tipos de documento suportados.

Acompanhe o progresso por meio de [Obter status do onboarding de entidade](/pt-br/reference/banking-connectivity/entity-onboarding-banking-connectivity/get-entity-onboarding-status) ou de eventos de webhook. Consulte [Status de onboarding](/pt-br/reference/banking-connectivity#onboarding-statuses) para ver o ciclo de vida completo dos status.
