---
title: "Criar conta"
openapi: "/openapi/pt-br/banking-connectivity/accounts/create-account-banking.json POST /banking/accounts"
description: "Crie uma conta bancária para uma entidade cujo status de onboarding foi bem-sucedido"
---

Crie uma conta bancária para uma entidade que já passou pelo onboarding. O onboarding referenciado por `onboarding_id` precisa ter `status: SUCCEEDED`. Hoje, um onboarding do tipo `PREVIOUSLY_ONBOARDED` não consegue criar uma conta: a API responde `500` com `PROVIDER_ACCOUNT_CREATION_FAILED`.

A resposta inclui identificadores bancários específicos de cada região. Consulte [Identificadores de conta por região](/pt-br/reference/banking-connectivity#account-identifiers-by-region) para saber quais campos são retornados em cada região.
