---
title: "Iniciar transferência de entidade (Banking Connectivity)"
openapi: "/openapi/pt-br/banking-connectivity/entity-transfers-banking-connectivity/initiate-entity-transfer.json POST /banking/transfers"
description: "Inicie uma transferência de saída ou uma transferência interna (book transfer) a partir de uma conta de banking connectivity"
---

Inicie uma transferência a partir de uma conta de Banking Connectivity. `transfer_type` é obrigatório: `OUTGOING` para transferências externas (informe os dados bancários em `destination_account`), `BOOK` para transferências internas entre contas no mesmo provedor (defina `destination_account.account_id` como a conta de destino) e `INCOMING` para transferências de entrada.

Os campos obrigatórios em `destination_account` dependem da região. Consulte [Trilhos de pagamento](/pt-br/reference/banking-connectivity#payment-rails) e [Identificadores de conta por região](/pt-br/reference/banking-connectivity#account-identifiers-by-region) para mais detalhes.

A resposta retorna `202 Accepted` com status `PENDING`. Acompanhe o progresso por meio de [Obter status da transferência de entidade](/pt-br/reference/banking-connectivity/entity-transfers-banking-connectivity/get-entity-transfer-status) ou de eventos de webhook. Consulte [Status de transferência](/pt-br/reference/banking-connectivity#transfer-statuses) para ver o ciclo de vida completo dos status.
