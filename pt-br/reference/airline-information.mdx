Nesta página, você encontra as informações de companhias aéreas de que pode precisar ao usar os endpoints da API da Yuno. Ela abrange tipos de passageiro, códigos de classe tarifária e níveis de fidelidade. Use esta página para entender e ter acesso aos valores padrão de cada categoria de informação.

## Tipo de passageiro {#passenger-type}

| `passenger_type` | Descrição      |
| ---------------- | -------------- |
| `A`              | Adulto         |
| `C`              | Criança        |
| `I`              | Bebê           |

## Código de classe tarifária {#fare-class-code}

| `fare_class_code` | Descrição                                       |
| ------------------ | ------------------------------------------------ |
| Letra (A-Z)        | Varia conforme a definição da companhia aérea. Máximo de 1 caractere. |

## Nível de fidelidade {#loyalty-tier}

| `loyalty_tier` | Descrição                   |
| ------------ | -------------------------- |
|       `1`      | Nível de classificação alto |
|       `2`      | Segundo nível de classificação |
|       `3`      | Terceiro nível de classificação |
