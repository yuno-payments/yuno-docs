Consulte um meio de pagamento específico que um usuário cadastrou.

<Note>
**Consultar meio de pagamento cadastrado**

Para recuperar as informações do meio de pagamento cadastrado, você precisa informar o `payment_method_id`, que é o `vaulted_token` recebido ao usar o endpoint [Cadastrar meio de pagamento](/pt-br/reference/payment-methods-direct-workflow/enroll-payment-method-api).
</Note>
