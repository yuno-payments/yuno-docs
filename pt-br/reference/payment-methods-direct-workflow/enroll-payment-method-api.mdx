---
title: "Cadastrar meio de pagamento"
openapi: "/openapi/pt-br/payment-methods-direct-workflow/enroll-payment-method-api.json POST /customers/{customer_id}/payment-methods"
description: "Cadastra um meio de pagamento do cliente e retorna um vaulted token para uso futuro"
---

Esta requisição cadastra um meio de pagamento para um cliente. Com as informações fornecidas pela Yuno depois que o cliente seleciona o meio de pagamento a cadastrar, você poderá salvar essas informações para compras futuras usando o objeto de meio de pagamento criado.

Consulte os [Meios de pagamento disponíveis na Yuno](/pt-br/reference/payment-type-list). Você precisará configurar suas credenciais para cada meio de pagamento no Dashboard da Yuno para poder usá-los.

Observe que esta requisição exige um `X-Idempotency-Key`. Consulte a página [Autenticação](/pt-br/reference/getting-started/authentication#idempotency) para mais informações.

<Note>
**Webhooks**

Recomendamos escutar os [Webhooks](/pt-br/docs/webhooks/configure-webhooks) para se manter atualizado sobre o estado dos meios de pagamento cadastrados dos seus clientes.
</Note>

Se um cliente cadastrar o mesmo cartão várias vezes, a Yuno cria um novo cadastro a cada vez e retorna um `vaulted_token` diferente. Use o `fingerprint` do cartão na resposta do cadastro para detectar duplicatas do seu lado (o fingerprint pode ser `null` para alguns provedores). Consulte [Card Fingerprint](/pt-br/docs/security-and-compliance/fingerprint).

<Warning>
**Disponível somente para lojistas com certificação PCI.**
</Warning>
