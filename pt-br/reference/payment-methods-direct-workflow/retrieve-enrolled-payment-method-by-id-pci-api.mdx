title: "Obter meio de pagamento cadastrado por ID com dados PCI"
openapi: "/openapi/pt-br/payment-methods-direct-workflow/retrieve-enrolled-payment-method-by-id-pci-api.json GET /customers/{customer_id}/payment-methods/{payment_method_id}"
description: "Obtém um meio de pagamento cadastrado incluindo o número completo do cartão, somente para lojistas PCI"
---

Obtenha um meio de pagamento específico que um usuário cadastrou, incluindo o número completo do cartão na resposta.

<Note>
**Obter meio de pagamento cadastrado**

Para obter as informações do meio de pagamento cadastrado, você precisa informar o `payment_method_id`, que é o `vaulted_token` recebido ao usar o endpoint [Cadastrar meio de pagamento](/pt-br/reference/payment-methods-direct-workflow/enroll-payment-method-api).
</Note>

<Warning>
**Somente para lojistas PCI**

Este endpoint está disponível somente para lojistas com certificação PCI. Para habilitá-lo, entre em contato com seu Key Account Manager (KAM).
</Warning>
