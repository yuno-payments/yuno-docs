Registre um lote de cartões já armazenados no [Card Account Updater](/pt-br/docs/additional-services/card-account-updater), para que os dados deles sejam mantidos atualizados automaticamente. Envie os ids dos meios de pagamento (o `vaulted_token` recebido ao cadastrar cada cartão) em uma única requisição.

<Note>
**Como o registro funciona**

- Você pode registrar entre **1 e 100** cartões por requisição; cada id deve ser um `vaulted_token` válido.
- A validação é **tudo ou nada**: se algum id for inválido, a requisição inteira é rejeitada.
- O registro é executado de forma **assíncrona**. Uma resposta `200` com `accepted` confirma que os cartões foram aceitos, não que a atualização já aconteceu; as atualizações são notificadas depois pelo webhook de cadastro.
- O Card Account Updater é habilitado por organização. Se sua organização não estiver inscrita, a requisição retorna `400` com `code: BAD_REQUEST` e a mensagem `organization is not enrolled in account updater.`
</Note>
