---
title: "Descadastrar meio de pagamento"
openapi: "/openapi/pt-br/payment-methods-direct-workflow/unenroll-payment-method-api.json POST /customers/{customer_id}/payment-methods/{payment_method_id}/unenroll"
description: "Descadastra um meio de pagamento salvo de um cliente e define o status dele como UNENROLLED"
---

Descadastre um meio de pagamento salvo do usuário. Depois que você fizer o POST para o endpoint de descadastro, o status do meio de pagamento será alterado para UNENROLLED.

<Note>
**Informações sobre o descadastro**

Para descadastrar o meio de pagamento, você precisa informar o `payment_method_id`, que é o `vaulted_token` recebido ao usar o endpoint [Cadastrar meio de pagamento](/pt-br/reference/payment-methods-direct-workflow/enroll-payment-method-api).
</Note>
