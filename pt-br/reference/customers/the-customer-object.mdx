---
title: "O objeto do cliente"
description: "Descreve o objeto do cliente e seus atributos, incluindo dados de contato, endereço e documento"
---

Este objeto representa um cliente que fará pagamentos usando o seu serviço.

## Atributos {#attributes}

<ParamField body="id" type="string">
  O identificador único do cliente (MAX 64; MIN 36).

  Exemplo: faa89e18-5a11-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="merchant_customer_id" type="string">
  O identificador único do cliente no lojista externo (MAX 255; MIN 1).

  Exemplo: 50ca6f06-5a12-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="merchant_customer_created_at" type="timestamp">
  Data de cadastro do cliente na plataforma do lojista (MAX 27; MIN 27 <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Exemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="first_name" type="string">
  O primeiro nome do cliente (MAX 255; MIN 1).

  Exemplo: John
</ParamField>

<ParamField body="last_name" type="string">
  O sobrenome do cliente (MAX 255; MIN 1).

  Exemplo: Doe
</ParamField>

<ParamField body="gender" type="enum">
  O gênero do cliente (MAX 2; MIN 1).

  Valores de enum possíveis: `M`, `F` ou `NB`
</ParamField>

<ParamField body="date_of_birth" type="string">
  A data de nascimento do cliente no formato YYYY-MM-DD (MAX 10; MIN 10).

  Exemplo: 1990-02-28
</ParamField>

<ParamField body="email" type="string">
  O email do cliente (MAX 255; MIN 3).

  Exemplo: john.doe@email.com
</ParamField>

<ParamField body="nationality" type="enum">
  A nacionalidade do cliente (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Valores de enum possíveis: consulte a <a href="/reference/country-reference">Referência de países</a>.
</ParamField>

<ParamField body="country" type="enum">
  O país do cliente (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Valores de enum possíveis: consulte a <a href="/reference/country-reference">Referência de países</a>.
</ParamField>

<ParamField body="document" type="object">
  Especifica o objeto de documento do cliente, incluindo o número e o tipo.

  <Expandable title="propriedades">

    <ParamField body="document_number" type="string">
      O número do documento do cliente (MAX 40; MIN 3).

      Exemplo: 1093333333
    </ParamField>

    <ParamField body="document_type" type="enum">
      O tipo de documento do cliente (MAX 6; MIN 2).

      Valores de enum possíveis: consulte a <a href="/reference/country-reference">Referência de países</a>.
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="phone" type="object">
  Especifica o objeto de número de telefone do cliente.

  <Expandable title="propriedades">

    <ParamField body="country_code" type="string">
      O código de discagem do país do telefone do cliente (MAX 3; MIN 1). Valores possíveis: consulte a <a href="/reference/country-reference">Referência de países</a>.

      Exemplo: 57
    </ParamField>

    <ParamField body="number" type="string">
      O número de telefone do cliente, sem o código do país (MAX 32; MIN 1).

      Exemplo: 3132450765
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="billing_address" type="object">
  Especifica o objeto de endereço de cobrança do cliente.

  <Expandable title="propriedades">

    <ParamField body="address_line_1" type="string">
      A linha principal do endereço de cobrança do cliente (MAX 255; MIN 3).

      Exemplo: Calle 34 # 56 - 78
    </ParamField>

    <ParamField body="address_line_2" type="string">
      A linha secundária do endereço de cobrança do cliente (MAX 255; MIN 3).

      Exemplo: Apartamento 502, Torre I
    </ParamField>

    <ParamField body="city" type="string">
      A cidade considerada para o endereço de cobrança (MAX 255; MIN 3).

      Exemplo: Bogotá
    </ParamField>

    <ParamField body="country" type="enum">
      O país considerado para o endereço de cobrança (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

      Valores de enum possíveis: consulte a <a href="/reference/country-reference">Referência de países</a>.
    </ParamField>

    <ParamField body="state" type="string">
      O estado considerado para o endereço de cobrança (MAX 255; MIN 3; <a href="https://en.wikipedia.org/wiki/ISO_3166-2">ISO 3166-2</a> ).

      Exemplo: Cundinamarca
    </ParamField>

    <ParamField body="zip_code" type="string">
      O CEP considerado para o endereço de cobrança (MAX 11; MIN 4).

      Exemplo: 111111
    </ParamField>

    <ParamField body="neighborhood" type="string">
      O bairro da linha de endereço do cliente (MAX 255; MIN 2)

      Exemplo: Barrio 11
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="shipping_address" type="object">
  Especifica o objeto de endereço de entrega do cliente.

  <Expandable title="propriedades">

    <ParamField body="address_line_1" type="string">
      A linha principal do endereço de entrega do cliente (MAX 255; MIN 3).

      Exemplo: Calle 34 # 56 - 78
    </ParamField>

    <ParamField body="address_line_2" type="string">
      A linha secundária do endereço de entrega do cliente (MAX 255; MIN 3).

      Exemplo: Apartamento 502, Torre I
    </ParamField>

    <ParamField body="city" type="string">
      A cidade considerada para o endereço de entrega (MAX 255; MIN 3).

      Exemplo: Bogotá
    </ParamField>

    <ParamField body="country" type="enum">
      O país considerado para o endereço de entrega (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

      Valores de enum possíveis: consulte a <a href="/reference/country-reference">Referência de países</a>.
    </ParamField>

    <ParamField body="state" type="string">
      O estado considerado para o endereço de entrega (MAX 255; MIN 3; <a href="https://en.wikipedia.org/wiki/ISO_3166-2">ISO 3166-2</a> ).

      Exemplo: Cundinamarca
    </ParamField>

    <ParamField body="zip_code" type="string">
      O CEP considerado para o endereço de entrega (MAX 10; MIN 5).

      Exemplo: 111111
    </ParamField>

    <ParamField body="neighborhood" type="string">
      O bairro da linha de endereço do cliente (MAX 255; MIN 2)

      Exemplo: Barrio 11
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="metadata" type="array of objects">
  Especifica uma lista de pares chave–valor personalizados associados ao cliente (para referências internas, segmentação ou tags de fluxo de trabalho). Você pode adicionar até 50 objetos de metadados.

  <Expandable title="propriedades">

    <ParamField body="metadata object" type="object">
      Especifica uma chave de metadados e o respectivo valor.

      Use para anexar contexto definido pelo lojista (por exemplo: `crm_id`, `segment`). Evite enviar dados sensíveis ou pessoais.

      <Expandable title="propriedades">

        <ParamField body="key" type="string">
          Especifica uma chave de metadados.

          Exemplo: age
        </ParamField>

        <ParamField body="value" type="string">
          Especifica o valor da chave de metadados definida.

          Exemplo: 28
        </ParamField>

      </Expandable>
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="created_at" type="timestamp">
  Data e hora de criação do cliente (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Exemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="updated_at" type="timestamp">
  Data e hora da última atualização do cliente (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Exemplo: 2022-05-09T20:46:54.786342Z
</ParamField>
