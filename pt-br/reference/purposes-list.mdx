---
title: "Lista de finalidades"
description: "Lista os valores de enum usados para identificar o motivo de um payout"
---

Nesta página, você encontra a lista de finalidades disponíveis no sistema da Yuno. A informação de finalidade é usada para identificar o motivo do payout. A tabela abaixo apresenta todos os ENUM aceitos para a finalidade do payout.

<div className="code-nowrap-table dense-table">

| Finalidade disponível              | Descrição                                          |
| :----------------------------- | :--------------------------------------------------- |
| `FAMILY_AND_FRIENDS`           | Manutenção/transferência para familiares e amigos.              |
| `PERSONAL_TRANSFER`             | Transferência pessoal                                    |
| `REMITTANCES`                    | Remessas                                          |
| `PROVIDER_SERVICES`             | Payout por serviços gerais do provedor.                |
| `ADVERTISING_SERVICES`          | Payout por serviços de publicidade do provedor.            |
| `REPRESENTATION_SERVICES`       | Payout por serviços de representação do provedor.         |
| `ADVISORY_SERVICES`             | Payout por serviços de consultoria do provedor.               |
| `FREELANCER_SERVICES`           | Payout por serviços de freelancer do provedor.             |
| `SUPPLIER`                       | Pagamentos a fornecedores.                                   |
| `BUSINESS_TO_BUSINESS`         | Business to Business.                                |
| `MARKETPLACE`                    | Payout por compras em marketplace.                    |
| `PAYROLL`                        | Payout por serviços de pagamento de folha salarial.                 |
| `GIFTS_AND_BENEFITS`           | Payout por presentes e benefícios.                        |
| `EXPENSES`                       | Payout por despesas gerais do provedor.                |
| `CORPORATE_PAYMENT`             | Payout por pagamentos corporativos.                       |
| `PURCHASE_OF_PHYSICAL_GOODS`  | Payout pela compra de bens físicos.               |
| `PURCHASE_OF_DIGITAL_GOODS`   | Payout pela compra de bens digitais.                |
| `PURCHASE_OF_SERVICES`         | Payout pela compra de serviços gerais.             |
| `CAPITAL_CONTRIBUTION`          | Payout por aporte de capital.                     |
| `INVESTMENTS`                    | Payout de um investimento devido a uma entidade financeira.  |
| `INVESTMENTS_SHARES`            | Payout de cotas de investimento.                         |
| `TAXES`                          | Pagamento de impostos.                                    |
| `LOGISTICS_AND_TRANSPORTATION` | Payout por serviços de logística e transporte.    |
| `DELIVERY`                       | Payout por serviços de entrega.                        |
| `AFFILIATION_PROGRAM`           | Programas de afiliados.                                |
| `LOANS`                          | Payout por liquidação de empréstimos.                         |
| `REAL_STATE`                    | Payout por compra de imóveis e despesas gerais. |
| `RENT`                           | Pagamento de aluguel de imóvel.                        |
| `TRAVEL_FLIGHTS`                | Pagamento de passagens ou agências de turismo.       |
| `TRAVEL_ACCOMMODATIONS`         | Pagamento de hospedagem em viagens.                    |
| `EDUCATION`                      | Payout por custos de educação.                          |
| `TRAININGS`                      | Payout por custos de treinamento.                           |
| `TUITION_COSTS`                 | Payout por custos de estudo/mensalidades.                      |
| `CHARITY`                        | Payout por doações de caridade.                       |
| `MEDICAL_SERVICES`              | Payout por serviços de assistência médica.                    |
| `SAVINGS`                        | Payout para poupança.                                  |
| `RETIREMENT`                     | Payout para conta de aposentadoria.                       |
| `PENSION`                        | Payout para fins de previdência.                         |
| `INSURANCE`                      | Pagamento de seguros.                               |
| `REWARDS`                        | Payout para fins de recompensas.                         |
| `TRADEMARKS_AND_COPYRIGHT`     | Payout por recompensas de marcas registradas e direitos autorais.          |
| `ENTERTAINMENT`                  | Payout por serviços de entretenimento.                   |
| `GOVERNMENT`                     | Serviços públicos/governamentais.                          |
| `OTHERS`                         | Outras finalidades de payout.                               |

</div>
