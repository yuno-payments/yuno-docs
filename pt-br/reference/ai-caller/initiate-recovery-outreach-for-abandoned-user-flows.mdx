<Warning>
Este endpoint ainda não está disponível pela API pública. `POST /smart-support/external/payments` retorna 404 hoje. Para iniciar o contato de recuperação para um pagamento recusado, use [Chamadas para pagamentos recusados](/pt-br/reference/ai-caller/declined-payment-calls).
</Warning>

Este endpoint permite que os lojistas notifiquem o Recovery Agent da Yuno quando um usuário abandona o fluxo de compra, por exemplo durante a seleção de produtos ou depois de iniciar o checkout, antes de concluir um pagamento. Os dados enviados permitem que a Yuno faça o acompanhamento com o usuário por ligação ou WhatsApp para incentivar a conclusão da transação.

## Segurança e conformidade {#security-and-compliance}

- **Autenticação**: o acesso à API exige uma chave de API válida informada nos cabeçalhos da requisição.

- **Proteção de dados**: todos os dados precisam ser transmitidos por HTTPS. A Yuno segue as regulamentações de proteção de dados aplicáveis, incluindo a **GDPR** e a **LGPD**.

- **Uso dos dados**: os dados enviados serão usados exclusivamente para fins de engajamento do cliente e não serão armazenados além do período necessário.

<Note>
**Exemplo de caso de uso**

Uma usuária chamada Jane Doe adiciona um par de fones de ouvido sem fio ao carrinho no site de um lojista, mas abandona o processo de checkout. O sistema do lojista detecta isso e envia o payload relevante para a API do Recovery Agent da Yuno. Em seguida, a Yuno envia uma mensagem de WhatsApp para Jane, lembrando-a dos itens deixados no carrinho e oferecendo ajuda para concluir a compra.
</Note>
