## v1.0.1 {#v101}
*April 13, 2026*

**Configuração**

- <ChangelogBadge type="added" /> **Ocultar a seleção de pagamento quando a Yuno é o único gateway**  
  Adiciona a configuração Hide Payment Selection, para que os botões de opção dos meios de pagamento fiquem ocultos no checkout quando a Yuno é o único gateway ativo, oferecendo uma experiência de checkout mais limpa, com um único meio. Vale tanto para o checkout legado quanto para o checkout baseado em blocos.

## v1.0.0 {#v100}
*April 7, 2026*

- <ChangelogBadge type="added" /> **Lançamento inicial no WordPress Plugin Directory**  
  Primeira versão pública do gateway de pagamento WooCommerce da Yuno no WordPress Plugin Directory, que integra a plataforma de orquestração de pagamentos da Yuno ao WooCommerce por meio do Yuno Web SDK e de uma camada de API REST em PHP.

**Pagamentos com cartão**

- <ChangelogBadge type="added" /> **Pagamentos com cartão, carteiras e meios de pagamento locais**  
  Aceita cartões, carteiras digitais e meios de pagamento locais por meio da plataforma de orquestração de pagamentos da Yuno a partir de uma única integração, com roteamento inteligente de pagamentos entre vários provedores.

- <ChangelogBadge type="added" /> **Suporte a 3D Secure e a autenticação adicional**  
  Trata desafios 3D Secure e fluxos de autenticação adicional durante o pagamento, incluindo uma detecção de retorno do 3DS que evita a duplicação acidental de pedidos.

**Checkout em blocos**

- <ChangelogBadge type="added" /> **Suporte ao checkout baseado em blocos do WooCommerce**  
  Suporta tanto o checkout legado por shortcode quanto o checkout baseado em blocos do WooCommerce (padrão desde o WooCommerce 8.3). Os dois fluxos convergem na página order-pay, então a orquestração do SDK é compartilhada.

**Webhooks**

- <ChangelogBadge type="added" /> **Receptor de webhooks para o status assíncrono do pagamento**  
  Recebe eventos de pagamento da Yuno (bem-sucedido, pendente, com falha, chargeback, reembolso) com verificação HMAC em três camadas e processamento idempotente por meio de bloqueios transitórios.

**Marketplace**

- <ChangelogBadge type="added" /> **Split de pagamento para marketplace**  
  Divide o total do pedido entre um destinatário vendedor e uma comissão da plataforma, configurável como porcentagem ou como valor fixo em unidades menores da moeda.

**Confiabilidade**

- <ChangelogBadge type="added" /> **Nova tentativa no mesmo lugar para pagamentos com falha**  
  Permite que o cliente tente novamente um pagamento com falha no mesmo lugar, remontando o SDK, em vez de criar um novo pedido duplicado a cada nova tentativa.

- <ChangelogBadge type="added" /> **Verificação do pagamento no servidor**  
  Verifica todo status de pagamento informado junto à API da Yuno antes de atualizar o pedido do WooCommerce, sem nunca confiar no status informado pelo cliente.

**Gestão de pedidos**

- <ChangelogBadge type="added" /> **Conclusão automática para pedidos virtuais e baixáveis**  
  Pedidos que contêm apenas produtos virtuais ou baixáveis pulam o estado de processamento e vão direto para concluído após o pagamento.

- <ChangelogBadge type="added" /> **Compatibilidade com HPOS**  
  Declara compatibilidade com o High-Performance Order Storage (tabelas de pedidos personalizadas) do WooCommerce e usa consultas de pedidos compatíveis com HPOS em todo o plugin.

**Cliente e endereço**

- <ChangelogBadge type="added" /> **Estratégia de cliente Yuno por pedido**  
  Cria um novo cliente Yuno para cada pedido do WooCommerce, com recuperação automática de erros de cliente duplicado e de cliente não encontrado, para que os pagamentos nunca sejam bloqueados por um estado de cliente desatualizado.

**Configuração**

- <ChangelogBadge type="added" /> **Suporte a vários ambientes**  
  Detecta automaticamente o ambiente da API da Yuno (desenvolvimento, staging, sandbox, produção) pelo prefixo da chave de API pública (Public API Key).

- <ChangelogBadge type="added" /> **Log de depuração configurável com ocultação de dados pessoais (PII)**  
  Log opcional integrado ao WooCommerce para a solução de problemas de pagamentos e webhooks. Números de telefone, endereços de email e payloads completos da API nunca são registrados.
