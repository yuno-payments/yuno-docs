# Migração da v1.1 para a v1.2 {#migrating-from-v11-to-v12}

<Note>
Este guia trata de uma mudança de versão histórica. Para a migração atual do cardFormType, consulte [Migração para o iOS SDK v2.12](/pt-br/changelog/migration-guides/ios/v2-11-to-v2-12).
</Note>

A configuração `cardFormType` agora é gerenciada pelo Dashboard.

### 1. Atualize a inicialização {#1-update-initialization}
Remova `cardFormType` da sua chamada a `Yuno.initialize()`.

### 2. Sincronização com o Dashboard {#2-dashboard-sync}
Garanta que as configurações do Checkout Builder correspondam ao fluxo de UI desejado.
