# Migração para o iOS SDK v2.12 {#migrating-to-ios-sdk-v212}

A versão 2.12.0 remove o parâmetro `cardFormType` de `Yuno.initialize()`. A configuração do tipo de formulário de cartão passa para o Dashboard da Yuno.

## O que mudou {#what-changed}

O parâmetro `cardFormType` de `Yuno.initialize()` foi removido. Passá-lo causará um **erro de compilação** depois da atualização.

## Etapas {#steps}

### 1. Remova `cardFormType` de Yuno.initialize() {#1-remove-cardformtype-from-yunoinitialize}

**Antes:**
```swift
Yuno.initialize(apiKey: "your_api_key", cardFormType: .oneStep)
```

**Depois:**
```swift
Yuno.initialize(apiKey: "your_api_key")
// Configure in Dashboard → Checkout → Builder
```

### 2. Configure o tipo de formulário de cartão no Dashboard {#2-configure-card-form-type-in-the-dashboard}

Abra **Dashboard → Checkout → Builder** e selecione o tipo de formulário de cartão:
- **One Step**: todos os campos do cartão em uma única tela
- **Multi Step**: campos do cartão distribuídos em várias telas

A configuração do Dashboard se aplica a todas as instâncias do SDK da sua conta.
