# Migração para o Android SDK v2.11 {#migrating-to-android-sdk-v211}

A versão 2.11.0 remove o parâmetro `cardFlow` de `YunoConfig`. A configuração do fluxo de cartão passa para o Dashboard da Yuno.

## O que mudou {#what-changed}

O parâmetro `cardFlow` de `YunoConfig` foi removido. Passá-lo causará um **erro de compilação** depois da atualização.

## Etapas {#steps}

### 1. Remova `cardFlow` de YunoConfig {#1-remove-cardflow-from-yunoconfig}

**Antes:**
```kotlin
val config = YunoConfig(
    apiKey = "your_api_key",
    cardFlow = CardFormType.ONE_STEP
)
```

**Depois:**
```kotlin
val config = YunoConfig(
    apiKey = "your_api_key"
)
```

### 2. Configure o fluxo de cartão no Dashboard {#2-configure-card-flow-in-the-dashboard}

Abra **Dashboard → Checkout → Builder** e selecione o fluxo de cartão:
- **One Step**: todos os campos do cartão em uma única tela
- **Multi Step**: campos do cartão distribuídos em várias telas

A configuração do Dashboard se aplica a todas as instâncias do SDK da sua conta.
