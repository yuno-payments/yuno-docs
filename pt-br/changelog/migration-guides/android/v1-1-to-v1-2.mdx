# Migração da v1.1 para a v1.2 {#migrating-from-v11-to-v12}

<Note>
Este guia trata de uma mudança de versão histórica. Para a migração atual do cardFlow, consulte [Migração para o Android SDK v2.11](/pt-br/changelog/migration-guides/android/v2-10-to-v2-11).
</Note>

A configuração `cardFlow` foi movida para o Dashboard.

### 1. Remova a configuração no código {#1-remove-code-configuration}
Remova a seguinte linha do seu `YunoConfig`:

```kotlin
cardFlow = CardFormType.ONE_STEP
```

### 2. Atualize o Dashboard {#2-update-dashboard}
Configure o fluxo de cartão desejado no **Checkout Builder** do Dashboard da Yuno.
