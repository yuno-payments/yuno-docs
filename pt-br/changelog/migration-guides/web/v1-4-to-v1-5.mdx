# Migração para o Web SDK v1.5 {#migrating-to-web-sdk-v15}

A versão 1.5.0 muda a forma como o Google Pay e o Apple Pay são renderizados no **Lite SDK**. As integrações com o Full SDK não são afetadas.

## O que mudou {#what-changed}

Na v1.5.0, os usuários do Lite SDK precisam chamar `mountExternalButtons()` explicitamente para renderizar os botões do Google Pay e do Apple Pay. Esses meios de pagamento não são mais renderizados automaticamente como botões de opção na lista de meios de pagamento.

As integrações com o Full SDK **não têm breaking changes**: o Google Pay e o Apple Pay passam a ser exibidos automaticamente como botões diretos em vez de botões de opção, sem exigir mudanças no código.

## Quem é afetado {#who-is-affected}

- **Usuários do Lite SDK**: ação necessária (veja as etapas abaixo)
- **Usuários do Full SDK**: nenhuma ação necessária

## Etapas (somente Lite SDK) {#steps-lite-sdk-only}

### 1. Atualize a tag script {#1-update-the-script-tag}

```html
<script src="https://sdk-web.y.uno/v1.5/main.js"></script>
```

### 2. Adicione elementos HTML para os botões de carteira {#2-add-html-elements-for-wallet-buttons}

Adicione elementos contêiner no seu HTML onde você quer que os botões apareçam:

```html
<div id="apple-pay"></div>
<div id="google-pay"></div>
```

### 3. Chame `mountExternalButtons()` depois de `startCheckout` {#3-call-mountexternalbuttons-after-startcheckout}

**Antes:**
```js
// Lite SDK — wallet buttons rendered automatically
await yuno.startCheckout({ checkoutSession, countryCode, elementSelector: '#root' })
```

**Depois:**
```js
// Explicitly mount wallet buttons after startCheckout
await yuno.startCheckout({ checkoutSession, countryCode, elementSelector: '#root' })

await yuno.mountExternalButtons([
  {
    paymentMethodType: 'APPLE_PAY',
    elementSelector: '#apple-pay',
  },
  {
    paymentMethodType: 'GOOGLE_PAY',
    elementSelector: '#google-pay',
  },
])
```

### 4. (Opcional) Desmonte os botões quando necessário {#4-optional-unmount-buttons-when-needed}

Para desmontar um único botão:

```js
yuno.unmountExternalButton('APPLE_PAY')
```

Para desmontar todos os botões externos de uma vez:

```js
yuno.unmountAllExternalButtons()
```
