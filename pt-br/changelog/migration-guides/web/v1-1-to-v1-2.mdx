# Migração para o Web SDK v1.2 {#migrating-to-web-sdk-v12}

A versão 1.2.0 é uma versão **sem breaking changes**. Nenhuma mudança é necessária nas integrações v1.1 existentes.

## O que mudou {#what-changed}

### Parâmetro opcional `options` em `Yuno.initialize()` {#optional-options-parameter-in-yunoinitialize}

`Yuno.initialize()` agora aceita um objeto de configuração opcional `options` como segundo argumento. As chamadas existentes sem esse argumento continuam funcionando sem modificações.

```js
// v1.1 — still valid in v1.2
const yuno = await Yuno.initialize(publicApiKey)

// v1.2 — optional options parameter
const yuno = await Yuno.initialize(publicApiKey, {
  // additional options here
})
```

### Parâmetros ampliados de `continuePayment` {#extended-continuepayment-parameters}

`continuePayment()` agora aceita parâmetros opcionais adicionais: `checkoutSession`, `showPaymentStatus`, `yunoPaymentResult`, `yunoError`, `countryCode` e `language`. Todos os parâmetros são opcionais: as chamadas existentes com menos argumentos continuam funcionando.

```js
// v1.1 usage — still valid in v1.2
await yuno.continuePayment()

// v1.2 — additional optional params available
await yuno.continuePayment({
  checkoutSession,
  showPaymentStatus: true,
  yunoPaymentResult,
  yunoError,
  countryCode: 'US',
  language: 'en',
})
```

## Etapas {#steps}

### 1. Atualize a tag script {#1-update-the-script-tag}

```html
<script src="https://sdk-web.y.uno/v1.2/main.js"></script>
```

### 2. (Opcional) Adote os novos parâmetros {#2-optional-adopt-new-parameters}

Nenhuma mudança de código é necessária. Se quiser aproveitar os novos parâmetros opcionais, atualize as suas chamadas de `initialize()` e `continuePayment()` como mostrado acima.

## Checklist {#checklist}

- [ ] Tag script atualizada para a v1.2
- [ ] (Opcional) Parâmetro `options` adicionado a `Yuno.initialize()`, se necessário
- [ ] (Opcional) `continuePayment()` ampliado com parâmetros adicionais, se necessário
