## Introdução {#introduction}

**Account Funding Transactions (AFT)** são transações financeiras que facilitam a transferência de fundos entre contas de pagamento. Elas são muito usadas para carregar ou recarregar contas de usuários e carteiras digitais e para realizar transferências internas de fundos dentro de uma plataforma de pagamento.

As AFTs permitem a movimentação eficiente e segura de dinheiro entre contas.

## O que é uma AFT? {#what-is-an-aft}

Uma **AFT (Account Funding Transaction)** é um tipo de transação projetado para:

* **Carregar fundos** em contas de usuários ou carteiras digitais.
* **Transferir fundos** entre contas dentro da mesma plataforma.
* **Depositar dinheiro** em contas comerciais ou pessoais. Remessas incluídas.

As AFTs aproveitam as redes de pagamento tradicionais (por exemplo, Visa, Mastercard, ACH) para processar transações de forma rápida e segura, otimizando os custos.

### Tipos de transações AFT {#types-of-aft-transactions}

1. **Transações de financiamento**:
   * Transferem fundos para uma conta a partir de um cartão de débito/crédito ou de uma conta bancária.
   * Exemplo: um usuário carrega a carteira digital usando o cartão de débito.

2. **Transações de saque**:
   * Movem fundos de uma conta de usuário de volta para a conta bancária ou o cartão dele.
   * Exemplo: um usuário transfere dinheiro da carteira digital para a conta bancária.

## Integração {#integration}

Para realizar uma AFT, você precisa enviar uma requisição para a nossa [Payments API](/reference/payments/create-payment) com o objeto `additional_data.order.account_funding` especificando os dados de `sender` e `beneficiary`.

Cada bandeira de cartão de crédito pode exigir informações diferentes sobre o destinatário e o remetente, dependendo da região de operação e da categoria da transação.

```Text Example
[...]
 "additional_data": {
   "order": {
    "account_funding": {
      "sender": {
        "first_name": "John",
        "last_name": "Doe",
        "email": "john.doe@mail.com"
      },
      "beneficiary": {
        "first_name": "Chris",
        "last_name": "Martin",
        "document": {
          "document_number": "38192019",
          "document_type": "CC"
        }
      }
     }
    }
  }
[...]
```

Para mais detalhes, consulte a seção de criação da [API de pagamentos](/reference/payments/create-payment).

<Note>
**Dados adicionais**

Caso você precise definir informações adicionais sobre o vendedor, como `merchant_category_code`, por exemplo, você encontra campos extras em `seller_details` dentro da [estrutura `additional_data`](/reference/payments/the-payment-object) do pagamento.
</Note>

<Note>
**Carteiras digitais staged**

Se você opera uma carteira digital staged, em que o cliente primeiro carrega um saldo e depois o gasta em uma transação separada, consulte [Staged Digital Wallet Operators (SDWO)](/pt-br/docs/payment-features/staged-digital-wallet-operators-sdwo) para ver os requisitos específicos das bandeiras de cartão que se aplicam a esse fluxo.
</Note>
