---
title: "Cadastrar cartões com links de pagamento"
description: "Gere um link de pagamento para que os clientes atualizem um cartão expirado ou recusado e façam o novo cadastro automaticamente"
---

A Yuno oferece aos lojistas a possibilidade de gerenciar pagamentos em atraso ou recusados usando links de pagamento seguros. Quando um cartão de crédito expira ou é informado como roubado ou perdido, você pode gerar um link de pagamento para compartilhar com os clientes por email ou mensagem de texto, permitindo que eles atualizem facilmente suas informações de pagamento.

Este recurso é voltado para lojistas que operam o próprio motor de assinaturas e precisam atualizar os dados do cartão de crédito para continuar processando pagamentos com um novo `vaulted_token` para seus clientes.

## Como funciona {#how-it-works}

### 1. Recebimento do link de pagamento {#1-receiving-the-payment-link}

Quando os usuários precisam atualizar suas informações de pagamento, eles recebem um link de pagamento seguro. Esse link permite que eles concluam qualquer pagamento pendente usando um cartão de crédito ou débito. Para criar o link de pagamento para cadastro, inclua os seguintes campos:

* `customer_payer.id`: o ID do [cliente criado](/reference/customers/create-customer) anteriormente
* `one_time_use`: defina como `true` para garantir que o link de pagamento só possa ser usado uma vez
* `vault_on_success`: defina como `true` para cadastrar o cartão de crédito após um pagamento bem-sucedido

### 2. Cadastro automático {#2-automatic-enrollment}

Quando o pagamento é concluído com sucesso pelo link, a Yuno gera automaticamente um novo `vaulted_token` para o cliente.

### 3. Continuar cobrando {#3-continue-charging}

Depois de obter o `vaulted_token`, você pode seguir com o calendário da sua assinatura. Use o endpoint [Consultar meios de pagamento](/reference/payment-methods-direct-workflow/retrieve-enrolled-payment-methods-api) para acessar os meios de pagamento do cliente.

Para mais informações sobre como criar e gerenciar links de pagamento, consulte a [referência da API de links de pagamento](/reference/payment-links/create-payment-link).
