Boas-vindas à prévia de acesso antecipado do Yuno Universal SDK. Esta integração única vai substituir todas as versões anteriores do SDK (Seamless, Lite, Headless) por um fluxo unificado e altamente configurável.

## Visão geral {#overview}

O Universal SDK foi criado para ser o "SDK único que governa todos". Ele se adapta dinamicamente à sua configuração de lojista no Dashboard.

### Principais benefícios {#key-benefits}
- **API unificada**: uma única chamada de método para todos os tipos de pagamento.
- **UI dinâmica**: configure tudo pelo Dashboard, sem mudanças no código.
- **Leve**: tamanho de bundle menor em comparação com manter vários SDKs legados.

## Exemplo de integração {#integration-example}

```javascript
import { Yuno } from '@yuno/universal-sdk';

const yuno = new Yuno('YOUR_PUBLIC_KEY');

// The new unified checkout call
yuno.checkout({
  checkoutSession: 'SESSION_ID',
  element: '#payment-element',
  onResponse: (response) => {
    console.log('Payment result:', response);
  }
});
```
