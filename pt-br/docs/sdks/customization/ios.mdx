Modifique os estilos do SDK iOS da Yuno (fonte, botão, cor) definindo campos de aparência. Use-os para combinar com a marca do seu app e melhorar a consistência. Para ver todos os parâmetros e opções de configuração do SDK iOS, consulte a [Referência comum do SDK iOS](/pt-br/docs/sdks/resources/references/ios).

## Configuração de aparência {#appearance-configuration}

Campos de personalização disponíveis:

| Campo                            | Descrição                                                                                                                            |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `fontFamily`                     | Especifica a família de fontes usada no SDK. Informe o nome do arquivo da fonte usada no seu app, garantindo que corresponda aos assets do seu app. |
| `accentColor`                    | Define a cor de destaque usada em vários elementos do SDK.                                                                                 |
| `buttonBackgroundColor`          | Define a cor de fundo dos botões primários.                                                                                     |
| `buttonTitleColor`               | Determina a cor do texto dos botões primários.                                                                                     |
| `buttonBorderColor`              | Especifica a cor da borda dos botões primários.                                                                                    |
| `secondaryButtonBackgroundColor` | Define a cor de fundo dos botões secundários.                                                                                    |
| `secondaryButtonTitleColor`      | Determina a cor do texto dos botões secundários.                                                                                  |
| `secondaryButtonBorderColor`     | Especifica a cor da borda dos botões secundários.                                                                                  |
| `disableButtonBackgroundColor`   | Define a cor de fundo dos botões desativados.                                                                                     |
| `disableButtonTitleColor`        | Determina a cor do texto dos botões desativados.                                                                                    |

<Note>
**Configuração de cores**

Garanta que todas as cores sejam especificadas como UIColor para manter a compatibilidade. As cores podem vir da paleta predefinida do Xcode ou dos assets do lojista, mas precisam sempre ser do tipo UIColor.
</Note>

Use a função `Yuno.Appearance()` para definir uma variável com todas as suas personalizações e controlar a aparência. Depois, informe-a ao inicializar o SDK:

```swift
let appearance = Yuno.Appearance(
    fontFamily: "Climate Crisis",
    accentColor: UIColor.orange, 
    buttonBackgroundColor: UIColor.yellow, 
    buttonTitleColor: UIColor.black, 
    buttonBorderColor: UIColor.black,
    secondaryButtonBackgroundColor: UIColor.yellow,
    secondaryButtonTitleColor: UIColor.black,
    secondaryButtonBorderColor: UIColor.black,
    disableButtonBackgroundColor: UIColor.gray,
    disableButtonTitleColor: UIColor.black
)

Yuno.initialize(
    apiKey: apiKey,
    config: YunoConfig(appearance: appearance)
)

```

### Exemplos de uso {#usage-examples}

Exemplo (duas personalizações de aparência):

```swift Example 1 (left)
let appearance = Yuno.Appearance(
    fontFamily: "Climate Crisis",
    accentColor: UIColor.black, 
    buttonBackgroundColor: UIColor.black, 
    buttonTitleColor: UIColor.white
)

Yuno.initialize(
    apiKey: apiKey,
    config: YunoConfig(appearance: appearance)
)

```
```swift Example 2 (right)
let appearance = Yuno.Appearance(
    fontFamily: "Climate Crisis",
    accentColor: UIColor.orange, 
    buttonBackgroundColor: UIColor.orange, 
    buttonTitleColor: UIColor.white
)

Yuno.initialize(
    apiKey: apiKey,
    config: YunoConfig(appearance: appearance)
)

```

## Preenchimento automático de endereço {#address-autocomplete}

Os lojistas podem ativar ou desativar o preenchimento automático de endereço no SDK iOS. Quando está ativado, o SDK preenche automaticamente os campos de endereço com base na consulta do código postal. Quando está desativado, os usuários precisam informar manualmente todos os dados de endereço.
