Modifique os estilos do Yuno Android SDK (cores, texto, botões) para alinhar os formulários de pagamento e o checkout à sua marca. A estrutura dos elementos continua uniforme. Para todos os parâmetros e opções de configuração do SDK Android, veja a [Referência comum do SDK Android](/pt-br/docs/sdks/resources/references/android).

## Diretrizes gerais {#general-guidelines}

A forma de personalizar o SDK Android depende da versão:

- **SDK 2.x:** estilize o SDK com Compose, passando `YunoStyles` em `YunoConfig` na inicialização. Veja [Estilização com Compose](#style-with-compose-sdk-2x).
- **SDK 1.x:** o SDK aceita temas e estilos XML, definidos nos estilos da sua aplicação. Veja [Elementos personalizáveis](#customizable-elements).
- **Yuno SDK (Android v3.x):** `YunoStyles` é substituído por `Appearance`, definido por transação. Veja [Estilização](/pt-br/docs/yuno-sdk/features/styling).

## Estilização com Compose (SDK 2.x) {#style-with-compose-sdk-2x}

No SDK 2.x, os formulários do checkout não usam mais views XML nem temas por tela. Passe um objeto `YunoStyles` em `YunoConfig` ao inicializar o SDK. Uma única configuração vale para todas as telas.

`YunoStyles` tem estes campos:

| Campo          | Descrição                                                                 |
| -------------- | --------------------------------------------------------------------------- |
| `fontFamily`   | Família de fontes usada em todo o SDK, como um `FontFamily` do Compose.                 |
| `buttonStyles` | Estilo dos botões, como um objeto `YunoButtonStyles`.                              |

`YunoButtonStyles` tem estes campos. Todos são opcionais:

| Campo             | Tipo       | Descrição                      |
| ----------------- | ---------- | -------------------------------- |
| `backgroundColor` | `Color`    | Cor de fundo do botão.  |
| `contentColor`    | `Color`    | Cor do conteúdo do botão.     |
| `cornerRadius`    | `Dp`       | Raio dos cantos do botão.     |
| `elevation`       | `Dp`       | Elevação do botão.         |
| `padding`         | `Dp`       | Padding do botão.           |
| `fontFamily`      | `FontFamily` | Família de fontes do texto do botão. |
| `fontSize`        | `TextUnit` | Tamanho da fonte do texto do botão.    |
| `fontStyle`       | `FontStyle` | Estilo da fonte do texto do botão.  |

Exemplo:

```kotlin
Yuno.initialize(
    applicationContext = this,
    apiKey = "YOUR_PUBLIC_API_KEY",
    config = YunoConfig(
        styles = YunoStyles(
            fontFamily = FontFamily(Font(R.font.inter_regular)),
            buttonStyles = YunoButtonStyles(
                backgroundColor = Color(0xFF000000),
                contentColor = Color(0xFFFFFFFF),
                cornerRadius = 8.dp,
                elevation = 0.dp,
                padding = 16.dp,
                fontSize = 16.sp,
                fontStyle = FontStyle.Normal,
            ),
        ),
    ),
)
```

### Estilos de fonte {#font-styles}

Você pode sobrescrever as fontes do Yuno Android SDK se quiser usar a sua própria família de fontes. Você pode sobrescrever os seguintes estilos de fonte:

- `YunoRegularFont`
- `YunoMediumFont`
- `YunoBoldFont`

Exemplo (estilo de fonte):

```xml
<style name="YunoRegularFont">
    <item name="android:fontFamily">@font/inter_regular</item>
</style>

<style name="YunoMediumFont">
    <item name="android:fontFamily">@font/inter_medium</item>
</style>

<style name="YunoBoldFont">
    <item name="android:fontFamily">@font/inter_bold</item>
</style>
```

## Crie o seu próprio fluxo de formulário de cartão {#create-your-own-card-form-flow}

<Note>
Esta seção se aplica ao SDK 1.x. As views XML que ela descreve não fazem parte do SDK 2.x.
</Note>

O primeiro passo para criar o seu fluxo de formulário de cartão é criar um novo arquivo de recurso de layout chamado `screen_payment_card_form.xml` para sobrescrever o XML atual e implementar o seu design.

Depois de criar o arquivo `screen_payment_card_form.xml`, você pode definir o seu próprio design. Você precisa usar os componentes secure-fields da Yuno, que garantem que o Yuno SDK consiga obter as informações do cartão de crédito durante o checkout. Abaixo, você encontra a lista de todos os componentes que pode usar para mudar o design:

<Warning>
**Como alterar componentes**

Ao alterar os componentes do Yuno Android SDK, você precisa usá-los com o `id` do Android definido.
</Warning>

### v1.10.0 ou superior {#v1100-or-higher}

Há componentes adicionais disponíveis para o Yuno SDK versão v1.10.0 ou superior. Esses componentes estão listados na [subseção abaixo](#components-available-for-v1100-and-higher).

- `CloseButton`: botão para fechar o formulário.

```xml
<ImageView
        android:id="@+id/imageView_close" />
```

- `CardNumberEditText`: campo em que o usuário pode informar o número do cartão de crédito.

```xml
<com.yuno.payments.features.base.ui.views.CardNumberEditText
    android:id="@+id/textField_number" />
```

- `CardDataStackView`: campo em que o usuário pode informar a data de validade e o código de verificação (CVV/CVC) do cartão de crédito.

```xml
<com.yuno.payments.features.base.ui.views.CardDataStackView
    android:id="@+id/cardDataStackView" />
```

- `TextView` para o tipo de cartão Voucher: é um texto que o Yuno SDK mostra quando o cartão é do tipo `VOUCHER `; você precisa colocá-lo abaixo do campo de CVV.

```xml
<TextView
    android:id="@+id/textView_voucher_copy"
    android:visibility="gone" />
```

- `TextFieldItemView `para o nome do titular do cartão: campo em que o usuário pode informar o nome do titular do cartão de crédito.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_name" />
```

- `SpinnerFieldItemView` para o tipo de documento de identificação: um seletor em que o titular do cartão de crédito pode escolher o tipo do seu documento de identificação.

```xml
<com.yuno.payments.features.base.ui.views.SpinnerFieldItemView
    android:id="@+id/spinner_document_type" />
```

- `TextFieldItemView` para o número do documento de identificação: campo em que o usuário pode informar o número do documento de identificação do titular do cartão de crédito.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_user_document" />
```

- `PhoneInformationView `para o número de telefone do cliente: campo em que o usuário pode informar o número de telefone, se necessário. Além de informar o `id` do Android, é obrigatório ter a visibilidade `gone`.

```xml
<com.yuno.payments.features.base.ui.views.PhoneInformationView
    android:id="@+id/layout_phone_information"
        android:visibility="gone" />
```

- `Installments`: componente que mostra o spinner das parcelas do cartão. Além de informar o `id` do Android, é obrigatório ter a visibilidade `gone`, e você precisa adicionar a dependência `ShimmerFrameLayout`: `implementation 'com.facebook.shimmer:shimmer:0.5.0'`.

```xml
<LinearLayout
  android:id="@+id/container_installments"
  android:orientation="vertical">

  <com.yuno.payments.features.base.ui.views.SpinnerFieldItemView
  android:id="@+id/spinner_installments"
  android:layout_width="match_parent"
  android:layout_height="wrap_content"
  android:visibility="gone"
  app:spinner_title="@string/payment.form_installments" />

  <com.facebook.shimmer.ShimmerFrameLayout
  android:id="@+id/shimmer_installments"
  android:layout_width="match_parent"
  android:layout_height="wrap_content"
  android:foregroundGravity="center"
  android:visibility="gone">

  <include layout="@layout/shimmer_component_field" />
  </com.facebook.shimmer.ShimmerFrameLayout>

</LinearLayout>
```

- `TextView` da Yuno: um texto para mostrar que a Yuno verificou o formulário.

```xml
<TextView
        android:id="@+id/textView_secure_payment" />
```

- `CustomYunoSwitch`: é um componente switch que permite ao usuário escolher se o cartão será usado como crédito ou débito. Além de informar o `id` do Android, é obrigatório ter a visibilidade `gone`.

```xml
<com.yuno.payments.features.base.ui.views.CustomYunoSwitch
                android:id="@+id/switch_cardType"
                android:visibility="gone" />
```

- `CustomYunoSwitch`: um tooltip para mostrar como o switch funciona. Além de informar o `id` do Android, é obrigatório ter a visibilidade `gone`. A Yuno recomenda posicionar este componente ao lado do switch.

```xml
<ImageView
                android:id="@+id/switch_tooltip"
                android:src="@drawable/ic_thin_info"
                android:visibility="gone"/>
```

- `AppCompatCheckBox`: uma caixa de seleção que os usuários podem usar para escolher se querem salvar o cartão de crédito para compras futuras.

```xml
<androidx.appcompat.widget.AppCompatCheckBox
android:id="@+id/checkBox_save_card" />
```

- `Button`: valida o formulário de cartão e continua o processo de pagamento. Quando o usuário clica neste botão, o SDK envia o formulário e envia as informações do cartão de crédito para a Yuno.

```xml
<Button
    android:id="@+id/button_complete_form" />
```

### Componentes disponíveis para a v1.10.0 e superiores {#components-available-for-v1100-and-higher}

Disponível apenas para o SDK v1.10.0 ou superior.

- `TextFieldItemView` para o endereço do cliente: é usado para informar o endereço do cliente quando necessário. Garanta que ele seja usado com o `id` do Android especificado (`@+id/textField_address`) e que tenha a visibilidade `gone` por padrão.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_address"
    android:visibility="gone" />
```

- `TextFieldItemView` para o estado do cliente: permite que o cliente informe o estado, se necessário. Ele precisa ser usado com o `id` do Android definido (`@+id/textField_state`) e deve ter `gone` como visibilidade padrão.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_state"
    android:visibility="gone" />
```

- `TextFieldItemView` para a cidade do cliente: é destinado à entrada da cidade do cliente. Ele deve ser usado com o `id` do Android informado (`@+id/textField_city`) e manter a visibilidade padrão `gone`.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_city"
    android:visibility="gone" />
```

## Preenchimento automático de endereço {#address-autocomplete}

Os lojistas podem ativar ou desativar o recurso de preenchimento automático de endereço no SDK Android. Quando está ativado, o SDK preenche automaticamente os campos de endereço com base na consulta do código postal. Quando está desativado, os usuários precisam informar manualmente todas as informações de endereço.
