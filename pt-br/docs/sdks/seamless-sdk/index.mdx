Assim como o [Lite SDK](/pt-br/docs/sdks/overview/quickstart), o Seamless SDK permite que você recupere os meios de pagamento disponíveis e decida quais exibir durante o checkout. Depois que a seleção é feita, uma única chamada de API e do SDK conclui o processo de pagamento, criando uma experiência idêntica à do Lite SDK.

Ao usar o Seamless SDK, você pode:

* Executar o processo de pagamento.
* Cadastrar um cartão de crédito enquanto faz um pagamento, definindo `vault_on_success: true` ao criar o pagamento.
* Usar um vaulted token de um meio de pagamento cadastrado para concluir um pagamento.

Use os guias a seguir para implementar cada processo.

### Fluxo de pagamento headless do SDK {#sdk-headless-payment-flow}

Este diagrama ilustra o processo de pagamento headless usando o SDK, detalhando as interações entre o cliente do lojista, o servidor do lojista, o servidor da Yuno e o Yuno SDK. Ele descreve as etapas desde o início de um checkout e a requisição dos meios de pagamento até a criação e o recebimento do resultado do pagamento.

#### Cliente do lojista {#merchant-client}

O cliente do lojista representa o seu app, que interage tanto com o seu servidor de backend quanto com o Yuno SDK. Ele cuida dos aspectos do fluxo de pagamento voltados ao usuário, incluindo:

* Listar os meios de pagamento
* O usuário seleciona os meios de pagamento
* Iniciar o SDK com a sessão de checkout e `payment_method`

#### Servidor do lojista {#merchant-server}

O servidor do lojista representa o seu app que cuida das operações do lado do servidor e se comunica com os servidores da Yuno. Suas principais responsabilidades incluem:

* Criar `checkout_session`
* Receber o webhook com o resultado do pagamento

#### Servidor da Yuno {#yuno-server}

O servidor da Yuno cuida de todas as operações de backend relacionadas à gestão de clientes, às sessões de checkout e ao processamento de pagamentos. Suas principais responsabilidades incluem:

* Cria `checkout_session`
* Criar o pagamento
* Envia o webhook com o resultado do pagamento

#### Yuno SDK {#yuno-sdk}

O Yuno SDK cuida da interface do usuário e do fluxo de pagamento no lado do cliente, gerenciando a seleção do meio de pagamento, a geração do token e a conclusão do pagamento. Suas principais responsabilidades incluem:

* Iniciar o SDK com `checkout_session` e `payment_method`
* Gerar o OTT
* Continuar o pagamento automaticamente, se necessário
* Mostra telas para o usuário concluir o cadastro
* Exibir o resultado do meio de pagamento (opcional)

#### Fluxo {#flow}

As etapas a seguir descrevem o fluxo completo de interação entre todos os componentes da integração de pagamento headless do SDK, detalhando como cada requisição e cada resposta passam pelo sistema:

1. Servidor do lojista: Criar `checkout_session` --> Servidor da Yuno: Cria `checkout_session`
2. Cliente do lojista: Iniciar o SDK com a sessão de checkout e `payment_method` --> Yuno SDK: Iniciar o SDK com `checkout_session` e `payment_method`
3. Servidor da Yuno: Criar o pagamento --> Yuno SDK: Gerar o OTT
