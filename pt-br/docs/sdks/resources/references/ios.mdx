Parâmetros, personalizações e recursos avançados para todos os fluxos do SDK iOS da Yuno. Para configurar a integração, consulte [Fluxos de pagamento (iOS)](/docs/sdks/full-checkout/ios-payments), [Fluxos de cadastro (iOS)](/pt-br/docs/sdks/card-enrollment/ios-enrollment) e [modos de integração](/pt-br/docs/sdks/overview/choose-integration).

## Parâmetros principais (criação da sessão de checkout) {#key-parameters-checkout-session-creation}

Ao criar uma sessão de checkout no seu backend para fluxos de pagamento, os seguintes parâmetros são usados com frequência nos SDKs iOS:

| Parâmetro            | Obrigatório | Descrição                                                                                                                                                                                                                                                                                                        |
| -------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `amount`             | Sim      | O objeto principal do valor da transação, que contém `currency` (código ISO 4217) e `value` (valor numérico nessa moeda).                                                                                                                                                                                         |
| `alternative_amount` | Não       | Uma representação do valor da transação em uma moeda alternativa, com a mesma estrutura de `amount` (`currency` e `value`). Útil em cenários com várias moedas. Por exemplo, você pode exibir os preços aos clientes na moeda de preferência deles (por exemplo, USD) enquanto processa o pagamento na moeda local (por exemplo, COP). |

## Parâmetros de pagamento (referência completa) {#payment-parameters-full-reference}

Parâmetros para fluxos de pagamento. Todos os parâmetros usados em [Fluxos de pagamento (iOS)](/docs/sdks/full-checkout/ios-payments) estão listados aqui com todos os detalhes.

| Parâmetro                  | Tipo             | Obrigatório | Descrição                                                                                                                                                                                                                                                                |
| -------------------------- | ---------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `checkoutSession`          | string           | Sim      | ID da sessão de checkout vindo do seu backend (API Create checkout session). Obrigatório em todos os fluxos de pagamento.                                                                                                                                                                       |
| `countryCode`              | string           | Sim      | Código ISO do país onde o pagamento é processado (por exemplo, `BR`, `US`). Determina os meios de pagamento disponíveis e a conformidade.                                                                                                                                                            |
| `language`                 | string           | Não       | Código do idioma da UI do SDK (por exemplo, `en`, `pt-BR`). Opcional. Consulte [Idiomas compatíveis](/pt-br/docs/sdks/resources/languages-supported) quando disponível.                                                                                                                                                |
| `viewController`           | UIViewController | Sim*     | O view controller que apresenta o fluxo de pagamento. O SDK o usa para apresentar modais e capturar o resultado.                                                                                                                                                                 |
| `yunoCreatePayment(with:)` | delegate         | Sim      | Método do delegate: crie o pagamento no seu backend usando o token de uso único fornecido pelo SDK. Depois de criar o pagamento pela API, informe o SDK para que ele possa continuar o fluxo.                                                                                      |
| `yunoPaymentResult(_:)`    | delegate         | Não       | Método do delegate: chamado quando o fluxo de pagamento termina. Recebe um valor do enum `Yuno.Result` (`.succeeded`, `.fail`, `.processing`, `.reject`, `.userCancelled`, `.internalError`). Esses valores correspondem aos [status de pagamento](/reference/getting-started/response-codes). Use para atualizar a UI ou para navegação. |

## Opções de YunoConfig (initialize) {#yunoconfig-options-initialize}

O comportamento em tempo de execução e a aparência são configurados por meio de `YunoConfig` ao chamar `Yuno.initialize(apiKey:config:)`. Todos os parâmetros usados nos fluxos de pagamento e de cadastro do iOS estão listados abaixo. Para a estilização visual (fontes, cores, botões), consulte [Personalizações do SDK (iOS)](/pt-br/docs/sdks/customization/ios).

| Parâmetro               | Tipo       | Obrigatório | Descrição                                                                                                                                                                                                                                     |
| ----------------------- | ---------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `appearance`            | Appearance | Não       | Aparência personalizada (fontes, cores, botões). Use `Yuno.Appearance(...)` para definir `fontFamily`, `accentColor`, `buttonBackgroundColor`, `buttonTitleColor` e campos relacionados. Consulte [Personalizações do SDK (iOS)](/pt-br/docs/sdks/customization/ios) para ver todas as opções. |
| `saveCardEnabled`       | boolean    | Não       | Quando `true`, permite que o usuário salve ou cadastre o cartão durante o pagamento. Exige suporte do backend para o armazenamento em cofre.                                                                                                                                  |

## Parâmetros de cadastro (referência completa) {#enrollment-parameters-full-reference}

Parâmetros para fluxos de cadastro. Todos os parâmetros usados em [Fluxos de cadastro (iOS)](/pt-br/docs/sdks/card-enrollment/ios-enrollment) estão listados aqui com todos os detalhes.

| Parâmetro                  | Tipo             | Obrigatório | Descrição                                                                                                                                                                                      |
| -------------------------- | ---------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `customerSession`          | string           | Sim      | ID da sessão de cliente vindo da API Create customer session. Obrigatório. Associa o meio de pagamento cadastrado a um cliente específico.                                                                 |
| `countryCode`              | string           | Sim      | Código ISO do país (por exemplo, `BR`, `US`). Obrigatório para o cadastro.                                                                                                                                     |
| `language`                 | string           | Não       | Código do idioma da UI do SDK. Opcional.                                                                                                                                                          |
| `viewController`           | UIViewController | Sim*     | O view controller que apresenta o fluxo de cadastro. Obrigatório no cadastro baseado em delegate.                                                                                                   |
| `yunoEnrollmentResult(_:)` | delegate         | Não       | Método do delegate: chamado quando o cadastro termina. Recebe o resultado (por exemplo, vaulted token, status). Use para atualizar a UI ou para navegação.                                                           |
| `YunoConfig`               | YunoConfig       | Não       | As mesmas opções do pagamento (por exemplo, `appearance`, `saveCardEnabled`, `keepLoader`). Consulte as [Opções de YunoConfig (initialize)](#yunoconfig-options-initialize) acima. |

## Cadastro de meios de pagamento {#enrolling-payment-methods}

Você pode cadastrar meios de pagamento (armazenar cartões para uso futuro) durante o fluxo de pagamento ou por meio de fluxos de cadastro dedicados. Nos fluxos de pagamento, habilite o salvamento do cartão em `YunoConfig` e defina `payment_method.vault_on_success` (ou equivalente) ao criar a sessão de checkout, onde houver suporte. Para o cadastro dedicado, consulte [Fluxos de cadastro (iOS)](/pt-br/docs/sdks/card-enrollment/ios-enrollment).
