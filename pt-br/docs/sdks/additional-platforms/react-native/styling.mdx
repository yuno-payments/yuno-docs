Você pode personalizar a aparência dos componentes do Yuno SDK para combinar com a marca do seu app.

## Configuração {#configuration}

A configuração de estilo é passada durante a inicialização do SDK.

```typescript
import { YunoSdk } from '@yuno-payments/yuno-sdk-react-native';

YunoSdk.initialize({
  apiKey: 'your-public-api-key',
  countryCode: 'US',
  yunoConfig: {
    // Global configuration
    language: 'en',
    theme: {
      // Customize colors, fonts, etc.
      // Note: Specific theme options depend on the native SDK versions
    }
  },
});
```

As opções de `theme` disponíveis dependem das versões dos SDKs nativos incluídas no SDK React Native. Consulte [Personalização no Android](/pt-br/docs/sdks/customization/android) e [Personalização no iOS](/pt-br/docs/sdks/customization/ios) para ver a lista completa de tokens.

## Estilização específica de cada plataforma {#platform-specific-styling}

Como o SDK React Native encapsula os SDKs nativos de iOS e Android, algumas opções de estilo podem ser específicas de cada plataforma.

```typescript
import { Platform } from 'react-native';

YunoSdk.initialize({
  apiKey: 'your-key',
  countryCode: 'US',
  ...(Platform.OS === 'ios' && {
    iosConfig: {
      // iOS-specific settings
    },
  }),
  ...(Platform.OS === 'android' && {
    androidConfig: {
      // Android-specific settings
    },
  }),
});
```

Para ver a lista completa de tokens de estilo disponíveis, consulte a documentação de [Personalização no Android](/pt-br/docs/sdks/customization/android) e [Personalização no iOS](/pt-br/docs/sdks/customization/ios).
