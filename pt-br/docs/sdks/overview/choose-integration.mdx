No SDK de cada plataforma, a Yuno oferece vários **métodos de integração**, que permitem diferentes níveis de controle sobre a UI e a experiência do usuário.

O método de integração que você escolhe afeta o nível de esforço de manutenção necessário. Ele também determina como você gerencia os meios de pagamento, o que pode ir da configuração sem código no Yuno Dashboard até o trabalho manual de desenvolvimento. Alguns tipos de integração também exigem certificações como **PCI-DSS** ou **ISO**, o que afeta as suas obrigações de conformidade.

<Check>
**Integração recomendada**

A Yuno recomenda o **Seamless SDK** pela flexibilidade e facilidade de integração. Ele oferece componentes de UI prontos e, ao mesmo tempo, dá a você controle total sobre a experiência de pagamento, com exibição automática dos meios de pagamento.
</Check>

## Tipos de integração {#integration-types}

Abaixo, você pode ver as especificações de cada tipo de integração.

| Recurso | seamless-sdk | lite-sdk | headless-sdk | secure-fields |
| :--- | :---: | :---: | :---: | :---: |
| Adicionar novos meios de pagamento sem código | ✅ | ❌ | ❌ | ❌ |
| Processar centenas de meios de pagamento com uma única API | ✅ | ✅ | ✅ | ✅ |
| Tokenizar cartões e meios de pagamento sem código | ✅ | ✅ | ✅ | ✅ |
| Usar a certificação PCI-DSS da Yuno | ✅ | ✅ | ✅ | ✅ |
| Usar 3D Secure | ✅ | ✅ | ✅ | ✅ |
| Usar uma solução antifraude sem código | ✅ | ✅ | ✅ | ✅ |
| Definir condições do checkout usando o Yuno Dashboard | ✅ | ❌ | ❌ | ❌ |
| Personalizar a aparência do seu checkout usando o Yuno Dashboard | ✅ | ❌ | ❌ | ❌ |

<CardGroup cols={4}>
  <Card title="seamless-sdk" icon="browser">
    A solução de integração mais flexível e recomendada. Oferece componentes de UI prontos, com controle total sobre a experiência de pagamento e gerenciamento automático dos meios de pagamento.
    * **Gerenciamento da experiência do usuário**: você controla a UI enquanto a Yuno cuida do trabalho pesado.
    * **Configuração sem código**: adicione e configure meios de pagamento diretamente pelo dashboard.
    * **Flexibilidade**: ideal para empresas que buscam um equilíbrio entre controle e simplicidade.
    * **Equivalente no novo SDK**: [Migração do modo Seamless (Web)](/pt-br/docs/yuno-sdk/migration/web/seamless).
  </Card>
  <Card title="lite-sdk" icon="bolt">
    Uma integração leve para ter o máximo de controle sobre o fluxo de checkout e a exibição dos meios de pagamento.
    * **Controle total da UI**: você decide como e onde exibir cada meio de pagamento.
    * **Voltado para desenvolvedores**: exige a implementação manual da seleção do meio de pagamento.
    * **Personalizável**: ideal para empresas com requisitos de UX muito específicos. Use [Web](/pt-br/docs/sdks/lite-web/payment), [Android](/pt-br/docs/sdks/lite-android/checkout) ou [iOS](/pt-br/docs/sdks/lite-ios/checkout).
    * **Equivalente no novo SDK**: [Migração do modo Lite (Web)](/pt-br/docs/yuno-sdk/migration/web/lite).
  </Card>
  <Card title="headless-sdk" icon="code">
    Máxima flexibilidade: você cria e gerencia toda a UI de pagamento por conta própria, enquanto a Yuno cuida da lógica de pagamento por trás e da segurança (como o 3DS) por meio de chamadas diretas às funções do SDK.
    * **UI totalmente sua**: nenhum componente pronto; cada tela e cada interação é você quem cria.
    * **Voltado para desenvolvedores**: você mesmo solicita e envia os campos obrigatórios exigidos por cada provedor de pagamento.
    * **Personalizável**: ideal para empresas que precisam de uma experiência de checkout totalmente personalizada. Use [Web](/pt-br/docs/sdks/headless-web/payment), [Android](/pt-br/docs/sdks/headless-android/checkout) ou [iOS](/pt-br/docs/sdks/headless-ios/checkout).
    * **Equivalente no novo SDK**: [Migração do modo Headless (Web)](/pt-br/docs/yuno-sdk/migration/web/headless).
  </Card>
  <Card title="secure-fields" icon="shield-check">
    Campos de entrada seguros e prontos que você incorpora diretamente ao seu próprio formulário de pagamento, para que os dados brutos do cartão nunca passem pelos seus servidores (somente Web).
    * **Coleta segura de dados**: simplifica a tokenização dos dados do cartão de pagamento.
    * **Conformidade com PCI**: garante uma experiência em conformidade com PCI com uma UI personalizada.
    * **Solução equilibrada**: ideal para equilibrar segurança e flexibilidade. Consulte a [implementação](/docs/sdks/customization/secure-fields/index).
    * **Equivalente no novo SDK**: [Secure Fields](/pt-br/docs/yuno-sdk/features/secure-fields).
  </Card>
</CardGroup>
