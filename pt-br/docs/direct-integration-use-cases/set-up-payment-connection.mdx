Antes de criar pagamentos usando a integração direta com a API da Yuno, você precisa configurar sua conta: configurar as conexões de pagamento, definir o roteamento de pagamentos, habilitar os meios de pagamento e obter suas credenciais de API. Esta página explica essas etapas essenciais de configuração.

Você vai aprender a:

* Configurar sua primeira conexão de pagamento
* Configurar o roteamento de pagamentos
* Habilitar meios de pagamento no checkout builder
* Obter suas credenciais de API, incluindo sua `public-api-key` e sua `private-secret-key`

<Note>
**Yuno Testing Gateway**

Ao seguir estas instruções, escolha a conexão de pagamento que atende às suas necessidades. Se você quiser testar pagamentos com cartão de crédito, use o [Yuno Testing Gateway](/pt-br/docs/direct-integration-use-cases/yuno-testing-gateway) como provedor.
</Note>

## Configurar o meio de pagamento {#configure-payment-method}

Antes de configurar um meio de pagamento, você precisa criar uma conexão com um dos provedores disponíveis.

### Etapa 1: configure sua conexão {#step-1-set-up-your-connection}

Para configurar sua primeira conexão de pagamento:

1. Acesse **Connections** na barra lateral do dashboard.
2. Use a barra de busca para encontrar a conexão de que você precisa.
3. Clique em **Connect** ao lado do gateway.
4. Informe um nome descritivo para a conexão e siga as instruções exibidas na tela.
5. Clique em **Save**.

Uma mensagem de confirmação aparecerá no dashboard quando sua conexão for adicionada com sucesso.

### Etapa 2: configure o roteamento da nova conexão {#step-2-set-up-routing-for-your-new-connection}

O roteamento de pagamentos na Yuno permite definir quais conexões serão usadas para processar tipos específicos de transações. Isso possibilita uma lógica de roteamento dinâmica e dá flexibilidade para gerenciar provedores com base em moeda, país ou outros fatores. Para uma configuração básica, siga estas etapas:

1. Acesse [Routing](https://dashboard.y.uno/routing) na barra lateral do dashboard.
2. Clique na aba **Not published** para ver os meios de pagamento que têm conexões disponíveis, mas nenhuma rota configurada.
3. Encontre o meio de pagamento desejado e clique em **Set Up**.
4. Na janela pop-up:
   * Clique em **+ Create new route**.
   * Informe um nome descritivo para a rota.
   * Clique em **Save**.
5. Clique na seta ao lado da nova rota e selecione **Add step**.
6. Escolha um **processor** na lista e clique em **Select**.
7. Clique em **Publish** para salvar todas as suas alterações.

Sua nova rota agora aparece na aba **Published**, indicando que o meio de pagamento configurado passará a processar todas as transações por essa rota configurada.

<Video src="https://github.com/writechoiceorg/yuno-images/raw/main/doc/set_up_you_account/routing_V2.mp4" />

### Etapa 3: habilite o meio de pagamento no Checkout Builder {#step-3-enable-the-payment-method-in-the-checkout-builder}

Depois de configurar sua conexão e o roteamento, você precisa habilitar o meio de pagamento para que ele fique disponível no seu checkout:

1. Acesse [Checkout Builder](https://dashboard.y.uno/checkout-builder) na barra lateral do dashboard.
2. Localize o meio de pagamento configurado na lista de meios disponíveis.
3. Ative a chave para habilitá-lo.
4. Clique em **Publish settings** para aplicar suas alterações.

<Video src="https://github.com/writechoiceorg/yuno-images/raw/main/doc/set_up_you_account/checkoutbuilder.mp4" />

### Etapa 4: obtenha suas credenciais de API {#step-4-get-your-api-credentials}

Para concluir a configuração e integrar a Yuno à sua aplicação, você precisa obter suas credenciais de API no dashboard da Yuno. Essas credenciais são específicas do ambiente Sandbox:

1. Acesse a seção **Developers** na barra lateral do dashboard.
2. Na seção Developer Tools, localize suas credenciais de API:
   * **Public API Key**: usada para a inicialização do SDK no lado do cliente.
   * **Secret API Key**: usada para chamadas de API no lado do servidor.

<Video src="https://raw.githubusercontent.com/writechoiceorg/yuno-images/main/doc/set_up_you_account/developer_V2.mp4" />

Depois de concluir essas etapas, você está pronto para criar pagamentos usando a **integração direta**.
