Neste guia, você encontra instruções passo a passo para cancelar manualmente um pagamento criado anteriormente na Yuno.

<Note>
**Cancelamento automático com atraso**

Se você preferir que a Yuno cancele automaticamente as autorizações após um atraso especificado, configure `delayed_cancel_settings` ao criar o pagamento. Isso ajuda a melhorar a experiência do cliente, liberando automaticamente os fundos retidos. Saiba mais no guia [Fluxo de cancelamento e captura](/pt-br/docs/payment-features/Cancel-and-capture-flow).
</Note>

<Warning>
**Pagamentos canceláveis**

Somente pagamentos com status **PENDING** podem ser cancelados. Consulte a página [Status do pagamento](/pt-br/docs/basic-concepts/payments-1) para mais detalhes sobre os possíveis status de pagamento.
</Warning>

## Requisitos {#requirements}

Para cancelar um pagamento, você precisa:

* Acessar suas [credenciais de API](/pt-br/docs/using-yuno/settings/developers-credentials) no Dashboard da Yuno, que consistem em:
  * `public-api-key`
  * `private-secret-key`
* Ter os dados de identificação do pagamento recebidos após criar o pagamento usando o [endpoint Create Payment](/reference/payments/create-payment):
  * `id`: o identificador único do pagamento, obtido do parâmetro `id` após criar o pagamento.
  * `transaction_id`: o identificador único da transação, obtido do parâmetro `transaction.id` após criar o pagamento.

<Note>
**Explore as Postman Collections da Yuno**

A Yuno oferece [Postman Collections](/reference/getting-started/postman-collections) que você pode usar para replicar os casos de uso localmente.
</Note>

## Cancelar um pagamento {#cancel-a-payment}

Você só pode cancelar um pagamento se ele tiver o status PENDING. Use o [endpoint Cancel Payment](/reference/payments/cancel-payment) para cancelar o pagamento. Para identificar o pagamento a ser cancelado, você precisa informar o `id` dele e o `transaction_id`.

Para confirmar que você cancelou o pagamento com sucesso, verifique se os parâmetros da resposta do [endpoint Cancel Payment](/reference/payments/cancel-payment) contêm os seguintes valores:

* `type = CANCEL`
* `status = SUCCEEDED`
* `payment.status = CANCELED`
* `payment.sub_status = CANCELED`

Se a resposta contiver os valores acima, o cancelamento foi bem-sucedido.

### Verificar o status do pagamento {#check-the-payment-status}

Se, por algum motivo, você precisar confirmar o cancelamento do pagamento:

* Use o [Retrieve Payment by ID](/reference/payments/retrieve-payment-by-id) ou o [Retrieve Payment by merchant\_order\_id](/reference/payments/retrieve-payment-by-merchant-order-id) para obter informações detalhadas sobre o pagamento.
* Como alternativa, configure webhooks para receber notificações de cada evento. Consulte o guia [Webhooks](/pt-br/docs/webhooks/configure-webhooks) para saber como configurar webhooks na Yuno.
