Os relatórios da Yuno oferecem uma forma prática de obter informações sobre as diferentes etapas dos pagamentos. Você pode solicitar e baixar com facilidade vários relatórios associados às suas operações na Yuno. A Yuno oferece os seguintes tipos de relatório por meio do endpoint [Create a Report](/reference/reports/create-a-report):

* Pagamento
* Transação
* Payouts
* Liquidações e tarifas
* Visão geral da conciliação
* Comunicações
* Payouts de liquidação

Você pode conferir a descrição detalhada de cada um acessando a documentação [Campos dos relatórios](/reference/reports/reports-fields). Os relatórios Visão geral da conciliação, Liquidações e tarifas e Payouts de liquidação fornecem informações relacionadas à conciliação. Para examinar todos os campos disponíveis em cada relatório e a descrição deles, acesse a [página Campos dos relatórios](/reference/reports/reports-fields).

## Requisitos {#requirements}

Para solicitar um relatório, você precisa:

* Acessar suas [credenciais de API](/pt-br/docs/using-yuno/settings/developers-credentials) no Dashboard da Yuno, que consistem em:
  * `public-api-key`
  * `private-secret-key`

<Note>
**Explore as Postman Collections da Yuno**

A Yuno oferece [Postman Collections](/reference/getting-started/postman-collections) que você pode usar para reproduzir os casos de uso localmente.
</Note>

## Resumo dos passos {#steps-summary}

O processo para receber um relatório usando a Yuno é composto de três passos:

1. [Criar um relatório](/reference/reports/create-a-report)
2. [Verificar se o relatório está pronto](/reference/reports/retrieve-a-report)
3. [Baixar um relatório](/reference/reports/download-a-report)

## Acessar um relatório {#access-a-report}

Como mostrado no resumo dos passos, você precisa concluir três passos antes de acessar o seu relatório.

### Passo 1: criar um relatório {#step-1-create-a-report}

Para iniciar o processo de geração do relatório, solicite à Yuno que crie o relatório usando o [endpoint Create a Report](/reference/reports/create-a-report). Primeiro, selecione o tipo de relatório desejado (`type`), que determina o conteúdo do relatório gerado. Em seguida, defina o intervalo de datas cujos dados você quer incluir no relatório, configurando os parâmetros `start_date` e `end_date`.

Ao criar o relatório, você pode filtrar os dados incluídos especificando os valores de alguns campos. Por exemplo, talvez você queira receber apenas dados de transações realizadas na Argentina e no Brasil. Nesse caso, você informaria o conteúdo `AR,BR` no parâmetro `country`.

Você pode filtrar os seguintes campos ao criar o relatório:

* `payment_status`
* `payment_sub_status`
* `payment_method`
* `currency`
* `country`
* `transaction_type`
* `transaction_status`
* `updated_at_start`
* `updated_at_end`

<Note>
**Formato dos valores de filtro**

Ao definir os valores de filtro, informe-os como uma lista em string, como no exemplo abaixo:
`"payment_status": "CREATED,READY_TO_PAY,DECLINED"`
</Note>

Nos relatórios de Pagamento, Transação ou Payouts de liquidação, você também pode selecionar os campos incluídos no relatório final usando o parâmetro `columns`. No relatório Payouts de liquidação, `columns` substitui a seleção padrão de colunas em vez de ampliá-la.

Ao usar o [endpoint Create a Report](/reference/reports/create-a-report) para solicitar a criação de um relatório, você receberá na resposta o `id` e o `status` do relatório. Você vai usar o `id` ao solicitar o download do relatório no [Passo 3](/pt-br/docs/direct-integration-use-cases/build-reports#step-3-download-your-report). O `status` informa se ele está pronto para download.

### Passo 2: verificar se o relatório está pronto {#step-2-check-if-the-report-is-ready}

Depois de solicitar a criação do relatório, você pode usar os endpoints [Retrieve a Report](/reference/reports/retrieve-a-report) ou [List All Reports](/reference/reports/list-all-reports) para verificar se ele está pronto para download. Ao usar o [endpoint Retrieve a Report](/reference/reports/retrieve-a-report), você precisa informar o `id` do relatório. Já com o  [endpoint List All Reports](/reference/reports/list-all-reports), você precisa informar o seu `account_id` para receber uma lista de todos os relatórios existentes e o status de cada um.

Quando o relatório estiver com o status `SUCCEEDED`, você pode solicitar o download dele. Acesse a [página Status do relatório](/reference/reports/report-status) para conferir todos os status possíveis de relatório.

### Passo 3: baixar o seu relatório {#step-3-download-your-report}

Use o [Download a Report](/reference/reports/download-a-report) para receber o seu relatório informando o `id` dele. Você receberá o relatório em um arquivo .zip. No entanto, para os relatórios de liquidação, a API retornará um arquivo .csv.
