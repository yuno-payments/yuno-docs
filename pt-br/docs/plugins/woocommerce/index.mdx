O plugin WooCommerce da Yuno integra a plataforma de orquestração de pagamentos da Yuno diretamente à sua loja WooCommerce, por meio do Web SDK da Yuno e de uma camada de API REST em PHP. É o segundo plugin de e-commerce compatível com a Yuno, depois da VTEX.

<Note>
  Esta é uma versão MVP. A Yuno está evoluindo o plugin ativamente com base no feedback dos lojistas. Entre no canal `WooCommerce` do Slack compartilhado para acompanhar as novas versões.
</Note>

## O que é {#what-it-is}

O plugin adiciona a Yuno como gateway de pagamento dentro do WooCommerce, com suporte tanto ao checkout legado por shortcode quanto ao checkout em blocos do WooCommerce. Os compradores concluem a compra sem sair da sua loja, e o status do pedido é atualizado automaticamente à medida que a Yuno informa os eventos de pagamento ao WooCommerce.

## Sincronização do status do pedido {#order-status-sync}

A Yuno mantém o status do pedido no WooCommerce sincronizado com o status do pagamento correspondente:

| Resultado do pagamento | Status do pedido no WooCommerce |
| :--- | :--- |
| Pagamento bem-sucedido, produto virtual ou para download | Completed |
| Pagamento bem-sucedido, produto que exige envio | Processing |
| Pagamento falhou | Failed |

## Consultar os logs de sincronização {#reviewing-sync-logs}

A tela de configurações do plugin inclui um visualizador de logs onde você pode consultar as mensagens trocadas entre o WooCommerce e a Yuno para cada pedido, o que ajuda a investigar um pagamento que não foi sincronizado como esperado.

## Configuração {#setup}

1. No painel de administração do WooCommerce, acesse as configurações do gateway de pagamento da Yuno.
2. Informe suas chaves de API da Yuno.
3. Salve as alterações e ative o gateway.

Para ver a lista completa de recursos compatíveis e o histórico de versões, consulte o [Changelog do plugin WooCommerce](/pt-br/changelog/plugins/woocommerce).
