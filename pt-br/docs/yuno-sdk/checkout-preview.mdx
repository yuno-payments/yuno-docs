Esta prévia executa o Web SDK da Yuno de produção. Altere as configurações à esquerda e o checkout é atualizado em tempo real. As mesmas configurações valem para os SDKs de iOS, Android e React Native. [Abra-a em uma nova aba](https://sdk-webview.dev.y.uno/playground.html).

Esta é uma demonstração. Os botões expressos (Revolut Pay, Google Pay, PayPal, Apple Pay) aparecem como espaços reservados, porque precisam de credenciais reais do lojista. Para criar este checkout no seu app, veja [Primeiros passos](/pt-br/docs/yuno-sdk/get-started).
</Note>
