---
title: "Cadastro Render"
description: "Migre o cadastro Render do iOS (Yuno.startEnrollmentRender) para a API unificada de Transaction."
---

O cadastro Render permitia incorporar o formulário de cadastro do SDK no seu próprio layout. Você recebia um `YunoEnrollmentRenderFlowProtocol`, pedia a ele uma `formView` e chamava `submitForm()` a partir do seu próprio botão. Ele também expunha `needSubmit: Bool` para informar se o formulário precisava de um botão de envio.

Na API unificada, o mesmo padrão é expresso sobrescrevendo [`showView`](/pt-br/docs/yuno-sdk/controllers/show-view): o SDK entrega a view do formulário junto com um `TransactionProcess` no qual você chama `onSubmit()`.

## Antes de começar {#before-you-start}

- Substitua `import YunoSDK` por `import SdkPayments`. A sua chave de API pública e as sessões de cliente que o seu backend cria não mudam ([Antes de começar](/pt-br/docs/yuno-sdk/get-started#before-you-begin)).
- Não há pagamento a criar: `createPayment` não é invocado durante o cadastro, então sobrescrevê-lo não tem efeito.

## Lado a lado {#side-by-side}

<CodeGroup>

```swift Before. Render enrollment
import SwiftUI
import YunoSDK

final class EnrollmentModel: YunoEnrollmentDelegate, ObservableObject {
    var customerSession: String = "session-from-backend"
    var countryCode: String = "CO"
    var language: String? = "en"
    var viewController: UIViewController?

    func yunoEnrollmentResult(_ result: Yuno.Result) { /* ... */ }
    func onLoading(isLoading: Bool) { /* show your own loader */ }
}

struct EnrollmentView: View {
    @StateObject var model = EnrollmentModel()
    @State var enrollmentFlow: YunoEnrollmentRenderFlowProtocol?
    @State var formView: AnyView?

    var body: some View {
        VStack {
            formView
            if enrollmentFlow?.needSubmit == true {
                Button("Enroll") {
                    enrollmentFlow?.submitForm()
                }
            }
        }
        .task {
            enrollmentFlow = Yuno.startEnrollmentRender(with: model)
            formView = await enrollmentFlow?.formView(with: model)
        }
    }
}
```

```swift After. showView override
import SwiftUI
import SdkPayments

final class EnrollmentModel: SdkPayments.TransactionController, ObservableObject {

    @Published var formView: AnyView?
    @Published var process: SdkPayments.TransactionProcess?
    @Published var isLoading: Bool = false

    func showView(view: AnyView?, process: SdkPayments.TransactionProcess, step: SdkPayments.TransactionViewStep) {
        self.formView = view
        self.process = process
    }

    func showLoading(isLoading: Bool) { self.isLoading = isLoading }

    func onStatus(status: SdkPayments.TransactionStatus) { /* ... */ }
}

struct EnrollmentView: View {
    @StateObject var model = EnrollmentModel()

    var body: some View {
        VStack {
            if model.isLoading { ProgressView() }
            model.formView
            Button("Enroll") {
                model.process?.onSubmit()
            }
        }
        .task {
            let config = SdkPayments.TransactionConfig(
                customerSession: "session-from-backend",
                countryCode: "CO",
                controller: model
            )

            let paymentSelected = SdkPayments.PaymentMethodSelected(
                paymentMethodType: "CARD"
            )

            SdkPayments.Transaction(config: config)
                .start(paymentSelected: paymentSelected)
        }
    }
}
```

</CodeGroup>

## O que muda {#what-changes}

Agrupado na ordem em que você edita o código. **Renomeado**: mesma função, novo nome. **Movido**: mesmo valor, novo dono. **Removido**: nada para chamar. **Novo**: sem equivalente legado. A última coluna é a única coisa que você precisa fazer além da renomeação.

### Inicialização e configuração {#initialization-and-config}

| Render | Unificada | Mudança | O que fazer |
|---|---|---|---|
| `import YunoSDK` | `import SdkPayments` | Renomeado | |
| `Yuno.initialize(apiKey:)` | `SdkPayments.initialize(apiKey:)` | Renomeado | O parâmetro `callback:` deixou de existir; use a sobrecarga `async` se você precisar esperar. |
| `Yuno.Appearance` passado em `YunoConfig.appearance` | `SdkPayments.Appearance` em `SdkPayments.TransactionConfig.appearance` | Renomeado | Mesmo inicializador; remova o prefixo `Yuno.` e passe-o por transação em vez de uma única vez na inicialização. |
| `YunoEnrollmentDelegate.customerSession`, `.countryCode`, `.language`, `.viewController` | Os mesmos campos em `SdkPayments.TransactionConfig` | Movido | As propriedades do delegate viram campos de configuração. `viewController` continua exclusivo do iOS e opcional no SwiftUI. |
| *(nenhum)* | `SdkPayments.PaymentMethodSelected` | Novo | `start` precisa dele. Passe o `paymentMethodType` com o qual a sessão de cliente foi criada: como antes, a sessão determina o meio efetivamente cadastrado. |

### Controller {#controller}

| Render | Unificada | Mudança | O que fazer |
|---|---|---|---|
| `YunoEnrollmentDelegate` | `SdkPayments.TransactionController` | Renomeado | Faça a mesma classe estar em conformidade e passe-a como `TransactionConfig.controller`. Como antes, o SDK não a retém: mantenha-a viva durante toda a transação. |
| `yunoEnrollmentResult(_:)` | `onStatus(status:)` | Renomeado | Continua sendo o único callback de resultado, uma vez por transação, também quando o SDK exibe a sua tela de resultado. `status` e `substatus` vêm do backend; o próprio SDK só emite `INTERNAL_ERROR` e `USER_CANCEL`. Consulte [`Status`](/pt-br/docs/yuno-sdk/reference/objects-you-receive#status). |
| `YunoEnrollmentRenderFlowProtocol.formView(with:) async -> AnyView?` | `showView(view:process:step:)` | Renomeado | O SDK envia, você não busca: ele entrega a view ao seu handler quando ela está pronta, junto com o `TransactionProcess` no qual você faz o envio (consulte Views). Consulte [`showView`](/pt-br/docs/yuno-sdk/controllers/show-view). |
| `YunoLoaderDelegate.onLoading(isLoading:)` | `showLoading(isLoading:)` | Renomeado | Opcional. Só é disparado quando sobrescrito: nesse caso, o SDK oculta o próprio loader e informa o estado a você. Consulte [`showLoading`](/pt-br/docs/yuno-sdk/controllers/show-loading). |

### Views {#views}

| Render | Unificada | Mudança | O que fazer |
|---|---|---|---|
| `YunoEnrollmentRenderFlowProtocol.submitForm()` | `process.onSubmit()` | Renomeado | Mesma função. Chame-o a partir do seu próprio botão, no `TransactionProcess` que você recebe em `showView`. |
| `YunoEnrollmentRenderFlowProtocol.needSubmit` | *(removido)* | Removido | Sem equivalente na API unificada: você renderiza o seu próprio botão de envio. Se precisar ocultá-lo para formulários que não exigem envio, controle isso a partir do seu próprio estado (por exemplo, inspecionando o `step` entregue a `showView`). |
| *(nenhum)* | `SdkPayments.defaultShowView(view:process:step:)` | Novo | Chame-o a partir da sua sobrescrita de `showView` para as etapas que você não quer incorporar (por exemplo, incorpore `.FORM` e devolva `.ACTION` ao SDK). |

### Pontos de entrada {#entry-points}

| Render | Unificada | Mudança | O que fazer |
|---|---|---|---|
| `Yuno.startEnrollmentRender(with:)` retornando `YunoEnrollmentRenderFlowProtocol` | `SdkPayments.Transaction(config:).start(paymentSelected:)` + sobrescrita de `showView` | Renomeado | Monte a configuração e o `PaymentMethodSelected` e depois chame `start`. Nada é retornado: a view chega por `showView` quando está pronta. |
| `Yuno.receiveDeeplink(_:)` | `SdkPayments.handleDeeplink(_:)` | Renomeado | Mesma função: encaminhe a URL que o seu app recebe após um redirecionamento externo. Consulte [Tratar deeplinks](/pt-br/docs/yuno-sdk/features/handle-deeplinks). |
