title: "Visão geral da migração"
description: "Migre de qualquer modo legado do Yuno SDK para a Transaction API unificada."
---

O SDK unificado substitui todos os modos anteriores do SDK (Full, Lite, Seamless, Render, Headless e Secure Fields) por uma única classe `Transaction`. Se você usa atualmente algum desses modos, escolha a sua plataforma e o seu modo legado na tabela abaixo. Em React Native, os guias partem da API 1.x do `@yuno-payments/yuno-sdk-react-native` e terminam na 2.0.0.

## O que mudou {#what-changed}

Todo modo legado corresponde à mesma classe `Transaction`. O nome do modo deixou de existir. O que você passa na config e quais controllers você sobrescreve determinam o comportamento:

- **Tipo de sessão** (`checkoutSession` ou `customerSession`) determina se é pagamento ou cadastro.
- **Controller `createPayment`** determina se o SDK cria o pagamento ou se o seu backend cria. Se você não o sobrescrever, o SDK gerencia a criação do pagamento de ponta a ponta (o equivalente ao Seamless).
- **Controller `showView`** (iOS, Android, React Native) determina se o SDK apresenta o formulário em tela cheia ou entrega a view para você incorporar (o equivalente ao Render).
- **`transactionData` em `PaymentMethodSelected`** (iOS, Android, React Native) ou **`data` no `paymentMethod` que você passa para `start()`** (Web) determina se o SDK mostra um formulário ou tokeniza os dados que você já coletou (o equivalente ao Headless).
- **`getPaymentMethodsViews`** substitui todas as APIs legadas de montagem de lista e de botões de carteiras externas (o equivalente ao Full).

<Note>
**3DS nativo no iOS:** a partir do SdkPayments 3.2.0, adicione o módulo `SdkPaymentsNetcetera` para executar os desafios 3DS de forma nativa; sem ele, eles são executados em uma WebView apresentada pelo SDK. Veja [Módulos nativos](/pt-br/docs/yuno-sdk/features/native-modules#netcetera-3ds).
</Note>

Cada guia tem o mesmo formato: o que resolver antes de começar, uma comparação de código lado a lado e uma tabela com o que muda e o que fazer em cada mudança.
