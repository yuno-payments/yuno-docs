## Instale com IA {#install-with-ai}

A integração mais rápida é a que o seu agente faz por você. Cole isto no
Claude Code, no Cursor ou em qualquer agente de programação. Ele lê o guia
[Primeiros passos](/pt-br/docs/yuno-sdk/get-started), configura tudo e
termina com um pagamento de teste para você saber que funciona:

```text
Read https://docs.y.uno/docs/yuno-sdk/get-started and integrate
the Yuno SDK into this project:

1. Load https://sdk-web.y.uno/v2/main.js with a script tag,
   or npm install @yuno-payments/sdk-web@^10 and call
   loadScript({ baseUrl: 'https://sdk-web.y.uno/v2' }).
   Both stay on the latest 2.x release.
   Do not install 9.x or older of that package: those load SDK 1.x
2. Initialize SdkPayments once with the public API key from my env
3. Add a backend endpoint that creates a checkout session
   (workflow: "SDK_SEAMLESS")
4. Start a Transaction with onStatus wired, then run a sandbox
   test payment with card 4507 9900 0000 0002, expiry 11/28,
   CVV 123, cardholder John Doe
```

O número do cartão é um cartão de teste: ele só funciona no sandbox, e nenhum dinheiro real
é movimentado. Saiba mais em [Cartões de teste](/pt-br/docs/yuno-sdk/get-started#test-cards).

## Conecte o seu agente (MCP) {#connect-your-agent-mcp}

O MCP é o plugue que conecta o seu agente de IA diretamente à Yuno. Depois de adicionado,
o seu agente pode criar sessões de teste, consultar pagamentos e testar fluxos para
você, sem sair do seu editor:

```json
{
  "mcpServers": {
    "yuno": {
      "url": "https://mcp.y.uno/v1"
    }
  }
}
```

<Note>
  O servidor MCP e o Agent Toolkit estão documentados em
  [Recursos de IA](/pt-br/docs/ai-capabilities/building-ai-integrations-with-yunos-llms-and-mcp);
  os detalhes de endpoint e autenticação estão lá.
</Note>

## Skills prontas {#ready-made-skills}

Skills são conhecimento pré-empacotado: elas ensinam ao seu agente os workflows da Yuno para que
você não precise explicá-los. *(Proposta, em definição com a equipe de
recursos de IA.)*

| Skill | O que faz |
|---|---|
| `yuno-sdk-install` | Monta a integração completa: instalação, inicialização, endpoint de sessão e controllers conectados. |
| `yuno-test-payment` | Executa pagamentos no sandbox nos cenários de cartão de teste e informa os resultados. |
| `yuno-migrate` | Mapeia uma integração legada (Full, Lite, Seamless…) para a API unificada `Transaction`. |

## Documentação que o seu agente pode ler (llms.txt) {#docs-your-agent-can-read-llmstxt}

Toda página desta documentação também é publicada em um formato que os agentes conseguem ler
sozinhos, indexado em [docs.y.uno/llms.txt](https://docs.y.uno/llms.txt).
Aponte o seu agente para lá e ele poderá explorar a documentação sem a sua
ajuda.
