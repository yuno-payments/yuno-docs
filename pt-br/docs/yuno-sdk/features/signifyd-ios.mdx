O módulo `SdkAntifraudSignifyd` adiciona o **device profiling da Signifyd** ao Yuno SDK para iOS (`SdkPayments`). Quando a Signifyd é um provedor de análise de fraude na sua rota de pagamento da Yuno, o Yuno SDK faz o profiling do dispositivo durante o checkout com o Profiling SDK da Signifyd e envia o ID da sessão com o pagamento. A Yuno então o encaminha à Signifyd junto com o pedido.

<Note>
  O módulo é **opcional**: adicione-o apenas se a sua conta da Yuno usa a Signifyd para análise de fraude. Instalá-lo não altera o seu código de pagamento nem de cadastro.
</Note>

Diferente dos outros [módulos nativos](/pt-br/docs/yuno-sdk/features/native-modules), a Signifyd é distribuída em **um pacote próprio do Swift Package Manager**, e o Profiling SDK da Signifyd é baixado do repositório privado da Signifyd com **o seu próprio token da Signifyd**. A Yuno não inclui nem redistribui o SDK da Signifyd.

## Requisitos {#requirements}

- iOS **14.0** ou superior.
- Xcode **26.2** ou superior.
- **`SdkPayments` ou `SdkPayments-Static` 3.2.0 ou superior**, instalado pelo **Swift Package Manager**.
- Um **token de download do SDK da Signifyd**, emitido pelo seu solution engineer da Signifyd.
- A Signifyd habilitada como **provedor de análise de fraude** na sua rota de pagamento da Yuno.

<Warning>
  O módulo está disponível **apenas pelo Swift Package Manager**. Não existe pod do CocoaPods. O Yuno SDK também precisa vir do Swift Package Manager: se o seu app instala o `SdkPayments` com CocoaPods e este módulo com Swift Package Manager, o app carrega duas cópias do Yuno SDK e o checkout não usa a Signifyd.
</Warning>

## Instalação {#installation}

<Steps>
  <Step title="Adicione o seu token da Signifyd">
    O token permite que o Swift Package Manager baixe o Profiling SDK da Signifyd do repositório privado da Signifyd. Ele só é usado quando o seu build resolve os pacotes, nunca em tempo de execução.

    - **Xcode 26:** vá em **Xcode > Settings > Source Control**, clique em **+**, escolha **GitHub** e informe a conta do GitHub e o token que a Signifyd forneceu a você. Em versões anteriores do Xcode, a mesma opção fica em **Settings > Accounts**.
    - **CI:** grave o token em `~/.netrc` antes do build e remova o arquivo quando o build terminar:

      ```
      machine github.com
        login x-access-token
        password <your-signifyd-token>
      ```
  </Step>

  <Step title="Adicione o pacote">
    No Xcode, vá em **File > Add Package Dependencies...** e adicione:

    ```
    https://github.com/yuno-payments/yuno-sdk-ios-signifyd
    ```

    escolha **Up to Next Major Version** a partir de `2.0.0` e adicione o produto `SdkAntifraudSignifyd` ao target do seu app, ao lado do produto `SdkPayments` ou `SdkPayments-Static` que você já usa. O Xcode baixa o Profiling SDK da Signifyd automaticamente.

    Se o seu app usa um `Package.swift`, adicione a dependência nele:

    ```swift
    dependencies: [
        .package(url: "https://github.com/yuno-payments/yuno-sdk-ios.git", from: "3.2.0"),
        .package(url: "https://github.com/yuno-payments/yuno-sdk-ios-signifyd.git", from: "2.0.0")
    ],
    targets: [
        .target(
            name: "YourApp",
            dependencies: [
                .product(name: "SdkPayments", package: "yuno-sdk-ios"),
                .product(name: "SdkAntifraudSignifyd", package: "yuno-sdk-ios-signifyd")
            ]
        )
    ]
    ```
  </Step>

  <Step title="Habilite a Signifyd na Yuno">
    Peça à equipe da sua conta na Yuno para adicionar a Signifyd como provedor de análise de fraude na sua rota de pagamento. Sem isso, o módulo fica instalado, mas o Yuno SDK nunca o executa.
  </Step>
</Steps>

## Ativação do módulo {#activating-the-module}

O módulo **se registra sozinho** quando o app é iniciado, com `SdkPayments` ou com `SdkPayments-Static`. Nenhum código é necessário além de adicionar o produto `SdkAntifraudSignifyd` ao target do seu app.

<Tip>
  Depois que o módulo estiver instalado e a Signifyd estiver na sua rota de pagamento, o Yuno SDK o usa automaticamente em todo checkout. Você não precisa alterar nenhum código de pagamento nem de cadastro.
</Tip>

## Como funciona {#how-it-works}

1. Quando o app é iniciado, o módulo registra o provedor Signifyd no Yuno SDK.
2. Durante o checkout, se a Signifyd for um provedor de análise de fraude da transação, o Yuno SDK executa o módulo.
3. O módulo faz o profiling do dispositivo com o Profiling SDK da Signifyd e retorna o ID da sessão usado no profiling.
4. O Yuno SDK envia esse ID da sessão com o pagamento, e a Yuno o encaminha à Signifyd junto com o pedido.

Se o profiling falhar ou demorar mais do que o checkout permite, o pagamento continua sem o fingerprint da Signifyd.

## Solução de problemas {#troubleshooting}

<AccordionGroup>
  <Accordion title="A resolução de pacotes falha para ios-sdk-dist (401 ou repositório não encontrado)">
    O Swift Package Manager não conseguiu baixar o Profiling SDK da Signifyd. Verifique se o seu token da Signifyd está adicionado em **Xcode > Settings > Source Control** (ou em `~/.netrc` no CI) e se ele ainda é válido. Se o token expirou ou foi revogado, peça um novo ao seu solution engineer da Signifyd. Os apps que você já lançou continuam funcionando, porque o token só é usado no momento do build.
  </Accordion>
  <Accordion title="O módulo está instalado, mas os pagamentos não levam o fingerprint da Signifyd">
    Verifique se o produto `SdkAntifraudSignifyd` está adicionado ao **target do app**, e não só ao projeto, e se a Signifyd é um provedor de análise de fraude na sua rota de pagamento da Yuno.
  </Accordion>
  <Accordion title="A resolução de pacotes falha com um conflito de versão em yuno-sdk-ios">
    As versões 2.x deste pacote exigem `yuno-sdk-ios` 3.2.0 ou superior. As versões 1.x são para o SDK legado (`YunoSDK` 2.x), veja [Antifraude Signifyd (iOS legado)](/pt-br/docs/sdks/external-native-modules/signifyd-ios).
  </Accordion>
  <Accordion title="Meu app instala o SdkPayments com CocoaPods">
    O módulo depende do Yuno SDK vindo do Swift Package Manager. Remova o pod e adicione o `SdkPayments-Static` (o mesmo linking estático que você tinha com CocoaPods) pelo Swift Package Manager antes de adicionar este módulo.
  </Accordion>
  <Accordion title="Framework SignifydProfilingSdk duplicado">
    O pacote `SdkAntifraudSignifyd` já traz o Profiling SDK da Signifyd. Se o seu app também incorpora `SignifydProfilingSdk.xcframework` manualmente, remova-o e mantenha apenas a dependência do pacote.
  </Accordion>
</AccordionGroup>
