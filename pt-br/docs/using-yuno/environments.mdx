Este guia explica como o **Test Mode** e o **Live Mode** funcionam no dashboard da Yuno e como alternar entre eles. Para as URLs base da API e as credenciais de cada ambiente, consulte a referência [Ambientes da API](/reference/getting-started/api-environments).

A Yuno usa uma única conta para os dois ambientes. Você pode alternar entre Test Mode e Live Mode pelo [chip de contexto](/pt-br/docs/using-yuno/account-context) na barra superior, usando o mesmo nome de usuário e senha.

## Entendendo os ambientes {#understanding-the-environments}

A Yuno tem dois ambientes distintos, cada um com uma finalidade específica:

* **Test Mode (Sandbox):** quando você se cadastra, sua organização começa com o status "Inactive" e tem acesso apenas ao Test Mode. Use-o para explorar o dashboard, aprender como os recursos funcionam e executar testes sem afetar as operações reais. O Test Mode é ideal para testar novas configurações e integrações com segurança.
* **Live Mode (Produção):** o Live Mode é onde ocorrem as transações reais dos clientes. Para acessá-lo, você precisa enviar uma requisição de ativação. Quando sua conta estiver ativa, você pode processar tráfego de produção mantendo a mesma segurança e os mesmos controles. Use o Live Mode quando estiver pronto para colocar sua integração em produção.

## Transição para o Live Mode {#transitioning-to-live-mode}

1. **Solicitação de ativação:** na página inicial do dashboard, envie uma requisição de ativação. O status da sua organização mudará de "Inactive" para "Under Verification". O Test Mode continua disponível durante a verificação.
2. **Processo de verificação:** a Yuno normalmente conclui a verificação em poucas horas. Se precisarmos de mais informações, entraremos em contato com você.
3. **Acesso liberado:** quando a verificação for concluída, o Live Mode será habilitado para a sua conta.

## Alternância entre ambientes {#switching-environments}

Alternar entre Sandbox e Produção no dashboard é simples:

* **Troca com um clique:** abra o [chip de contexto](/pt-br/docs/using-yuno/account-context) na barra superior e escolha **Live** ou **Test**.
* **Login único:** um único conjunto de credenciais dá acesso aos dois ambientes, sem senhas ou contas separadas.
