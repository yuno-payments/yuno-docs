**Início rápido para agentes**

1. Leia o [llms.txt](https://docs.y.uno/llms.txt) e esta página.
2. Carregue a [especificação OpenAPI](https://docs.y.uno/openapi.json).
3. Autentique-se como descrito em [Autenticação](/reference/getting-started/authentication).
4. Crie um pagamento com a Payments API ou um SDK. O [Quickstart](/pt-br/docs/quickstart) mostra as duas opções.
5. Assine os [webhooks](/docs/webhooks) para receber atualizações de status assíncronas.
