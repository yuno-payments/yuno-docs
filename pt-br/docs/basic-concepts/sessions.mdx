title: "Sessões"

---

Com a Yuno, você pode criar sessões para iniciar pagamentos ou cadastrar meios de pagamento para compras futuras. Existem dois tipos de sessões: **sessões de cliente** e **sessões de checkout**. Essas sessões garantem que as informações corretas sejam coletadas em cada cenário.

## Sessão de cliente {#customer-session}

Use sessões de cliente para cadastrar e armazenar os meios de pagamento de um cliente. Crie uma nova sessão de cliente sempre que cadastrar um meio de pagamento para um cliente específico. Você precisará do `customer_id` (um identificador único do cliente) gerado ao criar o cliente na Yuno. Uma sessão de cliente dá acesso a todos os meios de pagamento disponíveis para cadastro, que você pode oferecer aos clientes.

<Note>
**Meios de pagamento disponíveis**

Ao criar qualquer um dos tipos de sessão, de cliente ou de checkout, o sistema da Yuno retorna uma lista de todos os meios de pagamento habilitados. Esses são os meios de pagamento configurados no seu dashboard da Yuno, na seção Connections e Checkout builder.
</Note>

Para informações mais detalhadas sobre como usar o endpoint **Create customer session**, consulte a [referência da API](/pt-br/reference/customer-sessions-enrollment/the-customer-session-object).

## Sessão de checkout {#checkout-session}

Use sessões de checkout para criar pagamentos ou iniciar o fluxo de pagamento. Sempre que um cliente fizer um pagamento, você deve criar uma nova sessão. Você precisará do `customer_id` (um identificador único do cliente) gerado ao criar o cliente na Yuno. Uma sessão de checkout dá acesso a todos os meios de pagamento disponíveis para esse cliente, cadastrados anteriormente ou não. Uma sessão de checkout expira 2,5 horas depois de ser criada, e atualizá-la não estende esse prazo.

<Note>
**Criar um pagamento sem uma sessão de checkout**

A integração direta não exige o SDK da Yuno, então você pode criar um pagamento sem uma sessão de checkout.
</Note>

Para informações mais detalhadas sobre como usar o endpoint **Create checkout session**, consulte a [referência da API](/pt-br/reference/checkout-sessions/the-checkout-session-object).
