Conecte sua conta Yuno ao assistente de IA que você já usa (Claude, ChatGPT, Grok ou Cursor) ou adicione o mesmo conector a qualquer cliente compatível com MCP. Analise seus dados de pagamentos, pesquise a documentação da API da Yuno e opere pagamentos nas contas Yuno às quais você tem acesso, tudo em linguagem natural. Você entra com seu usuário Yuno, então o assistente só vê e executa o que seu usuário e sua organização têm permissão para fazer.

<Note>
  Está criando um produto de IA que recebe pagamentos? Veja o [Agent Toolkit](/pt-br/docs/ai-capabilities/agent-toolkit). Para as versões legíveis por máquina desta documentação (llms.txt, páginas em Markdown, AGENTS.md), veja [Documentação para agentes](/pt-br/docs/ai-capabilities/building-ai-integrations-with-yunos-llms-and-mcp).
</Note>

## Contas {#accounts}

As ações de pagamento são executadas em uma das suas contas Yuno. Por padrão, o conector usa sua conta principal: a que está definida como padrão para o seu usuário Yuno no dashboard ou, caso contrário, a primeira conta à qual você tem acesso.

* Pergunte **"Quais contas da Yuno posso usar?"** para listar as contas disponíveis para você e ver qual é a padrão.
* Diga ao assistente qual conta usar em uma determinada requisição (por exemplo, "use a conta `<account>`") para sair da conta padrão.
* Contas às quais você não tem acesso são rejeitadas: o conector só pode usar as contas permitidas para o seu usuário Yuno.

## Modelo de segurança {#safety-model}

* **Analytics é somente leitura**: instruções SQL que alteram dados ou o schema são sempre rejeitadas.
* **As ferramentas de pagamento podem gravar**: elas podem criar e alterar dados. Dependendo das configurações do seu assistente, ele pode pedir sua aprovação antes de executá-las.
* **Confirmação em produção**: em produção, cancelamentos, reembolsos e exclusões retornam primeiro uma prévia e só são executados depois que o assistente confirma, em até 5 minutos.
* As permissões vêm do acesso e da organização do seu usuário Yuno, não do assistente: ele só pode fazer o que sua conta já tem permissão para fazer.

## O que você pode fazer {#what-you-can-do}

O conector expõe ferramentas em quatro grupos de recursos: analytics, documentação da API da Yuno, contas e pagamentos. O assistente escolhe automaticamente a ferramenta certa, então você nunca precisa chamá-las pelo nome, mas saber o que está disponível ajuda você a saber o que perguntar.

### Analytics (SQL somente leitura) {#analytics-read-only-sql}

| Ferramenta | Tipo | Descrição |
| --- | --- | --- |
| `read_query` | Leitura | Executa SQL somente leitura (`SELECT`, `WITH`, `SHOW`, `DESCRIBE`, `EXPLAIN`) nos seus dados de analytics. É a base da maioria das perguntas: métricas, detalhamentos, tendências, exportações. |
| `table_overview` | Leitura | Descreve as colunas e os tipos de uma tabela e mostra algumas linhas de exemplo, para que o assistente entenda o formato dos seus dados antes de consultá-los. |
| `analyze_query` | Leitura | Retorna o plano de execução de uma consulta sem executá-la, para que consultas custosas possam ser verificadas antes. |

### Documentação da API da Yuno {#yuno-api-documentation}

| Ferramenta | Tipo | Descrição |
| --- | --- | --- |
| `docs__search_yuno_api_documentation` | Leitura | Pesquisa a documentação pública da API da Yuno. |
| `docs__query_docs_filesystem_yuno_api_documentation` | Leitura | Lê páginas da documentação. |
| `docs__submit_feedback` | Escrita | Informa à equipe de documentação uma página incorreta ou desatualizada. |

### Contas {#accounts-1}

| Ferramenta | Tipo | Descrição |
| --- | --- | --- |
| `yuno_list_accounts` | Leitura | Lista as contas Yuno que você pode usar e marca a conta padrão. |

### Pagamentos {#payments}

As ferramentas de pagamento têm o prefixo `pay__` e estão agrupadas por recurso abaixo. O assistente pode buscar sozinho os parâmetros completos de qualquer ferramenta de pagamento com `pay__describeTool`, por isso esta página agrupa as ferramentas por recurso em vez de listar cada parâmetro.

| Recurso | Ferramentas | Tipo |
| --- | --- | --- |
| Auxiliar | `pay__describeTool` | Leitura (retorna os parâmetros completos de uma ferramenta de pagamento) |
| [Pagamentos](/reference/payments/manage-payments) | `pay__paymentRetrieve`, `pay__paymentRetrieveByMerchantOrderId` | Leitura |
| | `pay__paymentCreate`, `pay__paymentAuthorize` | Escrita |
| | `pay__paymentCaptureAuthorization`, `pay__paymentCancel`, `pay__paymentRefund`, `pay__paymentCancelOrRefund`, `pay__paymentCancelOrRefundWithTransaction` | Destrutiva |
| [Clientes](/pt-br/reference/customers/the-customer-object) | `pay__customerRetrieve`, `pay__customerRetrieveByExternalId` | Leitura |
| | `pay__customerCreate`, `pay__customerUpdate` | Escrita |
| [Meios de pagamento](/pt-br/reference/payment-methods-direct-workflow/the-payment-method-object-api) | `pay__paymentMethodRetrieve`, `pay__paymentMethodRetrieveEnrolled` | Leitura |
| | `pay__paymentMethodEnroll` | Escrita |
| | `pay__paymentMethodUnenroll` | Destrutiva |
| [Checkout](/pt-br/reference/checkout-sessions/the-checkout-session-object) | `pay__checkoutSessionRetrievePaymentMethods` | Leitura |
| | `pay__checkoutSessionCreate`, `pay__checkoutSessionCreateOtt` | Escrita |
| [Assinaturas](/reference/subscriptions/the-subscription-object) | `pay__subscriptionRetrieve` | Leitura |
| | `pay__subscriptionCreate`, `pay__subscriptionResume`, `pay__subscriptionUpdate` | Escrita |
| | `pay__subscriptionPause`, `pay__subscriptionCancel` | Destrutiva |
| [Links de pagamento](/reference/payment-links/the-payment-link-object) | `pay__paymentLinkRetrieve` | Leitura |
| | `pay__paymentLinkCreate` | Escrita |
| | `pay__paymentLinkCancel` | Destrutiva |
| [Recebedores](/reference/recipients-for-marketplace/the-recipient-object) | `pay__recipientRetrieve` | Leitura |
| | `pay__recipientCreate`, `pay__recipientUpdate` | Escrita |
| | `pay__recipientDelete` | Destrutiva |
| [Planos de parcelamento](/pt-br/reference/installments/create-installments-plan) | `pay__installmentPlanRetrieve`, `pay__installmentPlanRetrieveAll` | Leitura |

| | `pay__installmentPlanDelete` | Destrutiva |

**Leitura** = nenhuma alteração. **Escrita** = cria ou atualiza dados. **Destrutiva** = cancela, reembolsa ou exclui; exige confirmação em produção.

## Pergunte em linguagem natural {#ask-in-plain-language}

* "Qual foi minha taxa de aprovação de pagamentos por meio de pagamento nos últimos 30 dias?"
* "Mostre o volume de transações por país em julho e destaque qualquer país que tenha caído mais de 10% em relação a junho."
* "Quais são os 5 principais motivos de recusa deste mês, e de qual provedor eles vêm?"
* "Compare a conversão entre cartão de crédito e PIX no Brasil neste trimestre."
* "Descreva a tabela de transações e me mostre algumas linhas de exemplo."
* "Monte um resumo semanal: volume, taxa de aprovação, taxa de reembolso e ticket médio."
* "Como crio um pagamento com 3DS?"
* "Quais contas da Yuno posso usar?"
* "Reembolse o pagamento `<payment_id>`."
* "Crie um link de pagamento de 50 USD."

## Restrito à sua conta {#scoped-to-your-account}

* **Restrito à sua conta**: o conector se autentica com suas credenciais da Yuno e só pode ver e executar ações nas contas permitidas para o seu usuário. Veja [Modelo de segurança](#safety-model) para saber como o analytics somente leitura e as gravações de pagamento são mantidos seguros.
* **Limites de consulta**: conjuntos de resultados muito grandes são truncados em vez de enviados por completo, e as sessões têm limite de taxa para manter o data warehouse saudável. Para exportações em massa, use o dashboard ou a API da Yuno.
* **Indisponibilidades parciais**: se um recurso (analytics, documentação ou pagamentos) estiver temporariamente indisponível, só as ferramentas dele desaparecem; as demais continuam funcionando.

## Solução de problemas {#troubleshooting}

**O Claude diz que o conector da Yuno está desconectado**

Acesse Settings → Connectors, encontre a Yuno, clique em Reconnect e autorize de novo. Se o conector não aparecer em um chat, confirme que ele está ativado no menu de pesquisa e ferramentas do chat.

**O ChatGPT não chama o app da Yuno**

Chame-o explicitamente digitando `@Yuno` no início da sua mensagem ou mencione "usando a Yuno" no prompt. Se ele continuar indisponível, remova o app e adicione-o de novo pela página dele no diretório.

**As consultas falham com o erro "no database selected"**

Peça ao assistente para qualificar as tabelas com o nome do banco de dados (por exemplo, `analytics.transactions`) ou para informar qual banco de dados usar. Perguntar antes "quais tabelas estão disponíveis?" costuma resolver isso.

**Os resultados parecem truncados**

Isso é esperado para saídas grandes. Peça ao assistente para agregar os dados (totais, top N, resumos agrupados) em vez de listar linhas brutas, ou reduza o intervalo de datas.

**O assistente usou a conta errada**

Pergunte "Quais contas da Yuno posso usar?" e diga a ele qual usar na requisição.

**"Confirmation expired"**

As confirmações em produção duram 5 minutos. Peça ao assistente para repetir a ação e obter uma nova confirmação.

**Mensagem "Connect" ou "consent required"**

O assistente está pedindo que você autorize (de novo) o conector da Yuno: sua sessão ou um consentimento anterior expirou ou não foi concluído. Refaça a etapa de conexão (veja Configuração acima) e tente sua requisição novamente.

## Perguntas frequentes {#faq}

<AccordionGroup>
  <Accordion title="Os conectores do Claude, ChatGPT, Grok e Cursor fazem a mesma coisa?">
    Sim. Todos expõem as mesmas ferramentas da Yuno: analytics, documentação e pagamentos. O conector também faz isso quando você o adiciona a outro cliente MCP. Escolha o assistente que sua equipe já usa ou conecte mais de um; o acesso e as permissões são idênticos porque são definidos pela sua credencial da Yuno, não pelo assistente.
  </Accordion>
  <Accordion title="O conector pode movimentar dinheiro ou alterar minha configuração de pagamentos?">
    Ele pode executar operações de pagamento (criar, capturar, cancelar e reembolsar pagamentos, e gerenciar clientes, assinaturas, links de pagamento, recebedores e planos de parcelamento) nas contas Yuno às quais você tem acesso. Ele não pode alterar seu dashboard da Yuno nem sua configuração de roteamento. Ações destrutivas em produção exigem uma etapa de confirmação explícita. Para incluir operações de pagamento no seu próprio produto de IA, veja o [Agent Toolkit](/pt-br/docs/ai-capabilities/agent-toolkit).
  </Accordion>
  <Accordion title="Meus dados são usados para treinar modelos de IA?">
    Seus dados são transferidos para o assistente somente dentro da sua própria conversa, sujeitos às políticas de dados do provedor do seu assistente para o seu plano. Consulte a política de tratamento de dados de IA do seu workspace; por exemplo, os planos enterprise da Anthropic e da OpenAI excluem dados empresariais do treinamento por padrão.
  </Accordion>
  <Accordion title="Posso conectar a Yuno ao meu próprio agente ou IDE como desenvolvedor?">
    Sim. Adicione o conector a qualquer cliente compatível com MCP e entre com seu usuário Yuno (veja a aba **Outros clientes MCP** em [Configuração](#setup)). Para incluir pagamentos da Yuno no seu próprio produto de IA com chaves de API, veja o [Agent Toolkit](/pt-br/docs/ai-capabilities/agent-toolkit).
  </Accordion>
  <Accordion title="Com quem falo se algo não estiver funcionando?">
    Entre em contato com o seu gerente de conta da Yuno ou abra um ticket pelo dashboard da Yuno. Para problemas de desenvolvimento com o servidor MCP, registre-os no [GitHub](https://github.com/yuno-payments/yuno-mcp).
  </Accordion>
</AccordionGroup>
