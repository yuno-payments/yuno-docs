A Yuno publica a sua documentação em formatos que modelos de linguagem de grande porte (LLMs) e agentes de código leem diretamente. Aponte o seu agente para esses arquivos para que ele responda perguntas e escreva integrações a partir da documentação atual, em vez de adivinhar com base nos dados de treinamento.

<Note>
  Quer que um assistente de IA trabalhe com a sua conta da Yuno (analisar dados de pagamentos, pesquisar a documentação, executar operações de pagamento)? Veja [Use a Yuno com assistentes de IA](/pt-br/docs/ai-capabilities/use-yuno-with-claude-and-chatgpt).
</Note>

## Arquivos para agentes {#files-for-agents}

| Arquivo | O que contém |
| --- | --- |
| [llms.txt](https://docs.y.uno/llms.txt) | Um índice de todas as páginas da documentação, com uma descrição curta de cada uma. Comece por aqui. |
| [llms-full.txt](https://docs.y.uno/llms-full.txt) | A documentação completa em um único arquivo de texto simples. |
| [AGENTS.md](https://docs.y.uno/AGENTS.md) | Instruções para agentes de código que integram a Yuno: instalação, configuração, primeiro pagamento e recursos. |
| [skill.md](https://docs.y.uno/skill.md) | Um arquivo de skill que os agentes podem carregar para trabalhar com a API da Yuno. |
| [sitemap.md](https://docs.y.uno/sitemap.md) | A lista de páginas da documentação em Markdown. |
| [openapi.json](https://docs.y.uno/openapi.json) | A especificação OpenAPI da API da Yuno, para geração de código e validação de requisições. |

## Qualquer página em Markdown {#any-page-in-markdown}

Adicione `.md` ao final de qualquer URL da documentação da Yuno para obter essa página em Markdown simples. Isso funciona tanto para os guias quanto para as páginas de referência da API. Por exemplo, [docs.y.uno/docs/quickstart.md](https://docs.y.uno/docs/quickstart.md).

Toda página também tem um botão **Copy page** que copia o Markdown dela, pronto para colar no contexto do seu agente.
