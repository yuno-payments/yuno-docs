A migração de tokens é o processo de transferir números de cartão de um provedor existente para o vault seguro da Yuno. Durante esse processo, um novo token é gerado para cada cartão, garantindo continuidade e segurança no processamento de pagamentos. O processo de migração de tokens tem três etapas principais:

1. O lojista solicita o processo de migração de tokens ao seu processador de pagamentos atual.
2. A Yuno e o provedor de pagamento trabalham juntos para importar com segurança todos os dados de cartão para o token vault da Yuno.
3. O lojista usa a API de migração de tokens da Yuno para mapear os tokens do provedor de pagamento para os `vaulted_tokens` da Yuno.

<Note>
**Primeira etapa**

Para iniciar o processo de migração de tokens, entre em contato com o seu consultor de negócios na Yuno para avaliar a viabilidade e o cronograma do procedimento.
</Note>

## Importação de cartões de uma conta de gateway (etapas 1 e 2) {#importing-cards-from-a-gateway-account-steps-1-and-2}

A importação de dados de cartão de uma conta de gateway envolve informações sensíveis, por isso é preciso seguir protocolos de segurança rigorosos. Para importar dados de cartão para a Yuno a partir de um gateway existente, siga estas etapas:

1. **Coordene com o gateway atual**: entre em contato com o seu vault ou gateway terceiro atual e solicite uma exportação dos dados dos meios de pagamento. Siga os protocolos definidos por ele.
2. **Faça a solicitação formal**: envie uma solicitação formal à Yuno, garantindo que todos os detalhes e processos necessários estejam documentados. O tempo de resposta e os procedimentos do gateway vão determinar o processo de transferência dos dados.

<Warning>
**Suas responsabilidades ao migrar tokens**

Você é responsável por gerenciar a comunicação com o seu provedor de gateway durante todo o processo de migração. A equipe da Yuno vai apoiar e trabalhar diretamente com o vault/gateway terceiro para facilitar o processo de importação. Além disso, as informações de assinatura do cliente, incluindo valores, datas etc., devem ser obtidas diretamente da entidade exportadora, já que a Yuno não vai extrair esses dados dos arquivos criptografados.
</Warning>

<Note>
**Segurança na transferência de dados**

Todos os dados durante o processo de migração são criptografados com chaves PGP e transferidos por SFTP (Secure File Transfer Protocol).
</Note>

## Requisitos do lado do cliente (etapa 3) {#client-side-requirements-step-3}

Para concluir com sucesso o processo de migração de tokens, é essencial cumprir os requisitos do lado do cliente descritos na etapa 3. Isso envolve fornecer os dados de usuário necessários, incluindo os compradores e os meios de pagamento que eles já têm.

Você pode executar o processo de migração de tokens usando a API da Yuno, que foi criada especificamente para lojistas. Como lojista, você vai usar essa API para:

1. **Adicionar clientes**: registre os clientes no sistema da Yuno.
2. **Cadastrar meios de pagamento**: registre, no sistema da Yuno, os meios de pagamento obtidos dos processadores de pagamento para cada cliente.

<Note>
**Opção de migração via API**

A opção de migração via API permite que os lojistas gerenciem os seus clientes e os respectivos dados de pagamento. [Saiba mais](/pt-br/docs/security-and-compliance/data-migration-processes/via-api)
</Note>

### Formato dos dados {#data-format}

A Yuno especifica os parâmetros obrigatórios de cada cliente e cartão de crédito para dar andamento ao processo de migração. Os parâmetros obrigatórios estão listados abaixo:

* Account ID
* ID do cliente no lojista
* Nome
* Sobrenome
* E-mail
* País
* Número do documento
* Tipo de documento
* Tipo de meio de pagamento
* ID do meio de pagamento
* Token do meio de pagamento

Consulte o [Objeto Customer](/reference/customers/the-customer-object) e o [Objeto Payment Method](/reference/payment-methods-direct-workflow/the-payment-method-object-api) para ver todos os parâmetros possíveis para importar/criar clientes ou cadastrar objetos de pagamento.

Limitações técnicas associadas a meios de pagamento alternativos podem torná-los inelegíveis para migração entre provedores de serviço. Se você está pensando em migrar tokens de meios de pagamento alternativos, como Mercado Pago Wallet Connect ou Bancolombia Tokenbox, para o vault da Yuno, entre em contato com a equipe de suporte da Yuno.

## Validação dos dados {#data-validation}

Para garantir um processamento eficiente e evitar atrasos durante o processo de migração de tokens, informe os seguintes dados ao se comunicar com o suporte da Yuno:

* O nome do identificador externo que será usado na importação.
* Uma contagem aproximada do número esperado de meios de pagamento a incluir (uma estimativa aproximada é aceitável).
* Qualquer lacuna conhecida nos dados, como nomes ou datas de validade faltando.

<Warning>
**Aviso importante**

A Yuno não valida as datas de validade durante a importação de cartões de crédito.
</Warning>

## Proteção de dados {#data-protection}

Ao processar pagamentos pela Yuno, a plataforma se conecta aos processadores de pagamento. A Yuno tokeniza e criptografa os dados para garantir a segurança, simplificando o processo de conformidade com o PCI. No entanto, você é responsável por gerenciar e proteger os dados dos seus clientes. Além disso, você deve comunicar quaisquer taxas adicionais ou problemas ao seu cliente.

## Requisitos para gateways e provedores de pagamento {#gateway-and-payment-provider-requirements}

Para dar andamento ao processo de migração, você vai precisar fornecer o seguinte:

* Uma chave SSH pública (você pode fornecer uma para produção e outra para testes). Use o seguinte comando para gerá-la: `ssh-keygen -t rsa -b 4096 -C your_email@example.com`
* Os IPs de saída que serão usados durante a migração.
* Um arquivo de modelo dos dados a migrar, para entender a estrutura deles. Ele deve incluir os seguintes dados obrigatórios:
  * **Nome do titular do cartão**: o nome completo do titular do cartão, como armazenado pelo provedor atual.
  * **Data de validade**: a data de validade do cartão.
  * **Número do cartão**: o número completo do cartão (PAN) que será tokenizado pela Yuno.
  * **ID do cartão**: um identificador único atribuído a cada cartão pelo provedor atual, usado pelo cliente para referenciar esse cartão durante as transações.

### Chave pública PGP {#pgp-public-key}
