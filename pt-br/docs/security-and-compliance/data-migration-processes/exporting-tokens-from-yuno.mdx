A Yuno oferece um processo seguro e em conformidade com o PCI DSS para exportar tokens do nosso vault para os seus sistemas ou para um provedor terceiro. Este guia explica os requisitos, os protocolos de criptografia, o formato dos dados e o método de entrega para garantir uma migração segura e em conformidade de dados sensíveis de cartão.

<Note>
**Requisitos de segurança**

As requisições de exportação de tokens são tratadas com o mesmo nível de rigor e de criptografia usado para proteger os dados em produção. Apenas clientes elegíveis, com casos de uso validados e conformidade com o PCI DSS, podem iniciar este processo.
</Note>

## Quando solicitar uma exportação de tokens {#when-to-request-a-token-export}

Você pode solicitar à Yuno uma exportação dos seus dados tokenizados quando:

* Estiver mudando para outro processador de pagamentos ou provedor de tokenização.
* Precisar gerenciar os tokens na sua própria infraestrutura certificada pelo PCI DSS.

## Elegibilidade e pré-requisitos {#eligibility-and-prerequisites}

Para seguir com uma exportação, as seguintes condições devem ser atendidas, nesta ordem:

### 1. Requisição formal {#1-formal-request}

O cliente deve enviar uma requisição por escrito que inclua:

* Uma requisição formal do terceiro que deseja receber os dados do lojista
* Autorização para exportar os dados tokenizados.
* Confirmação do destinatário (equipe interna ou provedor terceiro).
* Aprovação jurídica e de compliance por parte do cliente.

Envie essa requisição por escrito ao seu principal ponto de contato na Yuno e mande também uma cópia por email para [security-migrations@y.uno](mailto:security-migrations@y.uno), para garantir que as duas equipes estejam informadas.

### 2. Certificação PCI DSS {#2-pci-dss-certification}

Como os dados exportados contêm dados de cartão, a entidade receptora deve ser certificada pelo PCI DSS. Essa certificação é obrigatória independentemente de você estar:

* Mudando para outro provedor de pagamentos
* Solicitando os seus próprios dados para uso interno

Nós exigimos:

* Um Attestation of Compliance (AOC) válido da entidade receptora
* O AOC deve estar atualizado e válido no momento da requisição de exportação

### 3. Requisitos técnicos para a transferência segura dos dados {#3-technical-requirements-for-secure-data-transfer}

Depois que a requisição formal for aprovada e a conformidade com o PCI DSS for verificada, os seguintes requisitos técnicos devem ser atendidos:

#### a. Chave pública PGP para criptografia {#a-pgp-public-key-for-encryption}

A entidade receptora deve fornecer uma chave pública PGP para criptografar os arquivos exportados. Isso garante que os dados permaneçam seguros tanto em trânsito quanto em repouso.

* A entidade receptora deve enviar a chave
* A Yuno vai validar o formato e a compatibilidade da chave

#### b. Credenciais de acesso SFTP {#b-sftp-access-credentials}

A Yuno vai disponibilizar acesso a um servidor SFTP seguro hospedado pela Yuno.

**Você fornece:**

* Um endereço IP estático a partir do qual o arquivo será acessado
* Uma chave pública SSH para autenticação

**A Yuno fornece:**

* Uma conta de usuário SFTP dedicada para essa finalidade

## Formato do arquivo {#file-format}

O arquivo exportado será criptografado com a chave PGP fornecida e seguirá a estrutura abaixo:

| Campo              | Descrição                  |
| ------------------ | ---------------------------- |
| `holder_name`      | Nome do titular do cartão       |
| `number`           | Primary Account Number (PAN) |
| `token`            | Token armazenado no vault da Yuno |
| `expiration_year`  | Ano de expiração do cartão  |
| `expiration_month` | Mês de expiração do cartão |

* O arquivo será formatado como `.csv`
* Todos os campos são codificados em UTF-8.

## Processo de entrega segura {#secure-delivery-process}

Depois que todos os pré-requisitos forem atendidos:

1. A equipe de segurança da Yuno vai:
   * Preparar o arquivo de exportação com os dados de cartão
   * Criptografar o arquivo com a chave PGP fornecida
   * Criar a conta de usuário SFTP para a retirada do arquivo
   * Enviar o arquivo para o local SFTP seguro

2. Você será notificado quando:
   * O arquivo estiver pronto para download
   * O acesso SFTP estiver configurado
   * A janela de acesso estiver ativa

3. Então, você poderá:
   * Acessar o local SFTP seguro usando a sua chave SSH e o IP liberado na whitelist
   * Baixar o arquivo criptografado dentro da janela de tempo definida
   * O arquivo será removido automaticamente do servidor depois que a janela de acesso expirar

<Warning>
**Canal seguro obrigatório**

O arquivo nunca é enviado por email nem disponibilizado publicamente. O acesso é estritamente limitado ao canal seguro configurado.
</Warning>

## Segurança e compliance {#security-and-compliance}

A Yuno é certificada pelo PCI DSS Nível 1 e segue práticas rigorosas de criptografia, controle de acesso e retenção de dados durante todo este processo.

Nós garantimos que:

* Todas as exportações são registradas e monitoradas.
* Apenas pessoal autorizado manipula os dados criptografados.
* Os arquivos nunca ficam armazenados por mais tempo do que a janela de acesso exigida.
