Embora a Yuno ofereça diversas opções de pagamento, o processo básico de pagamento sempre segue a mesma sequência. Este guia apresenta, passo a passo, o processo e os elementos principais envolvidos, esclarecendo como os pagamentos fluem quando você usa os SDKs ou a API da Yuno.

## O processo de pagamento da Yuno {#the-yuno-payment-process}

O processo de pagamento é composto pelas seguintes etapas:

<Steps>
  <Step title="Crie um cliente">
    Os pagamentos na Yuno geralmente estão vinculados a um [cliente](/pt-br/docs/basic-concepts/customers). O sistema armazena os dados do cliente, como nome, endereço e número de telefone. A Yuno usa essas informações para processar pagamentos com diferentes [meios de pagamento](/pt-br/docs/basic-concepts/payment-methods) e processadores.
    Quando você cria um cliente, a Yuno gera um identificador único para uso nas etapas seguintes.
    <Note>
      Um pagamento pode ser criado sem um cliente. Se você criar a sessão de checkout com um `customer_id`, envie o mesmo cliente em `customer_payer.id` ao criar o pagamento.
    </Note>
  </Step>
  <Step title="Crie uma sessão de checkout">
    Para processar um pagamento com o Yuno SDK ou o Checkout, crie uma [sessão de checkout](/pt-br/docs/basic-concepts/sessions#checkout-session). Essa sessão conecta o cliente ao pagamento e armazena os principais dados da transação. A Yuno carrega todos os [meios de pagamento](/pt-br/docs/basic-concepts/payment-methods) disponíveis vinculados à sua conta.
    <Note>
      As integrações Direct/Server-to-server pulam esta etapa e informam os dados da transação diretamente na criação do pagamento. Defina `workflow` como `DIRECT` (ou `REDIRECT`) na requisição de pagamento. Sem isso, a API pede o objeto `checkout`.
    </Note>

  </Step>
  <Step title="Colete os dados de pagamento">
    Para processar um pagamento, você precisa coletar as informações de pagamento do cliente.
    * **Integração via SDK**: os SDKs da Yuno capturam os dados sensíveis com segurança e geram um token de uso único (OTT).
    * **Integração direta**: você coleta os dados de pagamento diretamente nos seus servidores (o que exige conformidade com o PCI) e os envia para o endpoint de pagamento.
    <Note>
      Um OTT é um código temporário de uso único usado pelos SDKs da Yuno para aumentar a segurança para os lojistas.
    </Note>
  </Step>

  <Step title="Crie o pagamento">
    Um [pagamento](/pt-br/docs/basic-concepts/payments-1) representa a transação final. Use os dados coletados nas etapas anteriores (ID do cliente e informações de pagamento) para processar a transação final.

    <Note>
      Alguns campos são opcionais, mas podem melhorar a experiência do usuário. Considere os campos obrigatórios se decidir incluir essas informações.
    </Note>
    <Note>
      A requisição de criação de pagamento exige o cabeçalho `X-Idempotency-Key`. Envie um valor único (por exemplo, um UUID) para poder repetir a requisição com segurança. Consulte [Idempotência](/reference/getting-started/authentication#idempotency).
    </Note>
  </Step>
</Steps>

Depois que o pagamento é criado, a Yuno mantém você informado sobre as atualizações por meio de [webhooks](/pt-br/docs/basic-concepts/webhooks-1). Além disso, a Yuno oferece soluções de [prevenção a fraude](/docs/basic-concepts/fraud) que você pode integrar ao processo de pagamento.
