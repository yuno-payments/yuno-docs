## Tipos de cambios {#types-of-changes}
- <ChangelogBadge type="added" /> : para nuevas funciones.
- <ChangelogBadge type="changed" /> : para cambios en la funcionalidad existente.
- <ChangelogBadge type="deprecated" /> : para funciones que se eliminarán pronto.
- <ChangelogBadge type="removed" /> : para funciones que ya se eliminaron.
- <ChangelogBadge type="fixed" /> : para cualquier corrección de errores.
- <ChangelogBadge type="security" /> : en caso de vulnerabilidades.
- <ChangelogBadge type="breaking" /> : para cambios que requieren una adaptación por parte del comercio.
