## v1.0.1 {#v101}
*April 13, 2026*

**Configuración**

- <ChangelogBadge type="added" /> **Ocultar la selección de método de pago cuando Yuno es el único gateway**  
  Agrega la opción Hide Payment Selection para ocultar los botones de selección del método de pago en el checkout cuando Yuno es el único gateway activo, con lo que se ofrece una experiencia de checkout más limpia con un solo método. Se aplica tanto al checkout heredado como al basado en bloques.

## v1.0.0 {#v100}
*April 7, 2026*

- <ChangelogBadge type="added" /> **Lanzamiento inicial en el WordPress Plugin Directory**  
  Primer lanzamiento público del gateway de pago de Yuno para WooCommerce en el WordPress Plugin Directory, que integra la plataforma de orquestación de pagos de Yuno con WooCommerce mediante el Yuno Web SDK y una capa de API REST en PHP.

**Pagos con tarjeta**

- <ChangelogBadge type="added" /> **Pagos con tarjeta, billeteras y métodos de pago locales**  
  Acepta tarjetas, billeteras digitales y métodos de pago locales a través de la plataforma de orquestación de pagos de Yuno desde una sola integración, con enrutamiento inteligente de pagos entre varios proveedores.

- <ChangelogBadge type="added" /> **Compatibilidad con 3D Secure y autenticación adicional**  
  Gestiona los desafíos de 3D Secure y otros flujos de autenticación adicional durante el pago, e incluye una detección de retorno desde 3DS que evita la duplicación accidental de pedidos.

**Checkout por bloques**

- <ChangelogBadge type="added" /> **Compatibilidad con el checkout basado en bloques de WooCommerce**  
  Es compatible con el checkout heredado por shortcode y con el checkout basado en bloques de WooCommerce (el predeterminado desde WooCommerce 8.3). Ambos flujos convergen en la página order-pay, de modo que la orquestación del SDK es compartida.

**Webhooks**

- <ChangelogBadge type="added" /> **Receptor de webhooks para el estado asíncrono de los pagos**  
  Recibe los eventos de pago de Yuno (exitoso, pendiente, fallido, contracargo, reembolso) con verificación HMAC de tres capas y procesamiento idempotente mediante bloqueos transitorios.

**Marketplace**

- <ChangelogBadge type="added" /> **Pagos divididos para marketplace**  
  Divide el total del pedido entre un destinatario vendedor y una comisión de la plataforma, configurable como porcentaje o como un monto fijo en unidades menores.

**Confiabilidad**

- <ChangelogBadge type="added" /> **Reintento en el mismo lugar para pagos fallidos**  
  Permite al cliente reintentar un pago fallido en el mismo lugar volviendo a montar el SDK, en lugar de crear un pedido duplicado nuevo en cada intento.

- <ChangelogBadge type="added" /> **Verificación de pagos en el servidor**  
  Verifica cada estado de pago reportado con la API de Yuno antes de actualizar el pedido de WooCommerce, sin confiar nunca en el estado reportado por el cliente.

**Gestión de pedidos**

- <ChangelogBadge type="added" /> **Completado automático para pedidos virtuales y descargables**  
  Los pedidos que contienen solo productos virtuales o descargables omiten el estado de procesamiento y pasan directamente a completado después del pago.

- <ChangelogBadge type="added" /> **Compatibilidad con HPOS**  
  Declara compatibilidad con el High-Performance Order Storage de WooCommerce (tablas de pedidos personalizadas) y usa consultas de pedidos seguras para HPOS en todo el plugin.

**Cliente y dirección**

- <ChangelogBadge type="added" /> **Estrategia de cliente de Yuno por pedido**  
  Crea un cliente de Yuno nuevo por cada pedido de WooCommerce, con recuperación automática de los errores de cliente duplicado y cliente no encontrado, para que los pagos nunca se bloqueen por un estado de cliente obsoleto.

**Configuración**

- <ChangelogBadge type="added" /> **Compatibilidad con varios entornos**  
  Detecta automáticamente el entorno de la API de Yuno (development, staging, sandbox, producción) a partir del prefijo de la clave de API pública.

- <ChangelogBadge type="added" /> **Registro de depuración configurable con redacción de PII**  
  Registro opcional integrado con WooCommerce para solucionar problemas de pagos y webhooks. Los números de teléfono, las direcciones de email y los payloads completos de la API nunca se registran.
