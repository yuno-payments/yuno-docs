# Migración a Web SDK v1.2 {#migrating-to-web-sdk-v12}

La versión 1.2.0 es una versión **sin cambios incompatibles**. No se requieren cambios en las integraciones existentes de la v1.1.

## Qué cambió {#what-changed}

### Parámetro opcional `options` en `Yuno.initialize()` {#optional-options-parameter-in-yunoinitialize}

`Yuno.initialize()` ahora acepta un objeto de configuración `options` opcional como segundo argumento. Las llamadas existentes sin este argumento siguen funcionando sin modificaciones.

```js
// v1.1 — still valid in v1.2
const yuno = await Yuno.initialize(publicApiKey)

// v1.2 — optional options parameter
const yuno = await Yuno.initialize(publicApiKey, {
  // additional options here
})
```

### Parámetros ampliados de `continuePayment` {#extended-continuepayment-parameters}

`continuePayment()` ahora acepta parámetros opcionales adicionales: `checkoutSession`, `showPaymentStatus`, `yunoPaymentResult`, `yunoError`, `countryCode` y `language`. Todos los parámetros son opcionales: las llamadas existentes con menos argumentos siguen funcionando.

```js
// v1.1 usage — still valid in v1.2
await yuno.continuePayment()

// v1.2 — additional optional params available
await yuno.continuePayment({
  checkoutSession,
  showPaymentStatus: true,
  yunoPaymentResult,
  yunoError,
  countryCode: 'US',
  language: 'en',
})
```

## Pasos {#steps}

### 1. Actualiza la etiqueta script {#1-update-the-script-tag}

```html
<script src="https://sdk-web.y.uno/v1.2/main.js"></script>
```

### 2. (Opcional) Adopta los nuevos parámetros {#2-optional-adopt-new-parameters}

No se requieren cambios en el código. Si quieres aprovechar los nuevos parámetros opcionales, actualiza tus llamadas a `initialize()` y `continuePayment()` como se muestra arriba.

## Lista de verificación {#checklist}

- [ ] Actualicé la etiqueta script a v1.2
- [ ] (Opcional) Agregué el parámetro `options` a `Yuno.initialize()` si es necesario
- [ ] (Opcional) Amplié `continuePayment()` con parámetros adicionales si es necesario
