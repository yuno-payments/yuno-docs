# Migración a Web SDK v1.5 {#migrating-to-web-sdk-v15}

La versión 1.5.0 cambia la forma en que se muestran Google Pay y Apple Pay en el **Lite SDK**. Las integraciones con el Full SDK no se ven afectadas.

## Qué cambió {#what-changed}

En la v1.5.0, los usuarios del Lite SDK deben llamar explícitamente a `mountExternalButtons()` para mostrar los botones de Google Pay y Apple Pay. Estos métodos de pago ya no se muestran automáticamente como botones de opción dentro de la lista de métodos de pago.

Las integraciones con el Full SDK **no tienen cambios incompatibles**: Google Pay y Apple Pay se mostrarán automáticamente como botones directos en lugar de botones de opción, sin necesidad de cambiar el código.

## Quién se ve afectado {#who-is-affected}

- **Usuarios del Lite SDK**: se requiere acción (consulta los pasos a continuación)
- **Usuarios del Full SDK**: no se requiere acción

## Pasos (solo Lite SDK) {#steps-lite-sdk-only}

### 1. Actualiza la etiqueta script {#1-update-the-script-tag}

```html
<script src="https://sdk-web.y.uno/v1.5/main.js"></script>
```

### 2. Agrega elementos HTML para los botones de billetera {#2-add-html-elements-for-wallet-buttons}

Agrega elementos contenedor en tu HTML donde quieras que aparezcan los botones:

```html
<div id="apple-pay"></div>
<div id="google-pay"></div>
```

### 3. Llama a `mountExternalButtons()` después de `startCheckout` {#3-call-mountexternalbuttons-after-startcheckout}

**Antes:**
```js
// Lite SDK — wallet buttons rendered automatically
await yuno.startCheckout({ checkoutSession, countryCode, elementSelector: '#root' })
```

**Después:**
```js
// Explicitly mount wallet buttons after startCheckout
await yuno.startCheckout({ checkoutSession, countryCode, elementSelector: '#root' })

await yuno.mountExternalButtons([
  {
    paymentMethodType: 'APPLE_PAY',
    elementSelector: '#apple-pay',
  },
  {
    paymentMethodType: 'GOOGLE_PAY',
    elementSelector: '#google-pay',
  },
])
```

### 4. (Opcional) Desmonta los botones cuando sea necesario {#4-optional-unmount-buttons-when-needed}

Para desmontar un solo botón:

```js
yuno.unmountExternalButton('APPLE_PAY')
```

Para desmontar todos los botones externos a la vez:

```js
yuno.unmountAllExternalButtons()
```
