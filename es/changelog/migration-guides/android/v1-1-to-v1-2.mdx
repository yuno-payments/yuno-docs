# Migración de v1.1 a v1.2 {#migrating-from-v11-to-v12}

<Note>
Esta guía cubre un cambio de versión histórico. Para la migración actual de cardFlow, consulta [Migración a Android SDK v2.11](/changelog/migration-guides/android/v2-10-to-v2-11).
</Note>

La configuración de `cardFlow` se trasladó al Dashboard.

### 1. Elimina la configuración del código {#1-remove-code-configuration}
Elimina la siguiente línea de tu `YunoConfig`:

```kotlin
cardFlow = CardFormType.ONE_STEP
```

### 2. Actualiza el Dashboard {#2-update-dashboard}
Configura el flujo de tarjeta que quieras en el **Checkout Builder** del Yuno Dashboard.
