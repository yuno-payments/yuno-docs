# Migración a Android SDK v2.11 {#migrating-to-android-sdk-v211}

La versión 2.11.0 elimina el parámetro `cardFlow` de `YunoConfig`. La configuración del flujo de tarjeta se traslada al Yuno Dashboard.

## Qué cambió {#what-changed}

Se eliminó el parámetro `cardFlow` de `YunoConfig`. Si lo pasas después de actualizar, se producirá un **error de compilación**.

## Pasos {#steps}

### 1. Elimina `cardFlow` de YunoConfig {#1-remove-cardflow-from-yunoconfig}

**Antes:**
```kotlin
val config = YunoConfig(
    apiKey = "your_api_key",
    cardFlow = CardFormType.ONE_STEP
)
```

**Después:**
```kotlin
val config = YunoConfig(
    apiKey = "your_api_key"
)
```

### 2. Configura el flujo de tarjeta en el Dashboard {#2-configure-card-flow-in-the-dashboard}

Abre **Dashboard → Checkout → Builder** y selecciona tu flujo de tarjeta:
- **One Step**: todos los campos de la tarjeta en una sola pantalla
- **Multi Step**: los campos de la tarjeta repartidos en varias pantallas

La configuración del Dashboard se aplica a todas las instancias del SDK de tu cuenta.
