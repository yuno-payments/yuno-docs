# Migración de v1.1 a v1.2 {#migrating-from-v11-to-v12}

<Note>
Esta guía cubre un cambio de versión histórico. Para la migración actual de cardFormType, consulta [Migración a iOS SDK v2.12](/es/changelog/migration-guides/ios/v2-11-to-v2-12).
</Note>

La configuración de `cardFormType` ahora se administra desde el Dashboard.

### 1. Actualiza la inicialización {#1-update-initialization}
Elimina `cardFormType` de tu llamada a `Yuno.initialize()`.

### 2. Sincronización con el Dashboard {#2-dashboard-sync}
Asegúrate de que la configuración de tu Checkout Builder coincida con el flujo de interfaz que quieres.
