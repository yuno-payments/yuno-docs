# Migración a iOS SDK v2.12 {#migrating-to-ios-sdk-v212}

La versión 2.12.0 elimina el parámetro `cardFormType` de `Yuno.initialize()`. La configuración del tipo de formulario de tarjeta se traslada al Yuno Dashboard.

## Qué cambió {#what-changed}

Se eliminó el parámetro `cardFormType` de `Yuno.initialize()`. Si lo pasas después de actualizar, se producirá un **error de compilación**.

## Pasos {#steps}

### 1. Elimina `cardFormType` de Yuno.initialize() {#1-remove-cardformtype-from-yunoinitialize}

**Antes:**
```swift
Yuno.initialize(apiKey: "your_api_key", cardFormType: .oneStep)
```

**Después:**
```swift
Yuno.initialize(apiKey: "your_api_key")
// Configure in Dashboard → Checkout → Builder
```

### 2. Configura el tipo de formulario de tarjeta en el Dashboard {#2-configure-card-form-type-in-the-dashboard}

Abre **Dashboard → Checkout → Builder** y selecciona el tipo de formulario de tarjeta:
- **One Step**: todos los campos de la tarjeta en una sola pantalla
- **Multi Step**: los campos de la tarjeta repartidos en varias pantallas

La configuración del Dashboard se aplica a todas las instancias del SDK de tu cuenta.
