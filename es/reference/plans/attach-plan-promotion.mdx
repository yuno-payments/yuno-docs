---
title: "Asociar promoción a un plan"
openapi: "/openapi/es/plans/attach-plan-promotion.json POST /subscriptions/plans/{plan_id}/promotions"
description: "Asocia una promoción existente a un plan de suscripción durante un número de cobros, para que las suscripciones del plan puedan recibirla"
---

Asocia una promoción existente a un plan. Después, las suscripciones del plan pueden recibir la promoción cuando se [crean](/es/reference/subscriptions/create-subscription) o se [actualizan](/es/reference/subscriptions/update-subscription). La asociación define cuántos cobros cubre el descuento (`cycles`) y qué efecto tiene una pausa sobre él (`on_pause`). Consulta [Promociones en planes de suscripción](/es/docs/payment-features/subscriptions/promotions).

La respuesta, y cada elemento de la lista `promotions` del plan, muestra los campos `promotion_id`, `name`, `type`, `status`, `cycles`, `on_pause` y `attached_at` de la asociación.

`type` es el modo de canje de la promoción: `AUTOMATIC` (se aplica sola cuando se crea una suscripción en el plan) o `CODE` (se aplica solo cuando el comercio envía su código).

<Note>
**Las asociaciones no se editan**

Para cambiar `cycles` o `on_pause`, elimina la asociación con [Eliminar promoción de un plan](/es/reference/plans/remove-plan-promotion) y vuelve a asociar la promoción. Eliminar una asociación no cambia las suscripciones que ya tienen la promoción.
</Note>

## Errores {#errors}

| HTTP | `code` | Cuándo |
| :--- | :----- | :--- |
| `404` | `PROMOTION_NOT_FOUND` | El `promotion_id` es desconocido o pertenece a otra cuenta. |
| `409` | `PROMOTION_ALREADY_ATTACHED` | El plan ya tiene esta promoción. |
| `422` | `PROMOTION_NOT_APPLICABLE` | No se puede asociar la promoción. El `reason` indica el motivo, por ejemplo `EXPIRED`, o `PROMOTIONS_NOT_ENABLED` cuando las promociones no están activadas para tu organización. |
| `503` | `PROMOTION_ENGINE_UNAVAILABLE` | El motor de promociones no respondió. |
| `504` | `PROMOTION_ENGINE_TIMEOUT` | El motor de promociones no respondió a tiempo. |

Consulta [Códigos de error de promociones de suscripción](/es/reference/subscriptions/subscription-promotion-error-codes) para ver todos los motivos.
