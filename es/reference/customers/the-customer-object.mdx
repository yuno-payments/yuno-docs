---
title: "El objeto cliente"
description: "Describe el objeto cliente y sus atributos, incluidos los datos de contacto, de dirección y de documento"
---

Este objeto representa a un cliente que realizará pagos mediante tu servicio.

## Atributos {#attributes}

<ParamField body="id" type="string">
  El identificador único del cliente (MAX 64; MIN 36).

  Ejemplo: faa89e18-5a11-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="merchant_customer_id" type="string">
  El identificador único del cliente en el comercio externo (MAX 255; MIN 1).

  Ejemplo: 50ca6f06-5a12-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="merchant_customer_created_at" type="timestamp">
  Fecha de registro del cliente en la plataforma del comercio (MAX 27; MIN 27 <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="first_name" type="string">
  El nombre del cliente (MAX 255; MIN 1).

  Ejemplo: John
</ParamField>

<ParamField body="last_name" type="string">
  El apellido del cliente (MAX 255; MIN 1).

  Ejemplo: Doe
</ParamField>

<ParamField body="gender" type="enum">
  El género del cliente (MAX 2; MIN 1).

  Valores posibles del enum: `M`, `F` o `NB`
</ParamField>

<ParamField body="date_of_birth" type="string">
  La fecha de nacimiento del cliente en formato YYYY-MM-DD (MAX 10; MIN 10).

  Ejemplo: 1990-02-28
</ParamField>

<ParamField body="email" type="string">
  El correo electrónico del cliente (MAX 255; MIN 3).

  Ejemplo: john.doe@email.com
</ParamField>

<ParamField body="nationality" type="enum">
  La nacionalidad del cliente (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Valores posibles del enum: consulta la <a href="/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="country" type="enum">
  El país del cliente (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Valores posibles del enum: consulta la <a href="/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="document" type="object">
  Especifica el objeto de documento del cliente, que incluye su número y su tipo.

  <Expandable title="propiedades">

    <ParamField body="document_number" type="string">
      El número de documento del cliente (MAX 40; MIN 3).

      Ejemplo: 1093333333
    </ParamField>

    <ParamField body="document_type" type="enum">
      El tipo de documento del cliente (MAX 6; MIN 2).

      Valores posibles del enum: consulta la <a href="/reference/country-reference">referencia de países</a>.
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="phone" type="object">
  Especifica el objeto de número de teléfono del cliente.

  <Expandable title="propiedades">

    <ParamField body="country_code" type="string">
      El código de llamada del país del teléfono del cliente (MAX 3; MIN 1). Valores posibles: consulta la <a href="/reference/country-reference">referencia de países</a>.

      Ejemplo: 57
    </ParamField>

    <ParamField body="number" type="string">
      El número de teléfono del cliente, sin el código de país (MAX 32; MIN 1).

      Ejemplo: 3132450765
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="billing_address" type="object">
  Especifica el objeto de dirección de facturación del cliente.

  <Expandable title="propiedades">

    <ParamField body="address_line_1" type="string">
      La línea principal de la dirección de facturación del cliente (MAX 255; MIN 3).

      Ejemplo: Calle 34 # 56 - 78
    </ParamField>

    <ParamField body="address_line_2" type="string">
      La línea secundaria de la dirección de facturación del cliente (MAX 255; MIN 3).

      Ejemplo: Apartamento 502, Torre I
    </ParamField>

    <ParamField body="city" type="string">
      La ciudad considerada para la dirección de facturación (MAX 255; MIN 3).

      Ejemplo: Bogotá
    </ParamField>

    <ParamField body="country" type="enum">
      El país considerado para la dirección de facturación (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

      Valores posibles del enum: consulta la <a href="/reference/country-reference">referencia de países</a>.
    </ParamField>

    <ParamField body="state" type="string">
      El estado considerado para la dirección de facturación (MAX 255; MIN 3; <a href="https://en.wikipedia.org/wiki/ISO_3166-2">ISO 3166-2</a> ).

      Ejemplo: Cundinamarca
    </ParamField>

    <ParamField body="zip_code" type="string">
      El código postal considerado para la dirección de facturación (MAX 11; MIN 4).

      Ejemplo: 111111
    </ParamField>

    <ParamField body="neighborhood" type="string">
      El barrio de la línea de dirección del cliente (MAX 255; MIN 2)

      Ejemplo: Barrio 11
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="shipping_address" type="object">
  Especifica el objeto de dirección de envío del cliente.

  <Expandable title="propiedades">

    <ParamField body="address_line_1" type="string">
      La línea principal de la dirección de envío del cliente (MAX 255; MIN 3).

      Ejemplo: Calle 34 # 56 - 78
    </ParamField>

    <ParamField body="address_line_2" type="string">
      La línea secundaria de la dirección de envío del cliente (MAX 255; MIN 3).

      Ejemplo: Apartamento 502, Torre I
    </ParamField>

    <ParamField body="city" type="string">
      La ciudad considerada para la dirección de envío (MAX 255; MIN 3).

      Ejemplo: Bogotá
    </ParamField>

    <ParamField body="country" type="enum">
      El país considerado para la dirección de envío (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

      Valores posibles del enum: consulta la <a href="/reference/country-reference">referencia de países</a>.
    </ParamField>

    <ParamField body="state" type="string">
      El estado considerado para la dirección de envío (MAX 255; MIN 3; <a href="https://en.wikipedia.org/wiki/ISO_3166-2">ISO 3166-2</a> ).

      Ejemplo: Cundinamarca
    </ParamField>

    <ParamField body="zip_code" type="string">
      El código postal considerado para la dirección de envío (MAX 10; MIN 5).

      Ejemplo: 111111
    </ParamField>

    <ParamField body="neighborhood" type="string">
      El barrio de la línea de dirección del cliente (MAX 255; MIN 2)

      Ejemplo: Barrio 11
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="metadata" type="array of objects">
  Especifica una lista de pares de clave y valor personalizados asociados al cliente (para referencias internas, segmentación o etiquetas de flujo de trabajo). Puedes agregar hasta 50 objetos de metadata.

  <Expandable title="propiedades">

    <ParamField body="metadata object" type="object">
      Especifica una clave de metadata y su valor correspondiente.

      Úsalo para adjuntar contexto definido por el comercio (por ejemplo: `crm_id`, `segment`). Evita enviar datos sensibles o personales.

      <Expandable title="propiedades">

        <ParamField body="key" type="string">
          Especifica una clave de metadata.

          Ejemplo: age
        </ParamField>

        <ParamField body="value" type="string">
          Especifica el valor de la clave de metadata definida.

          Ejemplo: 28
        </ParamField>

      </Expandable>
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="created_at" type="timestamp">
  Fecha y hora de creación del cliente (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="updated_at" type="timestamp">
  Fecha y hora de la última actualización del cliente (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>
