---
title: "Crear cliente"
openapi: "/openapi/es/customers/create-customer.json POST /customers"
description: "Crea un recurso de cliente con datos personales, de facturación y de envío para iniciar el checkout"
---

Esta solicitud crea un recurso de cliente. Debes proporcionar varios parámetros del cliente en el cuerpo de la solicitud, entre ellos el identificador único del cliente en el comercio externo, la información personal y las direcciones de facturación y de envío.

Al crear un cliente se genera un `id` de cliente que puedes usar para iniciar el checkout.

<Note>
**`merchant_customer_id` tiene alcance de organización, no de cuenta**

Si tu organización tiene varias cuentas, `merchant_customer_id` debe ser único entre todas ellas. Si creas un cliente desde una cuenta con un id que ya usa otra cuenta de la misma organización, se devuelve `CUSTOMER_ID_DUPLICATED`. Consulta [Cuentas](/es/docs/using-yuno/organization/accounts#customers-and-payment-methods-are-organization-scoped) para saber cómo estructurar los ids si gestionas varias empresas dentro de una organización.
</Note>

<Warning>
**Importante**

Hay ciertos objetos que no son obligatorios al crear un "cliente". Sin embargo, cuanta más información proporciones, más puede ayudar a mejorar las tasas de aprobación, conversión y prevención del fraude.
</Warning>
