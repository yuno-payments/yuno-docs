Obtén un método de pago específico en el que un usuario se ha inscrito.

<Note>
**Obtener método de pago inscrito**

Para recuperar la información del método de pago inscrito, debes proporcionar el `payment_method_id`, que es el `vaulted_token` recibido al usar el endpoint [Inscribir método de pago](/es/reference/payment-methods-direct-workflow/enroll-payment-method-api).
</Note>
