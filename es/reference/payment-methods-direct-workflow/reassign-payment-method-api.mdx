Reasigna un método de pago inscrito a un cliente distinto de la misma cuenta. Envía el `customer_id` del cliente de destino en el cuerpo de la solicitud. Solo se pueden reasignar métodos de pago de tipo tarjeta. La respuesta devuelve el método de pago con la misma estructura que la respuesta de [Enroll Payment Method](/reference/enroll-payment-method-api), con el nuevo propietario en el campo `customer_id`.

<Note>
Para reasignar el método de pago, debes proporcionar el `payment_method_id`, que es el `vaulted_token` recibido al usar el endpoint [Enroll Payment Method](/reference/enroll-payment-method-api).
</Note>

Un método de pago que ya está asignado a un cliente que tiene datos no se puede reasignar, y la solicitud se rechaza con `409 CONFLICT`.

<Warning>
Después de reasignar un método de pago, el comercio es responsable de actualizar el identificador del cliente en todos los lugares donde ya se usó el método de pago. Esto incluye cualquier suscripción creada con él, el mapeo propio del comercio entre un usuario y el `vaulted_token`, y cualquier par almacenado de cliente y método de pago. Yuno reasigna el método de pago al nuevo cliente, pero no actualiza esas referencias del lado del comercio.
</Warning>
