description: "Registra hasta 100 tarjetas almacenadas en Card Account Updater en una sola solicitud"
---

Registra un lote de tarjetas ya almacenadas en [Card Account Updater](/es/docs/additional-services/card-account-updater), para que sus datos se mantengan actualizados automáticamente. Envía los ids de los métodos de pago (el `vaulted_token` recibido al inscribir cada tarjeta) en una sola solicitud.

<Note>
**Cómo funciona el registro**

- Puedes registrar entre **1 y 100** tarjetas por solicitud; cada id debe ser un `vaulted_token` válido.
- La validación es **todo o nada**: si algún id no es válido, se rechaza toda la solicitud.
- El registro se ejecuta de forma **asíncrona**. Una respuesta `200` con `accepted` confirma que las tarjetas fueron aceptadas, no que la actualización ya se haya realizado; las actualizaciones se notifican más tarde mediante el webhook de inscripción.
- Card Account Updater se habilita por organización. Si tu organización no está inscrita, la solicitud devuelve `400` con `code: BAD_REQUEST` y el mensaje `organization is not enrolled in account updater.`
</Note>
