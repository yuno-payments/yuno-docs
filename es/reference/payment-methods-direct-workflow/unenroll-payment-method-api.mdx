---
title: "Cancelar inscripción de método de pago"
openapi: "/openapi/es/payment-methods-direct-workflow/unenroll-payment-method-api.json POST /customers/{customer_id}/payment-methods/{payment_method_id}/unenroll"
description: "Cancela la inscripción de un método de pago guardado de un cliente y establece su estado en UNENROLLED"
---

Cancela la inscripción de un método de pago guardado del usuario. Una vez que hagas el POST al endpoint de cancelación de inscripción, el estado del método de pago cambiará a UNENROLLED.

<Note>
**Información sobre la cancelación de inscripción**

Para cancelar la inscripción del método de pago, debes proporcionar el `payment_method_id`, que es el `vaulted_token` recibido al usar el endpoint [Inscribir método de pago](/reference/enroll-payment-method-api).
</Note>
