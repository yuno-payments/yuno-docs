title: "Obtener método de pago inscrito por ID con datos PCI"
openapi: "/openapi/es/payment-methods-direct-workflow/retrieve-enrolled-payment-method-by-id-pci-api.json GET /customers/{customer_id}/payment-methods/{payment_method_id}"
description: "Obtiene un método de pago inscrito, incluido el número completo de la tarjeta, solo para comercios PCI"
---

Obtén un método de pago específico en el que un usuario se ha inscrito, incluido el número completo de la tarjeta en la respuesta.

<Note>
**Obtener método de pago inscrito**

Para obtener la información del método de pago inscrito, debes proporcionar el `payment_method_id`, que es el `vaulted_token` recibido al usar el endpoint [Inscribir método de pago](/es/reference/payment-methods-direct-workflow/enroll-payment-method-api).
</Note>

<Warning>
**Solo para comercios PCI**

Este endpoint solo está disponible para comercios con certificación PCI. Para habilitarlo, contacta a tu Key Account Manager (KAM).
</Warning>
