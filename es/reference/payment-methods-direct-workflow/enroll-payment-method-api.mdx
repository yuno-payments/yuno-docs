---
title: "Inscribir un método de pago"
openapi: "/openapi/es/payment-methods-direct-workflow/enroll-payment-method-api.json POST /customers/{customer_id}/payment-methods"
description: "Inscribe el método de pago de un cliente y devuelve un token almacenado para uso futuro"
---

Esta solicitud inscribe un método de pago para un cliente. Con la información que Yuno proporciona después de que el cliente selecciona el método de pago a inscribir, podrás guardar esa información para compras futuras usando el objeto de método de pago creado.

Consulta los [métodos de pago disponibles en Yuno](/es/reference/payment-type-list). Deberás configurar tus credenciales para cada método de pago en el dashboard de Yuno para poder usarlos.

Ten en cuenta que esta solicitud requiere un `X-Idempotency-Key`. Consulta la página [Authentication](/reference/authentication#idempotency) para más información.

<Note>
**Webhooks**

Recomendamos escuchar [Webhooks](/docs/configure-webhooks) para mantenerte al día con el estado de los métodos de pago inscritos de tus clientes.
</Note>

Si un cliente inscribe la misma tarjeta varias veces, Yuno crea una nueva inscripción cada vez y devuelve un `vaulted_token` distinto. Usa el `fingerprint` de la tarjeta en la respuesta de la inscripción para detectar duplicados de tu lado (el fingerprint puede ser `null` para algunos proveedores). Consulta [Card Fingerprint](/docs/fingerprint).

<Warning>
**Disponible solo para comercios certificados en PCI.**
</Warning>
