## Atributos {#attributes}

Este objeto representa un método de pago que se puede asociar con un cliente para pagos back-to-back.

<ParamField body="id" type="string">
  El identificador único del método de pago (MAX 64; MIN 36).

  Ejemplo: 693ed90e-5aa9-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="name" type="string">
  El nombre del método de pago (MAX 255; MIN 3).

  Ejemplo: CARD
</ParamField>

<ParamField body="description" type="string">
  La descripción del método de pago (MAX 255; MIN 3).

  Ejemplo: CARD
</ParamField>

<ParamField body="type" type="enum">
  El tipo de método de pago (MAX 255; MIN 3).

  Valores posibles del enum: consulta la <a href="/es/reference/payment-type-list">
              lista de tipos de pago</a>.
</ParamField>

<ParamField body="category" type="enum">
  La categoría del método de pago (MAX 255; MIN 3).

  Ejemplo: CARD
</ParamField>

<ParamField body="country" type="enum">
  El país del cliente (MAX 2; MIN 2; <a href="/es/reference/country-reference">ISO 3166-1</a> ).

  Valores posibles del enum: consulta la <a href="/es/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="last_successfully_used" type="bool">
  Indica si el método de pago inscrito fue el último que el cliente usó con éxito ).

  Ejemplo: True
</ParamField>

<ParamField body="last_successfully_used_at" type="timestamp">
  Indica la fecha del último pago exitoso si el método de pago inscrito fue el último que el cliente usó
          con éxito ).

  Ejemplo: "2023-01-24T12:50:43.938087Z"
</ParamField>

<ParamField body="workflow" type="enum">
  El flujo de pago indica si la integración usará el SDK de Yuno o será una conexión back to back.

  Valores posibles del enum: si es `CHECKOUT`, usarás el SDK de Yuno. Si es `DIRECT`,
            usarás una integración back-to-back.
</ParamField>

<ParamField body="card_data" type="object">
  Especifica los detalles de la tarjeta.

  <Expandable title="propiedades">

    <ParamField body="iin" type="integer">
      El número de identificación del emisor (IIN) corresponde a los primeros dígitos del número de la tarjeta de pago emitida por una institución financiera (MAX 8; MIN 6).

      Ejemplo: 45079900
    </ParamField>

    <ParamField body="lfd" type="integer">
      Los últimos cuatro dígitos de la tarjeta (MAX 4; MIN 4).

      Ejemplo: 0010
    </ParamField>

    <ParamField body="expiration_month" type="integer">
      El mes de vencimiento de la tarjeta (MAX 2; MIN 2), solo disponible para comercios con certificación PCI.

      Ejemplo: 12
    </ParamField>

    <ParamField body="expiration_year" type="integer">
      El año de vencimiento de la tarjeta (MAX 2; MIN 2), solo disponible para comercios con certificación PCI.

      Ejemplo: 12
    </ParamField>

    <ParamField body="number_length" type="integer">
      La longitud del número de la tarjeta (MAX 19; MIN 8).

      Ejemplo: 41961111
    </ParamField>

    <ParamField body="security_code_length" type="integer">
      La longitud del código de seguridad de la tarjeta (MAX 4; MIN 3).

      Ejemplo: 123
    </ParamField>

    <ParamField body="brand" type="string">
      La información de la marca de la tarjeta (MAX 255; MIN 3).

      Ejemplo: VISA
    </ParamField>

    <ParamField body="issuer" type="string">
      El emisor de la tarjeta (MAX 255; MIN 3).

      Ejemplo: Banco Galicia
    </ParamField>

    <ParamField body="category" type="string">
      La categoría del emisor de la tarjeta (MAX 255; MIN 3).

      Ejemplo: Gold
    </ParamField>

    <ParamField body="type" type="string">
      El tipo del emisor de la tarjeta (MAX 255; MIN 3).

      Ejemplo: CREDIT, DEBIT, or PREPAID
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  URL a la que se devuelve al cliente después de una inscripción en el entorno de un proveedor. Solo es necesaria para integraciones de métodos de pago alternativos (MAX: 64; MIN: 36).

  Ejemplo: https://www.company.com/customer_1231324
</ParamField>

<ParamField body="verify" type="object">
  Indica si se debe verificar el pago con una transacción de verificación o no. Necesitarás tener un proveedor definido en tu ruta CARD.

  <Expandable title="propiedades">

    <ParamField body="vault_on_success" type="boolean">
      Indica si se debe verificar el pago con una transacción de verificación o no. False por defecto.
    </ParamField>

    <ParamField body="currency" type="enum">
      Moneda de la verificación de la tarjeta.(MAX 3; MIN 3; <a href="/es/reference/country-reference">ISO 4217</a> ).

      Valores posibles del enum: consulta la <a href="/es/reference/country-reference">referencia de países</a>.
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="status" type="enum">
  El estado del método de pago (MAX 255; MIN 5).

  Valores posibles del enum: consulta el <a href="/es/reference/customer-sessions-enrollment/enrollment-workflow#payment-method-status">estado del método de pago</a>.
</ParamField>

<ParamField body="vaulted_token" type="string">
  El token almacenado del método de pago inscrito previamente (MAX 64; MIN 36).

  Ejemplo: 321c12f6-42c2-45b7-bf0c-f2f767b31948
</ParamField>

<ParamField body="created_at" type="timestamp">
  Fecha y hora de creación del método de pago (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO
            8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="updated_at" type="timestamp">
  Fecha y hora de la última actualización del método de pago (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>
