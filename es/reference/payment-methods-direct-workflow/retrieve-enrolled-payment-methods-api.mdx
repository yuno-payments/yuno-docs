---
title: "Obtener métodos de pago inscritos"
openapi: "/openapi/es/payment-methods-direct-workflow/retrieve-enrolled-payment-methods-api.json GET /customers/{customer_id}/payment-methods"
description: "Obtiene la lista de métodos de pago que un cliente ha inscrito"
---

Obtén la lista de métodos de pago que el usuario ha inscrito.

<Note>
  Los instrumentos almacenados mediante un CIT de Apple Pay o Google Pay (`vault_on_success: true`) no se incluyen en esta lista de forma intencional. El `vaulted_token` solo se devuelve en la respuesta de pago del CIT, por lo que debes guardarlo de tu lado. Un token de billetera almacenado aún se puede resolver con [Obtener método de pago inscrito por ID](/reference/retrieve-enrolled-payment-method-by-id-api). Consulta [Credenciales almacenadas](/es/docs/payment-features/stored-credentials#wallet-originated-tokens-apple-pay-and-google-pay).
</Note>

<Note>
  Este endpoint tiene alcance de organización: devuelve los métodos de pago inscritos del cliente sin importar desde qué cuenta lo llames, no solo la cuenta usada para inscribirlos. Consulta [Cuentas](/es/docs/using-yuno/organization/accounts#customers-and-payment-methods-are-organization-scoped) para saber por qué, y qué hacer si tu organización gestiona varias empresas que necesitan registros de clientes separados.
</Note>
