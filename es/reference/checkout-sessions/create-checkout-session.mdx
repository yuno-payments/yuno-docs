---
title: "Crear sesión de checkout"
openapi: "/openapi/es/checkout-sessions/create-checkout-session.json POST /checkout/sessions"
description: "Crea una sesión de checkout vinculada a un cliente, que se usa para iniciar un pago con el SDK"
---

Esta solicitud crea una sesión de checkout con el identificador único que se generó al crear el recurso `customer`.

<Note>
  Si tu workflow requiere enviar el objeto `additional_data`, puedes enviarlo como parte de la sesión de checkout.
</Note>
