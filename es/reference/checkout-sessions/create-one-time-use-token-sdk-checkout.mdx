Crea un token volátil de un solo uso para el procesamiento seguro de pagos dentro de una sesión de checkout.

## Marca de tarjeta no aceptada {#card-brand-not-accepted}

Cuando el checkout acepta solo algunas marcas de tarjeta ([Marcas de tarjeta](/es/docs/using-yuno/dashboard-overview/checkout-builder-new-payment-method-settings#card-brands) en el Checkout Builder) y la tarjeta es de otra marca para el país y la moneda de la sesión, la solicitud responde `400` con el código `CARD_BRAND_NOT_ACCEPTED` y no se crea ningún token. El mensaje nombra la marca de la tarjeta y las marcas aceptadas para la sesión, o `none` cuando no se acepta ninguna marca para su país y su moneda:

```json
{
  "code": "CARD_BRAND_NOT_ACCEPTED",
  "messages": ["Brand MASTERCARD is not accepted for this checkout session. Accepted: VISA"]
}
```

Una tarjeta co-badged pasa cuando se acepta cualquiera de sus redes. Pide al comprador una tarjeta de una marca aceptada.
