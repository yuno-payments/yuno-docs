---
title: "El objeto de sesión de checkout"
description: "Describe el objeto de sesión de checkout y sus atributos, incluidos el monto, el país y las cuotas"
---

Este objeto representa una sesión de checkout que se puede crear para realizar un pago. Puedes crear una sesión de checkout con el id generado cuando se creó el recurso Customer.

<Note>
  Crear una sesión de checkout solo es necesario para el flujo **SDK\_CHECKOUT**.\
  Solo se admite un pago por cada sesión de checkout.
  Una sesión de checkout expira 2.5 horas después de su creación. La expiración no se puede cambiar mediante la API, y actualizar una sesión de checkout no la extiende.\
  En el entorno de sandbox, una sesión de checkout expira 3.5 horas después de su creación.
</Note>

## Atributos {#attributes}

<ParamField body="checkout_session" type="string">
  El identificador único de la sesión de checkout (MAX 64; MIN 36).

  Ejemplo: 9104911d-5df9-429e-8488-ad41abea1a4b
</ParamField>

<ParamField body="customer_id" type="string">
  El identificador único del cliente (MAX 64; MIN 36).

  Ejemplo: 9104911d-5df9-429e-8488-ad41abea1a4b
</ParamField>

<ParamField body="merchant_order_id" type="string">
  El identificador único del pedido del cliente (MAX 255; MIN 3).

  Ejemplo: 1234
</ParamField>

<ParamField body="payment_description" type="string">
  La descripción del pago (MAX 255; MIN 3).

  Ejemplo: Purchase in Pepito market
</ParamField>

<ParamField body="callback_url" type="string">
  La URL a la que se redirige al cliente después del pago (MAX 526; MIN 3).

  Ejemplo: https://www.company.com/customer_1231324
</ParamField>

<ParamField body="country" type="enum">
  País donde se debe procesar la transacción (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Valores posibles del enum: consulta la <a href="/es/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="created_at" type="timestamp">
  Fecha y hora de creación de la sesión de checkout (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="amount" type="object">
  Especifica el objeto de monto del pago, con el valor y la moneda.

  <Expandable title="propiedades">

    <ParamField body="currency" type="enum">
      La moneda utilizada para realizar el pago (MAX 3; MIN 3; <a href="https://en.wikipedia.org/wiki/ISO_4217">ISO 4217</a> ).

      Valores posibles del enum: consulta la <a href="/es/reference/country-reference">referencia de países</a>.
    </ParamField>

    <ParamField body="value" type="float">
      El monto del pago (múltiplo de 0.0001).

      Ejemplo: 23.5676
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="metadata" type="array of objects">
  Especifica una lista de objetos de metadata. Puedes agregar hasta 50 objetos de metadata. Cuando una regla de enrutamiento tiene una condición de metadata, esta metadata decide qué métodos de pago y cuotas lista la sesión. El enrutamiento de pagos no la lee: define también la metadata en el pago o en el cliente.

  <Expandable title="propiedades">

    <ParamField body="metadata object" type="object">
      Especifica una clave de metadata y su valor correspondiente.

      <Expandable title="propiedades">

        <ParamField body="key" type="string">
          Especifica una clave de metadata (MAX 48).

          Ejemplo: age
        </ParamField>

        <ParamField body="value" type="string">
          Especifica el valor de la clave de metadata definida (MAX 512).

          Ejemplo: 28
        </ParamField>

      </Expandable>
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="installments" type="array of objects">
  [Opcional] El objeto para enviar el plan de cuotas creado en Yuno, para mostrarlo a los clientes y permitirles elegir. Este campo opcional se usa cuando se necesita un plan de cuotas particular en la sesión. Si no se envía, se muestra el plan de cuotas creado para la cuenta en cada escenario, si existe.

  <Expandable title="propiedades">

    <ParamField body="plan_id" type="string">
      Especifica un id de plan creado en Yuno para mostrar a tu cliente en la sesión de checkout. Si no se define, se usan los creados para la cuenta, si aplica (MAX 64; MIN 64).
    </ParamField>

    <ParamField body="plan" type="array of objects">
      Cuotas que se muestran al cliente con la checkout_session. Esta estructura opcional se usa cuando se necesita un plan de cuotas particular en la sesión y no tiene un plan de cuotas creado.

      <Expandable title="propiedades">

        <ParamField body="installment object" type="object">
          Especifica una cuota disponible para la sesión de checkout.

          <Expandable title="propiedades">

            <ParamField body="installment" type="int">
              El número de cuotas mensuales que pueden elegir los compradores

              Ejemplo: 3
            </ParamField>

            <ParamField body="rate" type="float">
              La tasa que ve el usuario final en el checkout.

              Ejemplo: 1.5
            </ParamField>

          </Expandable>
        </ParamField>

      </Expandable>
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="wallet_card_acceptance" type="object">
  [Opcional] Limita qué tarjetas puede seleccionar el cliente en la hoja de pago de Apple Pay. Las tarjetas que no coinciden se muestran en gris. Todos los campos son opcionales; un campo que no se envía mantiene el comportamiento predeterminado. Solo se puede definir cuando se crea la sesión de checkout. Consulta [Filtrar tarjetas elegibles](/es/docs/wallets/apple-pay/sdk-integration/card-filters-and-good-to-know#filter-eligible-cards).

  <Expandable title="propiedades">

    <ParamField body="supported_countries" type="array of strings">
      Países que emitieron la tarjeta (<a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> alpha-2, en mayúsculas). Es el país emisor de la tarjeta, no la ubicación del cliente.

      Ejemplo: ["BR"]
    </ParamField>

    <ParamField body="supported_networks" type="array of strings">
      Redes de tarjetas que el cliente puede seleccionar, en mayúsculas. Reemplaza la lista predeterminada.

      Ejemplo: ["VISA", "MASTERCARD"]
    </ParamField>

    <ParamField body="supported_funding_types" type="array of enum">
      Tipos de fondeo que el cliente puede seleccionar.

      Valores posibles del enum: `CREDIT`, `DEBIT`.
    </ParamField>

  </Expandable>
</ParamField>
