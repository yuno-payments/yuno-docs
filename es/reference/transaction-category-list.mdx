---
title: "Categoría de transacción"
description: "Lista las categorías de transacción que Yuno usa para agrupar los métodos de pago"
---

Yuno organiza los métodos de pago disponibles en distintas categorías de transacción. En esta página encontrarás todas las categorías de transacción que se usan en la API de Yuno y sus descripciones. Ten en cuenta que cada método de pago está asociado a una de estas categorías de transacción.

| Categoría de transacción | Descripción                                        |
| -------------------- | -------------------------------------------------- |
| `BANK_TRANSFER`       | Transferencia bancaria.                                     |
| `CARD`                | Tarjetas.                                             |
| `BNPL`                | Compra ahora y paga después.                                     |
| `WALLET`              | Pagos con billetera.                                     |
| `TICKET`              | Pagos en efectivo.                                    |
| `PAYMENT_LINK`        | Enlaces de pago que aceptan varios métodos de pago. |

Para acceder a la lista de métodos de pago disponibles en la API de Yuno, consulta la página [Tipo de pago](/es/reference/payment-type-list).
