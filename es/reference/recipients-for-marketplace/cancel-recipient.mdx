---
title: "Cancelar onboarding"
openapi: "/openapi/es/recipients-for-marketplace/cancel-recipient.json POST /recipients/{recipient_id}/onboardings/{onboarding_id}/cancel"
description: "Cancela el onboarding de un destinatario antes de que se complete con un proveedor"
---

Cancela un onboarding de un destinatario.

Un onboarding en estado `SUCCEEDED`, `BLOCKED`, `CANCELLED`, `INACTIVE`, `TRANSFERRED` o `TERMINATED` no se puede cancelar, y la API devuelve `400 INVALID_STATE`. Un onboarding cancelado es definitivo. Para volver a hacer el onboarding del destinatario con el proveedor, crea un nuevo onboarding.
