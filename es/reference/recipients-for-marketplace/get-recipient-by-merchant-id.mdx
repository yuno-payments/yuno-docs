---
title: "Obtener destinatario por ID de comercio"
openapi: "/openapi/es/recipients-for-marketplace/get-recipient-by-merchant-id.json GET /recipients"
description: "Obtiene un único destinatario usando el identificador asignado por tu organización."
---

Usa `GET /v1/recipients?merchant_recipient_id=...` para buscar un destinatario por tu ID de destinatario de comercio. La búsqueda se limita a tu organización y no requiere `account_id`.

Una solicitud exitosa devuelve un objeto de destinatario de nivel superior. Si ningún destinatario coincide, el endpoint devuelve HTTP `400` con el código `RECIPIENT_NOT_FOUND`. El parámetro de consulta `merchant_recipient_id` es obligatorio.

Este endpoint mantiene su comportamiento actual. Las integraciones existentes que lo usan para buscar un destinatario no necesitan cambios.

Para una colección paginada, usa [Listar destinatarios](/es/reference/recipients-for-marketplace/list-recipients) en `GET /v1/recipients/list`. Ese endpoint devuelve un arreglo `data` y `pagination`, incluido un arreglo vacío cuando ningún destinatario coincide. Las integraciones o tareas cron que necesiten una lista deben usar `/list`.

Para buscar un destinatario por su ID de Yuno, usa [Obtener destinatario](/es/reference/recipients-for-marketplace/get-recipient).
