Obtiene información detallada sobre un onboarding específico de un destinatario.

Este endpoint obtiene información detallada sobre un onboarding específico de un destinatario en el [marketplace de pagos con split](/docs/split-payments-marketplace). Usa este endpoint para consultar el estado actual, la configuración y los detalles de un onboarding existente.

Este endpoint requiere un onboarding existente creado mediante [Create Onboarding](/reference/create-onboarding).
