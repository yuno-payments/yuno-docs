description: "Lista los valores enum que identifican el motivo de un payout"

En esta página encontrarás la lista de propósitos disponible en el sistema de Yuno. La información de propósito se usa para identificar el motivo del payout. La siguiente tabla incluye todos los valores ENUM aceptados para el propósito del payout.

<div className="code-nowrap-table dense-table">

| Propósito disponible           | Descripción                                          |
| :----------------------------- | :--------------------------------------------------- |
| `FAMILY_AND_FRIENDS`           | Manutención o transferencia a familiares y amigos.              |
| `PERSONAL_TRANSFER`             | Transferencia personal                                    |
| `REMITTANCES`                    | Remesas                                          |
| `PROVIDER_SERVICES`             | Payout por servicios generales del proveedor.                |
| `ADVERTISING_SERVICES`          | Payout por servicios de publicidad del proveedor.            |
| `REPRESENTATION_SERVICES`       | Payout por servicios de representación del proveedor.         |
| `ADVISORY_SERVICES`             | Payout por servicios de asesoría del proveedor.               |
| `FREELANCER_SERVICES`           | Payout por servicios de freelance del proveedor.             |
| `SUPPLIER`                       | Pagos a proveedores de suministros.                                   |
| `BUSINESS_TO_BUSINESS`         | Business to Business (entre empresas).                                |
| `MARKETPLACE`                    | Payout por compras en el marketplace.                    |
| `PAYROLL`                        | Payout por servicios de pago de nómina.                 |
| `GIFTS_AND_BENEFITS`           | Payout por regalos y beneficios.                        |
| `EXPENSES`                       | Payout por gastos generales del proveedor.                |
| `CORPORATE_PAYMENT`             | Payout por pagos corporativos.                       |
| `PURCHASE_OF_PHYSICAL_GOODS`  | Payout por la compra de bienes físicos.               |
| `PURCHASE_OF_DIGITAL_GOODS`   | Payout por la compra de bienes digitales.                |
| `PURCHASE_OF_SERVICES`         | Payout por la compra de servicios generales.             |
| `CAPITAL_CONTRIBUTION`          | Payout por aporte de capital.                     |
| `INVESTMENTS`                    | Payout de una inversión adeudada a una entidad financiera.  |
| `INVESTMENTS_SHARES`            | Payout de participaciones de inversión.                         |
| `TAXES`                          | Pago de impuestos.                                    |
| `LOGISTICS_AND_TRANSPORTATION` | Payout por servicios de logística y transporte.    |
| `DELIVERY`                       | Payout por servicios de entrega.                        |
| `AFFILIATION_PROGRAM`           | Programas de afiliación.                                |
| `LOANS`                          | Payout por la liquidación de préstamos.                         |
| `REAL_STATE`                    | Payout por la compra de bienes inmuebles y gastos generales. |
| `RENT`                           | Pago del alquiler de una propiedad.                        |
| `TRAVEL_FLIGHTS`                | Pago de boletos de viaje o agencias de turismo.       |
| `TRAVEL_ACCOMMODATIONS`         | Pago de alojamientos de viaje.                    |
| `EDUCATION`                      | Payout por costos de educación.                          |
| `TRAININGS`                      | Payout por costos de capacitación.                           |
| `TUITION_COSTS`                 | Payout por costos de estudios o matrícula.                      |
| `CHARITY`                        | Payout por donaciones benéficas.                        |
| `MEDICAL_SERVICES`              | Payout por servicios de atención médica.                    |
| `SAVINGS`                        | Payout por ahorros.                                  |
| `RETIREMENT`                     | Payout por cuenta de jubilación.                       |
| `PENSION`                        | Payout con fines de pensión.                         |
| `INSURANCE`                      | Pago de seguros.                               |
| `REWARDS`                        | Payout con fines de recompensas.                         |
| `TRADEMARKS_AND_COPYRIGHT`     | Payout por regalías de marcas y derechos de autor.          |
| `ENTERTAINMENT`                  | Payout por servicios de entretenimiento.                   |
| `GOVERNMENT`                     | Servicios públicos o gubernamentales.                          |
| `OTHERS`                         | Otros propósitos de payout.                               |

</div>
