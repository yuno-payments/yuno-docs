## Atributos {#attributes}

Este objeto representa un enlace de pago que se puede asociar con un cliente.

<ParamField body="id" type="string">
  El identificador único del enlace de pago (MAX 64; MIN 36).

  Ejemplo: 8546df3a-b83e-4bb5-a4b3-57aa6385924f
</ParamField>

<ParamField body="account_id" type="string">
  El identificador único de la cuenta (MAX 64; MIN 36).

  Ejemplo: 9104911d-5df9-429e-8488-ad41abea1a4b
</ParamField>

<ParamField body="description" type="string">
  La descripción del enlace de pago (MAX 255; MIN 3).

  Ejemplo: Marketplace payment
</ParamField>

<ParamField body="country" type="enum">
  País donde se debe procesar la transacción (MAX 2; MIN 2; <a href="/es/reference/country-reference">ISO 3166-1</a> ).

  Valores posibles del enum: Consulta la <a href="/es/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="status" type="enum">
  El estado del enlace de pago (MAX 255; MIN 3) (CREATED, USED, CANCELED, EXPIRED, ERROR).

  Ejemplo: CREATED
</ParamField>

<ParamField body="merchant_order_id" type="string">
  Identificación del enlace de pago (MAX 255; MIN 3).

  Ejemplo: 432245
</ParamField>

<ParamField body="created_at" type="timestamp">
  La fecha y hora en que se creó el enlace de pago.

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="updated_at" type="timestamp">
  La fecha y hora de la última actualización del enlace de pago.

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="capture" type="boolean">
  Decide si se autoriza el pago o se captura. Autorizar un pago con tarjeta permite reservar
          fondos en la cuenta bancaria de un cliente. Si no se envía el campo, se tomará como true. Más adelante puedes capturar el
          pago desde el dashboard de Yuno o con el <a href="/es/reference/payments/capture-authorization">método de la API</a> .

  Ejemplo: true
</ParamField>

<ParamField body="amount" type="object">
  Especifica el objeto del monto del pago, con el valor y la moneda.

  <Expandable title="propiedades">

    <ParamField body="currency" type="enum">
      La moneda utilizada para realizar el pago (MAX 3; MIN 3; <a href="/es/reference/country-reference">ISO 4217</a> ).

      Valores posibles del enum: Consulta la <a href="/es/reference/country-reference">referencia de países</a>.
    </ParamField>

    <ParamField body="value" type="number">
      El monto del pago (múltiplo de 0.0001).

      Ejemplo: 12100.00
    </ParamField>

  </Expandable>
</ParamField>
