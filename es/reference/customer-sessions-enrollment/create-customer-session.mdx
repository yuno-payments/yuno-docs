---
title: "Crear sesión de cliente"
openapi: "/openapi/es/customer-sessions-enrollment/create-customer-session.json POST /customers/sessions"
description: "Crea una sesión de cliente para inscribir y gestionar métodos de pago guardados para uso futuro"
---

Crea una sesión de cliente para inscribir y gestionar métodos de pago. Úsala para guardar tarjetas, billeteras y otros métodos de pago para uso futuro. Requiere un `customer_id` de [Crear cliente](/es/reference/customers/create-customer).
