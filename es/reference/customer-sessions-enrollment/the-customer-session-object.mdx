## Atributos {#attributes}

Este objeto representa una sesión de cliente que se puede crear para inscribir los métodos de pago de un cliente.

<ParamField body="customer_session" type="string">
  La sesión de cliente que se ha creado para la inscripción (MAX 64; MIN 36).

  Ejemplo: fe50d39a-5a1c-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="customer_id" type="string">
  El identificador único del cliente (MAX 64; MIN 36).

  Ejemplo: 3956053c-5a1d-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="country" type="enum">
  El país del cliente (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Posibles valores del enum: consulta la <a href="/es/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="callback_url" type="string">
  La URL a la que redirigir a tu cliente después de que la inscripción se realice en el entorno del proveedor (MAX 526; MIN 3).

  Ejemplo: www.your-url.com
</ParamField>

<ParamField body="created_at" type="timestamp">
  Fecha y hora de creación de la sesión de cliente (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="checkout_id" type="string">
  El identificador único del Custom Checkout usado para esta sesión de inscripción.

  Ejemplo: 6822f80c-684e-41a3-8628-78963d3d60f7
</ParamField>
