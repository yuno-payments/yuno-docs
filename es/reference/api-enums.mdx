Esta página es la **fuente única de verdad (SSOT)** de todos los enums e identificadores clave de la plataforma Yuno. Reunir estos valores aquí garantiza la coherencia, agiliza el desarrollo con la API y ofrece a los desarrolladores un lugar centralizado para consultar los parámetros válidos de todos los endpoints.

## Identificadores principales de la API {#core-api-identifiers}

Estos son los identificadores estándar principales que se usan en Yuno para el enrutamiento de transacciones, el procesamiento de métodos de pago y la selección de la estrategia de integración.

<Note>
  Para consultar una correspondencia exhaustiva, por categoría, de qué **Payment Method Types** admite cada **Provider**, consulta directamente el completo [Catálogo de pagos](/es/reference/payment-type-list). Las tablas de abajo sirven como referencias planas para consultar los valores de cada parámetro enum.
</Note>

### Flujo de inscripción (`type_of_enrollment_flow`) {#enrollment-flow-typeofenrollmentflow}

Define la estrategia de integración que se usa al inscribir nuevos métodos de pago de los clientes.

<div className="code-nowrap-table dense-table">

| Valor | Descripción |
| :--- | :--- |
| `SDK_FULL` | Flujo de inscripción completo gestionado por Yuno SDK. |
| `SDK_LITE` | Flujo de inscripción ligero con control parcial de la interfaz. |
| `SDK_HEADLESS` | Flujo de inscripción headless para personalizar por completo la interfaz. |
| `DIRECT_API` | Inscripción mediante llamadas directas a la API (servidor a servidor). |

</div>
