---
title: "Actualizar una disputa de contracargo"
openapi: "/openapi/es/payments/update-dispute.json PATCH /payments/{payment_id}/transactions/{transaction_id}/dispute"
description: "Actualiza una disputa de contracargo existente con evidencia adicional o información de estado."
---

Este endpoint te permite agregar evidencia adicional a una disputa existente después de haberla enviado. Usa este endpoint cuando necesites aportar documentación complementaria para respaldar tu caso de disputa.

El pago ya debe tener una transacción de tipo `CHARGEBACK` en estado `CREATED` o `ADDITIONAL_INFORMATION_REQUIRED`. De lo contrario, la API responde 400 `INVALID_TRANSACTION`. El cuerpo de la solicitud contiene solo el arreglo `evidence`.

<Info>
**Importante**

* **Estado del contracargo**: actualizar la evidencia no cambia el estado del contracargo. El estado del contracargo permanece igual, sin importar si se agrega evidencia adicional.
* **Soporte del proveedor**: no todos los proveedores de pago admiten actualizar las disputas después de haberlas enviado. Si un proveedor no admite actualizaciones, el endpoint devolverá un error controlado con un código de error en UPPER\_SNAKE\_CASE (por ejemplo, `UPDATE_NOT_SUPPORTED`), y el estado del contracargo permanecerá igual.
* **Manejo de errores**: si recibes un error 404 que indica que el proveedor no admite el flujo de actualización, el estado del contracargo permanecerá igual, y recibirás una respuesta de error controlado con un código y un mensaje de error descriptivos.
</Info>

<Note>
**Requisitos de la evidencia**

Los archivos cargados deben cumplir los siguientes criterios:

*Formato*: el archivo debe estar en formato PDF, codificado en base64.\
*Tamaño*: el archivo no debe pesar más de 1 MB.\
*Idioma*: la disputa debe estar redactada en inglés o en el idioma local del país.
</Note>
