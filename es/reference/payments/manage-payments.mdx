La API de Payments te permite crear y gestionar pagos a través de Yuno. Aquí encontrarás detalles sobre los formatos de solicitud y respuesta, los endpoints disponibles, los objetos comunes y ejemplos de payloads. Usa esta referencia para entender los flujos de trabajo, el manejo de estados y cómo integrar pagos sin complicaciones en tu aplicación. Para reembolsar un pago, consulta [Refund payments](/es/docs/direct-integration-use-cases/refund-payments) y la API [Refund payment](/es/reference/payments/refund-payment).
