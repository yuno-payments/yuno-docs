---
title: "Capturar autorización"
openapi: "/openapi/es/payments/capture-authorization.json POST /payments/{payment_id}/transactions/{transaction_id}/capture"
description: "Captura un pago previamente autorizado, de forma parcial o total según el proveedor."
---

<Warning>
No ejecutes una captura mientras otra está en curso. Espera a que la operación actual termine antes de iniciar una nueva.
</Warning>

Esta solicitud captura un pago que fue autorizado previamente. Esta acción es necesaria para finalizar un pago cuando una autorización se creó con la opción de captura en `false`. Según el proveedor de pago, la captura puede ser parcial (incluidas varias capturas) o total. El `amount` es opcional: si lo omites, la API captura el monto autorizado completo. Una captura mayor que la autorización se envía al proveedor, que decide si la acepta.

<Note>
**Pagos con una promoción de Yuno**

El monto autorizado es lo que paga el cliente, `amount.value` menos `discount_amount`, por lo que una captura completa toma ese monto y `payment.amount.captured` lo refleja. Consulta [Promotions](/docs/payment-features/promotions#refunds-captures-and-cancellations).
</Note>

Si la autorización se aumentó con [autorizaciones incrementales](/es/reference/payments/increment-authorization), un `amount` explícito puede liquidar hasta el total aumentado, y una captura sin `amount` liquida la retención actual completa de la transacción: el monto autorizado original más todos los incrementos exitosos de esa transacción.

Ten en cuenta que esta solicitud requiere un `X-Idempotency-Key`. Consulta la página [Authentication](/reference/authentication#idempotency) para obtener más información.
