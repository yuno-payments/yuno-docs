---
title: "Listar emisores"
openapi: "/openapi/es/payments/retrieve-issuers.json GET /issuers"
description: "Obtiene la lista de emisores compatibles con un método de pago específico."
---

Este endpoint obtiene una lista de todos los emisores compatibles con el método de pago específico. Te permite filtrar los emisores según su compatibilidad con un método de pago en particular.

La API responde 201 para cada `payment_method` excepto `PSE`, que responde 200. Por ejemplo, `country_code=CO&payment_method=NEQUI` responde 201 y `country_code=CO&payment_method=PSE` responde 200.
