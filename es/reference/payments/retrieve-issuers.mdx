title: "Obtener emisores"
openapi: "/openapi/es/payments/retrieve-issuers.json GET /issuers"
description: "Obtiene la lista de emisores compatibles con un método de pago específico."
---

Este endpoint obtiene una lista de todos los emisores compatibles con el método de pago específico. Te permite filtrar los emisores según su compatibilidad con un método de pago en particular.

La API responde 201 para cada `payment_method` excepto `PSE`, que responde 200. Por ejemplo, `country_code=CO&payment_method=NEQUI` responde 201 y `country_code=CO&payment_method=PSE` responde 200.

## Bancos en mantenimiento

Cuando programas una ventana de mantenimiento para un banco en el Dashboard, ese banco sigue en la lista, pasa al final y trae `"status": "OFFLINE"`. El campo `status` es opcional: no aparece en los bancos disponibles ni en ninguna parte de la respuesta cuando no hay bancos en mantenimiento.

No le ofrezcas al cliente un banco `OFFLINE`. Un pago creado con ese banco se rechaza con el código de respuesta [`BANK_UNAVAILABLE`](/es/reference/payments/status-and-response-codes/transaction#declined-status).

### En los SDK de Yuno

Yuno aplica la ventana en el servidor, así que el pago se rechaza con `BANK_UNAVAILABLE` en todos los SDK y versiones. No necesitas actualizar el SDK para que la ventana tenga efecto.

Lo que cambia según el SDK es cómo se ve la lista de bancos:

- **SDK Web 2.8.0 o posterior**: el banco aparece como no disponible, al final de la lista, y el cliente no puede elegirlo.
- **SDK de Android y de iOS**: el banco todavía no se marca. Se muestra como cualquier otro banco y el pago se rechaza si el cliente lo elige.
