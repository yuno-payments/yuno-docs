---
title: "El objeto de pago"
description: "Referencia de los campos del objeto de pago que se devuelven después de crear una sesión de checkout."
---

Este objeto representa el pago creado después de generar la sesión de checkout para un cliente. Para reembolsar un pago, consulta [Reembolsar pagos](/docs/refund-payments) y la API [Reembolsar pago](/reference/refund-payment).

<Note>
  **Metadatos y lógica de enrutamiento**

  Las reglas de enrutamiento leen los metadatos del pago, combinados con los metadatos de su cliente. Para definir la lógica de enrutamiento, establece metadatos en el pago o en el cliente. Los metadatos establecidos solo en la [sesión de checkout](/reference/the-checkout-session-object) no llegan al enrutamiento del pago; en la sesión, solo determinan qué métodos de pago y cuotas lista la sesión.
</Note>

<ParamField body="id" type="string">
  El identificador único del cliente (MAX 64 ; MIN 36).

  Ejemplo: 8546df3a-b83e-4bb5-a4b3-57aa6385924f
</ParamField>

<ParamField body="account_id" type="string">

  Ejemplo: 9104911d-5df9-429e-8488-ad41abea1a4b
</ParamField>

  La descripción del pago (MAX 255; MIN 3).

  Ejemplo: Purchase on web
</ParamField>

  País donde se debe procesar la transacción (MAX 2; MIN 2; <a href="/es/reference/country-reference">ISO 3166-1</a> ).

  Valores posibles del enum: consulta la <a href="/es/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="status" type="enum">
  El estado de la transacción.

  Ejemplo: SUCCEEDED
</ParamField>

<ParamField body="sub_status" type="enum">
  Es un complemento de la información del estado.

</ParamField>

  Ejemplo: 0000023
</ParamField>

</ParamField>

<ParamField body="updated_at" type="timestamp">

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="idempotency_key" type="string">
  opcional

  La clave de idempotencia enviada al crear el pago; está presente cuando el pago se creó con una clave de idempotencia.

  Ejemplo: fc0d89a1-8d18-4759-8d0a-ee1c6d0386e2
</ParamField>

<ParamField body="account_code" type="string">
  opcional

  El código de cuenta asociado al pago (identificador de la cuenta).

  Ejemplo: 26a6626c-d3ec-4caa-bf7c-a994b145dc00
</ParamField>

<ParamField body="payment_link_code" type="string">
  opcional

  Está presente cuando el pago se creó mediante un enlace de pago; identifica el enlace de pago utilizado.

  Ejemplo: (cadena vacía cuando no proviene de un enlace de pago)
</ParamField>

<ParamField body="subscription_code" type="string | null">
  opcional

  Está presente cuando el pago está asociado a una suscripción; el identificador de la suscripción.

  Ejemplo: null
</ParamField>

<ParamField body="plan_id" type="string">
  opcional

  El `id` del plan en el que estaba la suscripción cuando se creó este pago. Está presente solo en un pago creado con `subscription.plan_id` y en los pagos de renovación que Yuno genera para esa suscripción. Está ausente en cualquier otro pago. Consulta [Crear una suscripción a partir de un plan](/es/docs/payment-features/subscriptions/start-with-payment#create-a-subscription-from-a-plan).

  Ejemplo: 14898a9d-5a75-433d-ba17-f2ea5b33620c
</ParamField>

<ParamField body="plan_assigned_at" type="string">
  opcional

  Cuándo se asignó el plan a la suscripción, en UTC ([ISO 8601](https://en.wikipedia.org/wiki/ISO_8601)). Está presente solo en los pagos que incluyen `plan_id`.

  Ejemplo: 2026-09-24T22:53:42.814482Z
</ParamField>

<ParamField body="simplified_mode" type="boolean">
  opcional

  Indica si el pago se creó en modo simplificado (por ejemplo, en ciertos flujos como suscripción o reintento).

  Ejemplo: false
</ParamField>
