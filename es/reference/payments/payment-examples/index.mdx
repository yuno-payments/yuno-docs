---
title: "Ejemplos de pago"
description: "Explica los escenarios de métodos de pago que requieren información adicional del cliente dentro del flujo de checkout con el SDK."
---

Cuando usas el [SDK de Yuno](/docs/sdks/full-checkout/web-payments), nos encargamos de cada escenario particular que pueda tener cualquier método de pago. Una vez que el cliente selecciona el método de pago y elige pagar, si se necesita información adicional para procesar el pago (además de la que nos compartiste en la integración), mostraremos un formulario que le pide al cliente esa información. Algunos ejemplos de estos escenarios son:

* **Documento/teléfono**: Algunos métodos de pago alternativos requieren el documento o el número de teléfono del cliente, por lo que, si no tienes esa información en tu integración, la pediremos en el formulario mencionado para que no tengas que hacerlo tú.
* **PSE**: Este método de pago requiere que el cliente seleccione el banco que usará para realizar el pago, por eso le ofrecemos una lista de bancos para elegir.

<Note>
**Flujo `SDK_CHECKOUT`**

El flujo `SDK_CHECKOUT` te permite gestionar toda la experiencia de pago integrándote directamente con nuestras API. Según tus necesidades, puedes elegir entre los siguientes flujos:

* **Flujo DIRECT**: Adecuado para tarjetas (disponible solo para comercios que cumplen con PCI).
* **Flujo REDIRECT**: Ideal para métodos de pago alternativos.

Para ver ejemplos de pago detallados, consulta las secciones de cada categoría de método de pago.
</Note>

Para el flujo `SDK_CHECKOUT`, toda la información se almacena en el [`One-time token`](/es/docs/security-and-compliance/network-tokens#one-time-use-token-vs-vaulted-token-vs-network-token) devuelto por el SDK de Yuno, por lo que no tienes que cambiar tu integración según el método de pago. La estructura básica del pago es la misma para todos los métodos de pago, como en el ejemplo a continuación.

```sh Request (cURL)
curl --location 'https://api-sandbox.y.uno/v1/payments' \
--header 'X-Idempotency-Key: <your-X-idempotency-key>' \
--header 'public-api-key: <your-public-api-key>' \
--header 'private-secret-key: <your-private-secret-key>' \
--header 'Content-Type: application/json' \
--data '{
    "description": "SDK Checkout",
    "account_id": "<account_id>",
    "merchant_order_id": "123456",
    "merchant_reference": "reference_001",
    "country": "US",
    "amount": {
        "currency": "USD",
        "value": 100
    },
    "checkout": {
        "session": "<checkout_session>"
    },
    "customer_payer": {
        "id": "<customer_id>"
    },
    "payment_method": {
        "token": "<one_time_token>"
    }
}'
```
