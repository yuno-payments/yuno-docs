---
title: "Obtener planes de cuotas"
openapi: "/openapi/es/installments/get-installments-plan-by-account.json GET /installments-plans"
description: "Obtiene la lista de planes de cuotas configurados para una cuenta específica"
---

La API **Get Installments Plan** te permite obtener una lista de planes de cuotas asociados con una cuenta específica. Este endpoint ayuda a ver todos los planes disponibles vinculados a una cuenta, incluidas sus opciones de cuotas, límites y períodos de disponibilidad.

Usa esta API para obtener todos los planes de cuotas disponibles bajo un ID de cuenta determinado.
