---
title: "Crear un plan de cuotas"
openapi: "/openapi/es/installments/create-installments-plan.json POST /installments-plans"
description: "Crea un plan de cuotas que define el rango de montos, el BIN de la tarjeta, la moneda y las reglas de disponibilidad"
---

Yuno te permite crear planes de cuotas para ofrecer a tus clientes. Estos planes pueden usarse según factores como el monto a pagar, la moneda y la tarjeta utilizada, como se describe a continuación:

* **Filtrado por rango de montos (obligatorio):** El sistema comprueba si el plan de cuotas es adecuado para el monto específico de tu transacción. Solo se consideran los planes que pueden manejar ese monto.
* **BIN de la tarjeta:** El sistema verifica si el BIN de tu tarjeta coincide con los permitidos para ciertos planes de cuotas. Si hay coincidencia, ese plan se considera.
* **Moneda específica:** Solo se consideran los planes que funcionan con la moneda que estás usando.
* **Disponibilidad del plan:** El sistema comprueba si el plan de cuotas está activo. Solo se consideran los planes que no han expirado y están disponibles.

<Note>
**Definir el ID del plan**

El `plan_id` solo es necesario cuando se aplica un plan de cuotas fijo que no cambia durante la compra. Si no se envía `installment.plan_id`, el SDK buscará automáticamente entre todos los planes de cuotas disponibles asociados a esa cuenta y seleccionará el que considere más adecuado. Debes incluir el `plan_id` para asegurar que se aplique un plan específico.
</Note>

<Note>
**Cuotas del comercio**

Este endpoint solo es necesario para la [integración de cuotas del comercio](/es/docs/payment-features/installments). Para las cuotas definidas por el proveedor, usamos el plan de cuotas definido por tu proveedor de pagos.
</Note>

Para las cuotas creadas por el comercio, también puedes especificar el plan para cada sesión de checkout usando el `plan_id` al [crear la sesión](/es/reference/checkout-sessions/create-checkout-session). Si no lo envías, usaremos el plan de cuotas que coincida con las condiciones establecidas para la sesión de checkout.
