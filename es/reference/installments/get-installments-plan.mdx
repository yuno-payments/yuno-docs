title: "Obtener plan de cuotas por ID"
openapi: "/openapi/es/installments/get-installments-plan.json GET /installments-plans/{installment_code}"
description: "Obtiene los detalles de configuración de un plan de cuotas específico mediante su código"
---

La API **Get Installments Plan** te permite obtener información detallada sobre un plan de cuotas existente. Esto incluye las opciones de cuotas del plan, la frecuencia de facturación, los límites de monto y otros detalles relevantes.

Usa este endpoint para obtener la configuración actual de un plan de cuotas específico.
