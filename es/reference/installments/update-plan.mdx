---
title: "Actualizar plan"
openapi: "/openapi/es/installments/update-plan.json PATCH /installments-plans/{installment_code}"
description: "Actualiza el estado, los detalles de las cuotas o el método de pago de un plan de cuotas existente"
---

La API **Update Plan** te permite modificar un plan existente, lo que te permite actualizar atributos como el estado del plan, los detalles de las cuotas y el método de pago asociado al plan.

Usa esta API para gestionar y ajustar los planes de cuotas después de su creación.
