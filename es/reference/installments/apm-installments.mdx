El endpoint `apm-installments` te permite obtener los planes de cuotas disponibles para métodos de pago alternativos (APM) específicos. Es especialmente útil para integraciones como NuPay, donde puedes querer presentar opciones de cuotas al cliente antes de finalizar el pago.

### Escenarios de uso {#usage-scenarios}

Según el flujo de tu integración, usarás este endpoint de forma distinta:

*   **Flujo de inscripción**: se usa cuando un cliente ya inscribió su cuenta de NuPay. Debes proporcionar el `vaulted_token` y el `id` del cliente.
*   **Modo 2FA (directo)**: se usa en integraciones directas donde recopilas los datos del cliente (email/documento) para iniciar un flujo de autenticación de dos factores.

<Note>
Actualmente este endpoint es específico de ciertos APM. Para las cuotas de tarjeta de crédito estándar, consulta la documentación de [Obtener plan de cuotas por ID](/es/reference/installments/get-installments-plan).
</Note>
