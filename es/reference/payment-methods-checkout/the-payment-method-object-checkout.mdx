## Atributos {#attributes}

Este objeto representa un método de pago que se puede asociar con un cliente.

<ParamField body="id" type="string">
  El identificador único del método de pago (MAX 64; MIN 36).

  Ejemplo: 693ed90e-5aa9-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="account_id" type="string">
  El identificador único de la cuenta (MAX 64; MIN 36).

  Ejemplo: 8caa8bf4-5aa9-11ed-9b6a-0242ac120002
</ParamField>

<ParamField body="name" type="string">
  El nombre del método de pago (MAX 255; MIN 3).

  Ejemplo: Mercado Pago - Wallet
</ParamField>

<ParamField body="description" type="string">
  La descripción del método de pago (MAX 255; MIN 3).

  Ejemplo: Mercado Pago - Wallet, the best!
</ParamField>

<ParamField body="type" type="enum">
  El tipo de método de pago (MAX 255; MIN 3).

  Valores posibles del enum: consulta la <a href="/es/reference/payment-type-list">
    lista de tipos de pago</a>.
</ParamField>

<ParamField body="category" type="string">
  La categoría del método de pago (MAX 255; MIN 3).

  Ejemplo: CARD
</ParamField>

<ParamField body="country" type="enum">
  El país del cliente (MAX 2; MIN 2; <a href="https://en.wikipedia.org/wiki/ISO_3166-1">ISO 3166-1</a> ).

  Valores posibles del enum: consulta la  <a href="/reference/country-reference">referencia de países</a>.
</ParamField>

<ParamField body="verify" type="object">
  Indica si se debe verificar el pago con una transacción de verificación o no. Necesitarás tener un proveedor definido en tu ruta CARD.

  <Expandable title="propiedades">

    <ParamField body="vault_on_success" type="boolean">
      Indica si se debe verificar el pago con una transacción de verificación o no. False por defecto.
    </ParamField>

    <ParamField body="currency" type="enum">
      Moneda de la verificación de la tarjeta.(MAX 3; MIN 3; <a href="https://en.wikipedia.org/wiki/ISO_4217">ISO 4217</a> ).

      Valores posibles del enum: consulta la <a href="/reference/country-reference">referencia de países</a>.
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="status" type="enum">
  Estado del método de pago (MAX 255; MIN 5).

  Valores posibles del enum: consulta el <a href="/es/reference/customer-sessions-enrollment/enrollment-workflow#payment-method-status">estado del método de pago</a>.
</ParamField>

<ParamField body="created_at" type="timestamp">
  Fecha y hora de creación del método de pago (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="updated_at" type="timestamp">
  Fecha y hora de la última actualización del método de pago (MAX 27; MIN 27; <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> ).

  Ejemplo: 2022-05-09T20:46:54.786342Z
</ParamField>

<ParamField body="enrollment" type="object">
  Especifica el objeto de inscripción.

  <Expandable title="propiedades">

    <ParamField body="session" type="string">
      La sesión de cliente que se creó para el método de pago (MAX 64; MIN 36).

      Ejemplo: 9104911d-5df9-429e-8488-ad41abea1a4b
    </ParamField>

    <ParamField body="sdk_required_action" type="boolean">
      Acción requerida para llamar al SDK.

      Valores posibles: `True` o `False`
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="provider" type="object">
  Especifica el objeto de proveedor.

  <Expandable title="propiedades">

    <ParamField body="type" type="enum">
      El tipo de proveedor.

      Ejemplo: BANK
    </ParamField>

    <ParamField body="provider_status" type="string">
      El estado del proveedor (MAX 255; MIN 3).

      Ejemplo: OK
    </ParamField>

    <ParamField body="id" type="string">
      El identificador único de la inscripción (MAX 64; MIN 36).

      Ejemplo: a079d524-c3df-4470-b3c8-7f290f5a0ba4
    </ParamField>

    <ParamField body="token" type="string">
      El token devuelto por el proveedor (MAX 64; MIN 36).

      Ejemplo: a079d524-c3df-4470-b3c8-7f290f5a0ba4
    </ParamField>

  </Expandable>
</ParamField>
