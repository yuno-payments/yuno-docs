---
title: "Inscribir un método de pago"
openapi: "/openapi/es/payment-methods-checkout/enroll-payment-method-checkout.json POST /customers/sessions/{customer_session}/payment-methods"
description: "Inscribe el método de pago seleccionado por un cliente para uso futuro durante el checkout"
---

Esta solicitud inscribe un método de pago para un cliente. Con la información que Yuno proporciona después de que el cliente selecciona el método de pago a inscribir, podrás guardarlo para compras futuras en el objeto de método de pago creado.

Ten en cuenta que esta solicitud requiere un `X-Idempotency-Key`. Consulta [Authentication](/reference/authentication#idempotency).

<Note>
**Webhooks**

Recomendamos escuchar [Webhooks](/docs/configure-webhooks) para mantenerte al día con el estado de los métodos de pago inscritos de tus clientes.
</Note>

Si un cliente inscribe la misma tarjeta dos veces pero con una nueva fecha de vencimiento o con otros datos del titular de la tarjeta, daremos de baja la inscripción de la tarjeta inscrita anteriormente y conservaremos la nueva.

## Métodos de pago disponibles para inscripción {#available-payment-methods-for-enrollment}

Los siguientes métodos de pago pueden inscribirse usando este endpoint:

| Método de pago           | Tipo                   |
| ------------------------ | ---------------------- |
| **Cards**                | `CARD`                 |
| **Nupay**                | `NU_PAY_ENROLLMENT`    |
| **PayPal**               | `PAYPAL_ENROLLMENT`    |
| **Daviplata**            | `DAVIPLATA_ENROLLMENT` |
| **MercadoPago Wallet**   | `WALLET_CONNECT`       |
| **dLocal Yape**          | `YAPE_ENROLLMENT`      |
| **dLocal Smart PIX**     | `SMART_PIX`            |
| **Astropay**             | `ASTROPAY_ENROLLABLE`  |
| **Adyen PIX Biométrico** | `PIX_BIOMETRICO`       |

<Note>
**Disponibilidad de métodos de pago**

Cuando obtienes los métodos de pago disponibles para inscribir, solo estarán presentes los que hayas conectado, para los que hayas creado una ruta y que hayas agregado a tu checkout. Para más información sobre los flujos de inscripción, consulta la guía [Enroll Payment Methods](/docs/enroll-payment-methods).
</Note>
