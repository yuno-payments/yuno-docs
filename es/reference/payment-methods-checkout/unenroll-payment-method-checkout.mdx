---
title: "Cancelar inscripción de método de pago"
openapi: "/openapi/es/payment-methods-checkout/unenroll-payment-method-checkout.json POST /customers/payment-methods/{payment_method_id}/unenroll"
description: "Cancela la inscripción de un método de pago guardado, marcándolo como inactivo para futuras transacciones"
---

Cancela la inscripción de un método de pago guardado previamente para un cliente.

Para realizar esta acción, proporciona el `payment_method_id` en la ruta de la solicitud. Cuando la solicitud sea exitosa, el estado del método de pago se actualizará a `UNENROLLED`, lo que lo deja inactivo y ya no disponible para futuras transacciones.
