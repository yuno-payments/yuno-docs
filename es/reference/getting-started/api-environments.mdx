Esta página explica las URLs base de la API y los dos entornos que puedes usar al llamar a la API de Yuno: **Sandbox** y **Producción**.

Para saber cómo cambiar entre Test Mode y Live Mode en el dashboard de Yuno, consulta [Entornos (Dashboard)](/es/docs/using-yuno/environments).

## Resumen: sandbox frente a producción {#overview-sandbox-vs-production}

| Entorno               | Propósito                                                    | URL base                                       |
| --------------------- | ------------------------------------------------------------ | ---------------------------------------------- |
| **Sandbox**           | Pruebas y desarrollo. Sin datos reales ni transacciones reales. | <CopyChip value="https://api-sandbox.y.uno" /> |
| **Producción (US)**   | Entorno en vivo con base en EE. UU. Transacciones y contabilidad reales. | <CopyChip value="https://api.y.uno" />         |

En el dashboard, sandbox aparece como **Test Mode** y producción como **Live Mode**. Usas la misma cuenta para ambos; el interruptor del dashboard cambia el entorno que estás usando.

## Credenciales {#credentials}

<Warning>
**Credenciales**

Sandbox y producción usan **claves de API diferentes**. Las credenciales que usas en Test Mode (sandbox) no son las mismas que las de Live Mode (producción). En el dashboard, las claves que se muestran dependen del entorno que hayas seleccionado. Consulta [Credenciales de desarrolladores](/es/docs/using-yuno/settings/developers-credentials) para saber dónde encontrarlas.
</Warning>

## URLs base {#base-urls}

### Sandbox {#sandbox}

Usa esta URL base para todas las solicitudes a la API cuando estés haciendo pruebas. Los datos son simulados y no afectan la contabilidad ni las métricas en vivo.

```text
https://api-sandbox.y.uno
```

### Producción (US) {#production-us}

Usa esta URL base cuando tu integración esté en vivo, tenga base en EE. UU. y procese pagos reales.

```text
https://api.y.uno
```

## Tiempo de procesamiento y tiempo de espera {#processing-time-and-timeout}

<Note>
**Tiempo de procesamiento**

El tiempo de procesamiento de cada solicitud depende del procesador o adquirente. El tiempo total es la suma del tiempo de procesamiento de Yuno y el del procesador.
</Note>

<Warning>
**Tiempo de espera**

Yuno usa un **tiempo de espera de 60 segundos** para todos los endpoints. El ciclo completo de solicitud y respuesta debe completarse en 60 segundos. Los tiempos de respuesta suelen ser mucho menores; 60 segundos cubren las respuestas más lentas de los procesadores.
</Warning>
