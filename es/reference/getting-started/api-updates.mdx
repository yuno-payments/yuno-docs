Mantente al día con los cambios y las actualizaciones de la API de Yuno.

En Yuno, todas las actualizaciones que se hacen a la API son compatibles tanto con la versión actual como con las versiones anteriores.

Cuando se implementa una modificación disruptiva en la API de Yuno, se lanza una nueva versión. Para evitar problemas con tu código, no es necesario cambiar de versión hasta que estés listo para continuar con la actualización.

### Cambios compatibles con versiones anteriores {#backwards-compatible-changes}

Consideramos que las siguientes modificaciones mantienen la compatibilidad con versiones anteriores:

* Agregar nuevos recursos a la API.
* Agregar nuevos parámetros opcionales de solicitud a los métodos existentes de la API.
* Agregar nuevas propiedades a las respuestas existentes de la API.
* Modificar el orden de las propiedades en las respuestas existentes de la API.
* Alterar la longitud o el formato de cadenas opacas, como identificadores de objetos, mensajes de error y otras cadenas legibles por personas. Esto incluye agregar o quitar prefijos.
* Introducir nuevos tipos de eventos. Asegúrate de que tu servicio receptor de webhooks admita tipos de evento desconocidos.
