Esta sección describe los códigos de error más comunes y sus soluciones que puedes encontrar al usar la API de Yuno.

Yuno usa códigos de respuesta HTTP estándar para indicar si las solicitudes a la API tuvieron éxito o fallaron.

Los códigos del rango 2xx suelen indicar éxito. Los códigos del rango 4xx indican un error causado por la información proporcionada (por ejemplo, un parámetro faltante). Los códigos del rango 5xx indican un error interno.

## Ejemplo {#example}

```json
{
  "code": "INVALID_REQUEST",
  "messages": [
    "Invalid request."
  ]
}
```
