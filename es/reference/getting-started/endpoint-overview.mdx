description: "Un índice completo de los endpoints de la API de Yuno organizados por recurso"

Esta página ofrece un catálogo fácil de explorar de todos los endpoints de la API REST de Yuno. Úsala para descubrir qué operaciones están disponibles antes de pasar a las páginas de referencia individuales.

Para detalles de implementación:
- [Autenticación](/es/reference/getting-started/authentication): cómo autenticar las solicitudes a la API
- [Entornos](/es/reference/getting-started/api-environments): URLs base de sandbox y producción
- [Especificación OpenAPI](/openapi.json): definición de la API legible por máquina

<Note>
Este resumen se genera a partir de la especificación OpenAPI completa (172 operaciones). 
Un subconjunto de 39 operaciones se probó en sandbox y está disponible en `openapi/yuno_sandbox_tested.json`.
</Note>
