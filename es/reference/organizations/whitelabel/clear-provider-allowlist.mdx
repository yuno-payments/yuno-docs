---
title: "Borrar la lista de proveedores permitidos"
description: "Elimina todas las entradas de la lista de permitidos y devuelve la organización a filtered: false."
openapi: "/openapi/es/organizations/whitelabel/clear-provider-allowlist.json DELETE /whitelabel/providers"
---

Elimina todas las entradas de la lista de permitidos y devuelve tu organización a `filtered: false`.

Es idempotente y **conserva todas las personalizaciones de instrucciones**: al volver a habilitar un proveedor más adelante, se restaura tu redacción junto con él.

<Warning>
Esto no es un interruptor de "mostrar todo". Bajo la regla de opt-in, una organización sin entradas en la lista de permitidos no ha habilitado nada; borrar la lista deja el mismo estado final que [Replace the Provider Allowlist](/es/reference/organizations/whitelabel/replace-provider-allowlist) con un `provider_ids` vacío. Reconstruye la lista con `PUT` cuando quieras ampliar lo que ofreces.
</Warning>

### Respuesta {#response}

`204 No Content`. No hay cuerpo de respuesta.

<CodeGroup>
```bash cURL
curl -X DELETE 'https://api.y.uno/v1/whitelabel/providers' \
  -H 'public-api-key: <YOUR_PUBLIC_KEY>' \
  -H 'private-secret-key: <YOUR_SECRET_KEY>' \
  -i
```

```text 204 No Content
HTTP/1.1 204 No Content
```

```json 401 Unauthorized
{
  "code": "NOT_AUTHENTICATED",
  "messages": ["Not authenticated"]
}
```
</CodeGroup>

Lee el resultado con [List the White-label Provider Overlay](/es/reference/organizations/whitelabel/list-providers): `filtered` ahora es `false`, y `providers` sigue listando cualquier proveedor que tenga una personalización de instrucciones, cada uno con `allowed: false`.
