---
title: "Eliminar el logo de un proveedor"
description: "Elimina tu logo personalizado de un proveedor, de modo que vuelve al ícono del catálogo de Yuno."
openapi: "/openapi/es/organizations/whitelabel/delete-provider-logo.json DELETE /whitelabel/providers/{provider_id}/logo"
---

Elimina tu logo personalizado de este proveedor, de modo que vuelve al ícono del catálogo de Yuno.

Es idempotente y deja intactas la personalización de instrucciones y la lista de permitidos.

### Parámetros de ruta {#path-parameters}

<ParamField path="provider_id" type="string" required>
  Id del proveedor del catálogo de Yuno en UPPER_SNAKE_CASE. No distingue mayúsculas de minúsculas: se normaliza a mayúsculas.
</ParamField>

### Respuesta {#response}

`204 No Content`. No hay cuerpo de respuesta.

<CodeGroup>
```bash cURL
curl -X DELETE 'https://api.y.uno/v1/whitelabel/providers/YUNO_3DS/logo' \
  -H 'public-api-key: <YOUR_PUBLIC_KEY>' \
  -H 'private-secret-key: <YOUR_SECRET_KEY>' \
  -i
```

```text 204 No Content
HTTP/1.1 204 No Content
```

```json 400 Bad Request
{
  "code": "VALIDATION_ERROR",
  "messages": ["provider_id is invalid"]
}
```
</CodeGroup>

Después de eliminarlo, [Recuperar la personalización de un proveedor](/es/reference/organizations/whitelabel/retrieve-provider) ya no devuelve un `logo_url` para este proveedor.

### Errores {#errors}

<div className="code-nowrap-table dense-table">

| HTTP | `code` | Cuándo |
|---|---|---|
| `400` | `VALIDATION_ERROR` | `provider_id` no es un id de catálogo válido. |
| `401` | `NOT_AUTHENTICATED` | Faltan las claves de API o no son válidas. |

</div>
