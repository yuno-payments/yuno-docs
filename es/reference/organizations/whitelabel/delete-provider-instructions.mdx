---
title: "Eliminar el reemplazo de instrucciones de un proveedor"
description: "Elimina tu reemplazo de instrucciones para un proveedor, de modo que vuelva a usar los textos del catálogo de Yuno."
openapi: "/openapi/es/organizations/whitelabel/delete-provider-instructions.json DELETE /whitelabel/providers/{provider_id}/instructions"
---

Elimina tu reemplazo de instrucciones para este proveedor, de modo que vuelva por completo a los textos, el nombre y el enlace a la documentación del catálogo de Yuno.

Es idempotente y **no** cambia si ofreces o no el proveedor.

<Note>
El logo del proveedor se almacena por separado y no se toca. Restablécelo con [Eliminar el logo de un proveedor](/es/reference/organizations/whitelabel/delete-provider-logo).
</Note>

### Parámetros de ruta {#path-parameters}

<ParamField path="provider_id" type="string" required>
  ID de proveedor del catálogo de Yuno en UPPER_SNAKE_CASE. No distingue mayúsculas de minúsculas: se normaliza a mayúsculas.
</ParamField>

### Respuesta {#response}

`204 No Content`. No hay cuerpo de respuesta.

<CodeGroup>
```bash cURL
curl -X DELETE 'https://api.y.uno/v1/whitelabel/providers/STRIPE/instructions' \
  -H 'public-api-key: <YOUR_PUBLIC_KEY>' \
  -H 'private-secret-key: <YOUR_SECRET_KEY>' \
  -i
```

```text 204 No Content
HTTP/1.1 204 No Content
```

```json 400 Bad Request
{
  "code": "VALIDATION_ERROR",
  "messages": ["provider_id is invalid"]
}
```
</CodeGroup>

### Errores {#errors}

<div className="code-nowrap-table dense-table">

| HTTP | `code` | Cuándo |
|---|---|---|
| `400` | `VALIDATION_ERROR` | `provider_id` no es un id de catálogo válido. |
| `401` | `NOT_AUTHENTICATED` | Claves de API ausentes o no válidas. |
