---

Obtiene los detalles de una cuenta específica mediante su identificador único (UUID).

<Note>
Las cuentas suspendidas aún se pueden consultar por id: se devuelven con `status` en `SUSPENDED`, aunque [Listar cuentas](/es/reference/organizations/list-accounts) ya no las muestre.
</Note>

### No encontrada {#not-found}

Si ninguna cuenta coincide con el id, la API devuelve HTTP `400` (no `404`). El `code` del error en el cuerpo es `"404"`:

```json 400
{
  "code": "404",
  "messages": ["Account not found"]
}
```
