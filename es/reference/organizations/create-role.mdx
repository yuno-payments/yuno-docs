---
title: "Crear un rol"
openapi: "/openapi/organizations/create-role.json POST /organizations/roles"
description: "Crea un rol personalizado con un conjunto definido de permisos para la organización"
---

Crea un rol personalizado para la organización.

Define `role_type` para delimitar dónde se aplica el rol una vez asignado a un usuario: `account` (el valor predeterminado) otorga acceso en la cuenta o cuentas específicas a las que se asigna, mientras que `organization` otorga ese mismo acceso en todas las cuentas de la organización, incluidas las cuentas creadas más adelante.
