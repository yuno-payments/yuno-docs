Devuelve una conexión que creaste previamente. Los secretos se enmascaran.

### Parámetros de ruta {#path-parameters}

<ParamField path="connection_id" type="string" required>
  El id devuelto por [Create a Connection](/es/reference/organizations/connections/create-connection). Debe pertenecer a la cuenta a la que está asociada tu clave de API.
</ParamField>

### Respuesta {#response}

<ResponseField name="connection_id" type="string">
  Identificador único de la conexión.
</ResponseField>
<ResponseField name="merchant_connection_id" type="string">
  Tu etiqueta interna para esta conexión.
</ResponseField>
<ResponseField name="provider_id" type="string">
  El proveedor al que pertenece esta conexión.
</ResponseField>
<ResponseField name="status" type="string">
  Estado actual.
</ResponseField>
<ResponseField name="flow_type" type="string">
  Siempre `PAYIN`.
</ResponseField>
<ResponseField name="payment_methods" type="string[]">
  Lista de métodos de pago admitidos.
</ResponseField>
<ResponseField name="params" type="object[]">
  Parámetros devueltos. Los valores sensibles se enmascaran como `***`.
</ResponseField>
<ResponseField name="costs" type="object[]">
  Configuración de costos de la conexión.
</ResponseField>
<ResponseField name="created_at" type="string">
  Marca de tiempo ISO 8601.
</ResponseField>
<ResponseField name="updated_at" type="string">
  Marca de tiempo ISO 8601.
</ResponseField>

<CodeGroup>
```bash cURL
curl -X GET 'https://api.y.uno/v1/connections/f1a3c4d5-7b8e-4a2c-9d1e-3f4a5b6c7d8e' \
  -H 'public-api-key: <YOUR_PUBLIC_KEY>' \
  -H 'private-secret-key: <YOUR_SECRET_KEY>'
```

### Errores {#errors}

<div className="code-nowrap-table dense-table">

| HTTP | `code` | Cuándo |
|---|---|---|
| `401` | `NOT_AUTHENTICATED` | Falta la clave de API o no es válida. |
| `404` | `CONNECTION_NOT_FOUND` | `connection_id` desconocido, o el id pertenece a otra cuenta. |
