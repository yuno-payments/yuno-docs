---
title: "Listar enrutamientos"
description: "Lista todos los enrutamientos de una cuenta, con filtro opcional por método de pago."
openapi: "/openapi/es/organizations/routing/list-routings.json GET /routing"
---

Lista los enrutamientos configurados en una cuenta. Cada elemento devuelve la configuración activa actual del enrutamiento, con la misma forma que [Obtener un enrutamiento](/es/reference/organizations/routing/retrieve-routing).

Pasa `payment_method` para listar solo los enrutamientos de ese método de pago, y omítelo para listarlos todos.

### Parámetros de consulta {#query-parameters}

<ParamField query="account_id" type="string" required>
  La cuenta de la que se listan los enrutamientos. Debe pertenecer a la organización a la que están asociadas tus credenciales de API.
</ParamField>
<ParamField query="payment_method" type="enum">
  Filtro opcional por método de pago (por ejemplo, `CARD`, `PIX`). Mismos valores que el campo `payment_method` en las respuestas de enrutamiento.
</ParamField>

### Respuesta {#response}

Los enrutamientos configurados en la cuenta, o un arreglo vacío si no tiene ninguno. Cada enrutamiento contiene:

<ResponseField name="id" type="string">
  Identificador único del enrutamiento.
</ResponseField>
<ResponseField name="account_id" type="string">
  Identificador único de la cuenta.
</ResponseField>
<ResponseField name="payment_method" type="enum">
  El método de pago al que se aplica este enrutamiento (por ejemplo, `CARD`).
</ResponseField>
<ResponseField name="name" type="string">
  Etiqueta del enrutamiento.
</ResponseField>
<ResponseField name="default_route" type="object">
  La lógica de enrutamiento predeterminada.
</ResponseField>
<ResponseField name="condition_sets" type="object[]">
  Lógica condicional opcional.
</ResponseField>
<ResponseField name="created_at" type="string">
  Marca de tiempo ISO 8601.
</ResponseField>
<ResponseField name="updated_at" type="string">
  Marca de tiempo ISO 8601.
</ResponseField>
<ResponseField name="warnings" type="string[]">
  Lista opcional de advertencias de orquestación que no bloquean (por ejemplo, `MONITOR_REDISTRIBUTION_DEFERRED`).
</ResponseField>

### Errores {#errors}

<div className="code-nowrap-table dense-table">

| HTTP | `code` | Cuándo |
|---|---|---|
| `400` | `ROUTING_VALIDATION_FAILED` | Falta el parámetro de consulta `account_id`. |
| `400` | `INVALID_ACCOUNT_ID` | `account_id` pertenece a una organización que tu clave de API no posee. |
| `401` | `NOT_AUTHENTICATED` | Falta el encabezado `public-api-key` o `private-secret-key`. |
| `401` | `INVALID_CREDENTIALS` | Par de claves incorrecto, o se usó una **Customized API key** del Dashboard. Usa una clave de cuenta o una clave de organización. |

</div>
