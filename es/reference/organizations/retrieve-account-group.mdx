---
title: "Consultar grupo de cuentas"
openapi: "/openapi/organizations/retrieve-account-group.json GET /organizations/account-groups/{account_group_id}"
description: "Obtiene un grupo de cuentas específico mediante su identificador único"
---

Obtiene un grupo de cuentas específico mediante su identificador único (UUID).

### No encontrado {#not-found}

Si ningún grupo de cuentas coincide con el id, la API devuelve HTTP `400` (no `404`). El `code` del error en el cuerpo es `"404"`:

```json 400
{
  "code": "404",
  "messages": ["Account group not found"]
}
```
