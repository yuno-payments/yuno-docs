---
title: "Crear grupo de cuentas"
openapi: "/openapi/organizations/create-account-group.json POST /organizations/account-groups"
description: "Crea un nuevo grupo de cuentas para organizar comercios o unidades de negocio dentro de una organización"
---

Crea un nuevo grupo (suborganización) dentro de tu organización. Los grupos de cuentas se pueden usar para organizar distintos comercios o unidades de negocio bajo una única entidad matriz.

Pasa `account_codes` para asociar cuentas existentes al grupo en la misma solicitud. Un grupo nuevo siempre se crea como raíz; para anidarlo bajo otro grupo, define `parent_code` con [Update Account Group](/es/reference/organizations/update-account-group).
