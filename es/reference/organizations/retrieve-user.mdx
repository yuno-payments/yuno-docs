---
title: "Obtener usuario"
openapi: "/openapi/organizations/retrieve-user.json GET /organizations/users/{user_id}"
description: "Obtiene los detalles de un usuario específico por su identificador único"
---

Obtiene los detalles de un usuario específico mediante su identificador único (UUID).

### No encontrado {#not-found}

Si ningún usuario coincide con el id, la API devuelve HTTP `400` (no `404`). El `code` del error en el cuerpo es `"404"`:

```json 400
{
  "code": "404",
  "messages": ["User not found"]
}
```
