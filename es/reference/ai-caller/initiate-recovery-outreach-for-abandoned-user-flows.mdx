<Warning>
Este endpoint aún no está disponible a través de la API pública. `POST /smart-support/external/payments` devuelve 404 actualmente. Para iniciar el contacto de recuperación de un pago rechazado, usa [Declined Payment Calls](/es/reference/ai-caller/declined-payment-calls).
</Warning>

Este endpoint permite a los comercios notificar al Recovery Agent de Yuno cuando un usuario abandona su flujo de compra, por ejemplo durante la selección de productos o después de iniciar el checkout, antes de completar un pago. Los datos enviados permiten a Yuno hacer seguimiento al usuario por llamada o WhatsApp para animarlo a completar la transacción.

## Seguridad y cumplimiento {#security-and-compliance}

- **Autenticación**: El acceso a la API requiere una clave de API válida incluida en los encabezados de la solicitud.

- **Protección de datos**: Todos los datos deben transmitirse por HTTPS. Yuno cumple con las regulaciones de protección de datos pertinentes, incluidas **GDPR** y **LGPD**.

- **Uso de los datos**: Los datos enviados se usarán únicamente con el fin de interactuar con el cliente y no se almacenarán más allá del tiempo necesario.

<Note>
**Ejemplo de caso de uso**

Una usuaria llamada Jane Doe agrega unos audífonos inalámbricos a su carrito en el sitio web de un comercio, pero abandona el proceso de checkout. El sistema del comercio lo detecta y envía el payload correspondiente a la API del Recovery Agent de Yuno. Yuno inicia entonces un mensaje de WhatsApp a Jane, le recuerda los artículos que dejó en su carrito y le ofrece ayuda para completar la compra.
</Note>
