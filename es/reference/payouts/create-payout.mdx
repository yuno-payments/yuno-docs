---
title: "Crear payout"
openapi: "/openapi/es/payouts/create-payout.json POST /payouts"
description: "Crea un payout para transferir fondos de tu cuenta a un destinatario"
---

Esta solicitud te permite crear un payout para transferir fondos de tu cuenta a otra cuenta o a un destinatario.

Se requiere un enrutamiento de payout publicado para el método de payout y el país. Sin uno, la API responde `201` con el `status` del payout en `ERROR`.

<Note>
**Guía de métodos de payout**

Para ver las pautas de prueba y los detalles de la información del beneficiario que se necesitan para cada integración, consulta la guía de métodos de payout.
</Note>
