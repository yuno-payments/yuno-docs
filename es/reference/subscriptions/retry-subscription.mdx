---
title: "Reintentar suscripción"
openapi: "/openapi/es/subscriptions/retry-subscription.json POST /subscriptions/{subscription_id}/retry"
description: "Reintenta manualmente el pago rechazado más reciente de una suscripción para el ciclo de facturación actual."
---

Usa este endpoint para reintentar manualmente el pago fallido más reciente de una suscripción. Es útil cuando un cliente actualiza su método de pago o resuelve un problema con el pago (por ejemplo, fondos insuficientes, tarjeta vencida) a mitad del ciclo de facturación, ya que las actualizaciones de la suscripción solo entran en vigor a partir del siguiente ciclo de facturación. Llamar a este endpoint fuerza un nuevo intento de cobro para el ciclo actual usando la configuración más reciente de la suscripción.

* Solo se puede reintentar el **pago más reciente** de la suscripción.
* Se pueden ejecutar varios reintentos manuales **solo si** el intento de reintento anterior terminó con estado DECLINED.
* Activar manualmente un reintento **detiene** el [esquema de reintentos inteligentes](/es/docs/payment-features/subscriptions/retries) para el pago correspondiente. Los siguientes pagos de la suscripción seguirán el esquema de reintentos inteligentes si se habilitó en la creación.
* Después de un intento de reintento exitoso, el sistema **continúa** con el siguiente cobro programado de la suscripción.
* Si no se cumple ninguna de las dos condiciones, la solicitud devuelve `400` con el código **INVALID_STATE** y el mensaje `The last payment intent of the subscription does not support the action requested.` El mismo error se devuelve cuando la suscripción está cancelada.
* Si ninguna suscripción coincide con `subscription_id` en la cuenta, la solicitud devuelve `400` con el código **SUBSCRIPTION_NOT_FOUND**.
