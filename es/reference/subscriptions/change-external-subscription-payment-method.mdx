---
title: "Definir el método de pago de una suscripción externa"
openapi: "/openapi/es/subscriptions/change-external-subscription-payment-method.json POST /external-subscriptions/{external_subscription_id}/payment-method"
description: "Vincula una suscripción de Stripe Billing a una tarjeta que el cliente ya verificó en Yuno, o cambia una suscripción vinculada a otro método de pago registrado, sin realizar un pago."
---

Usa este endpoint con las [suscripciones de Stripe Billing](/es/docs/payment-features/subscriptions/stripe-billing) en dos casos:

- **La suscripción todavía no está vinculada a Yuno.** Por ejemplo, una suscripción creada en Stripe antes de integrar Yuno, cuyo cliente ya registró y verificó una tarjeta en Yuno. Yuno vincula la suscripción a esa tarjeta, y Yuno cobra las próximas renovaciones.
- **La suscripción ya está vinculada.** Yuno la cambia a otro método de pago almacenado del mismo cliente.

<Note>
**No se realiza ningún pago**

Yuno no cobra al cliente y no ejecuta una verificación de $0 ni 3DS. Yuno establece el método de pago como el predeterminado de la suscripción en Stripe, y las próximas renovaciones se cobran con él.
</Note>

## Solicitud {#request}

| Campo | Descripción |
|---|---|
| `external_subscription_id` (ruta) | El ID de la suscripción de Stripe (`sub_...`), de entre 3 y 255 caracteres. |
| `account_id` | La cuenta de Yuno incorporada al puente de facturación (UUID). |
| `customer_payer.id` | El **ID de cliente de Yuno** (UUID) propietario de la suscripción. No es el ID de cliente de Stripe (`cus_...`). |
| `vaulted_token` | El token almacenado (UUID) de uno de los métodos de pago registrados de ese cliente. |
| `external_customer_id` | El **ID de cliente de Stripe** (`cus_...`) de la suscripción, de entre 3 y 255 caracteres. |

El encabezado `X-Idempotency-Key` es obligatorio. Repetir la misma clave con la misma solicitud devuelve el primer resultado.

La respuesta devuelve los campos de la solicitud y `result`:

| `result` | Significado |
|---|---|
| `LINKED` | La suscripción no estaba vinculada a Yuno. Yuno la vinculó al método de pago. |
| `PAYMENT_METHOD_CHANGED` | La suscripción ya estaba vinculada. Yuno la cambió al método de pago. |
| `NO_CHANGE` | La suscripción ya cobra ese método de pago. No cambió nada. |

Para vincular una suscripción que todavía no está vinculada:

- La suscripción de Stripe tiene que estar `active` o `trialing` y cobrarse automáticamente (`collection_method: charge_automatically`), y su cliente tiene que ser `external_customer_id`.
- La tarjeta tiene que haberse verificado antes en Yuno, por ejemplo con una verificación de $0 al registrarla. Yuno usa esa verificación para cobrar las renovaciones como iniciadas por el comercio.

Esta API se habilita por cuenta. Contacta a tu Key Account Manager para solicitar acceso.

## Errores {#errors}

| Estado | Código | Significado | Qué hacer |
|---|---|---|---|
| `400` | `INVALID_PARAMETERS` | Falta un campo o el encabezado `X-Idempotency-Key`, o tiene un formato incorrecto, o la clave ya se usó para otra suscripción o método de pago. | Corrige la solicitud. Usa una clave nueva para un cambio diferente. |
| `400` | `CUSTOMER_NOT_FOUND` | El cliente no existe en la cuenta. | Verifica que `customer_payer.id` sea el ID de cliente de Yuno, no el ID `cus_` de Stripe. |
| `400` | `VAULTED_TOKEN_NOT_FOUND` | El `vaulted_token` no es uno de los métodos de pago del cliente. | Usa un token de los [métodos de pago registrados](/es/reference/payment-methods-direct-workflow/retrieve-enrolled-payment-methods-api) del cliente. |
| `400` | `VAULTED_TOKEN_NOT_ENROLLED` | El método de pago no está registrado. | Usa un método de pago con estado `ENROLLED`. |
| `400` | `VAULTED_TOKEN_WITHOUT_COUNTRY` | El método de pago no tiene país, y vincular una suscripción lo necesita. | Usa otro método de pago del cliente o vuelve a registrar la tarjeta. |
| `400` | `VAULTED_TOKEN_WITHOUT_NETWORK_TRANSACTION_ID` | La tarjeta nunca se verificó, así que Yuno no puede cobrar las renovaciones como iniciadas por el comercio. | Verifica la tarjeta primero: ejecuta una verificación de $0 con el objeto `external_subscription`, como en una [prueba gratuita](/es/docs/payment-features/subscriptions/stripe-billing#free-trials). |
| `400` | `EXTERNAL_SUBSCRIPTION_NOT_FOUND` | Stripe no tiene una suscripción con este ID para la cuenta. | Verifica el ID de la suscripción de Stripe y la cuenta. |
| `400` | `EXTERNAL_SUBSCRIPTION_NOT_ACTIVE` | La suscripción de Stripe no está `active` ni `trialing`. | Solo se pueden vincular suscripciones activas o en prueba. |
| `400` | `EXTERNAL_SUBSCRIPTION_NOT_CHARGED_AUTOMATICALLY` | La suscripción de Stripe envía facturas en lugar de cobrarse automáticamente. | Configura `collection_method` como `charge_automatically` en Stripe. |
| `400` | `CUSTOMER_MISMATCH` | La suscripción pertenece a otro cliente, o `external_customer_id` no es el cliente de Stripe de la suscripción. | Envía los clientes propietarios de la suscripción. |
| `403` | `PRODUCT_NOT_ENABLED` | La cuenta no está habilitada para el puente de facturación. | Contacta a tu Key Account Manager. |
| `409` | `CONCURRENT_CHANGE` | Otro cambio de método de pago de esta suscripción se completó primero. | Revisa la suscripción en Stripe antes de enviar otro cambio. |
| `409` | `EXTERNAL_SUBSCRIPTION_PENDING_ACTIVATION` | La suscripción se está migrando a Yuno. | Reintenta cuando termine la migración. |
| `502` | `BILLING_PLATFORM_ERROR` | La plataforma de facturación no pudo confirmar el cambio. Se mantiene el método de pago anterior, o la suscripción sigue sin vincular. | Reintenta con un nuevo `X-Idempotency-Key`. |
