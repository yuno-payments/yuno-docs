title: El objeto Seller
description: Referencia detallada de los atributos del objeto vendedor.
---

El objeto vendedor representa un mapeo de vendedor de franquicia con credenciales de comercio por proveedor.

## Atributos {#attributes}

| Campo | Tipo | Descripción |
| :---- | :---- | :---- |
| `seller_id` | string (UUID) | El identificador único de este vendedor, generado por Yuno. |
| `account_code` | string (UUID) | La cuenta bajo la cual se creó este vendedor. |
| `merchant_seller_id` | string | El identificador propio del comercio para esta tienda de franquicia (MAX 255; MIN 1). |
| `name` | string | El nombre visible del vendedor (MAX 255). |
| `email` | string | La dirección de email del vendedor. |
| `phone` | object | El teléfono del vendedor. Contiene `code` y `number`. |
| `phone.code` | string | Código de país del teléfono (por ejemplo, `"55"`). |
| `phone.number` | string | Número de teléfono (por ejemplo, `"11999999999"`). |
| `document` | object | El documento legal del vendedor. Contiene `type` y `number`. |
| `document.type` | string | Tipo de documento (por ejemplo, `CNPJ`, `CPF`, `RUT`, `NIT`). |
| `document.number` | string | Número de documento (por ejemplo, `"12345678000199"`). |
| `address` | object | La dirección del vendedor. |
| `address.line_1` | string | Nombre de la calle. |
| `address.line_2` | string | Número de la calle. |
| `address.city` | string | Nombre de la ciudad. |
| `address.state` | string | Código del estado o la provincia. |
| `address.country` | string | Código de país (ISO 3166-1 alpha-2). |
| `address.zip_code` | string | Código postal. |
| `country` | string | El país del vendedor (ISO 3166-1 alpha-2, MAX 2). |
| `website` | string | La URL del sitio web del vendedor. |
| `industry` | string | La industria o vertical de negocio del vendedor (MAX 255). |
| `merchant_category_code` | string | Código de categoría del comercio / MCC (MAX 4). |
| `payment_methods` | array | Configuraciones de método de pago con detalles específicos de cada proveedor. |
| `created_at` | timestamp | Marca de tiempo de creación (ISO 8601). |
| `updated_at` | timestamp | Marca de tiempo de la última actualización (ISO 8601). |
