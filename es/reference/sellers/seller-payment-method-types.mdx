---
title: Tipos de método de pago
description: Detalle de la estructura polimórfica payment_method para Sellers.
---

Cada entrada del arreglo `payment_method` asigna un tipo de método de pago a un proveedor específico y a sus credenciales de comercio.

## Estructura {#structure}

El arreglo `payment_method` usa una estructura `detail` polimórfica. La forma del objeto detail depende del campo `payment_method_type`.

<div className="nowrap-col1-table dense-table">

| Campo | Tipo | Obligatorio | Descripción |
| :---- | :---- | :---- | :---- |
| `payment_method_type` | string (enum) | Sí | El tipo de método de pago: `CARD`, `APPLE_PAY`, `GOOGLE_PAY`, etc. |
| `detail` | object | Sí | Objeto de detalle específico del tipo. Contiene la clave `card` o `wallet`. |

</div>

### Tipo CARD {#card-type}

**Ruta:** `detail.card.provider`

<div className="nowrap-col1-table dense-table">

| Campo | Tipo | Obligatorio | Descripción |
| :---- | :---- | :---- | :---- |
| `id` | string | Sí | El identificador del proveedor de pagos (p. ej., `CIELO`, `ADYEN`, `STRIPE`). |
| `merchant_id` | string | Sí | El ID de comercio asignado por este proveedor para este seller (MÁX. 255). |

</div>

### Tipo APPLE_PAY {#applepay-type}

**Ruta:** `detail.wallet.provider`

<div className="nowrap-col1-table dense-table">

| Campo | Tipo | Obligatorio | Descripción |
| :---- | :---- | :---- | :---- |
| `id` | string | Sí | El identificador del proveedor de wallet (p. ej., `APPLE_PAY`). |
| `merchant_id` | string | Sí | El ID de comercio asignado por el proveedor de wallet (MÁX. 255). |
| `payment_processing_key` | string | Sí | Contenido .pem codificado en Base64 de la clave privada de procesamiento de pagos. |
| `payment_processing_certificate` | string | Sí | Contenido .pem codificado en Base64 del certificado de procesamiento de pagos. |
| `merchant_identity_key` | string | Sí | Contenido .pem codificado en Base64 de la clave privada de identidad del comercio. |
| `merchant_identity_certificate` | string | Sí | Contenido .pem codificado en Base64 del certificado de identidad del comercio. |
| `merchant_identity_password` | string | Sí | Contraseña del certificado de identidad del comercio (MÁX. 255). |

</div>
