---
title: "Eliminar vendedor"
openapi: "/openapi/sellers/sellers-api.json DELETE /sellers/{merchant_seller_id}"
description: "Elimina de forma lógica el mapeo de un vendedor de franquicia y los datos de método de pago asociados"
---

Elimina de forma lógica el mapeo de un vendedor de franquicia y todos los datos de método de pago asociados.

<Warning>
**Importante**

Esta acción no se puede deshacer. Los pagos futuros que hagan referencia a este vendedor usarán el `merchant_id` predeterminado de la conexión.
</Warning>
