## Errores de CRUD de sellers {#seller-crud-errors}

<div className="code-nowrap-table dense-table">

| Estado HTTP | Código de error |
| :---- | :---- |
| `400 Bad Request` | `DUPLICATE_PROVIDER_MAPPING`<br />Se encontró una combinación `(provider.id, payment_method_type)` duplicada. |
| `400 Bad Request` | `VALIDATION_ERROR`<br />El cuerpo de la solicitud no supera la validación. |
| `400 Bad Request` | `INVALID_PROVIDER`<br />El `id` del proveedor no es válido. |
| `401 Unauthorized` | —<br />Claves de API inválidas o ausentes. |
| `403 Forbidden` | `FORBIDDEN`<br />Cuenta no encontrada o no autorizada. |
| `404 Not Found` | `FRANCHISE_MAPPING_NOT_FOUND`<br />No existe ningún mapeo de seller para el ID indicado. |
| `409 Conflict` | `FRANCHISE_MAPPING_ALREADY_EXISTS`<br />ya existe un mapeo con este `merchant_seller_id`. |

</div>

## Resolución de franquicia (no bloqueante) {#franchise-resolution-non-blocking}

Estos escenarios **no** devuelven errores al comercio. El pago siempre continúa:

| Escenario | Comportamiento |
| :---- | :---- |
| Se encontró un mapeo para el proveedor enrutado | El pago usa el `merchant_id` resuelto y el detalle específico del tipo. |
| No hay mapeo para el proveedor enrutado / `payment_method_type` | Se registra una advertencia y se usa el `merchant_id` original de la conexión. |
| No hay datos de `payment_method` para este seller | Se registra una advertencia y se usa el `merchant_id` original de la conexión. |
| El servicio de resolución de franquicia no está disponible | Se registra un error y se usa el `merchant_id` original de la conexión. |
| No están presentes ni `seller_id` ni `merchant_seller_id` | La resolución de franquicia se omite por completo: sin impacto. |
