---
title: "Crear una campaña"
openapi: "/openapi/communications-campaigns/create-campaign.json POST /campaigns"
description: "Crea una nueva campaña de comunicaciones para la recuperación de pagos rechazados, con estado INACTIVE de forma predeterminada."
---

Crea una nueva campaña. Si no se proporciona `status`, las campañas quedan en `INACTIVE` de forma predeterminada.

Consulta la [referencia del objeto campaña](/es/reference/communications-campaigns#campaign-object) para obtener más información.
