---
title: "Descargar un reporte"
openapi: "/openapi/reports/download-a-report.json GET /reports/{report_id}/download
"
description: "Obtiene el enlace de descarga de un reporte generado usando su ID de reporte."
---

<Warning>
**Actualización reciente del endpoint**

Este endpoint se actualizó recientemente a la versión 2 (consulta "V2" en la URL). La versión 1 está obsoleta, por lo que recomendamos cambiar a V2 lo antes posible.
</Warning>

Para obtener el contenido del archivo, usa tus credenciales de API para acceder al archivo especificado por el `id` del objeto reporte.

<Note>
**Descarga de reportes**

La respuesta de la API incluirá un enlace para descargar el reporte. Abre el enlace en tu navegador para acceder a los datos.
</Note>
