---
title: "Crear un reporte"
openapi: "/openapi/es/reports/create-a-report.json POST /reports"
description: "Solicita la generación de un reporte de pagos, transacciones o liquidaciones y devuelve su ID y estado."
---

Este endpoint te permite solicitar la generación de tipos de reporte específicos. `start_date` debe ser anterior a `end_date`; de lo contrario, la API responde 400 `REPORT_RANGE_ERROR`. `start_date` también debe ser anterior a la hora actual, excepto en los reportes `AGENDA` y `CASHFLOW`, que aceptan fechas futuras. Para los tipos de reporte distintos de `TRANSACTIONS`, `PAYMENTS`, `FRAUD_TRANSACTIONS`, `PAYOUTS`, `AGENDA` y `CASHFLOW`, el rango entre `start_date` y `end_date` es de máximo 62 días, y un rango mayor se rechaza con `400`. La respuesta de este endpoint proporciona un objeto que contiene:

* El `status` de la generación del reporte.
* Un `id` de reporte.

Usa el ID del reporte para descargarlo con el endpoint [Descargar un reporte](/es/reference/reports/download-a-report) después de que se genere.
