En esta página encontrarás la información de aerolíneas que puedes necesitar al usar los endpoints de la API de Yuno. Incluye los tipos de pasajero, los códigos de clase de tarifa y los niveles de fidelidad. Usa esta página para conocer y consultar los valores estándar de cada categoría de información.

## Tipo de pasajero {#passenger-type}

| `passenger_type` | Descripción    |
| ---------------- | -------------- |
| `A`              | Adulto         |
| `C`              | Niño           |
| `I`              | Infante o bebé |

## Código de clase de tarifa {#fare-class-code}

| `fare_class_code` | Descripción                                     |
| ------------------ | ------------------------------------------------ |
| Letra (A-Z)        | Varía según la definición de cada aerolínea. Máximo 1 carácter.   |

## Nivel de fidelidad {#loyalty-tier}

| `loyalty_tier` | Descripción                 |
| ------------ | -------------------------- |
|       `1`      | Nivel de clasificación alto   |
|       `2`      | Segundo nivel de clasificación |
|       `3`      | Tercer nivel de clasificación  |
