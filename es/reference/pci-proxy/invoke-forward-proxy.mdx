---
title: "Invocar el Forward Proxy"
description: "Llama a cualquier API HTTPS de terceros con datos reales de tarjeta a través del entorno PCI DSS Nivel 1 de Yuno, referenciando las tarjetas almacenadas mediante vaulted_token."
keywords: ["pci proxy", "forward proxy", "yuno-proxy-destination-url", "vaulted_token", "detokenization"]
openapi: "/openapi/es/pci-proxy/invoke-forward-proxy.json POST /pci-proxy/forward"
---

Reenvía tu solicitud al destino indicado en el encabezado `yuno-proxy-destination-url`, reemplazando las expresiones `{{vaulted_token.<TOKEN>.<field>}}` dentro del entorno seguro de Yuno con los datos almacenados bajo el token almacenado: la tarjeta (PAN, vencimiento, nombre del titular), su token de red (DPAN y su vencimiento) y su ID de transacción de red (NTID). Para los destinos que requieren solicitudes firmadas con HMAC, envía `yuno-proxy-auth` + `yuno-proxy-auth-secret-key` y el proxy firma por ti el cuerpo ya resuelto. Consulta [Destinos firmados](/es/docs/security-and-compliance/pci-proxy/forward-proxy#signed-destinations-hmac-request-signing) para más detalles. Consulta la [guía del Forward Proxy](/es/docs/security-and-compliance/pci-proxy/forward-proxy) para una integración paso a paso.

<Note>
**Beta**

El PCI Proxy está en beta y se habilita por organización. En producción, las solicitudes devuelven `403 PRODUCT_NOT_ENABLED` hasta que tu organización sea activada; contacta a tu Key Account Manager (KAM). El sandbox está abierto para pruebas.
</Note>

<Warning>
**Solo del lado del servidor**

Las solicitudes al proxy desencriptan datos de tarjeta y solo deben hacerse desde tu backend. Nunca expongas tu `private-secret-key` en código del lado del cliente.
</Warning>

Se admiten todos los métodos `GET`, `POST`, `PUT`, `PATCH` y `DELETE`: el destino recibe el mismo método que usaste. Incluye la URL completa del destino, con su ruta y cualquier query string, en el encabezado `yuno-proxy-destination-url`; un query string en la propia solicitud a `/pci-proxy/forward` se rechaza. El host de destino debe estar en tu [lista de destinos permitidos](/es/docs/security-and-compliance/pci-proxy/allowlist).

Si eres un comercio certificado en PCI y necesitas los datos de tarjeta en bruto en lugar de una llamada de paso, usa en su lugar [Retrieve Enrolled Payment Method by ID PCI Data](/es/reference/payment-methods-direct-workflow/retrieve-enrolled-payment-method-by-id-pci-api).
