---
title: "Registrar destino"
description: "Agrega un host de terceros a la lista de permitidos de tu PCI Proxy para que el proxy de reenvío pueda enviarle datos de tarjetas."
keywords: ["PCI Proxy", "lista de permitidos", "destino", "seguridad"]
openapi: "/openapi/es/pci-proxy/manage-destinations.json POST /pci-proxy/destinations"
---

Agrega un host a la lista de destinos permitidos de tu cuenta. El [proxy de reenvío](/es/reference/pci-proxy/invoke-forward-proxy) solo envía datos de tarjetas a los hosts de esta lista; no existe un modo "cualquier host". Consulta la [guía de la lista de destinos permitidos](/es/docs/security-and-compliance/pci-proxy/allowlist) para saber cómo funciona la coincidencia.

<Note>
**Agregar un destino es una acción sensible**

Registrar un host amplía los lugares a los que se pueden enviar tus tarjetas almacenadas. Restringe quién puede gestionar la lista de permitidos y revisa cualquier adición inesperada.
</Note>
