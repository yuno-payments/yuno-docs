---
title: "Habilitar destino"
description: "Vuelve a habilitar un destino desactivado en la lista de permitidos de tu PCI Proxy para que el proxy de reenvío pueda usarlo de nuevo."
keywords: ["PCI Proxy", "lista de permitidos", "destino", "seguridad"]
openapi: "/openapi/es/pci-proxy/manage-destinations.json POST /pci-proxy/destinations/{id}/enable"
---

Vuelve a habilitar un destino desactivado para que el [proxy de reenvío](/es/reference/pci-proxy/invoke-forward-proxy) lo use de nuevo. Solo se puede acceder a los destinos `ENABLED`. Una solicitud a un host `DISABLED` se rechaza con `403 DESTINATION_NOT_ALLOWED`. Consulta la [guía de la lista de destinos permitidos](/es/docs/security-and-compliance/pci-proxy/allowlist).
