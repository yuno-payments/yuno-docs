---
title: "Crear cuenta"
openapi: "/openapi/es/banking-connectivity/accounts/create-account-banking.json POST /banking/accounts"
description: "Crea una cuenta bancaria para una entidad cuyo estado de onboarding fue exitoso"
---

Crea una cuenta bancaria para una entidad con onboarding completado. El onboarding referenciado por `onboarding_id` debe tener `status: SUCCEEDED`. Un onboarding de tipo `PREVIOUSLY_ONBOARDED` no puede crear una cuenta hoy: la API responde `500` con `PROVIDER_ACCOUNT_CREATION_FAILED`.

La respuesta incluye identificadores bancarios específicos de cada región. Consulta [Identificadores de cuenta por región](/es/reference/banking-connectivity#account-identifiers-by-region) para saber qué campos se devuelven por región.
