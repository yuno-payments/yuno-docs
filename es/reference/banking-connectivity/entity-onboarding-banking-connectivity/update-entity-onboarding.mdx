---
title: "Actualizar onboarding de entidad"
openapi: "/openapi/es/banking-connectivity/entity-onboarding-banking-connectivity/update-entity-onboarding.json PATCH /banking/entities/{entity_id}/onboardings/{onboarding_id}"
description: "Envía documentación adicional para el onboarding de una entidad existente"
---

Envía documentos adicionales para un onboarding existente. Normalmente se usa cuando el onboarding está en estado `PENDING_ADDITIONAL_DOCUMENTATION`. Solo se pueden actualizar los onboardings que no han llegado a un estado terminal; de lo contrario, la API devuelve 400 `INVALID_STATE_TRANSITION`.
