Realiza el onboarding de una [entidad](/es/reference/banking-connectivity/entities-banking-connectivity/create-entity) existente con un proveedor de Banking Connectivity.

## Tipos de onboarding {#onboarding-types}

* **`ONE_STEP`**: Envía de una sola vez toda la información, las declaraciones de cumplimiento, la evaluación de riesgo y los documentos. El proveedor lo procesa de inmediato.
* **`PREVIOUSLY_ONBOARDED`**: Genera un ID de onboarding interno de Yuno sin contactar al proveedor. Úsalo cuando la entidad ya pasó por el onboarding de forma externa.

Para `ONE_STEP`, incluye `compliance_declaration`, `risk_assessment`, `source_of_funds` y `documentation`. Consulta [Tipos de documentación](/es/reference/banking-connectivity#documentation-types) para ver la lista completa de tipos de documento admitidos.

Monitorea el progreso mediante [Obtener el estado del onboarding de una entidad](/es/reference/banking-connectivity/entity-onboarding-banking-connectivity/get-entity-onboarding-status) o eventos de webhook. Consulta [Estados del onboarding](/es/reference/banking-connectivity#onboarding-statuses) para ver el ciclo de vida completo de los estados.
