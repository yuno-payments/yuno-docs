---
title: "Cancelar el onboarding de una entidad (Banking Connectivity)"
openapi: "/openapi/es/banking-connectivity/entity-onboarding-banking-connectivity/cancel-entity-onboarding.json POST /banking/entities/{entity_id}/onboardings/{onboarding_id}/cancel"
description: "Cancela el onboarding de una entidad en curso con un proveedor de banking connectivity"
---

<Warning>
  Este endpoint aún no está disponible a través de la API pública. Las solicitudes a esta ruta devuelven 404 `NOT_FOUND`. El resto de esta página describe un comportamiento que hoy no está implementado.
</Warning>

Cancela un onboarding pendiente. Solo se pueden cancelar los onboardings que no han llegado a un estado terminal. Consulta [Estados de onboarding](/es/reference/banking-connectivity#onboarding-statuses) para saber qué estados son terminales.
