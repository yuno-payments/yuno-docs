---
title: "Crear entidad (Banking Connectivity)"
openapi: "/openapi/es/banking-connectivity/entities-banking-connectivity/create-entity.json POST /banking/entities"
description: "Crea una entidad individual o empresarial para el onboarding de banking connectivity"
---

Crea una entidad de Yuno que representa a una persona o a una organización. Define `entity_type` como `INDIVIDUAL` o `BUSINESS` y proporciona el sub-objeto `entity_detail` correspondiente. Consulta [Entity types](/es/reference/banking-connectivity#entity-types) para más detalles.

Los campos sensibles como `tax_id` y `document_number` se enmascaran en las respuestas (por ejemplo `*******6789`).
