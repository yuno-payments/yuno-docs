**Inicio rápido para agentes**

1. Lee [llms.txt](https://docs.y.uno/llms.txt) y esta página.
2. Carga la [especificación OpenAPI](https://docs.y.uno/openapi.json).
3. Autentícate como se describe en [Autenticación](/es/reference/getting-started/authentication).
4. Crea un pago con la API de pagos o un SDK. La [guía de inicio rápido](/es/docs/quickstart) muestra ambos.
5. Suscríbete a los [webhooks](/docs/webhooks) para recibir actualizaciones de estado asíncronas.
