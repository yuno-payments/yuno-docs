```javascript Node.js
const res = await fetch("https://api-sandbox.y.uno/v1/payments", {
  method: "POST",
  headers: {
    "public-api-key": process.env.YUNO_PUBLIC_API_KEY,
    "private-secret-key": process.env.YUNO_PRIVATE_SECRET_KEY,
    "X-Idempotency-Key": crypto.randomUUID(),

  },
  body: JSON.stringify({
    account_id: process.env.YUNO_ACCOUNT_ID,
```

```python Python
import os
import uuid
import requests

res = requests.post(
    "https://api-sandbox.y.uno/v1/payments",
    headers={
        "public-api-key": os.environ["YUNO_PUBLIC_API_KEY"],
        "private-secret-key": os.environ["YUNO_PRIVATE_SECRET_KEY"],
        "X-Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "account_id": os.environ["YUNO_ACCOUNT_ID"],
        "merchant_order_id": "order-0001",
        "description": "First test payment",
        "country": "US",
        "amount": {"currency": "USD", "value": 25},
        "workflow": "DIRECT",
        "payment_method": {
            "type": "CARD",
            "detail": {"card": {"card_data": {
                "number": "4507990000000002",
                "expiration_month": 11,
                "expiration_year": 28,
                "security_code": "123",
                "holder_name": "John Doe",
            }}},
        },
    },
)
print(res.json()["status"])  # SUCCEEDED
```

    <li>

      </a>
    </li>
    <li>
      <a className="yd-object" href="/es/docs/basic-concepts/webhooks-1">
        <span className="yd-object-num">4</span>
        <span className="yd-object-title">Webhook</span>

        <span className="yd-object-body">Yuno envía cada cambio de estado a una URL que registras en el Dashboard o por API.</span>
      </a>
    </li>
  </ol>
  <p className="yd-foot">El SDK convierte los datos de la tarjeta en un token de un solo uso (OTT) que envías con el pago. La API directa omite la sesión y envía los datos de la tarjeta desde tu servidor, lo que requiere PCI DSS. Secuencia completa: <a href="/es/docs/how-yuno-works/how-yuno-payment-flow-works">Flujo de pago</a>.</p>
