title: "Crea con IA"
description: "Conecta Claude Code, Cursor, Windsurf, VS Code o cualquier agente de programación a la documentación y la API de Yuno para que integre el SDK y cree pagos con contexto actualizado"
---

Yuno publica su documentación y su API en los formatos que leen los agentes de programación. Conecta tu agente una sola vez y podrá generar la base del SDK, crear sesiones de checkout y pagos en sandbox, y leer las respuestas de la API con los nombres de campo actuales en lugar de adivinarlos a partir de sus datos de entrenamiento.

Hay tres cosas que puedes conectar, y rara vez necesitas todas:

| Quieres que el agente | Connect | Autenticación |
| :--- | :--- | :--- |
| Lea la documentación mientras escribe tu integración | Servidor MCP de documentación en `https://docs.y.uno/mcp` | Ninguna |
| Llame a la API de Yuno en tu cuenta (crear clientes, sesiones, pagos, reembolsos) | [Remote Yuno MCP Server](/es/docs/ai-capabilities/remote-yuno-mcp-server) en `https://mcp.prod.y.uno/mcp`, o el paquete local `@yuno-payments/yuno-mcp` | Tus claves de API |
| Lance un producto de IA que recibe pagos | [Agent Toolkit](/es/docs/ai-capabilities/agent-toolkit) (`@yuno-payments/agent-toolkit`) | Tus claves de API |

## Claude Code {#claude-code}

Agrega el servidor de documentación a Claude Code desde la terminal:

```bash
claude mcp add --transport http yuno-docs https://docs.y.uno/mcp
```

Para compartirlo con todas las personas del repositorio, haz commit de un archivo `.mcp.json` en la raíz del proyecto:

```json
{
  "mcpServers": {
    "yuno-docs": {
      "type": "http",
      "url": "https://docs.y.uno/mcp"
    }
  }
}
```

Luego pide lo que necesites en lenguaje natural, por ejemplo:

* "Integra el Yuno Seamless SDK en esta aplicación Next.js. Crea la sesión de checkout en un route handler y monta el SDK en un componente de cliente."
* "Agrega una ruta `/api/payments` que cree un pago de Yuno a partir del token de un solo uso y siga las reglas de reintento de pagos."
* "Suscríbete a los webhooks `payment.purchase` y `payment.chargeback` y verifica la firma HMAC."

Claude Code también lee archivos `AGENTS.md`. Yuno publica uno en [docs.y.uno/AGENTS.md](https://docs.y.uno/AGENTS.md) con comandos de instalación, URL base, credenciales y el flujo de pago de cuatro pasos; cópialo en tu proyecto o apunta al agente a la URL.

## Cursor, Windsurf y VS Code {#cursor-windsurf-and-vs-code}

Agrega el mismo servidor desde la configuración de MCP de cada editor. Las instrucciones paso a paso para Cursor, Claude Desktop, Windsurf y VS Code Copilot están en [Setup MCP](/setup-mcp). La configuración es la misma en todos: tipo `http`, URL `https://docs.y.uno/mcp`, sin credenciales.

## Cualquier agente {#any-agent}

Los agentes que no usan MCP también pueden leer todo:

* **`https://docs.y.uno/llms.txt`** enumera todas las páginas en un índice legible por máquinas. Agrega `.md` a cualquier URL de la documentación para obtener esa página en Markdown.
* **`https://docs.y.uno/openapi.json`** (también `.yaml`) es la especificación OpenAPI 3.1 de la API de pagos, agregada a partir de las especificaciones por operación que respaldan la referencia de la API.
* **[Recursos para desarrolladores](/es/docs/developers)** enumera los puntos de entrada que un agente debe leer primero y la guía de inicio rápido para agentes.

## Deja que el agente actúe en tu cuenta {#let-the-agent-act-on-your-account}

Cuando el agente debe crear objetos reales en lugar de escribir código, dale el servidor MCP de la API. El endpoint alojado es `https://mcp.prod.y.uno/mcp` con los encabezados `public-api-key`, `private-secret-key` y `account-code`; la opción local es `npx @yuno-payments/yuno-mcp@latest` con los mismos valores como variables de entorno. Ambos exponen como herramientas clientes, métodos de pago, sesiones de checkout, pagos, links de pago, suscripciones, destinatarios y planes de cuotas. Consulta [Building AI Integrations with Yuno's LLMs and MCP](/es/docs/ai-capabilities/building-ai-integrations-with-yunos-llms-and-mcp) para ver la lista de herramientas y [Remote Yuno MCP Server](/es/docs/ai-capabilities/remote-yuno-mcp-server) para conocer los límites de sesión.

<Warning>
  Usa claves de sandbox mientras el agente itera. El servidor MCP de la API ejecuta lo que el agente le pide, incluidos reembolsos y cancelaciones en producción si le das claves de producción.
</Warning>

## Verifica lo que escribió el agente {#verify-what-the-agent-wrote}

Un agente con la documentación conectada necesita las mismas revisiones que una persona:

* Los pagos se crean desde tu servidor con el token de un solo uso, nunca desde el navegador.
* `X-Idempotency-Key` se envía en cada llamada a la API.
* El callback `createPayment` sigue las [reglas de reintento de pagos](/es/docs/sdks/resources/references/web#payment-retry).
* Los manejadores de webhooks verifican `x-hmac-signature` antes de confiar en el payload.

Si el agente trabaja en React o Next.js, apúntalo a la guía de React y Next.js en SDKs para conocer el patrón de montaje solo en el cliente.
