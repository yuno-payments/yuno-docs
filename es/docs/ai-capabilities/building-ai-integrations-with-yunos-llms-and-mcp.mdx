Yuno publica su documentación en formatos que los modelos de lenguaje de gran tamaño (LLM) y los agentes de código leen directamente. Apunta tu agente a estos archivos para que responda preguntas y escriba integraciones a partir de la documentación actual, en lugar de adivinar a partir de sus datos de entrenamiento.

<Note>
  ¿Quieres que un asistente de IA trabaje con tu cuenta de Yuno (analizar los datos de tus pagos, buscar en la documentación, ejecutar operaciones de pago)? Consulta [Usa Yuno con asistentes de IA](/es/docs/ai-capabilities/use-yuno-with-claude-and-chatgpt).
</Note>

## Archivos para agentes {#files-for-agents}

| Archivo | Qué contiene |
| --- | --- |
| [llms.txt](https://docs.y.uno/llms.txt) | Un índice de todas las páginas de la documentación, con una breve descripción de cada una. Empieza aquí. |
| [llms-full.txt](https://docs.y.uno/llms-full.txt) | Toda la documentación en un solo archivo de texto plano. |
| [AGENTS.md](https://docs.y.uno/AGENTS.md) | Instrucciones para agentes de código que integran Yuno: instalación, configuración, primer pago y recursos. |
| [skill.md](https://docs.y.uno/skill.md) | Un archivo de skill que los agentes pueden cargar para trabajar con la API de Yuno. |
| [sitemap.md](https://docs.y.uno/sitemap.md) | La lista de páginas de la documentación en Markdown. |
| [openapi.json](https://docs.y.uno/openapi.json) | La especificación OpenAPI de la API de Yuno, para generar código y validar solicitudes. |

## Cualquier página en Markdown {#any-page-in-markdown}

Agrega `.md` al final de cualquier URL de la documentación de Yuno para obtener esa página en Markdown. Funciona tanto para las guías como para las páginas de la referencia de la API. Por ejemplo, [docs.y.uno/docs/quickstart.md](https://docs.y.uno/docs/quickstart.md).

Cada página también tiene un botón **Copy page** que copia su Markdown, listo para pegar en el contexto de tu agente.
