Yuno ofrece herramientas para ayudarte a crear experiencias de pago preparadas para la IA y amigables para el comercio. La documentación lista para máquinas de Yuno facilita que los modelos de lenguaje de gran tamaño (LLM) comprendan las API y la documentación de Yuno, mientras que el Model Context Protocol (MCP) de Yuno te permite integrar las capacidades de Yuno directamente en tu producto.

Esta guía presenta cómo trabajar con ambos componentes: cómo la capa de LLM ayuda a las herramientas de IA a ofrecer un soporte de integración más preciso y contextual, y cómo el MCP incorpora las funciones clave de pagos y de comercio directamente en tu entorno.

<Note>
  ¿Buscas el conector de un clic en lugar de crear tu propio cliente MCP? Consulta [Usa Yuno con asistentes de IA](/es/docs/ai-capabilities/use-yuno-with-claude-and-chatgpt).
</Note>

<Note>
  ¿Solo necesitas que un agente busque y lea la documentación de Yuno, sin credenciales de API y sin capacidad de actuar sobre tu cuenta? Consulta en su lugar el [MCP de documentación](/setup-mcp) de solo lectura.
</Note>

## Contenido listo para máquinas en texto plano {#machine-ready-content-in-plain-text}

Para ayudar a los modelos de lenguaje de gran tamaño a comprender y respaldar las integraciones con Yuno, Yuno proporciona un conjunto dedicado de archivos Markdown (.md) diseñados específicamente para que las máquinas los lean. Estos archivos describen las API de Yuno, el comportamiento del producto y los detalles de implementación en un formato que los LLM pueden analizar con facilidad.

Los archivos .md forman parte de [Yuno Docs](/). Puedes acceder a ellos agregando .md al final de cualquier URL de Yuno Docs (esto funciona tanto para las páginas de Guías como para las de API Reference). El contenido se sirve en texto plano, lo que facilita que las máquinas extraigan y procesen el conocimiento subyacente sin necesidad de interpretación humana.

Esta configuración permite que los asistentes de IA, las herramientas para desarrolladores y los agentes basados en chat respondan preguntas, expliquen funciones y guíen las integraciones de forma automática.

<Note>
  ¿Buscas un endpoint MCP administrado y accesible por red, con vinculación de IP, límites de frecuencia y TTL de sesión? Consulta el [servidor MCP remoto de Yuno](/es/docs/ai-capabilities/remote-yuno-mcp-server).
</Note>

## Model Context Protocol (MCP) de Yuno {#yunos-model-context-protocol-mcp}

Este paquete proporciona un servidor MCP que expone la API de la plataforma de pagos de Yuno como herramientas del Model Context Protocol. Permite el acceso programático para agentes de IA, sistemas de automatización y otros flujos de trabajo avanzados que dependen de un contexto estructurado y legible por máquinas.

### Características {#features}

* **Expone los endpoints de la API de Yuno como herramientas MCP**: cada endpoint se modela como una herramienta que los agentes pueden llamar de forma programática, con estructuras de entrada y salida claras

* **Habilita flujos de trabajo de IA y automatización con Yuno**: integra Yuno en agentes locales o flujos de trabajo personalizados sin lógica compleja creada a mano

* **Integración sencilla con Cursor y otros agentes compatibles con MCP**: funciona de inmediato con herramientas como Cursor, Claude Code, Claude Desktop, Codex y otros entornos que admiten el Model Context Protocol

### Herramientas disponibles {#available-tools}

El servidor MCP de Yuno pone las siguientes herramientas a disposición de los agentes de IA y la automatización:

| Nombre de la herramienta                | Descripción                                                                    |
| --------------------------------------- | ------------------------------------------------------------------------------ |
| `customerCreate`                        | Crear un nuevo cliente                                                         |
| `customerRetrieve`                      | Obtener un cliente por ID                                                      |
| `customerRetrieveByExternalId`          | Obtener un cliente por ID externo (`merchant_customer_id`)                     |
| `customerUpdate`                        | Actualizar un cliente existente por ID                                         |
| `paymentMethodEnroll`                   | Inscribir o crear un método de pago para un cliente                            |
| `paymentMethodRetrieve`                 | Obtener un método de pago                                                      |
| `paymentMethodRetrieveEnrolled`         | Obtener todos los métodos de pago inscritos de un cliente                      |
| `paymentMethodUnenroll`                 | Cancelar la inscripción de un método de pago                                   |
| `checkoutSessionCreate`                 | Crear una sesión de checkout                                                   |
| `checkoutSessionCreateOtt`              | Generar un One Time Token (OTT) para una sesión de checkout                    |
| `checkoutSessionRetrievePaymentMethods` | Obtener los métodos de pago para el checkout                                   |
| `paymentCreate`                         | Crear un pago con distintos flujos de trabajo                                  |
| `paymentRetrieve`                       | Obtener la información de un pago                                              |
| `paymentRetrieveByMerchantOrderId`      | Obtener uno o varios pagos por `merchant_order_id`                             |
| `paymentRefund`                         | Reembolsar un pago (total o parcial) por ID de pago y de transacción           |
| `paymentCancelOrRefund`                 | Cancelar o reembolsar un pago por ID de pago (detecta la acción automáticamente) |
| `paymentCancelOrRefundWithTransaction`  | Cancelar o reembolsar un pago por ID de pago y de transacción (detecta la acción automáticamente) |
| `paymentCancel`                         | Cancelar un pago pendiente por ID de pago y de transacción                     |
| `paymentAuthorize`                      | Autorizar un pago (`capture: false`)                                           |
| `paymentCaptureAuthorization`           | Capturar un pago previamente autorizado                                        |
| `paymentLinkCreate`                     | Crear un nuevo enlace de pago                                                  |
| `paymentLinkRetrieve`                   | Obtener un enlace de pago por ID                                               |
| `paymentLinkCancel`                     | Cancelar un enlace de pago por ID                                              |
| `subscriptionCreate`                    | Crear una nueva suscripción                                                    |
| `subscriptionRetrieve`                  | Obtener una suscripción por ID                                                 |
| `subscriptionPause`                     | Pausar una suscripción por ID                                                  |
| `subscriptionResume`                    | Reanudar una suscripción por ID                                                |
| `subscriptionUpdate`                    | Actualizar una suscripción por ID                                              |
| `subscriptionCancel`                    | Cancelar una suscripción por ID                                                |
| `recipientCreate`                       | Crear un nuevo destinatario                                                    |
| `recipientRetrieve`                     | Obtener un destinatario por ID                                                 |
| `recipientUpdate`                       | Actualizar un destinatario por ID                                              |
| `recipientDelete`                       | Eliminar un destinatario por ID                                                |
| `installmentPlanCreate`                 | Crear un nuevo plan de cuotas                                                  |
| `installmentPlanRetrieve`               | Obtener un plan de cuotas por ID                                               |
| `installmentPlanRetrieveAll`            | Obtener todos los planes de cuotas de una cuenta                               |
| `installmentPlanUpdate`                 | Actualizar un plan de cuotas por ID                                            |
| `installmentPlanDelete`                 | Eliminar un plan de cuotas por ID                                              |
| `documentationRead`                     | Acceder a la documentación y las guías de la API de Yuno                       |

<Note>
  El [servidor MCP remoto de Yuno](/es/docs/ai-capabilities/remote-yuno-mcp-server) solo acepta argumentos de herramientas en snake_case. Una clave desconocida como `idempotencyKey` se rechaza, y el error indica `idempotency_key`. `paymentAuthorize` retiene el monto o rechaza la llamada con `UNSUPPORTED_AUTHORIZATION`.
</Note>

## Uso del MCP con Cursor, Claude Code, Claude Desktop o Codex {#using-the-mcp-with-cursor-claude-code-claude-desktop-or-codex}

Puedes usar este servidor MCP con Cursor, Claude Code, Claude Desktop o Codex para habilitar flujos de pago impulsados por IA, creación de clientes y más.

### 1. Configura tus credenciales de la API de Yuno {#1-set-up-your-yuno-api-credentials}

Configura tus credenciales de la API de Yuno mediante variables de entorno (consulta los ejemplos de configuración más abajo).

### 2. Agrega el servidor MCP a tu cliente {#2-add-the-mcp-server-to-your-client}

<Tabs>
  <Tab title="Cursor">
    * Abre Cursor Settings (`Cmd+Shift+P` → "Cursor Settings")
    * Ve a la sección **MCP** y haz clic en **Add new global MCP server**
    * Agrega la siguiente configuración:

    ```json
    {
      "mcpServers": {
        "yuno-mcp": {
          "command": "npx",
          "args": ["@yuno-payments/yuno-mcp@latest"],
          "env": {
            "YUNO_ACCOUNT_CODE": "your_account_code",
            "YUNO_PUBLIC_API_KEY": "your_public_api_key",
            "YUNO_PRIVATE_SECRET_KEY": "your_private_secret_key",
            "YUNO_COUNTRY_CODE": "your_country_code",
            "YUNO_CURRENCY": "your_currency"
          }
        }
      }
    }
    ```
  </Tab>

  <Tab title="Claude Code">
    Ejecuta:

    ```bash
    claude mcp add yuno-mcp \
      -e YUNO_ACCOUNT_CODE=your_account_code \
      -e YUNO_PUBLIC_API_KEY=your_public_api_key \
      -e YUNO_PRIVATE_SECRET_KEY=your_private_secret_key \
      -e YUNO_COUNTRY_CODE=your_country_code \
      -e YUNO_CURRENCY=your_currency \
      -- npx @yuno-payments/yuno-mcp@latest
    ```

    Usa `--scope project` en lugar del alcance `local` predeterminado para compartir este servidor con tu equipo mediante `.mcp.json`. Nunca confirmes credenciales reales: en `.mcp.json`, escribe cada valor como una referencia, por ejemplo `"YUNO_PRIVATE_SECRET_KEY": "${YUNO_PRIVATE_SECRET_KEY}"`, para que Claude Code lo lea del entorno de shell de cada desarrollador.
  </Tab>

  <Tab title="Claude Desktop">
    * Abre la configuración de Claude Desktop → pestaña "Developer" → Edit Config.
    * Agrega la siguiente configuración:

    ```json
    {
      "mcpServers": {
        "yuno-mcp": {
          "command": "npx",
          "args": ["@yuno-payments/yuno-mcp@latest"],
          "env": {
            "YUNO_ACCOUNT_CODE": "your_account_code",
            "YUNO_PUBLIC_API_KEY": "your_public_api_key",
            "YUNO_PRIVATE_SECRET_KEY": "your_private_secret_key",
            "YUNO_COUNTRY_CODE": "your_country_code",
            "YUNO_CURRENCY": "your_currency"
          }
        }
      }
    }
    ```
  </Tab>

  <Tab title="Codex">
    Ejecuta:

    ```bash
    codex mcp add yuno-mcp \
      --env YUNO_ACCOUNT_CODE=your_account_code \
      --env YUNO_PUBLIC_API_KEY=your_public_api_key \
      --env YUNO_PRIVATE_SECRET_KEY=your_private_secret_key \
      --env YUNO_COUNTRY_CODE=your_country_code \
      --env YUNO_CURRENCY=your_currency \
      -- npx @yuno-payments/yuno-mcp@latest
    ```
  </Tab>
</Tabs>

### 3. Prueba la integración {#3-test-the-integration}

* En tu cliente, selecciona un archivo Markdown o un chat y pide al agente que cree un pago, un cliente o una sesión de checkout usando la herramienta yuno-mcp
* Asegúrate de que tus variables de entorno estén configuradas correctamente

## Variables de entorno {#environment-variables}

* `YUNO_ACCOUNT_CODE`\*
* `YUNO_PUBLIC_API_KEY`\*
* `YUNO_PRIVATE_SECRET_KEY`\*
* `YUNO_COUNTRY_CODE` (opcional)
* `YUNO_CURRENCY` (opcional)

El asterisco (\*) indica que es obligatorio.
