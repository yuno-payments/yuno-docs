El Remote Yuno MCP Server implementa el Model Context Protocol (MCP) para ofrecer acceso remoto y seguro a los servicios de Yuno. Actúa como un proxy alojado para que los agentes de IA y los clientes de automatización puedan llamar a las API de Yuno mediante MCP sin ejecutar un proceso local.

<Note>
  ¿Buscas el conector de un clic en lugar de crear tu propio cliente MCP? Consulta [Usa Yuno con asistentes de IA](/es/docs/ai-capabilities/use-yuno-with-claude-and-chatgpt).
</Note>

<Note>
  ¿Solo necesitas que un agente busque y lea la documentación de Yuno, sin credenciales de API y sin posibilidad de actuar en tu cuenta? Consulta en su lugar el [Documentation MCP](/setup-mcp) de solo lectura.
</Note>

## Capacidades principales {#key-capabilities}

### Seguridad {#security}

* Autenticación con clave de API: requiere `YUNO_PUBLIC_API_KEY`, `YUNO_PRIVATE_SECRET_KEY` y `YUNO_ACCOUNT_CODE`
* Sin estado: el servidor no guarda ninguna sesión, por lo que cada solicitud lleva sus propias credenciales

### Protocolos {#protocols}

* Transporte Streamable HTTP en modo sin estado: envía las solicitudes con `POST /mcp`. `GET` y `DELETE` devuelven `405 Method Not Allowed`
* JSON-RPC 2.0 para una solicitud y respuesta estandarizadas

## Cuándo usar el servidor remoto {#when-to-use-the-remote-server}

Usa el Remote MCP Server cuando quieras un endpoint alojado con observabilidad centralizada en lugar de ejecutar un proceso MCP en la máquina de cada desarrollador. Los clientes se siguen autenticando con los mismos `YUNO_PUBLIC_API_KEY`, `YUNO_PRIVATE_SECRET_KEY` y `YUNO_ACCOUNT_CODE` que el MCP local, enviados como los encabezados de solicitud `public-api-key`, `private-secret-key` y `account-code` en lugar de variables de entorno. Para el prototipado rápido en la máquina de un desarrollador, el [MCP local](/es/docs/ai-capabilities/building-ai-integrations-with-yunos-llms-and-mcp) (iniciado desde la CLI) puede ser suficiente.

## Argumentos de las herramientas {#tool-arguments}

Los argumentos de las herramientas usan snake_case. El servidor rechaza una clave desconocida, incluida una escritura en camelCase, en lugar de ignorarla. Enviar `idempotencyKey` produce un error que indica el campo aceptado, `idempotency_key`.

`paymentAuthorize` retiene el monto o rechaza la llamada. Los métodos de pago con tarjeta y billetera, incluidos Google Pay y Apple Pay, se autorizan con la captura deshabilitada. Un método de pago que el servidor no puede retener se rechaza con `UNSUPPORTED_AUTHORIZATION`, y no se envía nada al proveedor como cobro.

## Conexión desde clientes compatibles con MCP {#connecting-from-mcp-compatible-clients}

El Remote MCP Server expone un endpoint de transporte HTTP. Configura tu cliente MCP para que se conecte a tu URL asignada y envíe los encabezados requeridos.

Configuración de ejemplo (transporte HTTP):

Reemplaza los valores de encabezado de ejemplo que aparecen abajo por tus credenciales `YUNO_PUBLIC_API_KEY`, `YUNO_PRIVATE_SECRET_KEY` y `YUNO_ACCOUNT_CODE`.

```json
{
  "mcpServers": {
    "Yuno": {
      "type": "http",
      "url": "https://mcp.prod.y.uno/mcp",
      "headers": {
        "public-api-key": "<YUNO_PUBLIC_API_KEY>",
        "private-secret-key": "<YUNO_PRIVATE_SECRET_KEY>",
        "account-code": "<YUNO_ACCOUNT_CODE>"
      }
    }
  }
}
```

Para agregar el servidor desde Claude Code, ejecuta:

```bash
claude mcp add --transport http yuno https://mcp.prod.y.uno/mcp \
  --header "public-api-key: <YUNO_PUBLIC_API_KEY>" \
  --header "private-secret-key: <YUNO_PRIVATE_SECRET_KEY>" \
  --header "account-code: <YUNO_ACCOUNT_CODE>"
```

<Note>
  Puedes obtener tus `YUNO_PUBLIC_API_KEY`, `YUNO_PRIVATE_SECRET_KEY` y `YUNO_ACCOUNT_CODE` en el [dashboard de Yuno](https://dashboard.y.uno/).
</Note>
