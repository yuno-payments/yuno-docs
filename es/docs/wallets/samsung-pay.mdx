---
title: "Samsung Pay"
description: "Integra Samsung Pay en Yuno mediante el Web SDK o mediante el plugin de VTEX."
---

Samsung Pay es la billetera digital de Samsung que permite a los clientes pagar con las tarjetas guardadas en sus dispositivos Samsung, y confirmar cada pago con la seguridad de nivel militar de Samsung (huella digital, PIN o escaneo de iris). Samsung Pay funciona en dispositivos Samsung Galaxy compatibles y en algunos otros teléfonos Android, y usa NFC para pagos sin contacto o MST (Magnetic Secure Transmission) en dispositivos más antiguos.

## Integración con el SDK {#sdk-integration}

Samsung Pay está disponible como botón de billetera exprés en el **Web SDK** (desde el SDK 1.6). Cuando un comprador toca el botón de Samsung Pay, el SDK carga el Web Checkout SDK de Samsung, abre la hoja de pago de Samsung y envía a Yuno la credencial de pago tokenizada para su autorización.

Samsung Pay se habilita cuando tienes en el dashboard de Yuno una conexión con un proveedor de pago que lo admita y una regla de enrutamiento que lo incluya. Luego, el Web SDK lo detecta automáticamente según la configuración de tu dashboard, por lo que no se necesita ninguna configuración adicional del lado del SDK para mostrar el botón.

### Integración del Web SDK {#web-sdk-integration}

El Web SDK carga el Web Checkout SDK de Samsung y muestra el botón exprés con la marca. Para montar el botón en tu propio contenedor, usa [`mountExternalButtons`](/es/docs/sdks/resources/references/web#mount-external-buttons) *(Web SDK 1.10.0+)*:

```javascript
await yuno.mountExternalButtons([
  { paymentMethodType: 'SAMSUNG_PAY', elementSelector: '#samsung-pay' },
])
```

<Note>
**Localización al portugués (Web SDK 1.10.9+)**
Para el portugués de Brasil (`pt` / `pt-BR`), el Web SDK entrega automáticamente un recurso del botón de Samsung Pay localizado, para que los compradores vean el texto de la marca en portugués.
</Note>

Samsung Pay admite planes de cuotas mediante el endpoint [Create Installments Plan](/es/reference/installments/create-installments-plan) con `payment_method_type: SAMSUNG_PAY`. Los planes se limitan estrictamente al método de pago Samsung Pay: un plan creado para Samsung Pay solo se aplica cuando se selecciona Samsung Pay.

<Note>
  Las guías de integración para el **Android SDK** y la **Direct API** están en evaluación y se agregarán aquí cuando estén disponibles.
</Note>

## VTEX {#vtex}

Si usas el plugin de VTEX, puedes ofrecer Samsung Pay mediante la **Wallet enhanced experience**. Esto brinda a los compradores un botón de Samsung Pay simplificado en el checkout de VTEX, con la hoja de confirmación nativa de Samsung Pay.

<Steps>
  <Step title="Habilita Samsung Pay en tu tienda VTEX">

  Sigue la [guía de Wallet enhanced experience](/es/docs/plugins/vtex/apple-pay-google-pay-enhanced-experience) para configurar el snippet. Agrega `'Samsung Pay'` al arreglo `paymentMethods` junto con las demás billeteras.

  </Step>
  <Step title="Configura las cuotas de Samsung Pay (opcional)">

  Samsung Pay admite planes de cuotas en VTEX. Crea los planes desde el dashboard de Yuno con **Payment method type** configurado como **Samsung Pay**. La [sección de cuotas de Samsung Pay](/es/docs/plugins/vtex/apple-pay-google-pay-enhanced-experience#samsung-pay-installments) de la guía de VTEX explica las pantallas de creación de planes, las reglas de elegibilidad y la salvedad sobre cómo VTEX muestra los pedidos (VTEX muestra los pedidos en cuotas como un único pago completo en el resumen del pedido).

  </Step>
</Steps>
