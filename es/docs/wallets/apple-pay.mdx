Apple Pay es la billetera digital de Apple, que permite a los clientes pagar de forma rápida y segura con las tarjetas guardadas en sus dispositivos Apple, confirmando cada pago con Face ID, Touch ID o el código de acceso del dispositivo. Apple Pay funciona en apps nativas de iOS y en la web, y el soporte web no se limita a Safari ni a hardware de Apple: los clientes también pueden pagar desde navegadores de terceros en macOS y desde cualquier navegador en Windows. Consulta [Dispositivos y navegadores compatibles](#supported-devices-and-browsers) para ver la matriz completa.

Yuno ofrece una forma sencilla de incorporar Apple Pay como método de pago en tu app o sitio web. Tienes dos opciones de integración:

* Usar el SDK de Yuno
* Integrar directamente con la API de Yuno

Yuno simplifica el proceso de aceptar pagos con Apple Pay y ofrece la flexibilidad de enrutar los pagos a cualquier proveedor de servicios de pago. Al incorporar Apple Pay, puedes mejorar la experiencia del cliente e impulsar las conversiones en tu app y en tu sitio web.

## Dispositivos y navegadores compatibles {#supported-devices-and-browsers}

Apple Pay está disponible en dos contextos: **en la app**, para aplicaciones nativas de iOS que integran el SDK móvil de Yuno, y **en la web**, mediante el Web SDK de Yuno o una integración directa con la API.

En la web, Apple Pay está disponible en todas las plataformas y navegadores principales:

| Dispositivo del cliente | Navegador | Experiencia de pago |
|-----------------|---------|--------------------|
| iPhone / iPad (iOS, iPadOS) | Cualquier navegador: Safari, Chrome, Edge, Firefox y otros | Hoja de pago nativa de Apple Pay en el dispositivo |
| Mac (macOS) | Safari | Hoja de pago nativa de Apple Pay |
| Mac (macOS) | Chrome, Edge, Firefox y otros navegadores de terceros | Pago entre dispositivos: el cliente escanea un código con su iPhone y confirma el pago en el teléfono |
| PC con Windows | Cualquier navegador | Pago entre dispositivos: el cliente escanea un código con su iPhone y confirma el pago en el teléfono |

### Cómo funciona Apple Pay en navegadores de terceros {#how-apple-pay-works-in-third-party-browsers}

En los navegadores sin soporte integrado de Apple Pay (por ejemplo, Chrome en macOS o cualquier navegador en Windows), Apple ofrece un flujo de pago entre dispositivos: cuando el cliente selecciona Apple Pay en el checkout, aparece un código en la pantalla. El cliente lo escanea con su iPhone y aprueba el pago en el teléfono, usando las tarjetas de su Apple Wallet.

Este flujo lo proporciona el SDK oficial Apple Pay JS de Apple, que el Web SDK de Yuno carga y administra automáticamente:

- El Web SDK de Yuno comprueba la disponibilidad de Apple Pay en tiempo de ejecución mediante las API de Apple y muestra el botón de Apple Pay siempre que el navegador y el dispositivo del cliente puedan completar un pago, incluso en navegadores de terceros. No necesitas implementar la detección de navegador ni ocultar el botón tú mismo.
- No se requiere trabajo de integración adicional para el soporte de navegadores de terceros: los requisitos previos son exactamente los mismos que para Safari. Cada dominio donde aparece el botón de Apple Pay debe estar registrado, como se describe en la guía de [Requisitos previos (Apple Pay)](/es/docs/wallets/apple-pay/prerequisites-apple-pay).

<Note>
  **Requisitos de versión del Web SDK**

  El soporte para navegadores de terceros está disponible desde la versión **1.3** del Web SDK. Yuno recomienda encarecidamente usar la versión **1.8.0 o posterior**: a partir de la 1.8.0, toda la interacción de Apple Pay se completa antes de crear el token de un solo uso (OTT), por lo que el flujo ya no depende de los pasos de creación del pago y `continuePayment()` que requerían las versiones anteriores. Si usas una versión anterior, consulta el [Changelog del Web SDK (Legacy)](/es/changelog/web) para ver la guía de actualización.
</Note>

<Note>
  El flujo de pago entre dispositivos requiere que el cliente tenga un iPhone con iOS 18 o posterior. En iPhone y iPad, Apple Pay funciona de forma nativa en todos los navegadores principales (Chrome, Edge, Firefox y otros), ya que se basan en el motor WebKit del sistema.
</Note>

Para integrar Apple Pay con Yuno, primero debes completar el proceso de [Requisitos previos ](/es/docs/wallets/apple-pay/prerequisites-apple-pay). Después, elige la opción de integración que mejor se adapte a ti y accede a la documentación de integración correspondiente:

* [Integración con el SDK](/es/docs/wallets/apple-pay/apple-pay-sdk-integration): [configuración y pagos de un solo uso](/es/docs/wallets/apple-pay/apple-pay-sdk-integration), [pagos recurrentes](/es/docs/wallets/apple-pay/sdk-integration/recurring-payments), [express checkout](/es/docs/wallets/apple-pay/sdk-integration/express-checkout) y [filtros de tarjetas y datos útiles](/es/docs/wallets/apple-pay/sdk-integration/card-filters-and-good-to-know)

<Note>
  **Configuración del Merchant ID para Apple Pay**

  Si usas VTEX como plataforma de comercio electrónico, deberás configurar tu Merchant ID de Apple Pay. Para ver instrucciones detalladas, consulta la documentación oficial de VTEX: [Setting up Merchant ID in Apple Pay - VTEX Documentation](https://developers.vtex.com/docs/guides/setting-up-merchant-id-in-apple-pay).
