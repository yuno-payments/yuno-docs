PayPal es una billetera digital global que permite a los clientes pagar con su saldo de PayPal, cuentas bancarias vinculadas o tarjetas de crédito y débito almacenadas. En las regiones compatibles (como Estados Unidos), los compradores también pueden completar sus compras con **Venmo**.

## Características principales {#key-features}

* **Cobertura global**: acepta pagos de millones de cuentas activas de PayPal en todo el mundo.
* **Compatibilidad con Venmo**: cuando el parámetro `ENABLE_FUNDING` de tu conexión de PayPal incluye `venmo`, el Web SDK muestra un botón de Venmo debajo del botón de PayPal una vez que PayPal confirma que el comprador es elegible (un comprador de EE. UU. que paga en USD).
* **Checkout exprés**: muestra botones independientes de PayPal y Venmo directamente en las páginas de producto, de carrito o de pago.
* **Almacenamiento en el vault y Pay Later**: admite acuerdos de facturación y cuotas (Pay in 4 / Pay Later) donde sea elegible.

## Integración con el SDK {#sdk-integration}

PayPal está disponible como botón exprés en los flujos del Web SDK (Full Checkout, Lite y Seamless), así como en el Yuno SDK.

### Configuración del botón exprés {#express-button-configuration}

Pasa `externalButtons.paypal` en `startCheckout()` o `startSeamlessCheckout()` para personalizar la apariencia del botón:

```javascript
await yuno.startCheckout({
  checkoutSession,
  countryCode: 'US',
  language: 'en',
  externalButtons: {
    paypal: {
      color: 'gold',      // 'gold' | 'blue' | 'silver' | 'white' | 'black'
      shape: 'rect',      // 'rect' | 'pill' | 'sharp'
      label: 'paypal',    // 'paypal' | 'checkout' | 'buynow' | 'pay' | 'installment'
      layout: 'vertical', // 'vertical' | 'horizontal'
      height: 45,         // 25 to 55 px
      borderRadius: 4,
    },
  },
})
```

Para integraciones personalizadas de Braintree que usan PayPal, configura `externalButtons.paypalBraintree` con callbacks de envío como `onShippingAddressChange`. Consulta la [referencia del Web SDK](/es/docs/sdks/resources/references/web#paypal-braintree) para ver todas las opciones.

### Flujo de inscripción {#enrollment-flow}

Para pagos recurrentes o tokenización, monta el botón de PayPal en modo de inscripción con `mountEnrollmentLite()`. Consulta [PayPal enrollment with element render mode](/es/docs/sdks/lite-web/enrollment#paypal-enrollment-with-element-render-mode).

## Integración directa con un nonce de Braintree {#direct-integration-with-a-braintree-nonce}

Si cobras PayPal en tu propio checkout con el Braintree JS SDK y llamas a Yuno de servidor a servidor, envía el nonce de Braintree de un solo uso en un pago `DIRECT`. Yuno lo reenvía a la conexión de Braintree, que lo cobra y, con `vault_on_success`, almacena la cuenta de PayPal en el vault.

1. Obtén la aprobación de PayPal con el Braintree JS SDK y consigue el nonce.
2. Crea el pago con [Create Payment](/es/reference/payments/create-payment): `workflow` `DIRECT`, `payment_method.type` `PAYPAL_BRAINTREE`, el nonce en `payment_method.detail.wallet.provider_payment_token` y, para guardar la cuenta, `payment_method.vault_on_success` `true`.
3. Si el pago es exitoso, devuelve `payment_method.vaulted_token`. Cobra los pagos posteriores con ese `vaulted_token`. Yuno crea el `vaulted_token` solo cuando el pago incluye `customer_payer.id`.
4. Cuando necesites el id del método de pago de Braintree (por ejemplo, para compartir la cuenta de PayPal con un socio mediante la Braintree Grant API), léelo de la respuesta del pago en `payment_method.payment_method_detail.wallet.provider_token`. [Retrieve Payment](/es/reference/payments/retrieve-payment-by-id) devuelve el mismo valor, y [Retrieve Payment Method](/es/reference/payment-methods-checkout/retrieve-payment-method-by-id-checkout) lo devuelve como `provider.token` para el `vaulted_token`.

```json
{
  "account_id": "<ACCOUNT_ID>",
  "merchant_order_id": "order-1234",
  "country": "US",
  "amount": { "currency": "USD", "value": 50 },
  "workflow": "DIRECT",
  "customer_payer": { "id": "<CUSTOMER_ID>" },
  "payment_method": {
    "type": "PAYPAL_BRAINTREE",
    "vault_on_success": true,
    "detail": {
      "wallet": {
        "provider_payment_token": "<BRAINTREE_NONCE>"
      }
    }
  }
}
```

Reglas para `provider_payment_token`:

* Se acepta solo en el flujo de trabajo `DIRECT`; `REDIRECT` y `SDK_CHECKOUT` devuelven `400 INVALID_REQUEST`.
* No debe estar vacío y no debe combinarse con `wallet.payment_token`, `wallet.cryptogram`, `payment_method.token` ni `payment_method.vaulted_token`.
* El nonce es de un solo uso: envía uno nuevo en cada pago que lo use. Yuno no lo almacena.

## Presentación en el navegador móvil {#mobile-browser-presentation}

Cuando los compradores activan el checkout exprés de PayPal o Venmo en dispositivos móviles:
* **Navegadores de iOS (Safari, Chrome, Firefox, Edge en iOS), incluido Venmo**: de forma predeterminada, los navegadores móviles que abren ventanas emergentes congelan las pestañas en segundo plano, lo que puede interrumpir el intercambio del pago. El Web SDK puede mostrar PayPal y Venmo en una superposición modal con iframe dentro de la página, de modo que la página del comercio permanece activa mientras se transfiere la orden. La superposición se lanzó en el Web SDK 1.11.40 y está desactivada de forma predeterminada; Yuno la habilita por cuenta.
* **Escritorio**: los navegadores de escritorio (como Safari en macOS) siempre usan una ventana emergente.
* **Tiempo de generación de la orden**: el SDK registra cuando la generación de la orden tarda más de 30 segundos, sin hacer fallar la sesión ni devolver un error al comprador.
