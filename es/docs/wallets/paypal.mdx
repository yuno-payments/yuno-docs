PayPal es una billetera digital global que permite a los clientes pagar con su saldo de PayPal, cuentas bancarias vinculadas o tarjetas de crédito y débito almacenadas. En las regiones compatibles (como Estados Unidos), los compradores también pueden completar sus compras con **Venmo**.

## Características principales {#key-features}

* **Cobertura global**: acepta pagos de millones de cuentas activas de PayPal en todo el mundo.
* **Compatibilidad con Venmo**: cuando el parámetro `ENABLE_FUNDING` de tu conexión de PayPal incluye `venmo`, el Web SDK muestra un botón de Venmo debajo del botón de PayPal una vez que PayPal confirma que el comprador es elegible (un comprador de EE. UU. que paga en USD).
* **Checkout exprés**: muestra botones independientes de PayPal y Venmo directamente en las páginas de producto, de carrito o de pago.
* **Almacenamiento en bóveda y Pay Later**: admite acuerdos de facturación y cuotas (Pay in 4 / Pay Later) donde sea elegible.

## Integración con el SDK {#sdk-integration}

PayPal está disponible como botón exprés en los flujos del Web SDK (Full Checkout, Lite y Seamless), así como en el Yuno SDK.

### Configuración del botón exprés {#express-button-configuration}

Pasa `externalButtons.paypal` en `startCheckout()` o `startSeamlessCheckout()` para personalizar la apariencia del botón:

```javascript
await yuno.startCheckout({
  checkoutSession,
  countryCode: 'US',
  language: 'en',
  externalButtons: {
    paypal: {
      color: 'gold',      // 'gold' | 'blue' | 'silver' | 'white' | 'black'
      shape: 'rect',      // 'rect' | 'pill' | 'sharp'
      label: 'paypal',    // 'paypal' | 'checkout' | 'buynow' | 'pay' | 'installment'
      layout: 'vertical', // 'vertical' | 'horizontal'
      height: 45,         // 25 to 55 px
      borderRadius: 4,
    },
  },
})
```

Para integraciones personalizadas de Braintree que usan PayPal, configura `externalButtons.paypalBraintree` con callbacks de envío como `onShippingAddressChange`. Consulta la [referencia del Web SDK](/es/docs/sdks/resources/references/web#paypal-braintree) para ver todas las opciones.

### Flujo de inscripción {#enrollment-flow}

Para pagos recurrentes o tokenización, monta el botón de PayPal en modo de inscripción con `mountEnrollmentLite()`. Consulta [PayPal enrollment with element render mode](/es/docs/sdks/lite-web/enrollment#paypal-enrollment-with-element-render-mode).

## Presentación en el navegador móvil {#mobile-browser-presentation}

Cuando los compradores activan el checkout exprés de PayPal o Venmo en dispositivos móviles:
* **Navegadores de iOS (Safari, Chrome, Firefox, Edge en iOS), incluido Venmo**: de forma predeterminada, los navegadores móviles que abren ventanas emergentes congelan las pestañas en segundo plano, lo que puede interrumpir el intercambio del pago. El Web SDK puede mostrar PayPal y Venmo en una superposición modal con iframe dentro de la página, de modo que la página del comercio permanece activa mientras se transfiere el pedido. La superposición se lanzó en el Web SDK 1.11.40 y está desactivada de forma predeterminada; Yuno la habilita por cuenta.
* **Escritorio**: los navegadores de escritorio (como Safari en macOS) siempre usan una ventana emergente.
* **Tiempo de generación del pedido**: el SDK registra cuando la generación del pedido tarda más de 30 segundos, sin hacer fallar la sesión ni devolver un error al comprador.
