Al igual que el [Lite SDK](/es/docs/sdks/overview/quickstart), el Seamless SDK te permite obtener los métodos de pago disponibles y decidir cuáles mostrar durante el checkout. Una vez hecha la selección, una sola llamada a la API y al SDK completa el proceso de pago, y crea una experiencia idéntica a la del Lite SDK.

Con el Seamless SDK puedes:

* Ejecutar el proceso de pago.
* Inscribir una tarjeta de crédito mientras realizas un pago, configurando `vault_on_success: true` al crear el pago.
* Usar un token almacenado de un método de pago inscrito para completar un pago.

Usa las siguientes guías para implementar cada proceso.

### Flujo de pago headless del SDK {#sdk-headless-payment-flow}

Este diagrama ilustra el proceso de pago headless con el SDK y detalla las interacciones entre el cliente del comercio, el servidor del comercio, el servidor de Yuno y el Yuno SDK. Describe los pasos desde el inicio de un checkout y la solicitud de métodos de pago hasta la creación del pago y la recepción de su resultado.

#### Cliente del comercio {#merchant-client}

El cliente del comercio representa tu app, que interactúa tanto con tu servidor backend como con el Yuno SDK. Se encarga de los aspectos de cara al usuario del flujo de pago, entre ellos:

* Listar los métodos de pago
* El usuario selecciona un método de pago
* Iniciar el SDK con la sesión de checkout y `payment_method`

#### Servidor del comercio {#merchant-server}

El servidor del comercio representa tu app, que se encarga de las operaciones del lado del servidor y se comunica con los servidores de Yuno. Sus responsabilidades principales incluyen:

* Crear la `checkout_session`
* Recibir el webhook con el resultado del pago

#### Servidor de Yuno {#yuno-server}

El servidor de Yuno se encarga de todas las operaciones de backend relacionadas con la gestión de clientes, las sesiones de checkout y el procesamiento de pagos. Sus responsabilidades principales incluyen:

* Crea la `checkout_session`
* Crear el pago
* Envía el webhook con el resultado del pago

#### Yuno SDK {#yuno-sdk}

El Yuno SDK se encarga de la interfaz de usuario y del flujo de pago del lado del cliente, y gestiona la selección del método de pago, la generación del token y la finalización del pago. Sus responsabilidades principales incluyen:

* Iniciar el SDK con `checkout_session` y `payment_method`
* Generar el OTT
* Continuar el pago automáticamente si es necesario
* Mostrar las pantallas para que el usuario complete la inscripción
* Mostrar el resultado del método de pago (opcional)

#### Flujo {#flow}

Los siguientes pasos describen el flujo de interacción completo entre todos los componentes de la integración de pago headless del SDK, y detallan cómo se mueve cada solicitud y respuesta por el sistema:

1. Servidor del comercio: crear `checkout_session` --> Servidor de Yuno: crea `checkout_session`
2. Cliente del comercio: iniciar el SDK con la sesión de checkout y `payment_method` --> Yuno SDK: iniciar el SDK con `checkout_session` y `payment_method`
3. Servidor de Yuno: crear el pago --> Yuno SDK: generar el OTT
