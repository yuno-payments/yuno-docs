Parámetros, personalizaciones y funciones avanzadas de todos los flujos del Yuno SDK para iOS. Para la configuración de la integración, consulta [Flujos de pago (iOS)](/docs/sdks/full-checkout/ios-payments), [Flujos de inscripción (iOS)](/es/docs/sdks/card-enrollment/ios-enrollment) y [modos de integración](/es/docs/sdks/overview/choose-integration).

## Parámetros clave (creación de la sesión de checkout) {#key-parameters-checkout-session-creation}

Al crear una sesión de checkout en tu backend para los flujos de pago, los siguientes parámetros se usan comúnmente en los SDK de iOS:

| Parámetro            | Obligatorio| Descripción                                                                                                                                                                                                                                                                                                        |
| -------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `amount`             | Sí       | El objeto del monto principal de la transacción, que contiene `currency` (código ISO 4217) y `value` (monto numérico en esa moneda).                                                                                                                                                                               |
| `alternative_amount` | No       | Una representación del monto de la transacción en otra moneda, con la misma estructura que `amount` (`currency` y `value`). Es útil en escenarios multimoneda. Por ejemplo, puedes mostrar los precios a los clientes en su moneda preferida (por ejemplo, USD) mientras procesas el pago en la moneda local (por ejemplo, COP). |

## Parámetros de pago (referencia completa) {#payment-parameters-full-reference}

Parámetros de los flujos de pago. Todos los parámetros usados en [Flujos de pago (iOS)](/docs/sdks/full-checkout/ios-payments) se listan aquí con todo su detalle.

| Parámetro                  | Tipo             | Obligatorio| Descripción                                                                                                                                                                                                                                                                |
| -------------------------- | ---------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `checkoutSession`          | string           | Sí       | ID de la sesión de checkout de tu backend (API Crear sesión de checkout). Obligatorio en todos los flujos de pago.                                                                                                                                                         |
| `countryCode`              | string           | Sí       | Código ISO del país donde se ejecuta el pago (por ejemplo, `BR`, `US`). Determina los métodos de pago disponibles y el cumplimiento normativo.                                                                                                                             |
| `language`                 | string           | No       | Código de idioma de la interfaz del SDK (por ejemplo, `en`, `pt-BR`). Opcional. Consulta [Idiomas compatibles](/es/docs/sdks/resources/languages-supported) cuando esté disponible.                                                                                           |
| `viewController`           | UIViewController | Sí*      | El view controller que presenta el flujo de pago. El SDK lo usa para presentar modales y capturar el resultado.                                                                                                                                                            |
| `yunoCreatePayment(with:)` | delegate         | Sí       | Método del delegado: crea el pago en tu backend usando el token de un solo uso que entrega el SDK. Después de crear el pago mediante la API, informa al SDK para que continúe el flujo.                                                                                     |
| `yunoPaymentResult(_:)`    | delegate         | No       | Método del delegado: se invoca cuando el flujo de pago termina. Recibe un valor del enum `Yuno.Result` (`.succeeded`, `.fail`, `.processing`, `.reject`, `.userCancelled`, `.internalError`). Estos valores se corresponden con los [estados de pago](/es/reference/getting-started/response-codes). Úsalo para actualizar la interfaz o navegar. |

## Opciones de YunoConfig (inicialización) {#yunoconfig-options-initialize}

El comportamiento en tiempo de ejecución y la apariencia se configuran mediante `YunoConfig` al llamar a `Yuno.initialize(apiKey:config:)`. A continuación se listan todos los parámetros usados en los flujos de pago e inscripción de iOS. Para el estilo visual (fuentes, colores, botones), consulta [Personalizaciones del SDK (iOS)](/es/docs/sdks/customization/ios).

| Parámetro               | Tipo       | Obligatorio| Descripción                                                                                                                                                                                                                                     |
| ----------------------- | ---------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `appearance`            | Appearance | No       | Apariencia personalizada (fuentes, colores, botones). Usa `Yuno.Appearance(...)` para configurar `fontFamily`, `accentColor`, `buttonBackgroundColor`, `buttonTitleColor` y campos relacionados. Consulta [Personalizaciones del SDK (iOS)](/es/docs/sdks/customization/ios) para ver todas las opciones. |
| `saveCardEnabled`       | boolean    | No       | Cuando es `true`, permite que el usuario guarde o inscriba la tarjeta durante el pago. Requiere soporte del backend para el almacenamiento seguro (vaulting).                                                                                    |

## Parámetros de inscripción (referencia completa) {#enrollment-parameters-full-reference}

Parámetros de los flujos de inscripción. Todos los parámetros usados en [Flujos de inscripción (iOS)](/es/docs/sdks/card-enrollment/ios-enrollment) se listan aquí con todo su detalle.

| Parámetro                  | Tipo             | Obligatorio| Descripción                                                                                                                                                                                      |
| -------------------------- | ---------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `customerSession`          | string           | Sí       | ID de la sesión de cliente de la API Crear sesión de cliente. Obligatorio. Asocia el método de pago inscrito con un cliente específico.                                                          |
| `countryCode`              | string           | Sí       | Código ISO del país (por ejemplo, `BR`, `US`). Obligatorio para la inscripción.                                                                                                                  |
| `language`                 | string           | No       | Código de idioma de la interfaz del SDK. Opcional.                                                                                                                                               |
| `viewController`           | UIViewController | Sí*      | El view controller que presenta el flujo de inscripción. Obligatorio para la inscripción basada en delegado.                                                                                     |
| `yunoEnrollmentResult(_:)` | delegate         | No       | Método del delegado: se invoca cuando la inscripción termina. Recibe el resultado (por ejemplo, vaulted token, estado). Úsalo para actualizar la interfaz o navegar.                              |
| `YunoConfig`               | YunoConfig       | No       | Mismas opciones que en el pago (por ejemplo, `appearance`, `saveCardEnabled`, `keepLoader`). Consulta las [Opciones de YunoConfig (inicialización)](#yunoconfig-options-initialize) anteriores. |

## Inscribir métodos de pago {#enrolling-payment-methods}

Puedes inscribir métodos de pago (guardar tarjetas para uso futuro) durante el flujo de pago o mediante flujos de inscripción dedicados. En los flujos de pago, habilita guardar tarjeta en `YunoConfig` y configura `payment_method.vault_on_success` (o su equivalente) al crear la sesión de checkout, donde sea compatible. Para la inscripción dedicada, consulta [Flujos de inscripción (iOS)](/es/docs/sdks/card-enrollment/ios-enrollment).
