## Paso 1: incluye la biblioteca en tu proyecto {#step-1-include-the-library-in-your-project}

### CocoaPods {#cocoapods}

Agrega la siguiente línea a tu Podfile:

```ruby
pod 'YunoSDK', '~> 2.29.0'
```

### Swift Package Manager {#swift-package-manager}

Agrega `YunoSDK` como dependencia:

```swift
.package(url: "https://github.com/yuno-payments/yuno-sdk-ios.git", .upToNextMajor(from: "2.29.0"))
```

## Paso 2: inicializa el SDK {#step-2-initialize-sdk}

Inicializa el SDK con tu clave de API pública:

```swift
import YunoSDK

Yuno.initialize(
    apiKey: "PUBLIC_API_KEY",
    config: YunoConfig(),
    callback: { print("Yuno SDK initialized") }
)
```

## Paso 3: adopta YunoPaymentDelegate {#step-3-adopt-yunopaymentdelegate}

Adopta el protocolo `YunoPaymentDelegate`:

<Info>
**Requisitos de concurrencia en Swift 6**

Si usas Swift 6, deberás implementar el protocolo `YunoPaymentDelegate` con consideraciones de concurrencia específicas. Consulta la guía [Concurrencia en Swift 6](/es/docs/sdks/resources/swift-6-concurrency) para conocer las opciones de implementación y las mejores prácticas.
</Info>

```swift
class ViewController: UIViewController, @preconcurrency YunoPaymentDelegate {
    var checkoutSession: String { "checkout_session" }
    var countryCode: String { "US" }
    var viewController: UIViewController? { self }

    func yunoCreatePayment(with token: String) {
        // Call your backend to create a payment
    }

    func yunoCreatePayment(with token: String, information: [String: Any]) {
        // Call your backend to create a payment using the additional token information
    }

    func yunoPaymentResult(_ result: Yuno.Result) {
        // Handle final payment state
    }
}
```

| Método | Descripción |
| :--- | :--- |
| `yunoCreatePayment(with:)` | Se llama cuando se genera un token de un solo uso. Crea el pago en tu backend. |
| `yunoCreatePayment(with:information:)` | Callback alternativo que también incluye información adicional sobre el token de un solo uso, como los datos de la tarjeta (BIN de DPAN, marca, últimos cuatro dígitos). Consulta [Información adicional del OTT](/docs/sdks/full-checkout/ios-payments#ott-additional-information) para ver las claves disponibles. |
| `yunoPaymentResult(_:)` | Se llama cuando finaliza el proceso de pago. Recibe un valor `Yuno.Result`. |

<Danger>
**Nota importante**

Implementa `yunoCreatePayment(with:)` **o** `yunoCreatePayment(with:information:)`, no ambos. El SDK llama a cada versión que implementes, por lo que implementar ambos crea el pago dos veces.
</Danger>

## Paso 4: inicia el proceso de pago {#step-4-initiate-the-payment-process}

```swift
Yuno.startPaymentLite(
    with: self,
    paymentSelected: paymentSelected,
    showPaymentStatus: true
)
```

## Paso 5: continúa el pago (obligatorio) {#step-5-continue-payment-required}

Si la API devuelve `sdk_action_required: true`, llama a:

```swift
Yuno.continuePayment()
```
