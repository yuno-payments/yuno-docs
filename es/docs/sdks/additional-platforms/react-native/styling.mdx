Puedes personalizar el aspecto de los componentes del SDK de Yuno para que coincidan con la marca de tu app.

## Configuración {#configuration}

La configuración de estilos se pasa durante la inicialización del SDK.

```typescript
import { YunoSdk } from '@yuno-payments/yuno-sdk-react-native';

YunoSdk.initialize({
  apiKey: 'your-public-api-key',
  countryCode: 'US',
  yunoConfig: {
    // Global configuration
    language: 'en',
    theme: {
      // Customize colors, fonts, etc.
      // Note: Specific theme options depend on the native SDK versions
    }
  },
});
```

Las opciones de `theme` disponibles dependen de las versiones de los SDK nativos incluidas en el SDK de React Native. Consulta [Personalización en Android](/es/docs/sdks/customization/android) y [Personalización en iOS](/es/docs/sdks/customization/ios) para ver la lista completa de tokens.

## Estilos específicos de cada plataforma {#platform-specific-styling}

Como el SDK de React Native envuelve los SDK nativos de iOS y Android, algunas opciones de estilo pueden ser específicas de cada plataforma.

```typescript
import { Platform } from 'react-native';

YunoSdk.initialize({
  apiKey: 'your-key',
  countryCode: 'US',
  ...(Platform.OS === 'ios' && {
    iosConfig: {
      // iOS-specific settings
    },
  }),
  ...(Platform.OS === 'android' && {
    androidConfig: {
      // Android-specific settings
    },
  }),
});
```

Para ver la lista completa de tokens de estilo disponibles, consulta la documentación de [Personalización en Android](/es/docs/sdks/customization/android) y [Personalización en iOS](/es/docs/sdks/customization/ios).
