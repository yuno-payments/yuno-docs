El SDK de Yuno para React Native ofrece un conjunto de componentes y métodos para integrar las funciones de pago de Yuno en tu app móvil. Es compatible con iOS y Android.

## Instalación {#install}

```bash
npm install @yuno-payments/yuno-sdk-react-native@^1.5.0
```

**Configuración de iOS**:

```bash
cd ios && pod install
```

Define `platform :ios, '15.1'` o superior en `ios/Podfile`. `pod install` agrega `YunoSDK-Static` 2.31.0 al pod del paquete mediante Swift Package Manager, así que la app no agrega el SDK de iOS de Yuno por su cuenta.

**Requisitos**: 
- react-native 0.75+
- Node.js 16+
- Android Min SDK 21
- iOS 15.1+

La versión 1.5.0 subió estos mínimos desde React Native 0.70 e iOS 14.0.

El SDK incluye definiciones de TypeScript de forma predeterminada.

## Inicialización {#initialize}

Inicializa el SDK lo antes posible en tu app, normalmente en `App.tsx`.

```typescript
import { YunoSdk } from '@yuno-payments/yuno-sdk-react-native';
import { useEffect } from 'react';

export default function App() {
  useEffect(() => {
    YunoSdk.initialize({
      apiKey: 'your-public-api-key',
      countryCode: 'US', // Default country
    });
  }, []);
  
  return <YourApp />;
}
```

## Flujo de pago básico (Full Checkout) {#basic-payment-flow-full-checkout}

La integración más sencilla usa el componente `YunoPaymentMethods` para mostrar los métodos de pago disponibles y `startPayment` para procesar la transacción.

```typescript
import { YunoSdk, YunoPaymentMethods } from '@yuno-payments/yuno-sdk-react-native';

export default function PaymentScreen() {
  const [checkoutSession, setCheckoutSession] = useState<string | null>(null);
  const [isReady, setIsReady] = useState(false);
  
  useEffect(() => {
    // 1. Subscribe to payment events
    const subscription = YunoSdk.onPaymentStatus((state) => {
      if (state.status === 'SUCCEEDED') {
        // Handle success
      }
    });
    
    // 2. Fetch checkout session from your backend
    createCheckoutSession().then(session => {
      setCheckoutSession(session);
      setIsReady(true);
    });
    
    return () => subscription.remove();
  }, []);
  
  const handlePayment = async () => {
    // 3. Start payment flow
    await YunoSdk.startPayment(true); // true = show payment status screen
  };
  
  return (
    <View>
      {checkoutSession && (
        <YunoPaymentMethods
          checkoutSession={checkoutSession}
          countryCode="US"
        />
      )}
      <Button title="Pay Now" onPress={handlePayment} disabled={!isReady} />
    </View>
  );
}
```
