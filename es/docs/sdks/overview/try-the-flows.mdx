Yuno Flows es un sandbox interactivo que ejecuta un flujo de pago paso a paso. Úsalo para ver un pago completo antes de integrar, para revisar la solicitud y la respuesta de una función o para comparar el flujo del SDK con el flujo de la Direct API.

<Card title="Abrir Yuno Flows" icon="play" href="https://yuno-flows.tools.y.uno/" horizontal arrow>
  Ejecuta un pago paso a paso en el sandbox de Yuno.
</Card>

<Note>
  Yuno Flows se ejecuta en el sandbox de Yuno con tarjetas de prueba. No se mueve dinero real y no ingresas ninguna clave de API.
</Note>

## Cómo funciona {#how-it-works}

<Steps>
  <Step title="Elige un flujo">
    Filtra la lista por **SDK** o **API** y luego selecciona un flujo. Por ejemplo, **Default checkout** para el SDK.
  </Step>
  <Step title="Avanza por los pasos">
    Usa **Back** y **Next**, o las teclas de flecha. Cada paso explica lo que ocurre.
  </Step>
  <Step title="Lee el panel">
    Cambia entre **Code**, **Request** y **Response** para ver el código detrás de la llamada, lo que envía el comercio y lo que devuelve Yuno. El código está disponible en curl, Node y Python. Para ejecutarlo tú mismo, usa tus propias claves de sandbox.
  </Step>
  <Step title="Paga con una tarjeta de prueba">
    En los pasos en los que el comprador paga, ingresa una tarjeta de prueba en la tienda de demostración.
  </Step>
</Steps>

Si una llamada en vivo falla, el paso muestra una ejecución grabada de la misma llamada, marcada como **Recorded**.

## Yuno SDK o Direct API {#yuno-sdk-or-direct-api}

<CardGroup cols={2}>
  <Card title="Yuno SDK" icon="code" href="/es/docs/yuno-sdk/how-a-transaction-flows">
    El SDK recopila los datos del pago e informa el resultado a tu app. En algunos flujos el SDK crea el pago y en otros lo hace tu backend.
  </Card>
  <Card title="Direct API" icon="server" href="/es/docs/direct-integration-use-cases/direct-flow">
    Tu servidor envía las solicitudes directamente a Yuno. Tu empresa gestiona los datos de la tarjeta, por lo que se aplica el cumplimiento de PCI DSS.
  </Card>
</CardGroup>
