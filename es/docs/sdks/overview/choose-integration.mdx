Dentro del SDK de cada plataforma, Yuno ofrece varios **métodos de integración** que te dan distintos grados de control sobre la UI y la experiencia del usuario.

El método de integración que elijas afecta el nivel de esfuerzo de mantenimiento requerido. También determina cómo administras los métodos de pago, que pueden ir desde una configuración sin código en el Yuno Dashboard hasta trabajo manual de desarrollo. Algunos tipos de integración también requieren certificaciones como **PCI-DSS** o **ISO**, lo que afecta tus obligaciones de cumplimiento.

<Check>
**Integración recomendada**

Yuno recomienda usar **Seamless SDK** por su flexibilidad y facilidad de integración. Ofrece componentes de UI prediseñados y, al mismo tiempo, te da control total sobre la experiencia de pago y la visualización automática de los métodos de pago.
</Check>

## Tipos de integración {#integration-types}

A continuación, puedes ver las especificaciones de cada tipo de integración.

| Característica | seamless-sdk | lite-sdk | headless-sdk | secure-fields |
| :--- | :---: | :---: | :---: | :---: |
| Agregar nuevos métodos de pago sin código | ✅ | ❌ | ❌ | ❌ |
| Manejar cientos de métodos de pago con una sola API | ✅ | ✅ | ✅ | ✅ |
| Tokenizar tarjetas y métodos de pago sin código | ✅ | ✅ | ✅ | ✅ |
| Usar la certificación PCI-DSS de Yuno | ✅ | ✅ | ✅ | ✅ |
| Usar 3D Secure | ✅ | ✅ | ✅ | ✅ |
| Usar una solución antifraude sin código | ✅ | ✅ | ✅ | ✅ |
| Definir condiciones de checkout con el Yuno Dashboard | ✅ | ❌ | ❌ | ❌ |
| Personalizar la apariencia de tu checkout con el Yuno Dashboard | ✅ | ❌ | ❌ | ❌ |

<CardGroup cols={4}>
  <Card title="seamless-sdk" icon="browser">
    La solución de integración más flexible y recomendada. Ofrece componentes de UI prediseñados con control total sobre la experiencia de pago y administración automática de los métodos de pago.
    * **Gestión de la experiencia del usuario**: tú controlas la UI mientras Yuno se encarga del trabajo pesado.
    * **Configuración sin código**: agrega y configura métodos de pago directamente desde el Dashboard.
    * **Flexibilidad**: ideal para negocios que buscan un equilibrio entre control y simplicidad.
    * **Equivalente en el nuevo SDK**: [Migración del modo Seamless (Web)](/es/docs/yuno-sdk/migration/web/seamless).
  </Card>
  <Card title="lite-sdk" icon="bolt">
    Una integración ligera para tener el máximo control sobre el flujo de checkout y la visualización de los métodos de pago.
    * **Control total de la UI**: tú decides cómo y dónde mostrar cada método de pago.
    * **Orientada a desarrolladores**: requiere implementar manualmente la selección del método de pago.
    * **Personalizable**: ideal para negocios con requisitos de UX muy específicos. Usa [Web](/es/docs/sdks/lite-web/payment), [Android](/es/docs/sdks/lite-android/checkout) o [iOS](/es/docs/sdks/lite-ios/checkout).
    * **Equivalente en el nuevo SDK**: [Migración del modo Lite (Web)](/es/docs/yuno-sdk/migration/web/lite).
  </Card>
  <Card title="headless-sdk" icon="code">
    Máxima flexibilidad: tú construyes y administras toda la UI de pago, mientras Yuno se encarga de la lógica de pago subyacente y de la seguridad (como 3DS) mediante llamadas directas a funciones del SDK.
    * **Propiedad total de la UI**: no hay componentes prediseñados, cada pantalla e interacción la construyes tú.
    * **Orientada a desarrolladores**: tú solicitas y envías los campos obligatorios que exige cada proveedor de pago.
    * **Personalizable**: ideal para negocios que necesitan una experiencia de checkout totalmente personalizada. Usa [Web](/es/docs/sdks/headless-web/payment), [Android](/es/docs/sdks/headless-android/checkout) o [iOS](/es/docs/sdks/headless-ios/checkout).
    * **Equivalente en el nuevo SDK**: [Migración del modo Headless (Web)](/es/docs/yuno-sdk/migration/web/headless).
  </Card>
  <Card title="secure-fields" icon="shield-check">
    Campos de entrada seguros prediseñados que incrustas directamente en tu propio formulario de pago, para que los datos sin procesar de la tarjeta nunca toquen tus servidores (solo Web).
    * **Recolección segura de datos**: simplifica la tokenización de los datos de la tarjeta de pago.
    * **Cumplimiento de PCI**: garantiza una experiencia que cumple con PCI con una UI personalizada.
    * **Solución equilibrada**: ideal para equilibrar seguridad y flexibilidad. Consulta la [implementación](/docs/sdks/customization/secure-fields/index).
    * **Equivalente en el nuevo SDK**: [Secure Fields](/es/docs/yuno-sdk/features/secure-fields).
  </Card>
</CardGroup>
