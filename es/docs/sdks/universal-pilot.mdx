Te damos la bienvenida a la vista previa de acceso anticipado del SDK Universal de Yuno. Esta integración única reemplazará todas las versiones anteriores del SDK (Seamless, Lite, Headless) con un flujo unificado y altamente configurable.

## Resumen {#overview}

El SDK Universal está diseñado para ser el "One SDK to rule them all". Se adapta de forma dinámica a la configuración de tu comercio en el Dashboard.

### Beneficios principales {#key-benefits}
- **API unificada**: una sola llamada a un método para todos los tipos de pago.
- **Interfaz dinámica**: configura todo desde el Dashboard sin cambios de código.
- **Ligero**: tamaño de paquete reducido en comparación con mantener varios SDK heredados.

## Ejemplo de integración {#integration-example}

```javascript
import { Yuno } from '@yuno/universal-sdk';

const yuno = new Yuno('YOUR_PUBLIC_KEY');

// The new unified checkout call
yuno.checkout({
  checkoutSession: 'SESSION_ID',
  element: '#payment-element',
  onResponse: (response) => {
    console.log('Payment result:', response);
  }
});
```
