<LegacySdkNotice />

El Yuno iOS SDK se mantiene pequeño a propósito: cada SDK nativo de terceros se entrega como un **módulo independiente y opcional**. Agregas solo los módulos que necesita tu integración, y el Yuno SDK los detecta automáticamente cuando un checkout usa el proveedor correspondiente. Tu código de pago e inscripción no cambia.

<Note>
  Instalar un módulo no hace que el SDK lo use: un módulo se ejecuta solo cuando el proveedor está habilitado para tu cuenta de Yuno y el backend lo solicita para la transacción actual.
</Note>

## Módulos disponibles {#available-modules}

| Módulo | Qué agrega | iOS mínimo |
|---|---|---|
| ClearSale antifraud | Recopila el fingerprint del dispositivo de ClearSale y lo adjunta al pago | 14.0 |
| Koin antifraud | Recopila el fingerprint del dispositivo de Koin y lo adjunta al pago | 14.0 |
| Riskified antifraud | Inicia el beacon de Riskified con la sesión de checkout y adjunta esa sesión al pago | 14.0 |
| [Signifyd antifraud](/es/docs/sdks/external-native-modules/signifyd-ios) | Perfila el dispositivo con el Profiling SDK de Signifyd y adjunta el ID de sesión al pago | 14.0 |
| [Netcetera 3DS](/es/docs/sdks/external-native-modules/netcetera-3ds-ios) | Ejecuta los desafíos de 3D Secure de forma nativa en tu aplicación, para pagos e inscripción | 14.0 |
| Revolut Pay | Checkout nativo de Revolut Pay sobre el SDK oficial de Revolut | 15.0 |

Nombres de los paquetes según el método de instalación:

| Módulo | Producto de Swift Package Manager | Pod de CocoaPods |
|---|---|---|
| ClearSale antifraud | `YunoAntifraudClearsale` | `YunoClearsaleAntifraud` |
| Koin antifraud | `YunoAntifraudKoin` | `YunoAntifraudKoin` |
| Riskified antifraud | `YunoAntifraudRiskified` | `YunoAntifraudRiskified` |
| Signifyd antifraud | `YunoAntifraudSignifyd` (paquete independiente) | No disponible |
| Netcetera 3DS | `Yuno3DSNetcetera` | `Yuno3DSNetcetera` |
| Revolut Pay | No disponible | `YunoRevolutPay` |

Todos los módulos requieren **YunoSDK 2.25.0 o superior**, excepto Riskified, que requiere **YunoSDK 2.29.0 o superior**, y Signifyd, que requiere **YunoSDK 2.30.0 o superior** mediante Swift Package Manager. Netcetera tiene pasos de configuración adicionales (certificado de sandbox), que se explican en [Netcetera 3DS (iOS)](/es/docs/sdks/external-native-modules/netcetera-3ds-ios). Signifyd se entrega en su propio paquete y necesita un token de Signifyd, como se explica en [Signifyd antifraud (iOS)](/es/docs/sdks/external-native-modules/signifyd-ios).

## Instalación {#installation}

<Tabs>
  <Tab title="Swift Package Manager">
    Cada módulo vive en el mismo paquete que el Yuno SDK, así que solo hay una URL que agregar. En Xcode ve a **File > Add Package Dependencies...** y agrega:

    ```
    https://github.com/yuno-payments/yuno-sdk-ios
    ```

    elige la regla **Up to Next Major Version** a partir de `2.25.0` (`2.29.0` si agregas Riskified) y, en la lista de productos, marca `YunoSDK` más los módulos que necesites (`YunoAntifraudClearsale`, `YunoAntifraudKoin`, `YunoAntifraudRiskified`, `Yuno3DSNetcetera`). No se requiere nada más: cada producto incluye su propio binario del proveedor.

    <Note>
      Signifyd no está en este paquete: se entrega en `yuno-sdk-ios-signifyd` y necesita tu token de Signifyd para descargar el SDK de Signifyd. Consulta [Signifyd antifraud (iOS)](/es/docs/sdks/external-native-modules/signifyd-ios).
    </Note>
  </Tab>

  <Tab title="CocoaPods">
    Agrega los pods que necesites junto a `YunoSDK`. Cada pod de módulo ya depende de `YunoSDK ~> 2.25` (`~> 2.29` para Riskified), por lo que las versiones se mantienen compatibles:

    ```ruby
    platform :ios, '14.0'   # 15.0 if you add YunoRevolutPay

    target 'YourApp' do
      use_frameworks!

      pod 'YunoSDK', '~> 2.25'
      pod 'YunoClearsaleAntifraud', '~> 1.0'
      pod 'YunoAntifraudKoin', '~> 1.0'
      pod 'YunoAntifraudRiskified', '~> 2.0'
      pod 'Yuno3DSNetcetera', '~> 3.0'
      pod 'YunoRevolutPay', '~> 1.0'
    end

    # Required when you add YunoRevolutPay: Revolut's dependencies declare an old
    # deployment target that Xcode 14.3 or later cannot build as-is.
    post_install do |installer|
      installer.pods_project.targets.each do |target|
        target.build_configurations.each do |config|
          config.build_settings['IPHONEOS_DEPLOYMENT_TARGET'] = '15.0'
        end
      end
    end
    ```

    Luego ejecuta:

    ```bash
    pod install
    ```

    <Note>
      El módulo de antifraude Signifyd no está disponible mediante CocoaPods. Instala tanto `YunoSDK` como el módulo con Swift Package Manager, como se describe en [Signifyd antifraud (iOS)](/es/docs/sdks/external-native-modules/signifyd-ios).
    </Note>

    <Note>
      Riskified instala el pod oficial de Riskified `RiskifiedBeaconXCFramework` como dependencia, en el rango `~> 1.6.4`. Si tu Podfile ya lo declara, alinéalo a ese rango.
    </Note>

    <Note>
      Revolut Pay instala `lottie-ios` como dependencia, en el rango de 4.4.1 a 4.5.x.
    </Note>

    <Note>
      `YunoRevolutPay` fija `RevolutPayments/RevolutPay` en `~> 3.16.0`, porque el binario precompilado está ligado a esa API. Si tu Podfile ya declara `RevolutPayments`, alinéalo a ese rango.
    </Note>

    <Note>
      Revolut Pay vuelve a tu aplicación mediante un deeplink: reenvíalo a `Yuno.receiveDeeplink(url)` como se describe en [Maneja el regreso desde el navegador externo](/docs/sdks/full-checkout/ios-payments#step-10-handle-external-browser-return-optional).
    </Note>
  </Tab>
</Tabs>

## Activación de un módulo {#activating-a-module}

La forma en que un módulo se registra en el Yuno SDK depende de cómo lo instalaste.

<Tabs>
  <Tab title="Swift Package Manager">
    Los módulos instalados mediante Swift Package Manager son frameworks dinámicos y **se registran solos** cuando se inicia la aplicación. No se requiere código adicional más allá de agregar el producto a tu target.
  </Tab>

  <Tab title="CocoaPods">
    CocoaPods entrega cada módulo como un framework **estático**, que no puede registrarse solo. Llama a `register()` del módulo **una sola vez**, antes de `Yuno.initialize(...)`, por ejemplo en `application(_:didFinishLaunchingWithOptions:)`:

    ```swift
    import YunoSDK
    import YunoAntifraudClearsale
    import YunoAntifraudKoin
    import YunoAntifraudRiskified
    import Yuno3DSNetcetera
    import YunoRevolutPay

    YunoAntifraudClearsale.register()
    YunoAntifraudKoin.register()
    YunoAntifraudRiskified.register()
    Yuno3DSNetcetera.register()
    YunoRevolutPay.register()

    Yuno.initialize(apiKey: "YOUR_API_KEY", config: YunoConfig())
    ```

    Registra solo los módulos que necesites y hayas instalado; el ejemplo anterior registra los cinco como referencia.
  </Tab>
</Tabs>

<Tip>
  Una vez que un módulo está registrado, el Yuno SDK lo usa automáticamente. No necesitas cambiar ningún código de pago, inscripción ni 3DS.
</Tip>

## Solución de problemas {#troubleshooting}

<AccordionGroup>
  <Accordion title="El módulo está instalado pero nada cambia (CocoaPods)">
    Los frameworks estáticos no se registran solos. Asegúrate de llamar a `register()` del módulo antes de `Yuno.initialize(...)`.
  </Accordion>
  <Accordion title="pod install: required a higher minimum deployment target">
    La línea `platform` de tu Podfile está por debajo del mínimo del módulo. Usa `platform :ios, '14.0'` para los módulos de antifraude y 3DS, o `'15.0'` si agregas `YunoRevolutPay`.
  </Accordion>
  <Accordion title="pod install: CocoaPods could not find compatible versions for pod YunoSDK">
    Un pod de módulo depende de `YunoSDK ~> 2.25` (`~> 2.29` para `YunoAntifraudRiskified`). Si tu Podfile fija un SDK más antiguo (por ejemplo `'2.24.1'`), amplíalo al rango del módulo.
  </Accordion>
  <Accordion title="pod install: CocoaPods could not find compatible versions for pod RevolutPayments">
    `YunoRevolutPay` requiere `RevolutPayments/RevolutPay ~> 3.16.0`. Si tu Podfile fija otra versión de `RevolutPayments`, alinéala a `'~> 3.16.0'` o quita la fijación y deja que `YunoRevolutPay` la incluya.
  </Accordion>
  <Accordion title="pod install: SDK does not contain 'libarclite' (YunoRevolutPay)">
    Agrega el hook `post_install` que se muestra en la pestaña de CocoaPods anterior para que todos los targets de pods compilen para iOS 15.0.
  </Accordion>
  <Accordion title="Swift Package Manager: duplicate RiskifiedBeacon framework">
    El producto `YunoAntifraudRiskified` ya incluye `RiskifiedBeacon` 1.6.4 de Riskified. Si tu aplicación también agrega el paquete propio de Riskified, quítalo y conserva solo el producto de Yuno.
  </Accordion>
  <Accordion title="Revolut Pay nunca se completa después de volver a la aplicación">
    El deeplink de regreso no está llegando al Yuno SDK. Asegúrate de que tu aplicación declare un esquema de URL, de que las URL entrantes se reenvíen a `Yuno.receiveDeeplink(url)` y de que un `guard` sobre el esquema no esté descartando la URL de regreso de Revolut Pay (`yourscheme://revolut-pay`).
  </Accordion>
  <Accordion title="Swift Package Manager: no such module 'CSBehavior' when importing YunoAntifraudClearsale">
    Afecta solo a `YunoAntifraudClearsale` 1.0.0. El módulo se registra solo, así que no necesitas importarlo desde Swift: quita la línea `import YunoAntifraudClearsale` y el proyecto compila.
  </Accordion>
</AccordionGroup>
