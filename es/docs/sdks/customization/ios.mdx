Modifica los estilos del Yuno iOS SDK (fuente, botón, color) configurando los campos de apariencia. Úsalos para que coincida con la marca de tu app y mejorar la consistencia. Para ver todos los parámetros y opciones de configuración del iOS SDK, consulta la [Referencia común del iOS SDK](/es/docs/sdks/resources/references/ios).

## Configuración de la apariencia {#appearance-configuration}

Campos de personalización disponibles:

| Campo                            | Descripción                                                                                                                            |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `fontFamily`                     | Especifica la familia de fuentes que usa el SDK. Indica el nombre de archivo de la fuente que usa tu app y asegúrate de que coincida con los recursos de tu app. |
| `accentColor`                    | Define el color de acento que se usa en varios elementos del SDK.                                                                      |
| `buttonBackgroundColor`          | Establece el color de fondo de los botones principales.                                                                                |
| `buttonTitleColor`               | Determina el color del texto de los botones principales.                                                                               |
| `buttonBorderColor`              | Especifica el color del borde de los botones principales.                                                                              |
| `secondaryButtonBackgroundColor` | Establece el color de fondo de los botones secundarios.                                                                                |
| `secondaryButtonTitleColor`      | Determina el color del texto de los botones secundarios.                                                                               |
| `secondaryButtonBorderColor`     | Especifica el color del borde de los botones secundarios.                                                                              |
| `disableButtonBackgroundColor`   | Establece el color de fondo de los botones desactivados.                                                                               |
| `disableButtonTitleColor`        | Determina el color del texto de los botones desactivados.                                                                              |

<Note>
**Configuración de colores**

Asegúrate de especificar todos los colores como UIColor para mantener la compatibilidad. Los colores pueden provenir de la paleta predefinida de Xcode o de los recursos del comercio, pero siempre deben ser de tipo UIColor.
</Note>

Usa la función `Yuno.Appearance()` para definir una variable con todas tus personalizaciones y controlar la apariencia. Luego indícala al inicializar el SDK:

```swift
let appearance = Yuno.Appearance(
    fontFamily: "Climate Crisis",
    accentColor: UIColor.orange, 
    buttonBackgroundColor: UIColor.yellow, 
    buttonTitleColor: UIColor.black, 
    buttonBorderColor: UIColor.black,
    secondaryButtonBackgroundColor: UIColor.yellow,
    secondaryButtonTitleColor: UIColor.black,
    secondaryButtonBorderColor: UIColor.black,
    disableButtonBackgroundColor: UIColor.gray,
    disableButtonTitleColor: UIColor.black
)

Yuno.initialize(
    apiKey: apiKey,
    config: YunoConfig(appearance: appearance)
)

```

### Ejemplos de uso {#usage-examples}

Ejemplo (dos personalizaciones de apariencia):

```swift Example 1 (left)
let appearance = Yuno.Appearance(
    fontFamily: "Climate Crisis",
    accentColor: UIColor.black, 
    buttonBackgroundColor: UIColor.black, 
    buttonTitleColor: UIColor.white
)

Yuno.initialize(
    apiKey: apiKey,
    config: YunoConfig(appearance: appearance)
)

```

let appearance = Yuno.Appearance(

## Autocompletado de direcciones {#address-autocomplete}

Los comercios pueden activar o desactivar la función de autocompletado de direcciones en el iOS SDK. Cuando está activada, el SDK completa automáticamente los campos de dirección a partir de la búsqueda por código postal. Cuando está desactivada, los usuarios deben ingresar manualmente toda la información de la dirección.
