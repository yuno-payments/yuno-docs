Los secure-fields de Yuno ofrecen una forma de recopilar información de pago sensible de manera segura, manteniendo el cumplimiento de PCI. Este enfoque te permite crear interfaces de usuario personalizadas mientras mantienes seguros los datos sensibles. Para la configuración del SDK, consulta la [Guía de inicio rápido](/es/docs/sdks/overview/quickstart). Para comparar las integraciones, consulta [Elige la integración adecuada para ti](/es/docs/sdks/overview/choose-integration).

## Integraciones de secure fields disponibles {#available-secure-field-integrations}

Implementa secure-fields en Web:

* [secure-fields (Inscripción)](/docs/sdks/customization/secure-fields/enrollment-secure-fields): inscribe métodos de pago usando secure fields
* [secure-fields (Pago)](/es/docs/sdks/customization/secure-fields/payment-secure-fields): procesa pagos usando secure fields

## Beneficios principales {#key-benefits}

* **Cumplimiento de PCI**: los datos sensibles se manejan de forma segura sin pasar por tus servidores
* **Interfaz personalizada**: crea tus propios formularios de pago manteniendo la seguridad
* **Tokenización**: convierte los datos sensibles en tokens seguros para su procesamiento
* **Flexibilidad**: intégralo con tu sistema de diseño y tu experiencia de usuario actuales

Para ver una descripción completa de todos los parámetros de pago e inscripción del SDK de Web, consulta la [Referencia común del SDK de Web](/es/docs/sdks/resources/references/web).
