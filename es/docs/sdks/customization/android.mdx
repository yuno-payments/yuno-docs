Modifica los estilos del Yuno Android SDK (colores, texto, botones) para alinear los formularios de pago y el checkout con tu marca. La estructura de los elementos se mantiene uniforme. Para ver todos los parámetros y opciones de configuración del SDK de Android, consulta la [Referencia común del SDK de Android](/es/docs/sdks/resources/references/android).

## Pautas generales {#general-guidelines}

La forma de personalizar el SDK de Android depende de su versión:

- **SDK 2.x:** aplica estilos al SDK con Compose, pasando `YunoStyles` en `YunoConfig` al inicializar. Consulta [Estilos con Compose](#style-with-compose-sdk-2x).
- **SDK 1.x:** el SDK admite temas y estilos XML, definidos dentro de los estilos de tu aplicación. Consulta [Elementos personalizables](#customizable-elements).
- **Yuno SDK (Android v3.x):** `YunoStyles` se reemplaza por `Appearance`, que se define por transacción. Consulta [Estilos](/docs/yuno-sdk/features/styling).

## Estilos con Compose (SDK 2.x) {#style-with-compose-sdk-2x}

En el SDK 2.x los formularios de checkout ya no usan vistas XML ni temas por pantalla. Pasa un objeto `YunoStyles` en `YunoConfig` cuando inicialices el SDK. Una sola configuración cubre todas las pantallas.

`YunoStyles` tiene estos campos:

| Campo          | Descripción                                                                 |
| -------------- | --------------------------------------------------------------------------- |
| `fontFamily`   | Familia de fuentes que se usa en todo el SDK, como un `FontFamily` de Compose.                 |
| `buttonStyles` | Estilos de los botones, como un objeto `YunoButtonStyles`.                              |

`YunoButtonStyles` tiene estos campos. Todos son opcionales:

| Campo             | Tipo       | Descripción                      |
| ----------------- | ---------- | -------------------------------- |
| `backgroundColor` | `Color`    | Color de fondo del botón.  |
| `contentColor`    | `Color`    | Color del contenido del botón.     |
| `cornerRadius`    | `Dp`       | Radio de las esquinas del botón.     |
| `elevation`       | `Dp`       | Elevación del botón.         |
| `padding`         | `Dp`       | Relleno del botón.           |
| `fontFamily`      | `FontFamily` | Familia de fuentes del texto del botón. |
| `fontSize`        | `TextUnit` | Tamaño de fuente del texto del botón.    |
| `fontStyle`       | `FontStyle` | Estilo de fuente del texto del botón.  |

Ejemplo:

```kotlin
Yuno.initialize(
    applicationContext = this,
    apiKey = "YOUR_PUBLIC_API_KEY",
    config = YunoConfig(
        styles = YunoStyles(
            fontFamily = FontFamily(Font(R.font.inter_regular)),
            buttonStyles = YunoButtonStyles(
                backgroundColor = Color(0xFF000000),
                contentColor = Color(0xFFFFFFFF),
                cornerRadius = 8.dp,
                elevation = 0.dp,
                padding = 16.dp,
                fontSize = 16.sp,
                fontStyle = FontStyle.Normal,
            ),
        ),
    ),
)
```

## Elementos personalizables {#customizable-elements}

Elementos que puedes modificar para lograr un estilo personalizado. Algunas personalizaciones requieren la versión 1.13.0 o superior.

### Estilos de fuente {#font-styles}

Puedes reemplazar las fuentes del Yuno Android SDK si quieres usar tu propia familia de fuentes. Puedes reemplazar los siguientes estilos de fuente:

- `YunoRegularFont`
- `YunoMediumFont`
- `YunoBoldFont`

Ejemplo (estilo de fuente):

```xml
<style name="YunoRegularFont">
    <item name="android:fontFamily">@font/inter_regular</item>
</style>

<style name="YunoMediumFont">
    <item name="android:fontFamily">@font/inter_medium</item>
</style>

<style name="YunoBoldFont">
    <item name="android:fontFamily">@font/inter_bold</item>
</style>
```

## Crea tu propio flujo de formulario de tarjeta {#create-your-own-card-form-flow}

<Note>
Esta sección aplica al SDK 1.x. Las vistas XML que describe no forman parte del SDK 2.x.
</Note>

El primer paso para crear tu flujo de formulario de tarjeta es crear un nuevo archivo de recursos de diseño llamado `screen_payment_card_form.xml` para reemplazar el XML actual e implementar tu diseño.

Después de crear el archivo `screen_payment_card_form.xml`, puedes definir tu propio diseño. Debes usar los componentes de campos seguros de Yuno, lo que garantiza que el Yuno SDK pueda obtener la información de la tarjeta de crédito durante el checkout. A continuación, encontrarás una lista de todos los componentes que puedes usar para cambiar el diseño:

<Warning>
**Cambio de componentes**

Al cambiar los componentes del Yuno Android SDK, debes usarlos con su `id` de Android definido.
</Warning>

### v1.10.0 o superior {#v1100-or-higher}

Hay componentes adicionales disponibles para la versión v1.10.0 o superior del Yuno SDK. Estos componentes se enumeran en la [subsección siguiente](#components-available-for-v1100-and-higher).

- `CloseButton`: botón para cerrar el formulario.

```xml
<ImageView
        android:id="@+id/imageView_close" />
```

- `CardNumberEditText`: campo donde el usuario puede ingresar el número de la tarjeta de crédito.

```xml
<com.yuno.payments.features.base.ui.views.CardNumberEditText
    android:id="@+id/textField_number" />
```

- `CardDataStackView`: campo donde el usuario puede ingresar la fecha de vencimiento y el código de verificación (CVV/CVC) de la tarjeta de crédito.

```xml
<com.yuno.payments.features.base.ui.views.CardDataStackView
    android:id="@+id/cardDataStackView" />
```

- `TextView` para el tipo de tarjeta Voucher: es un texto que el Yuno SDK muestra cuando la tarjeta es de tipo `VOUCHER `, debes colocarlo debajo del campo CVV.

```xml
<TextView
    android:id="@+id/textView_voucher_copy"
    android:visibility="gone" />
```

- `TextFieldItemView `para el nombre del titular de la tarjeta: campo donde el usuario puede ingresar el nombre del titular de la tarjeta de crédito.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_name" />
```

- `SpinnerFieldItemView` para el tipo de documento de identificación: un selector donde el titular de la tarjeta de crédito puede elegir su tipo de documento de identificación.

```xml
<com.yuno.payments.features.base.ui.views.SpinnerFieldItemView
    android:id="@+id/spinner_document_type" />
```

- `TextFieldItemView` para el número de documento de identificación: campo donde el usuario puede ingresar el número de documento de identificación del titular de la tarjeta de crédito.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_user_document" />
```

- `PhoneInformationView `para el número de teléfono del cliente: campo donde el usuario puede ingresar su número de teléfono si es necesario. Además de proporcionar el `id` de Android, debe tener visibilidad `gone`.

```xml
<com.yuno.payments.features.base.ui.views.PhoneInformationView
    android:id="@+id/layout_phone_information"
        android:visibility="gone" />
```

- `Installments`: componente que muestra el selector de cuotas de la tarjeta. Además de proporcionar el `id` de Android, debe tener visibilidad `gone` y debes agregar la dependencia `ShimmerFrameLayout`: `implementation 'com.facebook.shimmer:shimmer:0.5.0'`.

```xml
<LinearLayout
  android:id="@+id/container_installments"
  android:orientation="vertical">

  <com.yuno.payments.features.base.ui.views.SpinnerFieldItemView
  android:id="@+id/spinner_installments"
  android:layout_width="match_parent"
  android:layout_height="wrap_content"
  android:visibility="gone"
  app:spinner_title="@string/payment.form_installments" />

  <com.facebook.shimmer.ShimmerFrameLayout
  android:id="@+id/shimmer_installments"
  android:layout_width="match_parent"
  android:layout_height="wrap_content"
  android:foregroundGravity="center"
  android:visibility="gone">

  <include layout="@layout/shimmer_component_field" />
  </com.facebook.shimmer.ShimmerFrameLayout>

</LinearLayout>
```

- `TextView` de Yuno: un texto que indica que Yuno verificó el formulario.

```xml
<TextView
        android:id="@+id/textView_secure_payment" />
```

- `CustomYunoSwitch`: es un componente de interruptor que permite al usuario elegir si la tarjeta se usará como crédito o débito. Además de proporcionar el `id` de Android, debe tener visibilidad `gone`.

```xml
<com.yuno.payments.features.base.ui.views.CustomYunoSwitch
                android:id="@+id/switch_cardType"
                android:visibility="gone" />
```

- `CustomYunoSwitch`: una información sobre herramientas (tooltip) que muestra cómo funciona el interruptor. Además de proporcionar el `id` de Android, debe tener visibilidad `gone`. Yuno recomienda colocar este componente junto al interruptor.

```xml
<ImageView
                android:id="@+id/switch_tooltip"
                android:src="@drawable/ic_thin_info"
                android:visibility="gone"/>
```

- `AppCompatCheckBox`: una casilla de verificación que los usuarios pueden usar para elegir si quieren guardar la tarjeta de crédito para compras futuras.

```xml
<androidx.appcompat.widget.AppCompatCheckBox
android:id="@+id/checkBox_save_card" />
```

- `Button`: valida el formulario de tarjeta y continúa el proceso de pago. Cuando el usuario hace clic en este botón, el SDK envía el formulario y manda la información de la tarjeta de crédito a Yuno.

```xml
<Button
    android:id="@+id/button_complete_form" />
```

### Componentes disponibles para v1.10.0 y superior {#components-available-for-v1100-and-higher}

Disponibles solo para el SDK v1.10.0 o superior.

- `TextFieldItemView` para la dirección del cliente: se usa para ingresar la dirección del cliente cuando es necesaria. Asegúrate de usarlo con su `id` de Android especificado (`@+id/textField_address`) y de que tenga visibilidad `gone` de forma predeterminada.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_address"
    android:visibility="gone" />
```

- `TextFieldItemView` para el estado del cliente: permite al cliente ingresar su estado si es necesario. Debe usarse con el `id` de Android definido (`@+id/textField_state`)  y debe tener `gone` como visibilidad predeterminada.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_state"
    android:visibility="gone" />
```

- `TextFieldItemView` para la ciudad del cliente:  está pensado para ingresar la ciudad del cliente. Debe usarse con el `id` de Android proporcionado (`@+id/textField_city`) y mantener `gone` como configuración de visibilidad predeterminada.

```xml
<com.yuno.payments.features.base.ui.views.TextFieldItemView
    android:id="@+id/textField_city"
    android:visibility="gone" />
```

## Autocompletado de direcciones {#address-autocomplete}

Los comercios pueden activar o desactivar la función de autocompletado de direcciones en el SDK de Android. Cuando está activada, el SDK completa automáticamente los campos de dirección a partir de la búsqueda por código postal. Cuando está desactivada, los usuarios deben ingresar manualmente toda la información de la dirección.
