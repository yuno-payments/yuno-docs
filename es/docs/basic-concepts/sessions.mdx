title: "Sesiones"

---

Con Yuno, puedes crear sesiones para iniciar pagos o registrar métodos de pago para compras futuras. Hay dos tipos de sesiones: **sesiones de cliente** y **sesiones de checkout**. Estas sesiones garantizan que se recopile la información correcta en cada caso.

## Sesión de cliente {#customer-session}

Usa las sesiones de cliente para inscribir y guardar los métodos de pago de un cliente. Crea una nueva sesión de cliente cada vez que registres un método de pago para un cliente específico. Necesitas el `customer_id` (un identificador único del cliente) que se genera al crear el cliente en Yuno. Una sesión de cliente da acceso a todos los métodos de pago disponibles para inscripción, que puedes ofrecer a tus clientes.

<Note>
**Métodos de pago disponibles**

Al crear cualquiera de los dos tipos de sesión, de cliente o de checkout, el sistema de Yuno devuelve la lista de todos los métodos de pago habilitados. Son los métodos de pago configurados en tu dashboard de Yuno, en las secciones Connections y Checkout builder.
</Note>

Para obtener más información sobre cómo usar el endpoint **Create customer session**, consulta la [referencia de la API](/reference/customer-sessions-enrollment/the-customer-session-object).

## Sesión de checkout {#checkout-session}

Usa las sesiones de checkout para crear pagos o iniciar el flujo de pago. Cada vez que un cliente realiza un pago, debes crear una nueva sesión. Necesitas el `customer_id` (un identificador único del cliente) que se genera al crear el cliente en Yuno. Una sesión de checkout da acceso a todos los métodos de pago disponibles para ese cliente, estén inscritos previamente o no. Una sesión de checkout vence 2,5 horas después de crearse, y actualizarla no extiende ese plazo.

<Note>
**Crear un pago sin sesión de checkout**

La integración directa no requiere el SDK de Yuno, así que puedes crear un pago sin una sesión de checkout.
</Note>

Para obtener más información sobre cómo usar el endpoint **Create checkout session**, consulta la [referencia de la API](/reference/checkout-sessions/the-checkout-session-object).
