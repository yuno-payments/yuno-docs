Esta guía explica cómo funcionan **Test Mode** y **Live Mode** en el Dashboard de Yuno y cómo cambiar entre ellos. Para las URL base de la API y las credenciales de cada entorno, consulta la referencia de [Entornos de la API](/es/reference/getting-started/api-environments).

Yuno usa una sola cuenta para ambos entornos. Puedes cambiar entre Test Mode y Live Mode desde el [chip de contexto](/es/docs/using-yuno/account-context) en la barra superior, con el mismo nombre de usuario y contraseña.

## Comprender los entornos {#understanding-the-environments}

Yuno tiene dos entornos distintos, cada uno con un propósito específico:

* **Test Mode (Sandbox):** Cuando te registras, tu organización comienza con el estado "Inactive" y solo tiene acceso a Test Mode. Úsalo para explorar el Dashboard, aprender cómo funcionan las funciones y ejecutar pruebas sin afectar las operaciones en vivo. Test Mode es ideal para probar nuevas configuraciones e integraciones de forma segura.
* **Live Mode (Producción):** Live Mode es donde ocurren las transacciones reales de los clientes. Para acceder, debes enviar una solicitud de activación. Una vez que tu cuenta esté activa, puedes procesar tráfico de producción con la misma seguridad y los mismos controles. Usa Live Mode cuando estés listo para salir a producción con tu integración.

## Pasar a Live Mode {#transitioning-to-live-mode}

1. **Solicitar la activación:** Desde la página de inicio del Dashboard, envía una solicitud de activación. El estado de tu organización cambiará de "Inactive" a "Under Verification". Test Mode sigue disponible durante la verificación.
2. **Proceso de verificación:** Yuno normalmente completa la verificación en pocas horas. Si necesitamos más información, nos pondremos en contacto contigo.
3. **Acceso concedido:** Cuando la verificación termina, Live Mode se habilita para tu cuenta.

## Cambiar de entorno {#switching-environments}

Cambiar entre Sandbox y Producción en el Dashboard es sencillo:

* **Cambio con un clic:** Abre el [chip de contexto](/es/docs/using-yuno/account-context) en la barra superior y elige **Live** o **Test**.
* **Un solo inicio de sesión:** Un único conjunto de credenciales te da acceso a ambos entornos, sin contraseñas ni cuentas separadas.
