---
title: "Inscribe tarjetas con enlaces de pago"
description: "Genera un enlace de pago para que los clientes actualicen una tarjeta vencida o rechazada y se vuelvan a inscribir automáticamente"
---

Yuno ofrece a los comercios la posibilidad de gestionar pagos vencidos o rechazados mediante enlaces de pago seguros. Cuando una tarjeta de crédito vence o se reporta como robada o perdida, puedes generar un enlace de pago para compartirlo con los clientes por email o mensaje de texto, de modo que puedan actualizar fácilmente su información de pago.

Esta función está pensada para los comercios que operan su propio motor de suscripciones y necesitan actualizar los datos de la tarjeta de crédito para seguir procesando pagos con un nuevo `vaulted_token` para sus clientes.

## Cómo funciona {#how-it-works}

### 1. Recepción del enlace de pago {#1-receiving-the-payment-link}

Cuando los usuarios necesitan actualizar su información de pago, reciben un enlace de pago seguro. Este enlace les permite completar cualquier pago pendiente con una tarjeta de crédito o débito. Para crear el enlace de pago para la inscripción, asegúrate de incluir los siguientes campos:

* `customer_payer.id`: el ID del [cliente generado](/reference/customers/create-customer) previamente
* `one_time_use`: configúralo en `true` para asegurar que el enlace de pago solo pueda usarse una vez
* `vault_on_success`: configúralo en `true` para inscribir la tarjeta de crédito después de un pago exitoso

### 2. Inscripción automática {#2-automatic-enrollment}

Una vez que el pago se completa correctamente mediante el enlace, Yuno genera automáticamente un nuevo `vaulted_token` para el cliente.

### 3. Continúa cobrando {#3-continue-charging}

Después de obtener el `vaulted_token`, puedes continuar con tu calendario de suscripciones. Usa el endpoint [Get payment methods](/reference/payment-methods-direct-workflow/retrieve-enrolled-payment-methods-api) para acceder a los métodos de pago del cliente.

Para más información sobre cómo crear y gestionar enlaces de pago, consulta la [referencia de la API de enlaces de pago](/reference/payment-links/create-payment-link).
