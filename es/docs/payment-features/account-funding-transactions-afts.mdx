## Introducción {#introduction}

Las **transacciones de fondeo de cuenta (AFT)** son transacciones financieras que facilitan la transferencia de fondos entre cuentas de pago. Se usan ampliamente para cargar o recargar cuentas de usuario y billeteras digitales, y para realizar transferencias internas de fondos dentro de una plataforma de pago.

Las AFT permiten mover dinero entre cuentas de forma eficiente y segura.

## ¿Qué es una AFT? {#what-is-an-aft}

Una **AFT (transacción de fondeo de cuenta)** es un tipo de transacción diseñada para:

* **Cargar fondos** en cuentas de usuario o billeteras digitales.
* **Transferir fondos** entre cuentas dentro de la misma plataforma.
* **Depositar dinero** en cuentas comerciales o personales. Incluye remesas.

Las AFT aprovechan las redes de pago tradicionales (por ejemplo, Visa, Mastercard, ACH) para procesar transacciones de forma rápida y segura, optimizando los costos.

### Tipos de transacciones AFT {#types-of-aft-transactions}

1. **Transacciones de fondeo**:
   * Transfieren fondos a una cuenta desde una tarjeta de débito/crédito o una cuenta bancaria.
   * Ejemplo: un usuario carga su billetera digital con su tarjeta de débito.

2. **Transacciones de retiro**:
   * Mueven fondos de una cuenta de usuario de vuelta a su cuenta bancaria o tarjeta.
   * Ejemplo: un usuario transfiere dinero de su billetera digital a su cuenta bancaria.

## Integración {#integration}

Para realizar una AFT, deberás enviar una solicitud a nuestra [API de Payments](/es/reference/payments/create-payment) con el objeto `additional_data.order.account_funding` que especifica los datos del `sender` y del `beneficiary`.

Cada esquema de tarjeta de crédito puede requerir información distinta sobre el destinatario y el remitente, según la región de operación y la categoría de la transacción.

```Text Example
[...]
 "additional_data": {
   "order": {
    "account_funding": {
      "sender": {
        "first_name": "John",
        "last_name": "Doe",
        "email": "john.doe@mail.com"
      },
      "beneficiary": {
        "first_name": "Chris",
        "last_name": "Martin",
        "document": {
          "document_number": "38192019",
          "document_type": "CC"
        }
      }
     }
    }
  }
[...]
```

Para más detalles, consulta la sección de la [API de pagos](/es/reference/payments/create-payment).

<Note>
**Datos adicionales**

Si necesitas definir información adicional sobre el vendedor, como `merchant_category_code`, por ejemplo, puedes encontrar campos extra en `seller_details`, dentro de la [estructura `additional_data`](/reference/payments/the-payment-object) del pago.
</Note>

<Note>
**Billeteras digitales escalonadas**

Si operas una billetera digital escalonada, en la que el cliente primero carga un saldo y luego lo gasta en una transacción aparte, consulta [Staged Digital Wallet Operators (SDWO)](/es/docs/payment-features/staged-digital-wallet-operators-sdwo) para ver los requisitos específicos de las redes de tarjetas que aplican a ese flujo.
</Note>
