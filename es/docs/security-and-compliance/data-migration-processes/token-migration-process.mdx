La migración de tokens es el proceso de transferir números de tarjeta de un proveedor existente al vault seguro de Yuno. Durante este proceso, se genera un nuevo token para cada tarjeta, lo que garantiza continuidad y seguridad en el procesamiento de pagos. El proceso de migración de tokens consta de tres pasos principales:

1. El comercio solicita el proceso de migración de tokens a su procesador de pagos actual.
2. Yuno y el proveedor de pagos colaboran para importar de forma segura todos los datos de las tarjetas al vault de tokens de Yuno.
3. El comercio usa la API de migración de tokens de Yuno para asociar los tokens del proveedor de pagos con los `vaulted_tokens` de Yuno.

<Note>
**Primer paso**

Para iniciar el proceso de migración de tokens, comunícate con tu asesor comercial en Yuno para evaluar la viabilidad y el calendario del procedimiento.
</Note>

## Importación de tarjetas desde una cuenta de gateway (pasos 1 y 2) {#importing-cards-from-a-gateway-account-steps-1-and-2}

La importación de datos de tarjetas desde una cuenta de gateway implica manejar información sensible, por lo que se deben seguir protocolos de seguridad estrictos. Para importar datos de tarjetas a Yuno desde un gateway existente, completa los siguientes pasos:

1. **Coordina con el gateway actual**: comunícate con tu vault o gateway de terceros actual y solicita una exportación de los datos del método de pago. Asegúrate de seguir los protocolos que te indiquen.
2. **Completa la solicitud formal**: envía una solicitud formal a Yuno y asegúrate de que todos los detalles y procesos requeridos estén documentados. El tiempo de respuesta y los procedimientos del gateway determinarán el proceso de transferencia de datos.

<Warning>
**Tus responsabilidades al migrar tokens**

Eres responsable de gestionar la comunicación con tu proveedor de gateway durante todo el proceso de migración. El equipo de Yuno dará soporte y colaborará directamente con el vault o gateway de terceros para facilitar el proceso de importación. Además, la información de suscripción del cliente, incluidos los montos, las fechas, etc., debe obtenerse directamente de la entidad exportadora, ya que Yuno no extraerá estos datos de archivos cifrados.
</Warning>

<Note>
**Seguridad en la transferencia de datos**

Todos los datos durante el proceso de migración se cifran con claves PGP y se transfieren mediante SFTP (Secure File Transfer Protocol).
</Note>

## Requisitos del lado del cliente (paso 3) {#client-side-requirements-step-3}

Para completar con éxito el proceso de migración de tokens, es esencial cumplir los requisitos del lado del cliente descritos en el paso 3. Esto implica proporcionar los datos de usuario necesarios, incluidos los compradores y sus métodos de pago existentes.

Puedes ejecutar el proceso de migración de tokens con la API de Yuno, diseñada específicamente para comercios. Como comercio, usarás esta API para:

1. **Agregar clientes**: registra clientes en el sistema de Yuno.
2. **Inscribir métodos de pago**: registra en el sistema de Yuno, para cada cliente, los métodos de pago obtenidos de los procesadores de pagos.

<Note>
**Opción de migración por API**

La opción de migración por API permite a los comercios gestionar a sus clientes y los datos de pago correspondientes. [Más información](/es/docs/security-and-compliance/data-migration-processes/via-api)
</Note>

### Formato de los datos {#data-format}

Yuno especifica los parámetros requeridos para cada cliente y tarjeta de crédito para continuar con el proceso de migración. Los parámetros requeridos se enumeran a continuación:

* Account ID
* Merchant customer ID
* First name
* Last name
* Email
* Country
* Document number
* Document type
* Payment method type
* Payment method ID
* Payment method token

Consulta el [objeto Customer](/es/reference/customers/the-customer-object) y el [objeto Payment Method](/es/reference/payment-methods-direct-workflow/the-payment-method-object-api) para explorar todos los parámetros posibles para importar o crear clientes, o para inscribir objetos de pago.

Las limitaciones técnicas asociadas a los métodos de pago alternativos pueden hacer que no sean elegibles para migrarse entre proveedores de servicios. Si estás considerando migrar al vault de Yuno tokens de métodos de pago alternativos, como Mercado Pago Wallet Connect o Bancolombia Tokenbox, comunícate con el equipo de soporte de Yuno.

## Validación de los datos {#data-validation}

Para garantizar un procesamiento eficiente y evitar retrasos durante el proceso de migración de tokens, proporciona la siguiente información al comunicarte con el soporte de Yuno:

* El nombre del identificador externo que se usará para la importación.
* Una cantidad aproximada de métodos de pago que se incluirán (se acepta una estimación aproximada).
* Cualquier vacío de datos conocido, como nombres o fechas de vencimiento faltantes.

<Warning>
**Aviso importante**

Yuno no valida las fechas de vencimiento durante la importación de tarjetas de crédito.
</Warning>

## Protección de los datos {#data-protection}

Al procesar pagos a través de Yuno, la plataforma se conecta con procesadores de pagos. Yuno tokeniza y cifra los datos para garantizar la seguridad, lo que simplifica el proceso de cumplimiento de PCI. Sin embargo, eres responsable de gestionar y proteger los datos de tus clientes. Además, debes comunicar a tu cliente cualquier cargo adicional o problema.

## Requisitos para gateways y proveedores de pagos {#gateway-and-payment-provider-requirements}

Para continuar con el proceso de migración, deberás proporcionar lo siguiente:

* Una clave SSH pública (puedes proporcionar una para producción y otra para pruebas). Usa el siguiente comando para generarla: `ssh-keygen -t rsa -b 4096 -C your_email@example.com`
* Las IP de salida que se usarán durante la migración.
* Un archivo de plantilla con los datos que se migrarán para entender su estructura. Debe incluir los siguientes datos obligatorios:
  * **Nombre del titular de la tarjeta**: el nombre completo del titular de la tarjeta tal como lo almacena el proveedor actual.
  * **Fecha de vencimiento**: la fecha de vencimiento de la tarjeta.
  * **Número de tarjeta**: el número completo de la tarjeta (PAN) que Yuno tokenizará.
  * **ID de la tarjeta**: un identificador único asignado a cada tarjeta por el proveedor actual, que el cliente usa para hacer referencia a esa tarjeta durante las transacciones.

### Clave pública PGP {#pgp-public-key}

Usa nuestra clave pública para cifrar los archivos sensibles para PCI que envíes a Yuno. Yuno usa la misma clave pública para todos los gateways y proveedores de pagos, y la publica en esta página para que puedas obtenerla desde el sitio oficial de Yuno.

Antes de cifrar un archivo, confirma que la huella (fingerprint) de la clave descargada coincida con la huella de la siguiente tabla:

```bash
gpg --show-keys --with-fingerprint generic-pgp-keys_public_key_production.asc
```
