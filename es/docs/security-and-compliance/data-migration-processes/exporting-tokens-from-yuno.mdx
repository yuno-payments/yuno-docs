---

Yuno ofrece un proceso seguro y conforme con PCI DSS para exportar tokens desde nuestro vault a tus sistemas o a un proveedor externo. Esta guía explica los requisitos, los protocolos de cifrado, el formato de los datos y el método de entrega para garantizar una migración segura y conforme de datos sensibles de tarjetas.

<Note>
**Requisitos de seguridad**

Las solicitudes de exportación de tokens se gestionan con el mismo nivel de rigor y cifrado que se usa para proteger los datos en producción. Solo los clientes elegibles con casos de uso validados y cumplimiento de PCI DSS pueden iniciar este proceso.
</Note>

## Cuándo solicitar una exportación de tokens {#when-to-request-a-token-export}

Puedes solicitar a Yuno una exportación de tus datos tokenizados cuando:

* Cambias a un procesador de pagos o a un proveedor de tokenización diferente.
* Necesitas gestionar tokens dentro de tu propia infraestructura certificada en PCI DSS.

## Elegibilidad y requisitos previos {#eligibility-and-prerequisites}

Para continuar con una exportación, se deben cumplir las siguientes condiciones en este orden:

### 1. Solicitud formal {#1-formal-request}

El cliente debe presentar una solicitud por escrito que incluya:

* Una solicitud formal del tercero que desea recibir los datos del comercio
* Autorización para exportar los datos tokenizados.
* Confirmación del destinatario (equipo interno o proveedor externo).
* Aprobación legal y de cumplimiento por parte del cliente.

Envía esta solicitud por escrito a tu punto de contacto principal en Yuno y envía también una copia por email a [security-migrations@y.uno](mailto:security-migrations@y.uno) para asegurarte de que ambos equipos estén informados.

### 2. Certificación PCI DSS {#2-pci-dss-certification}

Dado que los datos exportados contienen datos de tarjetas, la entidad receptora debe estar certificada en PCI DSS. Esta certificación es obligatoria independientemente de si:

* Cambias a un proveedor de pagos diferente
* Solicitas tus propios datos para uso interno

Requerimos:

* Una Attestation of Compliance (AOC) válida de la entidad receptora
* La AOC debe estar vigente y ser válida en el momento de la solicitud de exportación

### 3. Requisitos técnicos para la transferencia segura de datos {#3-technical-requirements-for-secure-data-transfer}

Después de que se apruebe la solicitud formal y se verifique el cumplimiento de PCI DSS, se deben cumplir los siguientes requisitos técnicos:

#### a. Clave pública PGP para el cifrado {#a-pgp-public-key-for-encryption}

La entidad receptora debe proporcionar una clave pública PGP para cifrar los archivos exportados. Esto garantiza que los datos permanezcan seguros tanto en tránsito como en reposo.

* La entidad receptora debe enviar la clave
* Yuno validará el formato y la compatibilidad de la clave

#### b. Credenciales de acceso SFTP {#b-sftp-access-credentials}

Yuno habilitará el acceso a un servidor SFTP seguro alojado por Yuno.

**Tú proporcionas:**

* Una dirección IP estática desde la cual se accederá al archivo
* Una clave pública SSH para la autenticación

**Yuno proporciona:**

* Una cuenta de usuario SFTP dedicada para este fin

## Formato del archivo {#file-format}

El archivo exportado se cifrará con la clave PGP proporcionada y seguirá la estructura siguiente:

| Campo              | Descripción                  |
| ------------------ | ---------------------------- |
| `holder_name`      | Nombre del titular de la tarjeta       |
| `number`           | Número de cuenta principal (PAN) |
| `token`            | Token almacenado en el vault de Yuno |
| `expiration_year`  | Año de vencimiento de la tarjeta  |
| `expiration_month` | Mes de vencimiento de la tarjeta |

* El archivo tendrá formato `.csv`
* Todos los campos están codificados en UTF-8.

## Proceso de entrega segura {#secure-delivery-process}

Una vez que se cumplan todos los requisitos previos:

1. El equipo de seguridad de Yuno:
   * Preparará el archivo de exportación con los datos de las tarjetas
   * Cifrará el archivo con la clave PGP proporcionada
   * Creará la cuenta de usuario SFTP para la obtención del archivo
   * Subirá el archivo a la ubicación SFTP segura

2. Recibirás una notificación cuando:
   * El archivo esté listo para descargar
   * El acceso SFTP esté configurado
   * La ventana de acceso esté activa

3. Entonces podrás:
   * Acceder a la ubicación SFTP segura con tu clave SSH y tu IP autorizada
   * Descargar el archivo cifrado dentro de la ventana de tiempo definida
   * El archivo se eliminará automáticamente del servidor cuando venza la ventana de acceso

<Warning>
**Canal seguro obligatorio**

El archivo nunca se envía por email ni se hace accesible públicamente. El acceso está estrictamente limitado al canal seguro configurado.
</Warning>

## Seguridad y cumplimiento {#security-and-compliance}

Yuno está certificado en PCI DSS Nivel 1 y cumple con estrictas prácticas de cifrado, control de acceso y retención de datos durante todo este proceso.

Garantizamos que:

* Todas las exportaciones se registran y se supervisan.
* Solo el personal autorizado gestiona los datos cifrados.
* Los archivos nunca se almacenan por más tiempo que la ventana de acceso requerida.
