Los reportes de Yuno ofrecen una forma práctica de obtener información sobre las distintas etapas de los pagos. Puedes solicitar y descargar fácilmente diversos reportes asociados a tus operaciones con Yuno. Yuno ofrece los siguientes tipos de reporte mediante el endpoint [Create a Report](/es/reference/reports/create-a-report):

* Payment
* Transaction
* Payouts
* Settlements & Fees
* Reconciliation Overview
* Communications
* Settlement Payouts

Puedes consultar la descripción detallada de cada uno en la documentación de [Reports Fields](/es/reference/reports/reports-fields). Los reportes Reconciliation Overview, Settlements & Fees y Settlement Payouts ofrecen información relacionada con la conciliación. Para revisar todos los campos disponibles en cada reporte y su descripción, consulta la [página Reports Fields](/es/reference/reports/reports-fields).

## Requisitos {#requirements}

Para solicitar un reporte, necesitas:

* Acceder a tus [credenciales de API](/es/docs/using-yuno/settings/developers-credentials) en el Yuno Dashboard, que constan de:
  * `public-api-key`
  * `private-secret-key`

<Note>
**Explora las colecciones de Postman de Yuno**

Yuno ofrece [colecciones de Postman](/es/reference/getting-started/postman-collections) que puedes usar para replicar los casos de uso de forma local.
</Note>

## Resumen de los pasos {#steps-summary}

El proceso para recibir un reporte con Yuno se compone de tres pasos:

1. [Create a Report](/es/reference/reports/create-a-report)
2. [Verificar si el reporte está listo](/es/reference/reports/retrieve-a-report)
3. [Download a Report](/es/reference/reports/download-a-report)

## Acceder a un reporte {#access-a-report}

Como se muestra en el resumen de los pasos, debes completar tres pasos antes de acceder a tu reporte.

### Paso 1: crear un reporte {#step-1-create-a-report}

Para iniciar el proceso de generación del reporte, solicita a Yuno que cree el reporte con el [endpoint Create a Report](/es/reference/reports/create-a-report). Primero, selecciona el tipo de reporte deseado (`type`), que determinará el contenido del reporte generado. Luego, define el rango de fechas de los datos que quieres incluir en el reporte con los parámetros `start_date` y `end_date`.

Al crear el reporte, puedes filtrar los datos incluidos especificando los valores de algunos campos. Por ejemplo, puedes recibir solo los datos de las transacciones realizadas en Argentina y Brasil. En ese caso, enviarías el contenido `AR,BR` en el parámetro `country`.

Tienes la opción de filtrar los siguientes campos al crear el reporte:

* `payment_status`
* `payment_sub_status`
* `payment_method`
* `currency`
* `country`
* `transaction_type`
* `transaction_status`
* `updated_at_start`
* `updated_at_end`

<Note>
**Formato de los valores de filtro**

Al definir los valores de filtro, envíalos como una lista de valores en una cadena de texto, como en el siguiente ejemplo:
`"payment_status": "CREATED,READY_TO_PAY,DECLINED"`
</Note>

En los reportes Payment, Transaction o Settlement Payouts, también puedes seleccionar los campos que se incluyen en el reporte final con el parámetro `columns`. En el reporte Settlement Payouts, `columns` reemplaza la selección de columnas predeterminada en lugar de ampliarla.

Cuando usas el [endpoint Create a Report](/es/reference/reports/create-a-report) para solicitar la creación de un reporte, en la respuesta recibirás el `id` y el `status` del reporte. Usarás el `id` al solicitar la descarga del reporte en el [Paso 3](/es/docs/direct-integration-use-cases/build-reports#step-3-download-your-report). El `status` indica si está listo para descargar.

### Paso 2: verificar si el reporte está listo {#step-2-check-if-the-report-is-ready}

Después de solicitar la creación del reporte, puedes usar los endpoints [Retrieve a Report](/es/reference/reports/retrieve-a-report) o [List All Reports](/es/reference/reports/list-all-reports) para verificar si está listo para descargar. Al usar el [endpoint Retrieve a Report](/es/reference/reports/retrieve-a-report), debes enviar el `id` del reporte. En cambio, con el [endpoint List All Reports](/es/reference/reports/list-all-reports), debes indicar tu `account_id` para recibir una lista de todos los reportes existentes y su estado.

Cuando el reporte tenga el estado `SUCCEEDED`, puedes solicitar su descarga. Consulta la [página Report status](/es/reference/reports/report-status) para ver todos los estados posibles de un reporte.

### Paso 3: descargar tu reporte {#step-3-download-your-report}

Usa [Download a Report](/es/reference/reports/download-a-report) para recibir tu reporte enviando su `id`. Recibirás el reporte en un archivo .zip. Sin embargo, en los reportes de liquidaciones (Settlement), la API devolverá un archivo .csv.
