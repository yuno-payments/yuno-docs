Antes de poder crear pagos con la integración directa con la API de Yuno, debes configurar tu cuenta: establecer conexiones de pago, definir el enrutamiento de pagos, habilitar métodos de pago y obtener tus credenciales de API. Esta página explica estos pasos de configuración esenciales.

Aprenderás a:

* Configurar tu primera conexión de pago
* Configurar el enrutamiento de pagos
* Habilitar métodos de pago en el checkout builder
* Obtener tus credenciales de API, incluidas tu `public-api-key` y tu `private-secret-key`

<Note>
**Yuno Testing Gateway**

Asegúrate de elegir la conexión de pago que se ajuste a tus necesidades al seguir estas instrucciones. Si quieres probar pagos con tarjeta de crédito, usa [Yuno Testing Gateway](/es/docs/direct-integration-use-cases/yuno-testing-gateway) como tu proveedor.
</Note>

## Configura el método de pago {#configure-payment-method}

Antes de configurar un método de pago, primero debes crear una conexión con uno de los proveedores disponibles.

### Paso 1: configura tu conexión {#step-1-set-up-your-connection}

Para configurar tu primera conexión de pago:

1. Ve a **Connections** en la barra lateral del dashboard.
2. Usa la barra de búsqueda para encontrar la conexión que necesitas.
3. Haz clic en **Connect** junto al gateway.
4. Escribe un nombre descriptivo para la conexión y sigue las indicaciones en pantalla.
5. Haz clic en **Save**.

Aparecerá un mensaje de confirmación en el dashboard cuando tu conexión se haya agregado correctamente.

<Video src="https://github.com/writechoiceorg/yuno-images/raw/main/doc/set_up_you_account/connection_setup_V4_v2.mp4" />

### Paso 2: configura el enrutamiento de tu nueva conexión {#step-2-set-up-routing-for-your-new-connection}

El enrutamiento de pagos en Yuno te permite definir qué conexiones se usarán para procesar tipos específicos de transacciones. Esto habilita una lógica de enrutamiento dinámica y te da flexibilidad para gestionar proveedores según la moneda, el país u otros factores. Para una configuración básica, sigue estos pasos:

1. Ve a [Routing](https://dashboard.y.uno/routing) en la barra lateral del dashboard.
2. Haz clic en la pestaña **Not published** para ver los métodos de pago que tienen conexiones disponibles pero ninguna ruta configurada.
3. Busca el método de pago que quieres y haz clic en **Set Up**.
4. En la ventana emergente:
   * Haz clic en **+ Create new route**.
   * Escribe un nombre descriptivo para la ruta.
   * Haz clic en **Save**.
5. Haz clic en la flecha junto a la nueva ruta y selecciona **Add step**.
6. Elige un **procesador** de la lista y haz clic en **Select**.
7. Haz clic en **Publish** para guardar todos tus cambios.

Tu nueva ruta ahora aparece en la pestaña **Published**, lo que indica que el método de pago configurado procesará todas las transacciones a través de esta ruta.

<Video src="https://github.com/writechoiceorg/yuno-images/raw/main/doc/set_up_you_account/routing_V2.mp4" />

### Paso 3: habilita el método de pago en el Checkout Builder {#step-3-enable-the-payment-method-in-the-checkout-builder}

Después de configurar tu conexión y el enrutamiento, debes habilitar el método de pago para que esté disponible en tu checkout:

1. Ve a [Checkout Builder](https://dashboard.y.uno/checkout-builder) en la barra lateral del dashboard.
2. Busca el método de pago configurado en la lista de métodos disponibles.
3. Activa el interruptor para habilitarlo.
4. Haz clic en **Publish settings** para aplicar tus cambios.

<Video src="https://github.com/writechoiceorg/yuno-images/raw/main/doc/set_up_you_account/checkoutbuilder.mp4" />

### Paso 4: obtén tus credenciales de API {#step-4-get-your-api-credentials}

Para completar la configuración e integrar Yuno en tu aplicación, debes obtener tus credenciales de API desde el dashboard de Yuno. Estas credenciales son específicas del entorno Sandbox:

1. Ve a la sección **Developers** en la barra lateral del dashboard.
2. En la sección Developer Tools, ubica tus credenciales de API:
   * **Public API Key**: Se usa para inicializar el SDK del lado del cliente.
   * **Secret API Key**: Se usa para las llamadas a la API del lado del servidor.

<Video src="https://raw.githubusercontent.com/writechoiceorg/yuno-images/main/doc/set_up_you_account/developer_V2.mp4" />

Después de completar estos pasos, estarás listo para crear pagos con la **integración directa**.
