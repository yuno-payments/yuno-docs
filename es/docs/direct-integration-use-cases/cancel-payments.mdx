En esta guía encontrarás instrucciones paso a paso para cancelar manualmente un pago creado previamente en Yuno.

<Note>
**Cancelación automática diferida**

Si prefieres que Yuno cancele automáticamente las autorizaciones después de un tiempo determinado, puedes configurar `delayed_cancel_settings` al crear el pago. Esto ayuda a mejorar la experiencia del cliente al liberar automáticamente los fondos retenidos. Obtén más información en la guía [Flujo de cancelación y captura](/docs/payment-features/Cancel-and-capture-flow).
</Note>

<Warning>
**Pagos cancelables**

Solo se pueden cancelar los pagos con estado **PENDING**. Consulta la página [Estado del pago](/es/docs/basic-concepts/payments-1) para obtener más detalles sobre los posibles estados del pago.
</Warning>

## Requisitos {#requirements}

Para cancelar un pago, debes:

* Acceder a tus [credenciales de API](/es/docs/using-yuno/settings/developers-credentials) en el Dashboard de Yuno, que consisten en:
  * `public-api-key`
  * `private-secret-key`
* Tener los datos de identificación del pago que recibiste después de crearlo con el [endpoint Create Payment](/es/reference/payments/create-payment):
  * `id`: El identificador único del pago, obtenido del parámetro `id` después de crear el pago.
  * `transaction_id`: El identificador único de la transacción, obtenido del parámetro `transaction.id` después de crear el pago.

<Note>
**Explora las colecciones de Postman de Yuno**

Yuno ofrece [colecciones de Postman](/reference/getting-started/postman-collections) que puedes usar para replicar los casos de uso de forma local.
</Note>

## Cancela un pago {#cancel-a-payment}

Solo puedes cancelar un pago si tiene el estado PENDING. Usa el [endpoint Cancel Payment](/reference/payments/cancel-payment) para cancelar el pago. Para identificar el pago que se va a cancelar, debes proporcionar su `id` y el `transaction_id`.

Para confirmar que cancelaste el pago correctamente, verifica que los parámetros de la respuesta del [endpoint Cancel Payment](/reference/payments/cancel-payment) contengan los siguientes valores:

* `type = CANCEL`
* `status = SUCCEEDED`
* `payment.status = CANCELED`
* `payment.sub_status = CANCELED`

Si la respuesta contiene los valores anteriores, la cancelación fue exitosa.

### Revisa el estado del pago {#check-the-payment-status}

Si, por algún motivo, necesitas confirmar la cancelación del pago:

* Usa [Retrieve Payment by ID](/reference/payments/retrieve-payment-by-id) o [Retrieve Payment by merchant\_order\_id](/reference/payments/retrieve-payment-by-merchant-order-id) para obtener información detallada sobre el pago.
* También puedes configurar webhooks para recibir notificaciones de cada evento. Consulta la guía de [Webhooks](/docs/webhooks/configure-webhooks) para aprender a configurar webhooks en Yuno.
