Esta vista previa ejecuta el Yuno Web SDK de producción. Cambia la configuración de la izquierda y el checkout se actualiza en vivo. La misma configuración se aplica a los SDK de iOS, Android y React Native. [Ábrela en una pestaña nueva](https://sdk-webview.dev.y.uno/playground.html).
