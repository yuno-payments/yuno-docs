## Instala con IA {#install-with-ai}

La integración más rápida es la que hace tu agente por ti. Pega esto en
Claude Code, Cursor o cualquier agente de código. Lee la guía
[Get Started](/es/docs/yuno-sdk/get-started), lo configura todo
y termina con un pago de prueba para que sepas que funciona:

```text
Read https://docs.y.uno/docs/yuno-sdk/get-started and integrate
the Yuno SDK into this project:

1. Load https://sdk-web.y.uno/v2.5.1/main.js with a script tag,
   or npm install @yuno-payments/sdk-web@^10 and call loadScript().
   Do not install 9.x or older of that package: those load SDK 1.x
2. Initialize SdkPayments once with the public API key from my env
3. Add a backend endpoint that creates a checkout session
   (workflow: "SDK_SEAMLESS")
4. Start a Transaction with onStatus wired, then run a sandbox
   test payment with card 4507 9900 0000 0002, expiry 11/28,
   CVV 123, cardholder John Doe
```

El número de tarjeta es una tarjeta de prueba: solo funciona en sandbox, no
se mueve dinero real. Más información en [Tarjetas de prueba](/es/docs/yuno-sdk/get-started#test-cards).

## Conecta tu agente (MCP) {#connect-your-agent-mcp}

MCP es el conector que une tu agente de IA directamente con Yuno. Una vez añadido,
tu agente puede crear sesiones de prueba, consultar pagos y probar flujos
por ti, sin salir de tu editor:

```json
{
  "mcpServers": {
    "yuno": {
      "url": "https://mcp.y.uno/v1"
    }
  }
}
```

<Note>
  El servidor MCP y el Agent Toolkit están documentados en
  [AI capabilities](/es/docs/ai-capabilities/building-ai-integrations-with-yunos-llms-and-mcp);
  los detalles del endpoint y de la autenticación están allí.
</Note>

## Skills listos para usar {#ready-made-skills}

Los skills son conocimiento preempaquetado: enseñan a tu agente los flujos de Yuno para que
no tengas que explicárselos. *(Propuesto, en definición con el equipo de
AI capabilities.)*

| Skill | Qué hace |
|---|---|
| `yuno-sdk-install` | Genera la integración completa: instalación, inicialización, endpoint de sesión y controladores conectados. |
| `yuno-test-payment` | Ejecuta pagos en sandbox con los escenarios de tarjetas de prueba e informa los resultados. |
| `yuno-migrate` | Asigna una integración anterior (Full, Lite, Seamless…) a la API `Transaction` unificada. |

## Documentación que tu agente puede leer (llms.txt) {#docs-your-agent-can-read-llmstxt}
