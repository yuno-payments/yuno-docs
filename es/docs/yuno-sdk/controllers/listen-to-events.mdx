---

Estos controllers te dicen lo que está ocurriendo. El SDK se comporta igual si los implementas o no: úsalos para dirigir tu propia interfaz o para responder a la hoja de la wallet con nuevos totales.

| Controller | Se activa cuando | Plataformas |
|---|---|---|
| [`onInstallmentSelected`](/es/docs/yuno-sdk/controllers/on-installment-selected) | El comprador elige o cambia una opción de cuotas en el formulario de tarjeta. | Web (`card.onInstallmentSelected`), iOS, Android, React Native |
| [`onCardInfoChanged`](/es/docs/yuno-sdk/controllers/on-card-info-changed) | La consulta de la tarjeta devuelve la marca, el tipo, la categoría, el emisor y el país de la tarjeta que el comprador está escribiendo, o esa tarjeta deja de aplicar. | iOS, Android (`TransactionConfig.onCardInfoChanged`) |
| [`onShippingAddressChanged`](/es/docs/yuno-sdk/controllers/on-shipping-address-changed) | El comprador selecciona o cambia la dirección de envío en una hoja de pago de wallet. | Web (`externalButtons.onShippingAddressChanged`), iOS, Android, React Native |
| `onChange` | Cambia la validez del formulario que renderizó el SDK. El handler recibe `{ form: { isValid } }` cuando inicia la transacción y en cada cambio. Cuando ocultas el botón Pay del SDK con `showPayButton: false`, úsalo para habilitar tu propio botón antes de llamar a `transaction.submit()`. | Web |

`onInstallmentSelected`, `onCardInfoChanged` y `onShippingAddressChanged` tienen cada uno una página con lo que recibes, lo que devuelves y la firma por plataforma.
