---

Sobrescribe estos controladores cuando quieras hacer tú mismo algo que el SDK hace por defecto. Sin una sobrescritura, el SDK mantiene su comportamiento por defecto. Con una, el SDK se hace a un lado y te entrega ese paso.

| Controlador | Sin sobrescribir | Sobrescrito |
|---|---|---|
| [`showView`](/es/docs/yuno-sdk/controllers/show-view) (iOS, Android, React Native) | El SDK presenta los formularios y las vistas de acción a pantalla completa. | El SDK te entrega la vista para que la insertes en tu propio diseño. |
| [`showLoading`](/es/docs/yuno-sdk/controllers/show-loading) | El SDK muestra su propio indicador de carga a pantalla completa. | El SDK oculta su indicador de carga y te informa el estado de carga. |
| [`createPayment`](/es/docs/yuno-sdk/controllers/create-payment) | El SDK crea el pago después de la tokenización. | El SDK entrega el token de un solo uso y espera a que tu backend cree el pago. |

Cada controlador tiene su propia página con el comportamiento, la firma por plataforma y las reglas de subprocesos.
