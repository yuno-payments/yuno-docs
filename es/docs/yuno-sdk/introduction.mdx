<div className="ysdk-intro">

Una integración, todas las plataformas. Los SDK de Yuno para iOS, Android, React Native 
y Web comparten la misma API unificada, así que lo que construyes una vez funciona en todas partes: la 
misma `Transaction`, el mismo `start()`, la misma configuración.

Inicializa el SDK con tu clave de API y empieza una `Transaction` para cada 
pago o inscripción. A partir de ahí, el SDK lleva a tu comprador desde elegir 
un método hasta un pago finalizado: formularios, tokenización, 3DS y el estado 
final, todo lo gestiona el SDK por ti. [Cómo fluye una transacción](/es/docs/yuno-sdk/how-a-transaction-flows) muestra la secuencia paso a paso.

## Empieza con el checkout predeterminado {#start-with-the-default-checkout}

El SDK incluye un checkout completo: lista de métodos, formularios, 3DS y resultados. 
Yuno lo renderiza y lo ejecuta todo; tú solo escuchas el resultado con 
`onStatus`.

El formulario que renderiza está ajustado para que los compradores terminen en segundos, sin nada 
que configurar. Consulta 
[Un checkout más rápido](/es/docs/yuno-sdk/features/form-behavior) para ver más 
ejemplos de lo que lo acelera.

## Elige un tipo de sesión {#choose-a-session-type}

La misma clase `Transaction` gestiona dos flujos:

- Pasa una **`checkoutSession`** para procesar un pago.
- Pasa una **`customerSession`** para inscribir un método de pago sin 
  cobrar.

Consulta [Sesiones](/es/docs/basic-concepts/sessions) para más detalles.

## Requisitos del backend {#backend-requirements}

Los SDK son solo del lado del cliente. Tu backend debe:

1. Crear sesiones de checkout o de cliente.
   - **Sesión de checkout**: consulta [`POST /v1/checkout/sessions`](https://docs.y.uno/es/reference/checkout-sessions/create-checkout-session).
   - **Sesión de cliente**: consulta [`POST /v1/customers/sessions`](https://docs.y.uno/es/reference/customer-sessions-enrollment/create-customer-session).

Consulta [Primeros pasos](/es/docs/yuno-sdk/get-started) para el recorrido completo de la 
integración del backend.

## Migrar desde una versión anterior {#migrating-from-a-previous-version}

Si actualmente usas uno de los SDK heredados (Full, Lite, Seamless, 
Render, Headless, Secure Fields), la nueva API unificada los reemplaza a 
todos con una sola clase `Transaction`. Tu integración existente 
seguirá funcionando, pero las nuevas funciones y mejoras se publican en el 
SDK unificado.

Consulta la [Guía de migración](/es/docs/yuno-sdk/migration/overview) para ver una correspondencia de los 
modos heredados con la nueva API y las instrucciones paso a paso para cada 
plataforma.
