El módulo `SdkAntifraudSignifyd` agrega el **perfilado de dispositivos de Signifyd** al Yuno SDK para iOS (`SdkPayments`). Cuando Signifyd es un proveedor de análisis de fraude en tu ruta de pago de Yuno, el Yuno SDK perfila el dispositivo durante el checkout con el Profiling SDK de Signifyd y envía el ID de sesión con el pago. Luego Yuno lo reenvía a Signifyd con la orden.

<Note>
  El módulo es **opcional**: agrégalo solo si tu cuenta de Yuno usa Signifyd para el análisis de fraude. Instalarlo no cambia tu código de pago ni de inscripción.
</Note>

A diferencia de los otros [módulos nativos](/es/docs/yuno-sdk/features/native-modules), Signifyd se distribuye en **su propio paquete de Swift Package Manager**, y el Profiling SDK de Signifyd se descarga desde el repositorio privado de Signifyd con **tu propio token de Signifyd**. Yuno no incluye ni redistribuye el SDK de Signifyd.

## Requisitos {#requirements}

- iOS **14.0** o superior.
- Xcode **26.2** o superior.
- **`SdkPayments` o `SdkPayments-Static` 3.2.0 o superior**, instalado mediante **Swift Package Manager**.
- Un **token de descarga del SDK de Signifyd**, emitido por tu ingeniero de soluciones de Signifyd.
- Signifyd habilitado como **proveedor de análisis de fraude** en tu ruta de pago de Yuno.

<Warning>
  El módulo está disponible **solo mediante Swift Package Manager**. No hay pod de CocoaPods. El Yuno SDK también debe venir de Swift Package Manager: si tu app instala `SdkPayments` con CocoaPods y este módulo con Swift Package Manager, la app carga dos copias del Yuno SDK y el checkout no usa Signifyd.
</Warning>

## Instalación {#installation}

<Steps>
  <Step title="Agrega tu token de Signifyd">
    El token le permite a Swift Package Manager descargar el Profiling SDK de Signifyd desde su repositorio privado. Solo se usa cuando tu compilación resuelve los paquetes, nunca en tiempo de ejecución.

    - **Xcode 26:** ve a **Xcode > Settings > Source Control**, haz clic en **+**, elige **GitHub** e ingresa la cuenta de GitHub y el token que te dio Signifyd. En versiones anteriores de Xcode la misma opción está en **Settings > Accounts**.
    - **CI:** escribe el token en `~/.netrc` antes de la compilación y elimina el archivo cuando termine:

      ```
      machine github.com
        login x-access-token
        password <your-signifyd-token>
      ```
  </Step>

  <Step title="Agrega el paquete">
    En Xcode ve a **File > Add Package Dependencies...**, agrega:

    ```
    https://github.com/yuno-payments/yuno-sdk-ios-signifyd
    ```

    elige **Up to Next Major Version** desde `2.0.0` y agrega el producto `SdkAntifraudSignifyd` al target de tu app, junto al producto `SdkPayments` o `SdkPayments-Static` que ya usas. Xcode descarga el Profiling SDK de Signifyd automáticamente.

    Si tu app usa un `Package.swift`, agrega la dependencia ahí:

    ```swift
    dependencies: [
        .package(url: "https://github.com/yuno-payments/yuno-sdk-ios.git", from: "3.2.0"),
        .package(url: "https://github.com/yuno-payments/yuno-sdk-ios-signifyd.git", from: "2.0.0")
    ],
    targets: [
        .target(
            name: "YourApp",
            dependencies: [
                .product(name: "SdkPayments", package: "yuno-sdk-ios"),
                .product(name: "SdkAntifraudSignifyd", package: "yuno-sdk-ios-signifyd")
            ]
        )
    ]
    ```
  </Step>

  <Step title="Habilita Signifyd en Yuno">
    Pide a tu equipo de cuenta de Yuno que agregue Signifyd como proveedor de análisis de fraude en tu ruta de pago. Sin eso, el módulo queda instalado pero el Yuno SDK nunca lo ejecuta.
  </Step>
</Steps>

## Activación del módulo {#activating-the-module}

El módulo **se registra solo** cuando la app inicia, con `SdkPayments` o con `SdkPayments-Static`. No necesitas código adicional además de agregar el producto `SdkAntifraudSignifyd` al target de tu app.

<Tip>
  Una vez instalado el módulo y con Signifyd en tu ruta de pago, el Yuno SDK lo usa automáticamente en cada checkout. No necesitas cambiar tu código de pago ni de inscripción.
</Tip>

## Cómo funciona {#how-it-works}

1. Cuando la app inicia, el módulo registra el proveedor Signifyd en el Yuno SDK.
2. Durante el checkout, si Signifyd es un proveedor de análisis de fraude para la transacción, el Yuno SDK ejecuta el módulo.
3. El módulo perfila el dispositivo con el Profiling SDK de Signifyd y devuelve el ID de sesión con el que lo perfiló.
4. El Yuno SDK envía ese ID de sesión con el pago, y Yuno lo reenvía a Signifyd con la orden.

Si el perfilado falla o tarda más de lo que permite el checkout, el pago continúa sin el fingerprint de Signifyd.

## Solución de problemas {#troubleshooting}

<AccordionGroup>
  <Accordion title="Falla la resolución del paquete ios-sdk-dist (401 o repositorio no encontrado)">
    Swift Package Manager no pudo descargar el Profiling SDK de Signifyd. Revisa que tu token de Signifyd esté agregado en **Xcode > Settings > Source Control** (o en `~/.netrc` en CI) y que siga vigente. Si el token venció o fue revocado, pide uno nuevo a tu ingeniero de soluciones de Signifyd. Las apps que ya publicaste siguen funcionando, porque el token solo se usa al compilar.
  </Accordion>
  <Accordion title="El módulo está instalado pero los pagos no llevan el fingerprint de Signifyd">
    Revisa que el producto `SdkAntifraudSignifyd` esté agregado al **target de tu app**, no solo al proyecto, y que Signifyd sea un proveedor de análisis de fraude en tu ruta de pago de Yuno.
  </Accordion>
  <Accordion title="Falla la resolución del paquete por un conflicto de versiones en yuno-sdk-ios">
    Las versiones 2.x de este paquete requieren `yuno-sdk-ios` 3.2.0 o superior. Las versiones 1.x son para el Legacy SDK (`YunoSDK` 2.x), consulta [Signifyd antifraud (Legacy iOS)](/es/docs/sdks/external-native-modules/signifyd-ios).
  </Accordion>
  <Accordion title="Mi app instala SdkPayments con CocoaPods">
    El módulo depende del Yuno SDK desde Swift Package Manager. Elimina el pod y agrega `SdkPayments-Static` (el mismo enlace estático que tenías con CocoaPods) desde Swift Package Manager antes de agregar este módulo.
  </Accordion>
  <Accordion title="Framework SignifydProfilingSdk duplicado">
    El paquete `SdkAntifraudSignifyd` ya trae el Profiling SDK de Signifyd. Si tu app también incrusta `SignifydProfilingSdk.xcframework` manualmente, elimínalo y deja solo la dependencia del paquete.
  </Accordion>
</AccordionGroup>
