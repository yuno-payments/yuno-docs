---
title: "Descripción general de la migración"
description: "Pasa de cualquier modo anterior del Yuno SDK a la API unificada Transaction."
---

El SDK unificado reemplaza todos los modos anteriores del SDK (Full, Lite, Seamless, Render, Headless y Secure Fields) con una sola clase `Transaction`. Si actualmente usas alguno de esos modos, elige tu plataforma y tu modo anterior en la tabla siguiente. En React Native, las guías parten de la API 1.x de `@yuno-payments/yuno-sdk-react-native` y terminan en la 2.0.0.

## Qué cambió {#what-changed}

Cada modo anterior corresponde a la misma clase `Transaction`. El nombre del modo desaparece. Lo que pasas a la configuración y los controllers que sobrescribes determinan el comportamiento:

- **El tipo de sesión** (`checkoutSession` frente a `customerSession`) determina si se trata de un pago o de una inscripción.
- **El controller `createPayment`** determina si el SDK crea el pago o lo hace tu backend. Si no lo sobrescribes, el SDK gestiona la creación del pago de principio a fin (el equivalente de Seamless).
- **El controller `showView`** (iOS, Android, React Native) determina si el SDK presenta el formulario a pantalla completa o te entrega la vista para que la insertes (el equivalente de Render).
- **`transactionData` en `PaymentMethodSelected`** (iOS, Android, React Native) o **`data` en el `paymentMethod` que pasas a `start()`** (Web) determina si el SDK muestra un formulario o tokeniza datos que ya recopilaste (el equivalente de Headless).
- **`getPaymentMethodsViews`** reemplaza todas las API anteriores de montaje de listas y de botones externos de billeteras (el equivalente de Full).

<Note>
**3DS nativo en iOS:** los módulos nativos de 3DS aún no están disponibles para el SDK de iOS 3.x, por lo que los desafíos de 3DS se ejecutan en un WebView presentado por el SDK. Consulta [Módulos nativos](/es/docs/yuno-sdk/features/native-modules#netcetera-3ds).
</Note>

Cada guía tiene la misma estructura: qué resolver antes de empezar, una comparación de código lado a lado y una tabla de lo que cambia, con qué hacer en cada caso.
