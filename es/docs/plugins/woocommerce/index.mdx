El plugin de WooCommerce de Yuno integra la plataforma de orquestación de pagos de Yuno directamente en tu tienda WooCommerce, a través del SDK Web de Yuno y una capa de API REST en PHP. Es el segundo plugin de e-commerce que Yuno admite, después de VTEX.

<Note>
  Esta es una versión MVP. Yuno está evolucionando activamente el plugin según los comentarios de los comercios. Únete al canal `WooCommerce` en el Slack compartido para mantenerte al tanto de las nuevas versiones.
</Note>

## Qué es {#what-it-is}

El plugin agrega Yuno como gateway de pago dentro de WooCommerce, y admite tanto el checkout heredado basado en shortcode como el checkout basado en bloques de WooCommerce. Los compradores completan su compra sin salir de tu tienda, y el estado del pedido se actualiza automáticamente a medida que Yuno informa a WooCommerce los eventos de pago.

## Sincronización del estado del pedido {#order-status-sync}

Yuno mantiene el estado de tu pedido de WooCommerce sincronizado con el estado del pago subyacente:

| Resultado del pago | Estado del pedido en WooCommerce |
| :--- | :--- |
| El pago fue exitoso, producto virtual o descargable | Completed |
| El pago fue exitoso, el producto requiere envío | Processing |
| El pago falló | Failed |

## Revisión de los logs de sincronización {#reviewing-sync-logs}

La pantalla de configuración del plugin incluye un visor de logs donde puedes revisar los mensajes intercambiados entre WooCommerce y Yuno para cada pedido, útil para solucionar problemas de un pago que no se sincronizó como se esperaba.

## Configuración {#setup}

1. En tu panel de administración de WooCommerce, ve a la configuración del gateway de pago de Yuno.
2. Ingresa tus claves de API de Yuno.
3. Guarda los cambios y habilita el gateway.

Para ver la lista completa de funciones compatibles y el historial de versiones, consulta el [Changelog del plugin de WooCommerce](/changelog/plugins/woocommerce).
