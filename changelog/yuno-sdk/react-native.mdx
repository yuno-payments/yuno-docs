## v2.0.0
*November 2, 2026*

- <ChangelogBadge type="breaking" /> **The Yuno SDK for React Native**  
  Version 2.0.0 runs on the native Yuno SDK 3.0.0 on Android and iOS and brings the same integration to React Native: initialize with `SdkPayments.initialize`, create a `Transaction`, start it, and get the result in `onStatus`. It replaces the 1.x API (`YunoSdk.startPayment`, `startPaymentLite`, `continuePayment`, the `YunoPaymentMethods` component and the status and token listeners) and isn't compatible with 1.x.  
  [Migration guide →](/docs/yuno-sdk/migration/overview)  
  *See also: [Yuno SDK documentation](/docs/yuno-sdk/introduction) · [Get started](/docs/yuno-sdk/get-started)*

- <ChangelogBadge type="added" /> **Embedded views with `YunoView`**  
  Implement `showView` in the controller to place the card form, APM forms and the enrollment form in your own screen: render the view with `<YunoView view={view} />` and submit it from your own button with `process.onSubmit()`. Without `showView`, the SDK presents its own screens.  
  *See also: [showView](/docs/yuno-sdk/controllers/show-view)*

- <ChangelogBadge type="added" /> **Payment methods list and wallet buttons**  
  `transaction.getPaymentMethodsViews` returns the payment methods list and the Google Pay (Android) or Apple Pay (iOS) button to render with `<YunoView>`, with selection, height and unenroll callbacks.  
  *See also: [Payment Methods List](/docs/yuno-sdk/features/payment-methods-list)*

- <ChangelogBadge type="added" /> **Create the payment on your backend**  
  Implement `createPayment(token)` and the SDK waits for the Promise it returns before it continues with 3DS and the result.  
  *See also: [createPayment](/docs/yuno-sdk/controllers/create-payment)*

- <ChangelogBadge type="added" /> **Hand a step back to the SDK**  
  `SdkPayments.defaultShowView`, `SdkPayments.defaultShowLoading` and `SdkPayments.defaultCreatePayment` let the SDK handle a single call of your controller, for example to embed only the card form or to let the SDK create the payment for some methods.  
  *See also: [Take over the SDK](/docs/yuno-sdk/controllers/take-over-the-sdk)*

- <ChangelogBadge type="changed" /> **Minimum versions**  
  React Native 0.73 or higher, with the new or the old architecture. On Android, `minSdkVersion` 23 and the Yuno Maven repository in your Gradle repositories; on iOS, 14.0.  
  *See also: [Get started](/docs/yuno-sdk/get-started)*
