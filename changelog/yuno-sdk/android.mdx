## v3.0.0
*October 16, 2026*

- <ChangelogBadge type="breaking" /> **A new Yuno SDK**  
  Version 3.0.0 is the new Yuno SDK: one integration for payments and enrollment, with the same API on Android, iOS and Web. Create a `Transaction`, start it, and get the result in `onStatus`. It replaces the Full, Lite, Seamless, Render and Headless integrations and isn't compatible with 2.x.  
  [Migration guide →](/docs/yuno-sdk/migration/overview)  
  *See also: [Yuno SDK documentation](/docs/yuno-sdk/introduction) · [Get started](/docs/yuno-sdk/get-started)*

- <ChangelogBadge type="breaking" /> **New package and entry point**  
  The new SDK lives in `com.yuno.payments.sdk.api` and starts from `SdkPayments` (previously `com.yuno.sdk.Yuno`). The Gradle dependency keeps its name; only the version changes to 3.0.0.  
  *See also: [Get started](/docs/yuno-sdk/get-started)*

- <ChangelogBadge type="deprecated" /> **Previous SDK supported until 2027**  
  The 2.x SDK (Full, Lite, Seamless, Render and Headless) stays supported side by side with the new Yuno SDK during the transition. Its deprecation is scheduled for 2027. Contact your Account Manager to plan the migration.
