## v3.1.0
*November 6, 2026*

- <ChangelogBadge type="added" /> **Multiple Cards Without the SDK UI**  
  You can now pay one checkout with multiple cards without the SDK UI.

- <ChangelogBadge type="added" /> **Card Information While Typing**  
  The card brand, type, issuer and country are delivered to the merchant while the shopper types the card number.

- <ChangelogBadge type="added" /> **Backend-Driven Form Copy**  
  Field labels, placeholders and texts in the forms can now come from the backend.

- <ChangelogBadge type="changed" /> **Card Brand Icons**  
  Card brand icons in payment and enrollment forms now come from the backend brand catalog, with fallback to bundled icons.

- <ChangelogBadge type="changed" /> **Payment Method Descriptions**  
  The payment method description set in the Checkout Builder is now displayed under its name in the full payment methods list.

- <ChangelogBadge type="changed" /> **Form Field Colors**  
  Form fields now follow the field color set in the Checkout Builder.

- <ChangelogBadge type="fixed" /> **Card Brand Loading Spinner**  
  The loading spinner now stays aligned with the brand icon while the card number is validated.

- <ChangelogBadge type="fixed" /> **Cybersource 3DS Device Data Collection**  
  Device data collection now falls back to cancel when messages arrive from an unexpected origin.

## v3.0.0
*October 16, 2026*

- <ChangelogBadge type="breaking" /> **A new Yuno SDK**  
  Version 3.0.0 is the new Yuno SDK: one integration for payments and enrollment, with the same API on iOS, Android and Web. Create a `Transaction`, start it, and get the result in `onStatus`. It replaces the Full, Lite, Seamless, Render and Headless integrations and isn't compatible with 2.x.  
  [Migration guide →](/docs/yuno-sdk/migration/overview)  
  *See also: [Yuno SDK documentation](/docs/yuno-sdk/introduction) · [Get started](/docs/yuno-sdk/get-started)*

- <ChangelogBadge type="breaking" /> **Module renamed to SdkPayments**  
  The pod, the Swift Package product and the module are now named `SdkPayments` (previously `YunoSDK`). Update your Podfile or package dependency and replace `import YunoSDK` with `import SdkPayments`.  
  *See also: [Get started](/docs/yuno-sdk/get-started)*

- <ChangelogBadge type="deprecated" /> **Previous SDK supported until 2027**  
  The 2.x SDK (Full, Lite, Seamless, Render and Headless) stays supported side by side with the new Yuno SDK during the transition. Its deprecation is scheduled for 2027. Contact your Account Manager to plan the migration.
