- <ChangelogBadge type="added" /> **Czech Checkout Language**  
  Adds Czech (`cs`, `cs-CZ`) localization to the Yuno SDK checkout.

- <ChangelogBadge type="added" /> **Payment method description from the Checkout Builder**  
  In the payment method list, the description configured in the Checkout Builder (`custom_description`) displays as a secondary grey line beneath the payment method name.

## v2.0.0
*October 16, 2026*

```html
<script src="https://sdk-web.y.uno/v2.0.0/main.js"></script>
```

- <ChangelogBadge type="breaking" /> **A new Yuno SDK**  
  Version 2.0.0 is the new Yuno SDK for Web: unified payments and enrollment with the same architecture across Web, Android, and iOS. Initialize with `Yuno.initialize()`, mount components via `yuno.mount()`, and listen for unified events. It replaces the legacy Full, Lite, Seamless, Render, and Headless integrations.  
  [Migration guide →](/docs/yuno-sdk/migration/overview)  
  *See also: [Yuno SDK documentation](/docs/yuno-sdk/introduction) · [Get started](/docs/yuno-sdk/get-started)*

- <ChangelogBadge type="deprecated" /> **Previous SDK supported until 2027**  
  Legacy Web SDK (1.x) remains supported side by side during the transition. Deprecation is scheduled for 2027.
