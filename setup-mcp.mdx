---
title: "Model Context Protocol (MCP)"
description: "Connect your AI coding agents directly to Yuno's documentation."
---

The Model Context Protocol (MCP) allows AI tools like **Cursor**, **Windsurf**, and **Claude** to browse, search, and read Yuno's documentation in real-time. This gives your AI assistant access to up-to-date context when helping you integrate Yuno.

This MCP server is **read-only**: it exposes only documentation search and retrieval tools, and requires no Yuno API credentials. It cannot create, modify, or refund payments, and it cannot read data from your Yuno account.

<Note>
  Looking for an MCP that can act on your Yuno account, for example to create payments, customers, or subscriptions? See the [Local Action MCP](/docs/ai-capabilities/building-ai-integrations-with-yunos-llms-and-mcp) or the [Remote Action MCP](/docs/ai-capabilities/remote-yuno-mcp-server) below.
</Note>

## Which Yuno MCP do you need?

<CardGroup cols={3}>
  <Card title="Documentation MCP" icon="book-open">

  </Card>
  <Card title="Local Action MCP" icon="terminal" href="/docs/ai-capabilities/building-ai-integrations-with-yunos-llms-and-mcp" arrow>

## Documentation MCP URL
Use the following URL to connect your tools to the Yuno documentation:

[https://docs.y.uno/mcp](https://docs.y.uno/mcp)

## Connecting to AI Tools

<Tabs>
  <Tab title="Cursor">
    1. Open **Cursor Settings** (`Cmd+Shift+P` or `Ctrl+Shift+P` -> "Open MCP Settings").
    2. Click on **+ Add New MCP Server**.
    3. Fill in the details:
       - **Name**: Yuno Docs
       - **Type**: `http`
       - **URL**: `https://docs.y.uno/mcp`
    4. Click **Save**.
  </Tab>

  <Tab title="Claude Code">
    Run:

    ```bash
    claude mcp add --transport http yuno-docs https://docs.y.uno/mcp
    ```

    Use `--scope project` instead of the default `local` scope to share this server with your team via `.mcp.json`.
  </Tab>

  <Tab title="Claude Desktop">
    1. Open your Claude Desktop configuration file (usually `~/Library/Application Support/Claude/claude_desktop_config.json` or `%APPDATA%\Claude\claude_desktop_config.json`).
    2. Add the Yuno Docs connector to the `mcpServers` section:

    ```json
    {
      "mcpServers": {
        "yuno-docs": {
          "url": "https://docs.y.uno/mcp"
        }
      }
    }
    ```
  </Tab>

  <Tab title="Codex">
    Run:

    ```bash
    codex mcp add yuno-docs --url https://docs.y.uno/mcp
    ```
  </Tab>

  <Tab title="Windsurf / VS Code Copilot">
    For tools that support native MCP via folder configuration, create a `.vscode/mcp.json` file in your project:

    ```json
    {
      "servers": {
        "yuno-docs": {
          "type": "http",
          "url": "https://docs.y.uno/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>
