This page explains how Yuno handles API versioning, SDK versions, and deprecation schedules.

## API versioning

Yuno uses backward-compatible versioning for the API. All updates are compatible with both the current version and previous versions.

### Backward-compatible changes

These changes do not require you to update your integration:

- New resources added to the API
- New optional request parameters added to existing methods
- New properties added to existing responses
- Changed order of properties in responses
- Changes to the length or format of identifiers and error messages
- New webhook event types

### Breaking changes

When a breaking change is required, Yuno releases a new API version. You can continue using the previous version until you are ready to upgrade.

## SDK versions

### Yuno SDK (current)

The Yuno SDK is the recommended SDK for new integrations. It provides one unified API across all platforms.

| Platform | Current version | Package |
|----------|----------------|---------|
| Web | 2.x | CDN: `https://sdk-web.y.uno/v2.x.x/main.js` |
| iOS | 3.x | Swift Package Manager or CocoaPods |
| Android | 3.x | Maven: `com.yuno.payments:android-sdk` |

See [Get started with the Yuno SDK](/docs/yuno-sdk/get-started) for installation.

### Legacy SDKs

The legacy SDKs (Full, Lite, Seamless, Render, Headless, and Secure Fields) remain supported during the transition period.

| Platform | Legacy version | Status |
|----------|---------------|--------|
| Web | 1.11.x | Supported until 2027 |
| iOS | 2.x | Supported until 2027 |
| Android | 2.x | Supported until 2027 |

## Deprecation schedule

### Legacy SDK deprecation (2027)

Legacy SDKs are scheduled for deprecation in 2027. After deprecation:

- No new features will be added to legacy SDKs
- Security patches will continue for a transition period
- New integrations should use the Yuno SDK

**Action required:** If you use a legacy SDK, plan your migration to the Yuno SDK. See the [migration guide](/docs/yuno-sdk/migration/overview) for step-by-step instructions.

### Getting migration support

Contact your Account Manager for:

- Migration planning and timeline
- Technical support during migration
- Questions about feature parity
