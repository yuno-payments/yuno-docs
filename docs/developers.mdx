**Quick start for agents**

1. Read [llms.txt](https://docs.y.uno/llms.txt) and this page.
2. Load the [OpenAPI spec](https://docs.y.uno/openapi.json).
3. Authenticate as described in [Authentication](/reference/getting-started/authentication).
4. Create a payment with the Payments API or an SDK. The [Quickstart](/docs/quickstart) shows both.
5. Subscribe to [webhooks](/docs/webhooks) for asynchronous status updates.
