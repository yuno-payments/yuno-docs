A connection links your Yuno account to a provider. Add it once, then use it in routing.

## Concepts

| Dashboard term | What it is | Where you use it |
|---------------|------------|-----------------|
| Connection | A configured link to one provider, with credentials and settings. | Routing, Checkout Builder |
| Provider | A payment processor, acquirer, fraud tool or authentication service. | Connections > Explore |
| Credentials | API keys, merchant IDs or tokens from the provider. | Connection setup |
| Costs | Transaction fees for Smart Routing and Reconciliations. | Connection settings |

## Quickstart: add your first connection

Do this in Test Mode. The Yuno Test Payment Gateway is always available.

<Steps>
  <Step title="Open Connections">
    In the Dashboard, go to **Connections**. The **Explore** tab shows all available providers.
  </Step>
  <Step title="Find a provider">
    Browse the list or use the search box. Click **Connect** on the provider you want.
  </Step>
  <Step title="Enter credentials">
    Name the connection and enter the credentials from your provider. The fields vary by provider. Click **Next**.
  </Step>
  <Step title="Set up costs (optional)">
    Enter cost information for Smart Routing and Reconciliations. You can skip this step and add costs later.
  </Step>
  <Step title="Select accounts">
    Choose which accounts can use this connection. Click **Save**.
  </Step>
  <Step title="Use it in Routing">
    Go to [Routing](/docs/using-yuno/dashboard-overview/routing) to add this connection to a payment route.
  </Step>
</Steps>

## How-to guides

<AccordionGroup>
  <Accordion title="Edit a connection">
    Go to **Connections** > **Your connections**. Click the three dots (⋮) next to the connection and select **Edit**. Update credentials or settings and save.

    <Note>
    When you create a connection for multiple accounts, one connection is created per account. To make changes, edit each connection individually.
    </Note>
  </Accordion>

  <Accordion title="Pause or unpause a connection">
    Go to **Connections** > **Your connections**. Click the three dots (⋮) and select **Pause** or **Unpause**.

    A paused connection is not available for routing. Use this to temporarily disable a provider without deleting the connection.
  </Accordion>

  <Accordion title="Delete a connection">
    Go to **Connections** > **Your connections**. Click the three dots (⋮) and select **Delete**.

    <Warning>
    Deleting a connection is permanent. Make sure no routes depend on it before you delete.
    </Warning>
  </Accordion>

  <Accordion title="Manage multiple connections">
    Check the box next to two or more connections to pause, unpause or delete them in bulk.
  </Accordion>

  <Accordion title="Set up costs for Smart Routing">
    When you add or edit a connection, click **Set up cost** in the costs step. Enter costs for successful and unsuccessful payments.

    You can set default costs for all payments and add conditions for specific cases, like a different cost for Visa transactions. Drag conditions to reorder them. The first matching condition applies.

    Costs are used for both [Smart Routing](/docs/using-yuno/dashboard-overview/routing#smart-routing) and Fees in Reconciliations.
  </Accordion>

  <Accordion title="Configure dynamic metadata">
    Turn on **Dynamic Metadata Configuration** in the connection settings to control which metadata fields are sent to each provider.

    Set up key mappings from your API metadata to provider-specific metadata. Only the configured keys are sent during transactions.
  </Accordion>

  <Accordion title="Add 3DS credentials">
    When setting up credentials, check **3DS Credentials** and enter the required data. This enables 3D Secure for card payments through this connection.
  </Accordion>
</AccordionGroup>

## Reference

### Connection statuses

| Status | Meaning |
|--------|---------|
| Active | The connection is ready for routing. |
| Paused | The connection exists but is not available for routing. |

### Provider types

| Type | Examples |
|------|----------|
| Payment processor | Adyen, Stripe, dLocal, Mercado Pago |
| Acquirer | Direct bank integrations |
| Fraud | Yuno Risk Screening, Cybersource |
| 3DS | Yuno 3DS, Netcetera |
| Authentication | Provider-specific authentication services |

## Troubleshooting

| Problem | Cause | Fix |
|---------|-------|-----|
| Connection not showing in Routing | The connection is paused or not for the selected payment method. | Check the connection status and payment method support. |
| Credentials error | Invalid API keys or expired tokens from the provider. | Update the credentials in the connection settings. |
| Costs not used in Smart Routing | Costs are not configured, or Smart Routing is set to optimize latency only. | Add costs to the connection and select cost optimization in routing. |
