<Step titleSize="h3" title="Get your sandbox credentials">

Log in to the [Yuno dashboard](https://dashboard.y.uno/) and open **Developers** to find three values:

* **Account code**, shown as `account_id` in the dashboard
* **`public-api-key`**
* **`private-secret-key`**

Sandbox keys start with `sandbox_`. Production keys are different and start with `prod_`.

<Step titleSize="h3" title="Connect the Yuno Test Payment Gateway and publish a route">

The Yuno Test Payment Gateway simulates a card provider. It works in sandbox only and needs no credentials.

1. Open [Connections](https://dashboard.y.uno/connections), search for **Yuno Test Payment Gateway**, click **Connect**, name the connection, and click **Save**.
2. Open [Routing](https://dashboard.y.uno/routing), open the **Not published** tab, find **Card**, and click **Set Up**.
3. Click **+ Create new route**, name it, and click **Save**.
4. Click the arrow, choose **Add step**, select **Yuno Test Payment Gateway**, and click **Publish**.
5. Open [Checkout builder](https://dashboard.y.uno/checkout-builder), turn on **Card**, and publish the settings.

<Step titleSize="h3" title="Send the payment">

<Tabs>
<Tab title="API">

<Warning>
Sending raw card numbers from your server is for sandbox testing. In production it requires PCI DSS scope. Otherwise use the Yuno SDK or Secure Fields to collect card data.
</Warning>

The API tab uses the `DIRECT` workflow, a back-to-back payment where your server sends the card data. Set your credentials as environment variables:

```bash Shell
export YUNO_PUBLIC_API_KEY="sandbox_..."
export YUNO_PRIVATE_SECRET_KEY="sandbox_..."
export YUNO_ACCOUNT_ID="your-account-code"
```

First, create a customer. The base URL is `https://api-sandbox.y.uno`.

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api-sandbox.y.uno/v1/customers \
  --header "public-api-key: $YUNO_PUBLIC_API_KEY" \
  --header "private-secret-key: $YUNO_PRIVATE_SECRET_KEY" \
  --header "content-type: application/json" \
  --data '{
    "merchant_customer_id": "customer-0001",
    "first_name": "John",
    "last_name": "Doe",
    "email": "john.doe@example.com"
  }'
```

```javascript Node.js
const res = await fetch("https://api-sandbox.y.uno/v1/customers", {
  method: "POST",
  headers: {
    "public-api-key": process.env.YUNO_PUBLIC_API_KEY,
    "private-secret-key": process.env.YUNO_PRIVATE_SECRET_KEY,
    "content-type": "application/json",
  },
  body: JSON.stringify({
    merchant_customer_id: "customer-0001",
    first_name: "John",
    last_name: "Doe",
    email: "john.doe@example.com",
  }),
});
const customer = await res.json();
console.log(customer.id);
```

```python Python
import os
import requests

res = requests.post(
    "https://api-sandbox.y.uno/v1/customers",
    headers={
        "public-api-key": os.environ["YUNO_PUBLIC_API_KEY"],
        "private-secret-key": os.environ["YUNO_PRIVATE_SECRET_KEY"],
    },
    json={
        "merchant_customer_id": "customer-0001",
        "first_name": "John",
        "last_name": "Doe",
        "email": "john.doe@example.com",
    },
)
print(res.json()["id"])
```

</CodeGroup>

The response includes an `id`. Save it as `YUNO_CUSTOMER_ID` for the next call.

Then create the payment with a test card. Send a new `X-Idempotency-Key` with each payment.

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api-sandbox.y.uno/v1/payments \
  --header "public-api-key: $YUNO_PUBLIC_API_KEY" \
  --header "private-secret-key: $YUNO_PRIVATE_SECRET_KEY" \
  --header "X-Idempotency-Key: $(uuidgen)" \
  --header "content-type: application/json" \
  --data '{
    "account_id": "'"$YUNO_ACCOUNT_ID"'",
    "merchant_order_id": "order-0001",
    "description": "First test payment",
    "country": "US",
    "amount": { "currency": "USD", "value": 25 },
    "workflow": "DIRECT",
    "customer_payer": { "id": "'"$YUNO_CUSTOMER_ID"'" },
    "payment_method": {
      "type": "CARD",
      "detail": { "card": { "card_data": {
        "number": "4507990000000002",
        "expiration_month": 11,
        "expiration_year": 28,
        "security_code": "123",
        "holder_name": "John Doe"
      } } }
    }
  }'
```

```javascript Node.js
const res = await fetch("https://api-sandbox.y.uno/v1/payments", {
```

<Tab title="Web SDK">

The Web SDK tab splits the work. Your server creates a checkout session, and the browser loads the SDK and starts the transaction.

**On your server**, create the checkout session. Use `workflow: "SDK_SEAMLESS"` so the SDK creates the payment for you. Without it the transaction ends in `INTERNAL_ERROR`.

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api-sandbox.y.uno/v1/checkout/sessions \
  --header "public-api-key: $YUNO_PUBLIC_API_KEY" \
  --header "private-secret-key: $YUNO_PRIVATE_SECRET_KEY" \
  --header "content-type: application/json" \
  --data '{
    "account_id": "'"$YUNO_ACCOUNT_ID"'",
    "merchant_order_id": "order-0001",
    "payment_description": "First test payment",
    "country": "US",
    "amount": { "currency": "USD", "value": 25 },
    "workflow": "SDK_SEAMLESS"
  }'
```

**In the browser**, load the SDK from the CDN, then start a transaction with the `checkout_session` value from your server.

```html Browser
<div id="payment-form"></div>
<script src="https://sdk-web.y.uno/v2.0.0/main.js"></script>
<script>
  async function startYuno() {
    const sdkPayments = await SdkPayments.initialize("your-public-api-key");
    const transaction = sdkPayments.transaction({
      checkoutSession: "checkout-session-from-your-server",
      countryCode: "US",
      elementSelector: "#payment-form",
      onStatus: (result) => console.log("Final status:", result.status),
    });
    await transaction.start({ paymentMethod: { type: "CARD" } });
  }

  if (window.SdkPayments) {
    startYuno();
  } else {
    window.addEventListener("sdk-payments-ready", startYuno);
  }
</script>
```

## Troubleshooting

<AccordionGroup>
<Accordion title="The API returns 401">
The `public-api-key` or `private-secret-key` header is missing or wrong. Sandbox and production use different keys, so check that you copied the sandbox keys from the dashboard in Test Mode. See [Authentication](/reference/getting-started/authentication).
</Accordion>
<Accordion title="The payment ends in INTERNAL_ERROR">
The `workflow` does not match your integration. Use `DIRECT` when your server sends the card, and `SDK_SEAMLESS` on the checkout session when the Web SDK creates the payment.
</Accordion>
<Accordion title="No provider processes the payment">
Card has no published route. Open [Routing](https://dashboard.y.uno/routing) and check that the Card route with the Yuno Test Payment Gateway is under the **Published** tab, and that Card is turned on in the [Checkout builder](https://dashboard.y.uno/checkout-builder).
</Accordion>
<Accordion title="The card is declined">
Test cards are specific to a provider. The cards in this Quickstart only work when your sandbox routes Card to the Yuno Test Payment Gateway. Other results are listed on the [Yuno Test Payment Gateway](/docs/direct-integration-use-cases/yuno-testing-gateway) page.
</Accordion>
</AccordionGroup>
