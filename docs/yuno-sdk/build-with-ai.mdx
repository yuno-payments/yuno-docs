## Install with AI

The fastest integration is the one your agent does for you. Paste this
prompt into Claude Code, Cursor, or any coding agent — it points at the
[Get Started](/docs/yuno-sdk/get-started) guide and ends with a sandbox
test payment:

```text
Read https://docs.y.uno/docs/yuno-sdk/get-started and integrate
the Yuno SDK into this project:

1. Install @yuno-payments/sdk-web@2.0.0
2. Initialize SdkPayments once with the public API key from my env
3. Add a backend endpoint that creates a checkout session
   (workflow: "SDK_SEAMLESS")
4. Start a Transaction with onStatus wired, then run a sandbox
   test payment with card 4111 1111 1111 1111
```

The test card `4111 1111 1111 1111` is the sandbox success card — see
[Test cards](/docs/yuno-sdk/get-started#5-test-cards).

## MCP server

Yuno's remote MCP server exposes the API as tools your agent can call —
create checkout sessions, inspect payments, and exercise sandbox flows
without leaving the editor. Add it to your agent's MCP configuration:

{/* TODO(verify): confirm the MCP endpoint with the AI capabilities team */}

```json
{
  "mcpServers": {
    "yuno": {
      "url": "https://mcp.y.uno/v1"
    }
  }
}
```

</Note>

## Agent skills

Skills package Yuno-specific workflows so your agent doesn't have to
rediscover them. *(Proposed — in definition with the AI capabilities team.)*

| Skill | What it does |
|---|---|
| `yuno-sdk-install` | Scaffolds the full integration: install, initialize, session endpoint, controllers wired. |
| `yuno-test-payment` | Runs sandbox payments across the test-card scenarios and reports results. |
| `yuno-migrate` | Maps a legacy integration (Full, Lite, Seamless…) to the unified `Transaction` API. |
