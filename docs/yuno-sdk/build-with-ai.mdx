## Install with AI

The fastest integration is the one your agent does for you. Paste this into
Claude Code, Cursor, or any coding agent — it reads the
[Get Started](/docs/yuno-sdk/get-started) guide, sets everything up, and
finishes with a test payment so you know it works:

```text
Read https://docs.y.uno/docs/yuno-sdk/get-started and integrate
the Yuno SDK into this project:

1. Install @yuno-payments/sdk-web@2.0.0
2. Initialize SdkPayments once with the public API key from my env
3. Add a backend endpoint that creates a checkout session
   (workflow: "SDK_SEAMLESS")
4. Start a Transaction with onStatus wired, then run a sandbox
   test payment with card 4111 1111 1111 1111
```

The card number is a test card — it only works in sandbox, no real money
moves. More in [Test cards](/docs/yuno-sdk/get-started#test-cards).

## Connect your agent (MCP)

MCP is the plug that connects your AI agent straight to Yuno. Once added,
your agent can create test sessions, look up payments, and try flows for
you — without leaving your editor:

```json
{
  "mcpServers": {
    "yuno": {
      "url": "https://mcp.y.uno/v1"
    }
  }
}
```

## Ready-made skills

Skills are prepackaged know-how: they teach your agent Yuno's workflows so
you don't have to explain them. *(Proposed — in definition with the AI
capabilities team.)*

| Skill | What it does |
|---|---|
| `yuno-sdk-install` | Scaffolds the full integration: install, initialize, session endpoint, controllers wired. |
| `yuno-test-payment` | Runs sandbox payments across the test-card scenarios and reports results. |
| `yuno-migrate` | Maps a legacy integration (Full, Lite, Seamless…) to the unified `Transaction` API. |

## Docs your agent can read (llms.txt)

Every page of these docs is also published in a format agents can read on
their own, indexed at [docs.y.uno/llms.txt](https://docs.y.uno/llms.txt).
Point your agent there and it can explore the documentation without your
