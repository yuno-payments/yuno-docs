Override these controllers when you want to do yourself something the SDK does by default. Without an override the SDK keeps its default behavior. With one, the SDK steps aside and hands that step to you.

| Controller | Not overridden | Overridden |
|---|---|---|
| [`showView`](/docs/yuno-sdk/controllers/show-view) (iOS, Android) | The SDK presents forms and action views full-screen. | The SDK hands you the view to embed in your own layout. |
| [`showLoading`](/docs/yuno-sdk/controllers/show-loading) | The SDK shows its own full-screen loader. | The SDK hides its loader and reports the loading state to you. |
| [`createPayment`](/docs/yuno-sdk/controllers/create-payment) | The SDK creates the payment after tokenization. | The SDK delivers the One-Time Token and waits for your backend to create the payment. |

Each controller has its own page with the behavior, the signature per platform and the threading rules.
