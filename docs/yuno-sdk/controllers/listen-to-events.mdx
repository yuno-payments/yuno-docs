These controllers tell you what is happening. The SDK behaves the same whether you implement them or not: use them to drive your own UI, or to answer the wallet sheet with new totals.

| Controller | Fires when | Platforms |
|---|---|---|
| [`onInstallmentSelected`](/docs/yuno-sdk/controllers/on-installment-selected) | The shopper picks or changes an installment option in the card form. | iOS, Android |
| [`onShippingAddressChanged`](/docs/yuno-sdk/controllers/on-shipping-address-changed) | The shopper selects or changes the shipping address in a wallet payment sheet. | iOS, Android |

Each controller has its own page with what you receive, what you return and the signature per platform.
