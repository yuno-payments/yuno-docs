Follow this step-by-step guide to implement and enable Yuno's Lite Web SDK enrollment capability in your app.

## Step 1: Include the library in your project

Before proceeding with the Lite SDK implementation, see the [Quickstart Guide](/docs/sdks/overview/quickstart) for detailed instructions on how to properly integrate the SDK into your project.

The integration guide provides three flexible methods:

1. Direct HTML script inclusion
2. Dynamic JavaScript injection
3. NPM module installation

Choose the integration method that best suits your development workflow and technical requirements. After completing the SDK integration, you can proceed with the following steps to implement the lite enrollment capability.

<Note>
**TypeScript Library**

If you are using TypeScript, Yuno offers a [library](https://www.npmjs.com/package/@yuno-payments/sdk-web-types) that provides access to all available methods in the Yuno Web SDK.
</Note>

## Step 2: Initialize SDK with the public key

Initialize the Yuno SDK in your JavaScript application by providing a valid `PUBLIC_API_KEY`:

```javascript
const yuno = await Yuno.initialize(PUBLIC_API_KEY);
```

<Note>
**Credentials**

See the credentials page for more information: [/reference/getting-started/authentication](/reference/getting-started/authentication)
</Note>

## Step 3: Create a customer session

To start the enrollment process, you need to provide the `customer_session`. First, you need to create a customer. Use the [Create Customer](/reference/customers/create-customer) endpoint to create new customers. In the response, you will receive the customer `id`, which you use to create the customer session.

After creating the customer, you can create the customer session. Use the customer `id` and the [Create Customer Session](/reference/customer-sessions-enrollment/create-customer-session) endpoint. The `customer_session` will be provided in the response. You need a new `customer_session` every time you enroll in a new payment method.

## Step 4: Start the enrollment process

Use the configuration below to provide a lite and user-friendly enrollment experience for your customers:

```javascript
await yuno.mountEnrollmentLite({
  customerSession: "438413b7-4921-41e4-b8f3-28a5a0141638",
  renderMode: {
    type: "element",
    elementSelector: "#root",
  },
  countryCode: "US",
  language: "en",
  showLoading: true,
  issuersFormEnable: true,
  onLoading: (args) => console.log(args),
  card: {
    type: "extends",
    styles: "",
    texts: {},
  },
  texts: {},
  enrollmentStatus(data) {
    console.log("Enrollment status:", data);
  },
  async error(error, data) {
    console.error("An error occurred:", error);
    await yuno.hideLoader();
  },
});
```

When using `mountEnrollmentLite`, specify the callbacks to handle enrollment. You can also customize the interface using the `texts` objects.

### Parameters

Configure the lite enrollment with the following options:

| Parameter              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `customerSession`      | Refers to the current enrollment's [customer session](/reference/customer-sessions-enrollment/create-customer-session).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `elementSelector`      | The HTML element where the enrollment form renders. Pass it inside `renderMode: { type: "element", elementSelector }`; a top-level `elementSelector` is ignored and the form opens as a modal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `countryCode`          | This parameter specifies the country code for which the enrollment is being set up.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `language`             | Language for enrollment forms.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `showLoading`          | Controls the visibility of the Yuno loading/spinner page during the enrollment process.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `onLoading`            | Required to receive notifications about server calls or loading events during the enrollment process.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `issuersFormEnable`    | Enables the issuer's form (for example, a list of banks).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `card`                 | Defines the configuration for the card form.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `texts`                | Allows you to set custom button texts.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `enrollmentStatus` | Callback invoked when the enrollment process finishes. Receives `{ vaultedToken, status }`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `error`            | Callback invoked when there is an error in the enrollment process.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `onChange`                        | Reports whether the enrollment form is complete. Receives `{ form: { isValid } }`. Available since v1.10.11. |

<Note>
**Status Values**

Common status values include `ENROLLED`, `DECLINED`, `CANCELED`, and `ERROR`.
</Note>

## PayPal enrollment with element render mode

<Note>
Available from Web SDK **1.10.13**.
</Note>

By default, `mountEnrollmentLite` opens the Yuno modal for PayPal enrollment. The shopper clicks your PayPal button, sees the modal, and has to click PayPal a second time. With element render mode the PayPal button renders directly on your page, and the shopper completes the enrollment in one click.

### How it works

Add an empty container to your page, then pass `renderMode: { type: 'element', elementSelector }` to `mountEnrollmentLite`. The SDK renders the real PayPal button inside that container and shows a loading skeleton until PayPal finishes loading.

The PayPal button replaces your own button — do not place your button in front of it. If you do not pass `renderMode`, the modal behavior stays exactly as before.

### Integration steps

1. Remove your existing PayPal button.
2. Add an empty `<div>` where the PayPal button should appear.
3. Pass `renderMode` with `type: 'element'` and an `elementSelector` pointing at that `<div>`.

```html
<div id="paypal-enrollment"></div>
```

```javascript
await yuno.mountEnrollmentLite({
  customerSession: "438413b7-4921-41e4-b8f3-28a5a0141638",
  countryCode: "US",
  language: "en",
  renderMode: {
    type: "element",
    elementSelector: "#paypal-enrollment",
  },
  enrollmentStatus(data) {
    console.log("Enrollment status:", data);
  },
  error(error, data) {
    console.error("An error occurred:", error);
  },
});
```

The button takes 100% of the container width unless you set `width`.

### Customizing the PayPal button

Optional. Pass `externalButtons.paypal` to `mountEnrollmentLite` to style the button, using the same properties as the [PayPal express button](/docs/sdks/resources/references/web#paypal) in checkout. The defaults differ from checkout, so they are listed in full below.

```javascript
await yuno.mountEnrollmentLite({
  customerSession: "438413b7-4921-41e4-b8f3-28a5a0141638",
  countryCode: "US",
  language: "en",
  renderMode: {
    type: "element",
    elementSelector: "#paypal-enrollment",
  },
  externalButtons: {
    paypal: {
      color: "blue",
      shape: "pill",
      label: "paypal",
      height: 48,
      width: 300,
      locale: "en_US",
    },
  },
  // ... rest of config
});
```

<div className="nowrap-col1-table dense-table">

| Property | Type | Default | Description |
| -------- | ---- | ------- | ----------- |
| `color` | `'gold'` \| `'blue'` \| `'silver'` \| `'white'` \| `'black'` | PayPal decides | Button background color |
| `shape` | `'rect'` \| `'pill'` \| `'sharp'` | `'rect'` | Button shape |
| `label` | `'paypal'` \| `'checkout'` \| `'buynow'` \| `'pay'` \| `'installment'` | PayPal decides | Button label text |
| `height` | `number` | `48` | Button height in px (valid range: 25–55) |
| `width` | `number` | 100% of the container | Wrapper width in px |
| `locale` | `string` | PayPal decides from the shopper's browser | Button language, in PayPal's `language_COUNTRY` format (for example `en_US`, `es_ES`, `pt_BR`). See PayPal's [supported locales](https://developer.paypal.com/sdk/js/configuration/#locale). |

</div>

### Result

- The shopper clicks the PayPal button, approves in the PayPal popup, and the SDK completes the enrollment.
- `enrollmentStatus` receives the `vaultedToken` with status `ENROLLED`.
- If the shopper closes the popup, `error` receives `CANCELED_BY_USER`.

## KCP KakaoPay and PAYCO enrollment (Web)

<Note>
KakaoPay is available from Web SDK **1.11.27**. PAYCO desktop enrollment is supported from Web SDK **1.11.43**.
</Note>

Yuno Lite Web SDK supports KakaoPay (`KAKAO_PAY`) and PAYCO (`KCP_PAYCO`) enrollment via KCP on desktop browsers, as well as automatic HTTP POST form redirects for enrollment providers requiring form-based handoffs.

### Desktop enrollment flow

On desktop browsers, KakaoPay and PAYCO enrollments render an action button inside the lite enrollment component.

#### How it works

1. **Script loading:** When the enrollment component mounts, the SDK verifies and loads KCP's script bundle from `script_url` (`https://*.kcp.co.kr`).
2. **User action:** The shopper clicks the action button. The SDK sets up the KCP callback handler (`window.m_Completepayment`) and opens the KCP authorization window (`KCP_Pay_Execute_Web`).
3. **Completion & submission:** Once the shopper completes or closes the provider flow, KCP populates the result fields (`res_cd`, `res_msg`, `enc_data`, `enc_info`, `tran_cd`) and forwards them via POST to the backend `result_url` (`https://*.y.uno` or your white-label API host).

#### Button states and error recovery

- **Button disabled:** If required backend enrollment configuration (`script_url`, `form_fields`, or `result_url`) is missing or targets an unauthorized host, the button is disabled and displays an inline error message.
- **Script load retry:** If KCP scripts fail to load initially, clicking the button re-attempts loading the SDK before initiating payment execution.
- **Dismissed popup recovery:** If the shopper closes the KCP popup without approving, the SDK detects layer removal via DOM mutation observers and re-enables the button for another attempt.
- **Timeout recovery:** If the browser remains on the page 10 seconds after posting the enrollment result (typically caused by missing CSP form-action policies blocking form submission), the SDK clears the processing state, triggers an error callback, and allows the shopper to retry.

### KCP mobile POST redirect

When enrolling via KCP on mobile browsers or providers requiring form submissions, the backend returns a `require_action.redirect` payload with `method: "POST"` and `init_url` targeting a KCP host (`*.kcp.co.kr`).

The Lite Web SDK automatically detects the POST redirect configuration, builds a hidden form populated with `form_fields`, appends it to the DOM, and submits the form to navigate the user directly to the provider.

### Content Security Policy (CSP) requirements

If your website enforces a strict Content Security Policy (CSP), configure the following directives to allow the KCP scripts, iframe overlays, and form submissions:

<div className="nowrap-col1-table dense-table">

| Directive | Allowed sources | Description |
| --------- | --------------- | ----------- |
| `script-src` | `https://*.kcp.co.kr` | Allows loading KCP SDK hub and helper scripts (`kcp_spay_hub.js`, `kcp_jquery`, etc.). |
| `frame-src` | `https://*.kcp.co.kr` | Allows rendering the KCP overlay modal and payment iframe. |
| `form-action` | `https://*.kcp.co.kr https://*.y.uno` | Allows hidden form POST navigation to KCP and posting the enrollment result to Yuno (or your white-label API domain). |

</div>

<Warning>
Missing `form-action` directives for `*.y.uno` or `*.kcp.co.kr` will cause browser-level form submission blocks without JavaScript errors, resulting in the enrollment timing out.
</Warning>

## Step 5: Initiate the enrollment (Required)

After mounting the SDK using `await yuno.mountEnrollmentLite()`, the form will be displayed in the specified element. The user can then proceed with entering their payment method details to complete the enrollment.
