Yuno Flows is an interactive sandbox that runs a Yuno payment flow step by step. For each step, it shows the request your server sends, the response Yuno returns, and the code behind the call.

[Open Yuno Flows](https://yuno-flows.vercel.app/)

<Note>
  Yuno Flows runs against the Yuno sandbox with test cards. No real money moves, and you don't enter any API keys.
</Note>

## What you can do

- **Pick an integration type.** Choose how the checkout is built, for example Full SDK or API only. To compare the types first, see [Choose integration](/docs/sdks/overview/choose-integration).
- **Pick a scenario.** Each scenario covers one use case, for example a one-time card payment or a payment with a local method.
- **Follow the steps.** Move through the flow with the arrow keys or the Next button. Each step explains what happens and shows the matching request, response, and code.
- **Run it yourself.** In steps that involve the shopper, you enter a test card in the demo store and pay.

If a live call fails, the step shows a recorded run of the same call, marked **Recorded**.

## Example: one-time card payment with the Full SDK

The first flow follows the same sequence described in [Payment flow](/docs/how-yuno-works/how-yuno-payment-flow-works). It has six steps:

1. Create the customer: `POST /v1/customers`.
2. Open a checkout session: `POST /v1/checkout/sessions`.
3. Mount the Yuno checkout in the browser.
4. The shopper enters a card and pays. The SDK returns a one-time token.
5. Create the payment: `POST /v1/payments`.
6. Confirm the result: `GET /v1/payments/{id}`.
