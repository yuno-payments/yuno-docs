Yuno Flows is an interactive sandbox that runs a payment flow step by step against the Yuno sandbox. Use it to see how the requests, responses, and SDK calls described in these docs fit together before you write any code.

[Open Yuno Flows](https://yuno-flows.vercel.app/)

<Note>
  Yuno Flows runs against the Yuno sandbox with test cards. No real money moves, and you don't enter any API keys.
</Note>

## When to use it

- You are new to Yuno and want to see a complete payment before you integrate.
- You want to check what the request and response look like for a specific feature.
- You want to compare the SDK flow with the Direct API flow.

## How it works

1. Choose **Yuno SDK** or **Direct API**.
2. Choose a flow, for example a one-time payment.
3. Move through the steps with **Back** and **Next**, or with the arrow keys. Each step explains what happens.
4. In the panel, switch between **Request**, **Response**, and **Code** to see what the merchant sends, what Yuno returns, and the code behind the call.
5. In steps where the shopper pays, enter a test card in the demo store. The tool shows which card to use.

If a live call fails, the step shows a recorded run of the same call, marked **Recorded**.

## Yuno SDK or Direct API

- **Yuno SDK:** the SDK collects the payment details and reports the result to your app. In some flows the SDK creates the payment, in others your backend does.
- **Direct API:** your server sends the requests to Yuno directly. Your company handles card data, so PCI DSS compliance applies.
