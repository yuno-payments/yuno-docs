Yuno Flows is an interactive sandbox that runs a payment flow step by step. Use it to see a complete payment before you integrate, to check the request and response of a feature, or to compare the SDK flow with the Direct API flow.

<Card title="Open Yuno Flows" icon="play" href="https://yuno-flows.vercel.app/" horizontal arrow>
  Run a payment step by step in the Yuno sandbox.
</Card>

<Note>
  Yuno Flows runs against the Yuno sandbox with test cards. No real money moves, and you don't enter any API keys.
</Note>

## How it works

<Steps>
  <Step title="Choose a path">
    Select **Yuno SDK** or **Direct API**.
  </Step>
  <Step title="Choose a flow">
    For example, a one-time payment.
  </Step>
  <Step title="Move through the steps">
    Use **Back** and **Next**, or the arrow keys. Each step explains what happens.
  </Step>
  <Step title="Read the panel">
    Switch between **Request**, **Response**, and **Code** to see what the merchant sends, what Yuno returns, and the code behind the call.
  </Step>
  <Step title="Pay with a test card">
    In steps where the shopper pays, enter a test card in the demo store. The tool shows which card to use.
  </Step>
</Steps>

If a live call fails, the step shows a recorded run of the same call, marked **Recorded**.

## Yuno SDK or Direct API

<CardGroup cols={2}>
  <Card title="Yuno SDK" icon="code" href="/docs/yuno-sdk/how-a-transaction-flows">
    The SDK collects the payment details and reports the result to your app. In some flows the SDK creates the payment, in others your backend does.
  </Card>
  <Card title="Direct API" icon="server" href="/docs/direct-integration-use-cases/direct-flow">
    Your server sends the requests to Yuno directly. Your company handles card data, so PCI DSS compliance applies.
  </Card>
</CardGroup>
