## Step 1: Include the library in your project

### CocoaPods

Add the following line to your Podfile:

```ruby
pod 'YunoSDK', '~> 2.27.0'
```

### Swift Package Manager

Add `YunoSDK` as a dependency:

```swift
.package(url: "https://github.com/yuno-payments/yuno-sdk-ios.git", .upToNextMajor(from: "2.27.0"))
```

## Step 2: Initialize SDK

Initialize the SDK with your Public API Key:

```swift
import YunoSDK

Yuno.initialize(
    apiKey: "PUBLIC_API_KEY",
    config: YunoConfig(),
    callback: { print("Yuno SDK initialized") }
)
```

## Step 3: Adopt YunoPaymentDelegate

Adopt the `YunoPaymentDelegate` protocol:

<Info>
**Swift 6 Concurrency Requirements**

If you're using Swift 6, you'll need to implement the `YunoPaymentDelegate` protocol with specific concurrency considerations. See the [Swift 6 Concurrency](/docs/sdks/resources/swift-6-concurrency) guide for detailed implementation options and best practices.
</Info>

```swift
class ViewController: UIViewController, @preconcurrency YunoPaymentDelegate {
    var checkoutSession: String { "checkout_session" }
    var countryCode: String { "US" }
    var viewController: UIViewController? { self }

    func yunoCreatePayment(with token: String) {
        // Call your backend to create a payment
    }

    func yunoCreatePayment(with token: String, information: [String: Any]) {
        // Call your backend to create a payment using the additional token information
    }

    func yunoPaymentResult(_ result: Yuno.Result) {
        // Handle final payment state
    }
}
```

| Method | Description |
| :--- | :--- |
| `yunoCreatePayment(with:)` | Called when a one-time token is generated. Create the payment on your backend. |
| `yunoCreatePayment(with:information:)` | Alternative callback that also includes additional information about the one-time token, such as card data (DPAN BIN, brand, last four digits). See [OTT additional information](/docs/sdks/full-checkout/ios-payments#ott-additional-information) for the available keys. |
| `yunoPaymentResult(_:)` | Called when the payment process completes. Receives a `Yuno.Result` value. |

<Danger>
**Important Note**

Implement either `yunoCreatePayment(with:)` **or** `yunoCreatePayment(with:information:)`, not both. The SDK calls every version you implement, so implementing both creates the payment twice.
</Danger>

## Step 4: Initiate the payment process

```swift
Yuno.startPaymentLite(
    with: self,
    paymentSelected: paymentSelected,
    showPaymentStatus: true
)
```

## Step 5: Continue payment (Required)

If `sdk_action_required: true` is returned by the API, call:

```swift
Yuno.continuePayment()
```
