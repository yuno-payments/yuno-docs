<Info>Most integrations start with **SDK checkout** — pre-built UI, no PCI scope, fastest to production.</Info>

| Path | PCI | UI | Best for |
|------|-----|-----|----------|
| [SDK checkout](/docs/sdks/overview/quickstart) | None | Yuno-hosted | Fast integration |
| [Direct API](/docs/direct-integration-use-cases/direct-flow) | Required | Full | Custom UI |
| [Payment Links](/docs/using-yuno/dashboard-overview/payment-links) | None | Dashboard | No-code |
| [Plugins](/docs/plugins/vtex/index) | None | Platform | VTEX, WooCommerce |

**SDK checkout** — Web, iOS, Android. Yuno handles UI, card capture, 3DS. Two endpoints: session + payment. → [Quickstart](/docs/sdks/overview/quickstart)

**Direct API** — Your own form, your PCI scope. Server-to-server. → [Guide](/docs/direct-integration-use-cases/direct-flow)

**Payment Links** — Dashboard-generated URLs, no code. → [Payment Links](/docs/using-yuno/dashboard-overview/payment-links)

**Plugins** — [VTEX](/docs/plugins/vtex/index) · [WooCommerce](/docs/plugins/woocommerce/index)
