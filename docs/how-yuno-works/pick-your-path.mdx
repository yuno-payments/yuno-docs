<Info>
**Which path?** Most integrations start with **SDK checkout** — pre-built UI, no PCI scope, fastest to production.
</Info>

## Comparison

| Path | PCI scope | UI control | Best for |
|------|-----------|------------|----------|
| **[SDK checkout](/docs/sdks/overview/quickstart)** | None | Yuno-hosted | Fast integration, pre-built forms |
| **[Direct API](/docs/direct-integration-use-cases/direct-flow)** | Required | Full | Custom UI, server-to-server |
| **[Payment Links](/docs/using-yuno/dashboard-overview/payment-links)** | None | Dashboard | No-code, share links |
| **[Plugins](/docs/plugins/vtex/index)** | None | Platform | VTEX, WooCommerce |

---

## SDK checkout

Use our Web, iOS, or Android SDKs. Yuno handles checkout UI, card capture, and 3DS. You call two endpoints: create session, create payment.

→ [SDK Quickstart](/docs/sdks/overview/quickstart)

## Direct API

Build your own payment form. Call the API directly with card data. Requires PCI compliance.

→ [Direct flow guide](/docs/direct-integration-use-cases/direct-flow)

## Payment Links

Create links in the Dashboard and share with customers. No integration required.

→ [Payment Links](/docs/using-yuno/dashboard-overview/payment-links)

## Plugins

Pre-built integrations for e-commerce platforms.

→ [VTEX](/docs/plugins/vtex/index) · [WooCommerce](/docs/plugins/woocommerce/index)
