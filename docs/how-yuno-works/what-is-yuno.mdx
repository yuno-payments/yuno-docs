<section className="yd-section" id="flow">
  <div className="yd-eyebrow-sm">03 / How a payment works</div>
  <h2 className="yd-h2">Four steps from cart to confirmation.</h2>
  <p className="yd-sub">The same sequence applies to every payment method and provider.</p>
  <ol className="yd-flow-steps">
    <li className="yd-flow-step">
      <span className="yd-flow-num">1</span>
      <span className="yd-flow-title">Create a customer</span>
      <code>POST /v1/customers</code>
      <span className="yd-flow-body">Optional. Stores the payer so you can reuse their details and saved cards.</span>
    </li>
    <li className="yd-flow-step">
      <span className="yd-flow-num">2</span>
      <span className="yd-flow-title">Create a checkout session</span>
      <code>POST /v1/checkout/sessions</code>
      <span className="yd-flow-body">Holds the amount and country. The SDK uses it to list the payment methods your account has enabled. The Direct API skips this step.</span>
    </li>
    <li className="yd-flow-step">
      <span className="yd-flow-num">3</span>
      <span className="yd-flow-title">Collect payment details</span>
      <code>SDK</code>
      <span className="yd-flow-body">The SDK returns a one-time token (OTT). With the Direct API, your server sends the card data and needs PCI DSS.</span>
    </li>
    <li className="yd-flow-step">
      <span className="yd-flow-num">4</span>
      <span className="yd-flow-title">Create the payment</span>
      <code>POST /v1/payments</code>
      <span className="yd-flow-body">Send the OTT with an <code>X-Idempotency-Key</code> header. Yuno routes the payment and reports each status change by webhook.</span>
    </li>
  </ol>
  <p className="yd-foot">Field-level detail for each step: <a href="/docs/how-yuno-works/how-yuno-payment-flow-works">Payment flow</a>.</p>
</section>
