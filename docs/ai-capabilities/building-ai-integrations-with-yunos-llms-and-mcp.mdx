Yuno publishes its documentation in formats that large language models (LLMs) and coding agents read directly. Point your agent at these files so it answers questions and writes integrations from the current docs instead of guessing from training data.

<Note>
  Want an AI assistant to work with your Yuno account (analyze payments data, search the docs, run payment operations)? See [Use Yuno with AI assistants](/docs/ai-capabilities/use-yuno-with-claude-and-chatgpt).
</Note>

## Files for agents

| File | What it contains |
| --- | --- |
| [llms.txt](https://docs.y.uno/llms.txt) | An index of every docs page, with a short description of each. Start here. |
| [llms-full.txt](https://docs.y.uno/llms-full.txt) | The full docs in one plain-text file. |
| [AGENTS.md](https://docs.y.uno/AGENTS.md) | Instructions for coding agents integrating Yuno: install, configure, first payment, and resources. |
| [skill.md](https://docs.y.uno/skill.md) | A skill file agents can load to work with the Yuno API. |
| [sitemap.md](https://docs.y.uno/sitemap.md) | The list of docs pages in Markdown. |
| [openapi.json](https://docs.y.uno/openapi.json) | The OpenAPI specification of the Yuno API, for code generation and request validation. |

## Any page in Markdown

Add `.md` to the end of any Yuno docs URL to get that page in plain Markdown. This works for both guides and API reference pages. For example, [docs.y.uno/docs/quickstart.md](https://docs.y.uno/docs/quickstart.md).

Every page also has a **Copy page** button that copies its Markdown, ready to paste into your agent's context.
