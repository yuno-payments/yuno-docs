---
title: "Cancel Onboarding"
openapi: "/openapi/recipients-for-marketplace/cancel-recipient.json POST /recipients/{recipient_id}/onboardings/{onboarding_id}/cancel"
description: "Cancel a recipient's onboarding before it completes with a provider"
---

Cancels an onboarding of a recipient. The recipient itself is not cancelled.

An onboarding in status `SUCCEEDED`, `BLOCKED`, `CANCELLED`, `INACTIVE`, `TRANSFERRED` or `TERMINATED` cannot be cancelled, and the API returns `400 INVALID_STATE`. A cancelled onboarding is final. To onboard the recipient with the provider again, create a new onboarding.
