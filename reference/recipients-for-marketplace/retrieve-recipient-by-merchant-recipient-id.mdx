---
title: "Retrieve Recipient by Merchant Recipient ID"
openapi: "/openapi/recipients-for-marketplace/retrieve-recipient-by-merchant-recipient-id.json GET /recipients"
description: "Retrieves a single recipient using the merchant_recipient_id your system assigned when the recipient was created."
---

This request enables you to retrieve a recipient based on its `merchant_recipient_id`, which needs to be provided as a query parameter. The response is a single [recipient object](/reference/recipients-for-marketplace/the-recipient-object), the same one returned by [Get Recipient](/reference/recipients-for-marketplace/get-recipient).

- `merchant_recipient_id` is required. A request without it returns `400` with `INVALID_PARAMETERS`.
- The lookup covers every account in your organization.
- If no recipient in your organization has that `merchant_recipient_id`, or the recipient was deleted, the request returns `400` with `RECIPIENT_NOT_FOUND`.

<Info>
  This endpoint does not list recipients and does not accept pagination or filter parameters such as `limit`, `offset`, `country`, or `national_entity`. To browse or export recipients, use the Yuno Dashboard.
</Info>
