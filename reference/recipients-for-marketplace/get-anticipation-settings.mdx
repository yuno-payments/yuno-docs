<Warning>
Preview. Contact Yuno to confirm release availability for your account. GET remains available when anticipation write admission is disabled and does not require provider-connection enablement.
</Warning>

Read [Anticipation settings](/reference/recipients-for-marketplace/anticipation-settings) for target selection, partial updates and uncertain-result handling.

GET reads Yuno's stored state and does not query the provider. It is available while write admission is disabled. No stored settings returns exactly `recipient_id`, `onboarding_id` and `enabled: false`; existing resources retain their revision and operational metadata.
