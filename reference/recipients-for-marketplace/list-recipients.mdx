---
title: "List Recipients"
openapi: "/openapi/recipients-for-marketplace/list-recipients.json GET /recipients"
description: "Retrieve a list of recipients registered in the marketplace"
---

Retrieves a list of recipients for the authenticated account. Supports pagination and filtering.

- Results are scoped to the authenticated account within your organization.
- Items are ordered by creation date, newest first.
- Each item carries the recipient's own fields. Nested collections such as `withdrawal_methods`, `documentation` and `legal_representatives` are not included — retrieve a single recipient with [Get Recipient](/reference/recipients-for-marketplace/get-recipient) to read those.
- `limit` defaults to `20` and accepts `1` to `100`. `offset` accepts any value from `0` and does not need to be a multiple of `limit`.

<Warning>
  This endpoint is eventually consistent. It reads from a replica, so a recipient you just created with [Create Recipient](/reference/recipients-for-marketplace/create-recipient-1) may not appear in the list yet. To read a recipient immediately after creating it, use [Retrieve Recipient by Merchant Recipient ID](/reference/recipients-for-marketplace/retrieve-recipient-by-merchant-recipient-id) or [Get Recipient](/reference/recipients-for-marketplace/get-recipient), which both read the primary store.
</Warning>

<Note>
  `merchant_recipient_id` remains an optional query parameter on this path, and it changes the response. Omit it and you get this paginated list. Send it and the request is served by [Retrieve Recipient by Merchant Recipient ID](/reference/recipients-for-marketplace/retrieve-recipient-by-merchant-recipient-id), which returns a single recipient object instead of a paginated envelope.
</Note>
