---
title: "Get Recipient by Merchant ID"
openapi: "/openapi/recipients-for-marketplace/get-recipient-by-merchant-id.json GET /recipients"
description: "Retrieve a single recipient using the identifier assigned by your organization."
---

Use `GET /v1/recipients?merchant_recipient_id=...` to look up a recipient by your merchant recipient ID. The lookup is scoped to your organization and does not require `account_id`.

A successful request returns a top-level recipient object. If no recipient matches, the endpoint returns HTTP `400` with code `RECIPIENT_NOT_FOUND`. The `merchant_recipient_id` query parameter is required.

This endpoint keeps its existing behavior. Existing integrations that use it to look up a recipient do not need to change.

For a paginated collection, use [List Recipients](/reference/recipients-for-marketplace/list-recipients) at `GET /v1/recipients/list`. That endpoint returns a `data` array and `pagination`, including an empty array when no recipients match. Integrations or cron jobs that need a list should use `/list`.

To look up a recipient by its Yuno ID, use [Get Recipient](/reference/recipients-for-marketplace/get-recipient).
