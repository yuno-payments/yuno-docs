---
title: "Attach Promotion to Plan"
openapi: "/openapi/plans/attach-plan-promotion.json POST /subscriptions/plans/{plan_id}/promotions"
description: "Attaches an existing promotion to a subscription plan for a number of charges, so the plan's subscriptions can receive it"
---

Attaches an existing promotion to a plan. Subscriptions on the plan can then receive the promotion when they are [created](/reference/subscriptions/create-subscription) or [updated](/reference/subscriptions/update-subscription). The attachment sets how many charges the discount covers (`cycles`) and what a pause does to it (`on_pause`). See [Promotions on subscription plans](/docs/payment-features/subscriptions/promotions).

<Note>
**Attachments are not edited**

To change `cycles` or `on_pause`, remove the attachment with [Remove Promotion from Plan](/reference/plans/remove-plan-promotion) and attach the promotion again. Removing an attachment does not change the subscriptions that already have the promotion.
</Note>

## Errors

| HTTP | `code` | When |
| :--- | :----- | :--- |
| `404` | `PROMOTION_NOT_FOUND` | The `promotion_id` is unknown, or belongs to another account. |
| `409` | `PROMOTION_ALREADY_ATTACHED` | The plan already has this promotion. |
| `422` | `PROMOTION_NOT_APPLICABLE` | The promotion cannot be attached. The `reason` says why, for example `EXPIRED`, or `PROMOTIONS_NOT_ENABLED` when promotions are not turned on for your organization. |
| `503` | `PROMOTION_ENGINE_UNAVAILABLE` | The promotions engine did not respond. |
| `504` | `PROMOTION_ENGINE_TIMEOUT` | The promotions engine did not respond in time. |

See [Subscription promotion error codes](/reference/subscriptions/subscription-promotion-error-codes) for every reason.
