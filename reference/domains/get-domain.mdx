---
title: "Get Domain"
openapi: "/openapi/domains/get-domain.json GET /v1/payment-methods/{payment_method}/domains/{domain_id}"
description: "Retrieve a registered wallet domain by its id and read its registration status"
---

Returns one domain registration. Pass the `id` that [Register domain](/reference/domains/register-domain) returned for that domain as `domain_id`, and the payment method it was registered for as `payment_method`

Registration is synchronous, so this status matches the one the Register domain response already returned, and no polling is required. Use this endpoint to read a domain's status again later, for example after you fix an association file and register the domain a second time

A domain stays in `CREATED` when the call to the wallet provider does not complete. That status does not advance on its own, so reading the domain again will not change it: contact Yuno support to have the row cleared, then register the domain again
