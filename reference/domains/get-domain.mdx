---
title: "Get Domain"
openapi: "/openapi/domains/get-domain.json GET /v1/payment-methods/{payment_method}/domains/{domain_id}"
description: "Retrieve a registered wallet domain by its id and read its registration status"
---

Returns one domain registration. Pass the `id` that [Register domain](/reference/domains/register-domain) returned for that domain as `domain_id`, and the payment method it was registered for as `payment_method`

Registration is synchronous, so this status matches the one the Register domain response already returned. Use this endpoint to read a domain's status again, for example after you fix an association file and register the domain a second time
