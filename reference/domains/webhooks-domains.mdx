<Warning>
  **These events are not emitted.** No Yuno service publishes `payment_method_domain.*` events today, so you cannot subscribe to them and nothing reaches your endpoint. This page describes a planned feature, and the event names and payload can change before it ships
</Warning>

## Read the status from the API instead

Domain registration is synchronous. The [Register domain](/reference/domains/register-domain) response carries the final status of every domain in the request, so you do not need a callback to learn the result

| Status       | Meaning                                                                                 |
| ------------ | --------------------------------------------------------------------------------------- |
| `CREATED`    | The request reached the wallet provider and no final result was stored yet               |
| `REGISTERED` | The domain is verified and can display the wallet button                                 |
| `ERROR`      | The provider rejected the registration, for example the association file was unreachable |
| `INACTIVE`   | The domain was unregistered                                                              |

Call [Get domain](/reference/domains/get-domain) whenever you need to read a domain's status again, for example after you fix an association file and register the domain a second time

## Planned events

Yuno plans to publish the following events. None of them is available yet, and no delivery date is committed

| Event                                       | Description                                                 |
| ------------------------------------------- | ----------------------------------------------------------- |
| `payment_method_domain.registered`          | Domain + payment method combination successfully registered |
| `payment_method_domain.verified`            | Domain + payment method verification successful             |
| `payment_method_domain.verification_failed` | Domain + payment method verification failed                 |
| `payment_method_domain.deleted`             | Domain + payment method combination deleted                 |

## Configuration and delivery

When these events ship, they will follow the same rules as every other Yuno webhook: you register the endpoint in the Dashboard under **Developers › Webhooks**, HMAC signatures arrive in the `x-hmac-signature` header, and a failed delivery is retried up to seven times over 96 hours. Read [Configure webhooks](/docs/webhooks/configure-webhooks) and [Verify webhook signatures (HMAC)](/docs/webhooks/verify-webhook-signatures-hmac) for the behaviour that applies today
