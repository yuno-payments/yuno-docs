## Report status

The reports can have the following status. A report stays available for download for 7 days after it reaches `SUCCEEDED`; downloading it does not remove it.

| Status       | Description                                                                                                                                                   |
| :----------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `IN_PROCESS` | The report is being generated.                                                                                                                                |
| `SUCCEEDED`  | The report creation request has been executed successfully.                                                                                                   |
| `DOWNLOADED` | The merchant has downloaded the report.                                                                                                                       |
| `EXPIRED`    | The report file is no longer available for download. Download links are valid for 7 days after the report is generated; after that, create the report again.           |
| `FAILED`     | The report generation failed.                                                                                                                                 |
| `ERROR`      | An error occurred in the process.                                                                                                                             |
