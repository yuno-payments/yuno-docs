---
title: "Subscription Promotion Error Codes"
description: "Error codes and reasons for promotions on subscription plans: attaching, applying, removing and plan changes"
---

Errors for promotions on subscription plans use the standard error format: a `code` and a `messages` array. Errors about the subscription's status also include `current_status`. Errors with HTTP status `422` include a `reason`.

```json 422 Not Applicable
{
  "code": "PROMOTION_NOT_APPLICABLE",
  "messages": [
    "The promotion cannot be applied to this subscription."
  ],
  "reason": "CONDITIONS_NOT_MET"
}
```

## Error codes

<div className="code-nowrap-table dense-table">

| HTTP | `code` | When |
| :--- | :----- | :--- |
| `404` | `PROMOTION_NOT_FOUND` | The promotion ID or code is unknown, or belongs to another account. |
| `409` | `PROMOTION_ALREADY_ATTACHED` | The plan already has this promotion. |
| `422` | `PROMOTION_NOT_ATTACHED_TO_PLAN` | The promotion is applied to a subscription whose plan does not have it. |
| `422` | `PROMOTION_NOT_APPLICABLE` | The promotion cannot be attached or applied. The `reason` says why (see below). |
| `409` | `SUBSCRIPTION_STATUS_NOT_ELIGIBLE` | The subscription is not `ACTIVE` or `TRIALING`. The response includes `current_status`. |
| `409` | `SUBSCRIPTION_PROMOTION_NOT_ACTIVE` | The request removes a promotion, but the subscription has no active promotion. The response includes `current_status`. |
| `503` | `PROMOTION_ENGINE_UNAVAILABLE` | The promotions engine did not respond when the promotion was attached or applied. |
| `504` | `PROMOTION_ENGINE_TIMEOUT` | The promotions engine did not respond in time when the promotion was attached or applied. |

</div>

## Reasons for `PROMOTION_NOT_APPLICABLE`

<div className="code-nowrap-table dense-table">

| `reason` | Meaning |
| :------- | :------ |
| `EXPIRED` | The promotion has expired. |
| `DISABLED` | The promotion is disabled. |
| `NOT_STARTED` | The promotion's start date has not arrived yet. |
| `USAGE_LIMIT_REACHED` | The promotion has no uses left. |
| `CONDITIONS_NOT_MET` | The subscription does not meet the promotion's conditions: country, currency and amount, payment method type, BIN, or the type of the stored card. Conditions are checked only when the promotion is applied, not on renewals. |
| `CURRENCY_MISMATCH` | A fixed-amount promotion has no amount in the subscription's currency. |
| `PROMOTIONS_NOT_ENABLED` | Promotions are not turned on for your organization, or the region does not support them. Subscription promotions run in the US region only. |
| `EXECUTION_TYPE_NOT_SUPPORTED` | Yuno does not charge this subscription: the merchant or the provider charges it. |
| `SUBSCRIPTION_NOT_ON_A_PLAN` | The subscription is not on a plan. Promotions apply only to subscriptions on a plan. |

</div>
