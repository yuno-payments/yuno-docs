---
title: "List Subscriptions"
openapi: "/openapi/subscriptions/list-subscriptions.json GET /subscriptions"
description: "Lists the account's subscriptions with combinable filters and page-based pagination."
---

<Note>
**Pagination is `page`/`size` on this endpoint**

Unlike [List Plans](/reference/plans/list-plans) and [List Subscription Payments](/reference/subscriptions/list-subscription-payments) (which use `limit`/`offset`), this endpoint paginates with `page` (starting at 1) and `size` (1-100, default 20), and responds with `items[]` plus `pagination { page, size, total, total_pages }`.
</Note>

<Note>
**Items are summaries**

Each item is a subset of [the subscription object](/reference/subscriptions/the-subscription-object) — enough to render a list. Fields like `description`, `availability`, `retries`, `metadata`, or `billing_phases` are only on the single-object [Retrieve Subscription](/reference/subscriptions/retrieve-subscription).
</Note>

<Warning>
**`merchant_reference` is not a filter here**

The `merchant_reference` query parameter is ignored on this endpoint. To look up a single subscription by merchant reference, use [Retrieve Subscription](/reference/subscriptions/retrieve-subscription).
</Warning>
