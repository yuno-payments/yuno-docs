---
title: "List Subscriptions"
openapi: "/openapi/subscriptions/list-subscriptions.json GET /subscriptions"
description: "Lists the account's subscriptions with combinable filters and page-based pagination."
---

<Note>
**Pagination is `page`/`size` on this endpoint**

Unlike [List Subscription Payments](/reference/subscriptions/list-subscription-payments) (which uses `limit`/`offset`), this endpoint paginates with `page` (starting at 1) and `size` (1-100, default 20), and responds with `items[]` plus `pagination { page, size, total, total_pages }`.
</Note>

<Note>
**Items are summaries**

Each item is a subset of [the subscription object](/reference/subscriptions/the-subscription-object) — enough to render a list. Fields like `description`, `availability`, `retries`, `metadata`, `billing_phases`, `pending_plan_change`, and the `current_period_start`/`current_period_end` pair are only on the single-object [Retrieve Subscription](/reference/subscriptions/retrieve-subscription).
</Note>

<Note>
**Nullable item fields**

`frequency` is `null` on subscriptions billed by `billing_date`, `plan_id` is `null` when the subscription is not on a plan, `billing_cycles.total` is `null` on open-ended subscriptions, and `billing_cycles.next_at` is `null` once the subscription is `CANCELED` or `COMPLETED`. On list items these keys are always present carrying `null` — unlike [Retrieve Subscription](/reference/subscriptions/retrieve-subscription), which omits `plan_id` when it is not set. The exception is `frequency.monthly_billing_day`: it is present only when the subscription pins a billing day, and is omitted rather than nulled.
</Note>

<Warning>
**`merchant_reference` is not a filter here**

The `merchant_reference` query parameter is ignored on this endpoint — passing it returns the unfiltered list, not a single subscription. There is no public endpoint that resolves a subscription by `merchant_reference`: store the `id` returned by [Create Subscription](/reference/subscriptions/create-subscription) and use it with [Retrieve Subscription](/reference/subscriptions/retrieve-subscription).
</Warning>
