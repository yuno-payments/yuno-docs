description: "Submit additional documentation for an existing entity onboarding"
---

Submit additional documents for an existing onboarding. Typically used when the onboarding is in `PENDING_ADDITIONAL_DOCUMENTATION` status. Only onboardings that have not reached a terminal status can be updated; otherwise the API returns 400 `INVALID_STATE_TRANSITION`.
