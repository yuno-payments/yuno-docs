---
title: "Delete a Connection"
description: "Deletes a connection. It must not be referenced by an active routing rule."
openapi: "/openapi/organizations/connections/delete-connection.json DELETE /connections/{connection_id}"
---

Deletes a connection you previously created. Returns `204 No Content` on success.

<Warning>
Known issue: after the `204`, the connection still reads `ACTIVE` when you retrieve it. The call does not change the status that retrieve returns.
</Warning>

<Warning>
A connection that is still referenced by an active routing rule cannot be deleted — the request fails with `409 CONNECTION_IN_USE`. Detach it from your routes first, then retry. For an organization connection, `details.accounts` lists the accounts whose routes still reference it.
</Warning>

### Path Parameters

<ParamField path="connection_id" type="string" required>
  The id returned by [Create a Connection](/reference/organizations/connections/create-connection). Must belong to the account your API key is scoped to, or be an organization connection of your organization.
</ParamField>

### Headers

<ParamField header="X-Account-Code" type="string">
  UUID of the account the connection belongs to. Required for an account connection. Omit it for an organization connection, which belongs to no account.
</ParamField>

### Response

Returns `204 No Content` with an empty body.

<CodeGroup>
```bash cURL
curl -X DELETE 'https://api.y.uno/v1/connections/f1a3c4d5-7b8e-4a2c-9d1e-3f4a5b6c7d8e' \
  -H 'public-api-key: <YOUR_PUBLIC_KEY>' \
  -H 'private-secret-key: <YOUR_SECRET_KEY>' \
  -H 'X-Account-Code: a1b2c3d4-e5f6-7890-abcd-ef1234567890'
```

```json 409 — In Use
{
  "type": "conflict",
  "code": "CONNECTION_IN_USE",

}
```

</CodeGroup>

### Errors

<div className="code-nowrap-table dense-table">

| HTTP | `code` |
| --- | --- |
| `400` | `ORGANIZATION_SCOPE_NOT_SUPPORTED`<br />The connection is an organization connection and the request was sent with `X-Account-Code`. Send it without the header. |
| `401` | `NOT_AUTHENTICATED`<br />Missing or invalid API key. |
| `404` | `CONNECTION_NOT_FOUND`<br />Unknown `connection_id`, or the id is neither a connection of your account nor an organization connection of your organization. |
| `409` | `CONNECTION_IN_USE`<br />The connection is still referenced by an active routing rule. For an organization connection, `details.accounts` lists the accounts whose routes reference it. |
| `503` | `ORGANIZATION_ACCOUNTS_UNAVAILABLE`<br />The connection is an organization connection and its accounts could not be listed. Nothing changes; retry the request. |

</div>
