---
title: "Create a Connection"
description: "Creates a connection in ACTIVE status from credentials and configuration you fill in based on the provider's catalog."
openapi: "/openapi/organizations/connections/create-connection.json POST /connections"
---

Creates a connection in `ACTIVE` status from credentials and configuration you fill in based on the provider's catalog. The response includes the `connection_id` you'll use to reference this connection from routing rules.

### Headers

<ParamField header="X-account-code" type="string">
  Code of the account under which the connection is created. The account comes from this header, not from the request body. Required for an account connection (`scope: "ACCOUNT"`). Omit it for an organization connection (`scope: "ORGANIZATION"`): that connection belongs to the organization, not to an account.
</ParamField>

<ParamField header="X-Idempotency-Key" type="string" required>
  UUID, 24-hour scope. Re-sending the same key + body returns the cached response; same key with a different body returns a `409`.
</ParamField>

### Body

<ParamField body="scope" type="enum">
  Optional. Who the connection belongs to. Defaults to `"ACCOUNT"`.

  - `"ACCOUNT"`: the connection belongs to the account in `X-account-code`.
  - `"ORGANIZATION"`: one wallet connection for the whole organization, used by every account, including accounts created later. Supported only for Apple Pay with your own certificates and for Google Pay (Yuno or partner gateway mode). See [Apple Pay and Google Pay for all accounts](/docs/wallets/apple-pay-and-google-pay-for-all-accounts).
</ParamField>

<ParamField body="organization_connection_confirmation" type="boolean">
  Required as `true` when `scope` is `"ORGANIZATION"`. Confirms that you understand the connection reaches every account in the organization, including accounts created later. Not used on account connections.
</ParamField>

<ParamField body="checkout_activation" type="enum">
  Required when `scope` is `"ORGANIZATION"`. Not used on account connections.

  - `"AVAILABLE"`: the wallet is available to every account, and each account turns it on in its own checkout.
  - `"ENABLED"`: the wallet is switched on in every account's checkout at once.
</ParamField>

<ParamField body="merchant_connection_id" type="string" required>
  Your label for this connection. Must be unique within the account. Free-form (e.g., `"adyen-us-prod-001"`, `"stripe-eu-test"`).
</ParamField>

<ParamField body="provider_id" type="string" required>
  Yuno provider identifier (e.g., `"STRIPE"`, `"ADYEN"`). Must exist in the catalog.
</ParamField>

<ParamField body="flow_type" type="enum">
  Optional. Defaults to `"PAYIN"`, the only supported value.
</ParamField>

<ParamField body="payment_methods" type="string[]">
  Optional. Subset of the provider's `payment_method_type[]` (from the catalog).

  Omit this field to enable every payment method the provider supports. Payment methods the provider adds later are added to the connection too.

  If you send it, include at least one payment method. An empty array (`[]`) is rejected with `400 VALIDATION_ERROR`: either omit the field or send it with values.
</ParamField>

<ParamField body="params" type="object[]" required>
  One `{param_id, value}` pair per parameter you're supplying. **Flat array** — even nested catalog params are submitted at the top level; Yuno resolves the hierarchy from the catalog tree. 
  
  Required params (where the catalog has `optional: false`) must be present and non-empty. Activating a `boolean` parent (`"value": true`) makes its `optional: false` children required.
  
  <Expandable title="item">
    <ParamField body="param_id" type="string" required>
      The exact `param_id` from the catalog. Casing matters.
    </ParamField>
    <ParamField body="value" type="string | boolean | number | array" required>
      Match the `field_type` from the catalog. Numerics are submitted as JSON numbers (or strings if the catalog says `field_type: "string"`). For `field_type: "array"`, submit a JSON array.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="costs" type="object[]">
  Optional. Per-connection cost configuration. Omit it for a connection without costs. `currency` must be one supported by the provider.
  <Expandable title="item">
    <ParamField body="sort_number" type="integer">
      Order of priority for the cost entry.
    </ParamField>
    <ParamField body="cost_name" type="string">
      Label for the cost entry.
    </ParamField>
    <ParamField body="currency" type="string">
      ISO 4217 currency code.
    </ParamField>
    <ParamField body="cost_values" type="object">
        <Expandable title="successful | unsuccessful">
            <ParamField body="fixed_fee" type="number">
                Fixed fee amount.
            </ParamField>
            <ParamField body="percentage" type="number">
                Percentage fee.
            </ParamField>
        </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

### Response

<ResponseField name="connection_id" type="string">
  Unique identifier for the connection. **Save this value** to reference it from routing rules.
</ResponseField>
<ResponseField name="scope" type="string">
  `ACCOUNT` or `ORGANIZATION`.
</ResponseField>
<ResponseField name="checkout_activation" type="string">
  `AVAILABLE` or `ENABLED`. Present only on organization connections.
</ResponseField>
<ResponseField name="merchant_connection_id" type="string">
  Your internal label for this connection.
</ResponseField>
<ResponseField name="provider_id" type="string">
  The provider this connection belongs to (e.g., `ADYEN`).
</ResponseField>
<ResponseField name="status" type="string">
  Current status (always `ACTIVE` on create).
</ResponseField>
<ResponseField name="flow_type" type="string">
  Always `PAYIN`.
</ResponseField>
<ResponseField name="payment_methods" type="string[]">
  List of supported payment methods.
</ResponseField>
<ResponseField name="params" type="object[]">
  Echoed parameters. Sensitive values are masked as `***`.
</ResponseField>
<ResponseField name="costs" type="object[]">
  Cost configuration for the connection.
</ResponseField>
<ResponseField name="created_at" type="string">
  ISO 8601 timestamp.
</ResponseField>
<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp.
</ResponseField>

<Note>
Yuno validates `param_id` values, required params and `costs[].currency` against the provider's catalog. It does not call the provider to check the credentials, so a wrong key is accepted with `201`.
</Note>

<Note>
**Secret handling:** any param marked `secret: true` in the catalog is returned as `"value": "***"`. Your submitted secret is stored encrypted and never echoed back.
</Note>

### Errors

<div className="code-nowrap-table dense-table">

| HTTP | `code` |
| --- | --- |
| `400` | `PROVIDER_NOT_FOUND`<br />Unknown `provider_id`. |
| `400` | `MISSING_REQUIRED_PARAM`<br />A required param is missing. `details.param_id` names which one. |
| `400` | `UNSUPPORTED_PAYMENT_METHOD`<br />`payment_methods` contains a method the provider doesn't support. |
| `400` | `NO_SUPPORTED_PAYMENT_METHODS`<br />`payment_methods` was omitted and the provider has no payment method available for the connection's integration type. |
| `400` | `VALIDATION_ERROR`<br />The body failed validation, for example `payment_methods` sent as an empty array. `details` names the field. |
| `400` | `UNSUPPORTED_CURRENCY`<br />A `costs[].currency` isn't in the provider's supported list. |
| `400` | `ORGANIZATION_SCOPE_NOT_SUPPORTED`<br />Organization connections are not available for this organization or request. |
| `400` | `ORGANIZATION_CONNECTION_CONFIRMATION_REQUIRED`<br />`scope` is `ORGANIZATION` and `organization_connection_confirmation` is missing or not `true`. |
| `400` | `ORGANIZATION_SCOPE_NOT_SUPPORTED_FOR_PROVIDER`<br />`scope` is `ORGANIZATION` and the provider or payment method is not Apple Pay or Google Pay. |
| `400` | `ORGANIZATION_APPLE_PAY_REQUIRES_OWN_CERTIFICATES`<br />An organization Apple Pay connection must use your own certificates. |
| `400` | `ORGANIZATION_CHECKOUT_ACTIVATION_REQUIRED`<br />`scope` is `ORGANIZATION` and `checkout_activation` is missing. |
| `401` | `NOT_AUTHENTICATED`<br />Missing or invalid API key. |
| `409` | `CONNECTION_MERCHANT_ID_CONFLICT`<br />`merchant_connection_id` already exists in this account. |
| `503` | `ORGANIZATION_ACCOUNTS_UNAVAILABLE`<br />The organization's accounts could not be listed while creating an organization connection. Nothing changes; retry the request. |

</div>
