---
title: "Reactivate Account"
openapi: "/openapi/organizations/reactivate-account.json POST /organizations/accounts/{account_id}/reactivate"
description: "Reactivates a suspended merchant account of your organization"
---

Reactivates one account that was suspended with [Suspend Account](/reference/organizations/suspend-account). No request body is needed.

Once reactivated, the account appears again in [List Accounts](/reference/organizations/list-accounts) and [List Accounts of Group](/reference/organizations/list-accounts-of-group). Only the account you name changes. Reactivating an account that is already active returns it unchanged, so a retry is safe.

To reactivate several accounts in one call, use [Reactivate Accounts in Bulk](/reference/organizations/bulk-reactivate-accounts).

### Path Parameters

<ParamField path="account_id" type="string" required>
  Account UUID. It must belong to your organization.
</ParamField>

### Response

The account, with `status` set to `ACTIVE`.

<ResponseField name="id" type="string">
  Account id.
</ResponseField>
<ResponseField name="name" type="string">
  Account name.
</ResponseField>
<ResponseField name="account_group_id" type="string | null">
  Account group the account belongs to, or `null` when it belongs to none.
</ResponseField>
<ResponseField name="status" type="string">
  `ACTIVE` or `SUSPENDED`. Read-only: it changes only through the suspend and reactivate endpoints.
</ResponseField>
<ResponseField name="created_at" type="string">
  Creation time, ISO 8601.
</ResponseField>
<ResponseField name="updated_at" type="string">
  Last update time, ISO 8601.
</ResponseField>

<CodeGroup>
```bash cURL
curl -X POST 'https://api-sandbox.y.uno/v1/organizations/accounts/6f1c2b9e-3a4d-4e5f-8a7b-9c0d1e2f3a4b/reactivate' \
  -H 'public-api-key: <YOUR_PUBLIC_KEY>' \
  -H 'private-secret-key: <YOUR_SECRET_KEY>'
```

<div className="code-nowrap-table dense-table">
