---
title: "Reactivate Accounts in Bulk"
openapi: "/openapi/organizations/bulk-reactivate-accounts.json POST /organizations/accounts/bulk-reactivate"
description: "Reactivates up to 100 merchant accounts of your organization in one all-or-nothing call"
---

Reactivates up to 100 accounts of your organization in one call. Each account behaves exactly as with [Reactivate Account](/reference/organizations/reactivate-account), applied to every id in the list.

<Warning>
The call is all-or-nothing: if any id is invalid or does not belong to your organization, the request is rejected and **no** account is changed. Fix the list and send it again.
</Warning>

Accounts that are already active are returned unchanged, so a retry of the whole list is safe.

### Body

<ParamField body="account_ids" type="string[]" required>
  Between 1 and 100 account UUIDs of your organization.
</ParamField>

### Response

<ResponseField name="data" type="object[]">
  The reactivated accounts, each with `status` set to `ACTIVE`.
  <Expandable title="account">
    <ResponseField name="id" type="string">
      Account id.
    </ResponseField>
    <ResponseField name="name" type="string">
      Account name.
    </ResponseField>
    <ResponseField name="account_group_id" type="string | null">
      Account group the account belongs to, or `null` when it belongs to none.
    </ResponseField>
    <ResponseField name="status" type="string">
      `ACTIVE` or `SUSPENDED`. Read-only: it changes only through the suspend and reactivate endpoints.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Creation time, ISO 8601.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      Last update time, ISO 8601.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>
```bash cURL
curl -X POST 'https://api-sandbox.y.uno/v1/organizations/accounts/bulk-reactivate' \
  -H 'public-api-key: <YOUR_PUBLIC_KEY>' \
  -H 'private-secret-key: <YOUR_SECRET_KEY>' \
  -H 'Content-Type: application/json' \
  -d '{ "account_ids": ["6f1c2b9e-3a4d-4e5f-8a7b-9c0d1e2f3a4b", "0a9b8c7d-6e5f-4a3b-9c2d-1e0f9a8b7c6d"] }'
```

### Errors

Every error below rejects the whole request: no account is changed.

<div className="code-nowrap-table dense-table">

| HTTP | `code` | When |
|---|---|---|
| `400` | — | `account_ids` is empty, has more than 100 ids, or contains an id that is not a valid UUID. |
| `401` | — | Missing or invalid API keys. |
| `404` | `ACCOUNT_NOT_FOUND` | An id does not exist in your organization. |

</div>
