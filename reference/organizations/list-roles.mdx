---
title: "List Roles"
openapi: "/openapi/organizations/list-roles.json GET /organizations/roles"
description: "Lists Yuno default roles and organization custom roles"
---

List Yuno default and organization custom roles.

Each role's `role_type` indicates its scope: `account` roles apply only where individually assigned, while `organization` roles apply across every account in the organization, including accounts created later. See [Create Role](/reference/organizations/create-role).
