---
title: "Retrieve Unreferenced Refund by ID"
description: "Retrieve the details of an existing unreferenced refund by the id provided in the request path."
api: "GET /v1/unreferenced-refunds/{unreferenced_refund_id}"
---

This request enables you to retrieve details of an unreferenced refund based on its `id`, which needs to be provided in the request path.

<Info>
**Provider data in the response**

The response always includes a `provider_data` object with the result from the provider that processed the refund. Webhook payloads carry the same object without `raw_request`, `raw_request_details`, and `raw_response_details`.

| Field | Content |
| --- | --- |
| `id` | Provider that processed the refund, for example `STRIPE`. |
| `type` | Provider type, for example `PSP`. |
| `connection_id` | Connection that processed the refund (UUID). |
| `transaction_id` | The provider's identifier for the refund. |
| `category` | Category of the provider's result, for example `APPROVED`. |
| `response_code` | Response code returned by the provider. |
| `response_message` | Response message returned by the provider. |

The following fields carry the untouched provider exchange. Their shape is defined by the provider, not by Yuno, so it varies per provider and per operation. Each is controlled separately:

| Field | Content | How to obtain it |
| --- | --- | --- |
| `raw_request` | The exact payload Yuno sent to the provider. | Requires your account to be enabled for provider raw data. Contact your Yuno account manager to request access. Returned only when Yuno called the provider. Not affected by `include_raw_responses`. |
| `raw_request_details` | Details of the request Yuno sent to the provider, such as the HTTP method, URL, and headers, with credentials redacted. | Same as `raw_request`. |
| `raw_response` | The full payload the provider returned. | Pass `include_raw_responses=true` on this request. |
| `raw_response_details` | Details of the provider's response, such as the HTTP status code. | Same as `raw_request`. |

`response_code` and `response_message` are summaries of the provider's answer and are always returned, independently of the raw fields above.
</Info>

<ParamField header="public-api-key" type="string" required>
The unique public API key for your account.
</ParamField>

<ParamField header="private-secret-key" type="string" required>
The unique private secret key for your account.
</ParamField>

<ParamField path="unreferenced_refund_id" type="string" required>
Yuno-generated unique identifier of the unreferenced refund.
</ParamField>

<ParamField query="include_raw_responses" type="boolean" default="false">
When `true`, the `provider_data` object in the response payload will include `raw_response`, the full payload the provider returned. The `response_code` and `response_message` summary fields are always returned, regardless of this parameter.
</ParamField>

<ParamField query="include_transaction_responses" type="boolean" default="false">
When `true`, returns the full list of attempts and intermediate network responses if the refund triggered multiple internal retries.
</ParamField>

<RequestExample>
```bash Example request
curl --request GET \
  --url 'https://api.y.uno/v1/unreferenced-refunds/d290f1ee-6c54-4b01-90e6-d701748f0851?include_raw_responses=true' \
  --header 'public-api-key: YOUR_PUBLIC_API_KEY' \
  --header 'private-secret-key: YOUR_PRIVATE_SECRET_KEY' \
  --header 'Accept: application/json'
```
</RequestExample>
