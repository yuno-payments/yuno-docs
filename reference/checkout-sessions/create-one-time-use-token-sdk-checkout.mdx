Creates a one-time volatile token for secure payment processing within a checkout session.

## Card brand not accepted

When the checkout only accepts some card brands ([Card brands](/docs/using-yuno/dashboard-overview/checkout-builder-new-payment-method-settings#card-brands) in the Checkout Builder) and the card is of another brand for the session's country and currency, the request returns `400` with code `CARD_BRAND_NOT_ACCEPTED` and no token is created. The message names the card's brand and the brands accepted for the session, or `none` when no brand is accepted for its country and currency:

```json
{
  "code": "CARD_BRAND_NOT_ACCEPTED",
  "messages": ["Brand MASTERCARD is not accepted for this checkout session. Accepted: VISA"]
}
```

A co-badged card passes when any of its networks is accepted. Ask the shopper for a card of an accepted brand.
