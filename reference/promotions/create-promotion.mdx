---
title: "Create Promotion"
openapi: "/openapi/promotions/create-promotion.json POST /promotions"
description: "Creates a promotion: a discount, a date window, and the conditions a payment must meet."
noindex: true
---

<Warning>
**Promotions is enabled per organization**

This endpoint works only after Yuno enables Promotions for your organization. Ask your Technical Account Manager or Key Account Manager. See [Promotions](/docs/payment-features/promotions#enable-promotions-for-your-organization).
</Warning>

<Note>
**Promotions can't be edited**

There's no update endpoint. To change a discount, a date or a condition, [disable the promotion](/reference/promotions/disable-promotion) and create a new one. Payments already charged keep the promotion they were charged with.
</Note>

Creating a promotion doesn't discount any payment by itself. A payment gets the discount only when it carries a `quote_id` from [Create Promotion Quote](/reference/promotions/create-promotion-quote) or from the Yuno checkout (on `additional_data.order.discounts`).

Each promotion belongs to **one** `account_id`. If you run the same campaign on several accounts, create it once per account.

When two or more promotions match the same payment, the one with the **biggest saving** applies, then the oldest, then the smallest `id`. One promotion per payment.

Set `redemption.mode` to `CODE` to require a promotion code, with `redemption.code` (3 to 32 characters). A code is unique per account among the promotions that can still apply; creating a second active promotion with a code already in use returns `409 CODE_ALREADY_EXISTS`. The code becomes reusable once the earlier promotion is disabled or its schedule ends.

Refer to the [HTTP Response Codes](/reference/getting-started/response-codes) section for details on possible error outcomes.
