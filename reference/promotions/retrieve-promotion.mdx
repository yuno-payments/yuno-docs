---
title: "Retrieve Promotion"
openapi: "/openapi/promotions/retrieve-promotion.json GET /promotions/{promotion_id}"
description: "Returns one promotion of an account, with its status and, for a code promotion with a cap, the uses counted so far."
noindex: true
---

<Warning>
**Promotions is enabled per organization**

This endpoint works only after Yuno enables Promotions for your organization. Until then it answers `404 PROMOTION_NOT_FOUND`. Ask your Technical Account Manager or Key Account Manager. See [Promotions](/docs/payment-features/promotions#enable-promotions-for-your-organization).
</Warning>

The promotion must belong to the account in the `X-Account-Code` header. A promotion of another account, and an id that no promotion holds, answer `404 PROMOTION_NOT_FOUND`. An id that is not a UUID v4 answers `400 INVALID_PARAMETERS`.

`status` is computed when you read the promotion: `SCHEDULED` before `starts_at`, `ACTIVE` inside the window, `EXPIRED` after `ends_at`, and `DISABLED` once you disable it. For a code promotion with a cap, `limits.used` is the number of uses counted so far. A promotion with no cap shows `limits: null`.
