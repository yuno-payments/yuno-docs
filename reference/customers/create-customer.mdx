---
title: "Create Customer"
openapi: "/openapi/customers/create-customer.json POST /customers"
description: "Creates a customer resource with personal, billing, and shipping details for checkout initialization"
---

This request creates a customer resource. You need to provide several parameters of the customer in the request body, including the unique identifier of the customer in the external merchant, personal information, as well as billing and shipping addresses.

Creating a customer generates a customer `id` that can be used to initialize the checkout.

<Note>
**`merchant_customer_id` is scoped to the organization, not the account**

If your organization has several accounts, `merchant_customer_id` still has to be unique across all of them. Creating a customer from one account with an id already used by another account in the same organization returns `CUSTOMER_ID_DUPLICATED`. See [Accounts](/docs/using-yuno/organization/accounts#customers-and-payment-methods-are-organization-scoped) for how to structure ids if you run several companies under one organization.
</Note>

<Warning>
**Important**

There are certain objects that are not mandatory when creating a "Customer." However, the more information you provide, the more it can help approval, conversion, and fraud prevention rates.
</Warning>
