---
title: "Update Customer"
openapi: "/openapi/customers/update-customer.json PATCH /customers/{id}"
description: "Updates fields on an existing customer, modifying only the values included in the request"
---

You can update a customer created earlier with the `POST/customers` API request. The only required field for the request is the customer `id`. Other supported request fields are equal to the ones on the customer creation process.

You need to specify only the fields you want to update. Every field is available for update.

## Clearing an address

Send `null` to remove a stored address:

- `"billing_address": null` or `"shipping_address": null` removes the whole address. Retrieving the customer then returns the address as `null`.
- A field set to `null` inside the address, for example `"billing_address": {"address_line_2": null}`, removes only that field and keeps the others. If it was the last field with a value, the whole address is removed.
- A key you leave out keeps its stored value, as before.

Clearing also removes the address saved with the customer's enrolled payment methods, so later payments made with only the customer `id` don't send it to the provider. Setting a new address only updates the customer.

After you clear a single field, retrieving the customer may return `address_line_1`, `city` or `country` as an empty string (`""`) instead of `null`. Both mean the field has no value.

If the request fails with a `5xx` error, the customer may already be updated while some of its payment methods are not. Send the same request again; repeating a clear is safe.

<Note>
Clearing is enabled per organization on request. For other organizations, `null` address values are ignored and the stored address is kept.
</Note>

```json Example: remove the billing address and the shipping address's second line
{
  "billing_address": null,
  "shipping_address": {
    "address_line_2": null
  }
}
```
