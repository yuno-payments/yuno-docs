---
title: "Cancel or Refund with Transaction (two cards)"
openapi: "/openapi/payments/cancel-or-refund-payment-with-transaction-v2.json POST /payments/{payment_id}/transactions/{transaction_id}/cancel-or-refund"
description: "Cancels one card of a two-card payment if it is only authorized, or refunds it if it was charged."
---

This request acts on one card of a payment created with [Create Payment (two cards)](/reference/payments/create-payment-v2), using the `id` of that card's transaction from `payment_method.payment_methods[].transactions`:

* **Cancels** the card if it is only authorized.
* **Refunds** the card if it was charged. The refund is capped at that card's amount minus what was already refunded on it.

The response is `201` with the payment in the v2 shape.

<Warning>
While a card has an open chargeback, refunds are rejected with `INVALID_STATUS`.
</Warning>

This request requires an `X-Idempotency-Key`. See [Authentication](/reference/getting-started/authentication#idempotency) for details.
