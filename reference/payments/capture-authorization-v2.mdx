---
title: "Capture Authorization (two cards)"
openapi: "/openapi/payments/capture-authorization-v2.json POST /payments/{payment_id}/transactions/{transaction_id}/capture"
description: "Captures the authorization of one card of a two-card payment, using that card's transaction id."
---

This request captures one card of a payment created with `capture: false` in [Create Payment (two cards)](/reference/payments/create-payment-v2). Capture is per card: call it once for each card, with the `id` of that card's `AUTHORIZE` transaction from `payment_method.payment_methods[].transactions`.

After the first capture, the payment is `SUCCEEDED / PARTIALLY_CAPTURED`. After both, it is `SUCCEEDED / CAPTURED`. The response is `201` with the payment in the v2 shape.

<Warning>
While the payment is in `REFUND_RETRY_IN_PROCESS` or `CANCEL_RETRY_IN_PROCESS`, a capture is rejected. See [Pay with two cards](/docs/payment-features/pay-with-two-cards#operations).
</Warning>

This request requires an `X-Idempotency-Key`. See [Authentication](/reference/getting-started/authentication#idempotency) for details.
