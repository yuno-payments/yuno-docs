---
title: "Get Conversion Rate"
openapi: "/openapi/conversion-rate/get-conversion-rate.json POST /currency-conversion"
description: "Retrieves the currency conversion rate for a given transaction using an external provider"
---

This page will help you get started with Currency conversions.

For more information on how to use the currency conversion service, please refer to the [Currency conversion page](/reference/currency-conversion)  in the guides section.

The `provider_data.id` value must be a provider that is connected to the account and present in the account's PAYMENT routing. If it is not, the request fails with `PROVIDER_NOT_CONFIG`.
