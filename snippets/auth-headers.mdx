All server-side API requests require these headers:

| Header | Description | Where to find it |
|--------|-------------|------------------|
| `public-api-key` | Your public API key | [Dashboard](https://dashboard.y.uno) > Developers > Credentials |
| `private-secret-key` | Your private secret key | [Dashboard](https://dashboard.y.uno) > Developers > Credentials |

<Warning>
Never expose `private-secret-key` in client-side code. Use it only on your server.
</Warning>

```bash
curl https://api-sandbox.y.uno/v1/payments \
  -H "public-api-key: $YUNO_PUBLIC_API_KEY" \
  -H "private-secret-key: $YUNO_PRIVATE_SECRET_KEY"
```
