Yuno operates in three environments. Use sandbox for testing. Each production region has its own API and dashboard.

| Environment | API base URL | Dashboard |
|------------|--------------|-----------|
| **Sandbox** | <CopyChip value="https://api-sandbox.y.uno" /> | [dashboard.y.uno](https://dashboard.y.uno) (Test Mode) |
| **Production (US)** | <CopyChip value="https://api.y.uno" /> | [dashboard.y.uno](https://dashboard.y.uno) (Live Mode) |
| **Production (EMEA)** | <CopyChip value="https://api.eu.y.uno" /> | [dashboard.eu.y.uno](https://dashboard.eu.y.uno) |

<Note>
Sandbox and production use different API keys. Switch between Test Mode and Live Mode in the dashboard to see the correct keys for each environment. See [Developers credentials](/docs/using-yuno/settings/developers-credentials).
</Note>
