## Accept payments in many countries with one integration

Connect your providers once. Yuno routes each payment and tells you the result. Start in sandbox. No real money moves.

Try: [Troubleshooting](/docs/troubleshooting) · [Test cards](/docs/direct-integration-use-cases/yuno-testing-gateway) · [Verify a webhook](/docs/webhooks/verify-webhook-signatures-hmac)
</Tip>

## Build with AI

Give your coding agent the Yuno docs. Connect the read-only docs MCP server. It needs no API keys. Or point your agent at llms.txt or the OpenAPI spec.

<CardGroup cols={2}>
  <Card title="Connect the docs MCP" icon="plug" href="/setup-mcp">
    Add the Yuno docs MCP server to your coding agent
  </Card>
  <Card title="llms.txt" icon="file-lines" href="https://docs.y.uno/llms.txt">
    Lightweight index for LLMs
  </Card>
</CardGroup>

```json MCP config
{
  "mcpServers": {
    "yuno-docs": { "url": "https://docs.y.uno/mcp" }
  }
}
```
